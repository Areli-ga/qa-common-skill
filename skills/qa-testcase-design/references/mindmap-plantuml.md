# 飞书思维导图输出（PlantUML mindmap）

`testcases.md` → `scripts/md_to_mindmap.py` → `mindmap.puml` → 随飞书文档以代码块发布 → 用户复制粘进飞书画板 PlantUML，渲染成思维导图。零依赖、零 API。

同一次运行还会在 `.puml` 旁边写出 `mindmap.xmind`：由生成好的 PlantUML 节点逐行转成 XMind 8 格式（zip 内含 `content.xml` / `META-INF/manifest.xml` / `styles.xml` / `meta.xml`，与团队 opentest 导出格式一致），结构与 `.puml` 一一对应，用 XMind 桌面版直接打开；只存本地，不进飞书。

> **跑脚本，别手抄**：`python3 scripts/md_to_mindmap.py <交付目录>/testcases.md <交付目录>/mindmap.puml`（默认 full；只要主结构加 `--compact`）。AI 逐行手抄会重复/断行/报错。本文件只说明脚本背后的规则，不是手抄模板。
> 导图**默认必产**：飞书发布会裁掉两块用例正文、改由导图承载，没有 `mindmap.puml` 发布脚本会拒绝发布。

## 结构从哪来（唯一来源：testcases.md 分解树）

导图层级**完全来自** `testcases.md` 的标题树，脚本不推断、不编造中间层：

| 导图层级 | 来源 |
|---|---|
| 根 `*` | `testcases.md` 首行 `# 需求名` |
| 一级 `**` | 第 3 块各 `###` 端（`Admin`、`App` 等；只涉及一个端时为页面/模块）→ 第 4 块六个 APP 常驻维度（`边界/兼容`、`跨端联动`、`后端/配置`、`AB`、`埋点`、`多语言兼容`） |
| 更深层级 | 第 3/4 块 `####/#####/######/…` 分解树标题，不限层数，树多深图多深 |
| 用例操作节点 | 用例行「｜」前的操作或条件（隐藏 `[P0-01]` ID、不带优先级，保留「（待确认）」）；同一位置操作文字相同的用例合并为一个节点 |
| 结果叶子（full） | 「期望：」后的结果，一条用例一个叶子；`--compact` 不输出 |

- 常驻维度无用例时保留一级节点并挂 `无`。
- 同一条用例只出现一次；它兼顾的其他维度靠覆盖自检表追踪，不在图里复制节点。
- 导图粒度不够 = 分解树不够深：回 `testcases.md` 按 authoring-core §C「先树后例」拆树，不要改导图。

**不进导图**：需求理解、风险判断、风险与待确认、覆盖自检表、`history-hits.md`；P0/P1/P2 不做一级菜单。

**校验拦截**（`validate_output.py`）：出现「功能点」「其他业务场景」占位节点、附录文字（风险与待确认 / history-hits / 历史回归 / 覆盖自检 / qa-knowledge-base）、内部 ID、层级跳变（一次 +2 以上）→ FAIL。出现「其他业务场景」说明有用例既不在分解树里、也没进覆盖自检表——回去补自检表或把用例挂到树上。

## 进阶：手写 PlantUML 块（极少用）

确需表达树外结构（如 `example-mindmap-rich.puml` 的「测试数据组」7 层）时，可在 `testcases.md` 写一段 ` ```plantuml ` 的 `@startmindmap` 块，脚本检测到会**原样提取**、不再自动生成；层级合法性自负，仍需过校验。日常不要用——优先把结构写进分解树。

## 语法与清洗规则（脚本已实现，供排查）

- `*` 个数 = 层级；首尾 `@startmindmap` / `@endmindmap`；一行一节点 `<N个*><空格><文字>`；层级每次最多 +1。
- 单行化：`\r`、`\n`、`<br>` 统一替成空格，合并连续空格、去首尾空白。
- 业务文本中的 `@startmindmap` / `@endmindmap` 去掉 `@`，防止提前结束。
- 中文、`(待确认)`、`→`、`/`、`_`、`，`、`'` 原样输出，飞书全支持。
- 用 PlantUML，**不要用 Mermaid**——Mermaid 把方括号/圆括号当节点形状语法，用例全是括号会全崩。

## 粘贴铁律（实测踩坑）

长行在聊天框会软换行，从对话复制会把一个节点断成两行 → 飞书解析报错。所以：

1. 首选：打开已发布的飞书文档 → 复制「用例设计思维导图（PlantUML）」代码块；
2. 备选：本地 `mindmap.puml` 全选复制；
3. **先清空飞书 PlantUML 编辑框 → 只粘一次**（残留叠加也会报错）；**绝不从对话里复制**。

## 最小语法片段

    @startmindmap
    * 需求名
    ** App
    *** 跟读挑战课
    **** 战斗页
    ***** 前置：配置目标词数 N=5
    ****** 进入课程
    ******* 对手血量为 4
    ******* 用户血量为 3
    @endmindmap
