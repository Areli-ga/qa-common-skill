# Unity 代码风险库（按需读取）

用途：当 PRD 涉及 Unity 玩法、课程资源、热更、动画、视频、音频、低端机、Unity 与原生通信时，用本文件补充 Unity 侧测试点。它是测试启发，不替代 PRD。

读取后只编入命中本需求的风险点；不涉及 Unity 时标 N/A，不要硬塞。

## 常见高风险面

| 风险面 | 触发条件 | 用例补充方向 |
|---|---|---|
| Unity 生命周期 | 进入/退出 Unity 课件、切后台、锁屏、来电、杀进程 | 状态恢复、音频暂停恢复、重复初始化、退出后资源释放 |
| 原生通信 | Unity 与 Android/iOS 互传参数、结果、跳转 | 参数缺失/null/旧字段；结果回传一次性；切端后回调是否丢失 |
| 热更与资源 | Addressables/AssetBundle/远端资源、版本切换 | 首次下载、断点/失败重试、资源缺失兜底、旧资源缓存、热更后重进 |
| 动画状态机 | 角色动画、入场/离场、成功/失败反馈、状态切换 | 快速切换、打断恢复、状态不串线、动画结束回调驱动下一步 |
| 音频/视频播放 | BGM、音效、跟读音频、视频背景 | 首播、重播、静音、音量、弱网加载、切后台恢复、多音频抢占 |
| 语音识别联动 | 跟读、收音、评分、跳过、Unity UI 反馈 | 权限拒绝、提前发声、超时、低分/高分、结果到动画/文案/埋点一致 |
| 性能与低端机 | 复杂特效、长资源、低端设备、内存敏感 | 卡顿、掉帧、内存上涨、长时间连续玩、返回首页后再次进入 |

## 本产品已知规律（截至 2026-07 代码扫描；稳定的设计取舍，命中即补）

- **失败默认「静默降级」、基本不弹窗**：热更代码/资源失败会偷偷回退旧资源或卡加载页，不报错给孩子。测降级后内容/语音是否缩水、是不是卡加载页不动。
- AOT 泛型元数据缺失时启动不报错，要跑到用该泛型的具体玩法/功能才崩——崩溃点离启动很远，专门覆盖各类玩法模板的深层功能。
- 清单/资源超时窗口短（约 5 秒清单、120 秒加载）：弱网抖动就可能误降级到离线旧资源，导致新课「时有时无」。
- 语音包只等约 5 秒，超时就带着「没下好」进课：无语音对低龄儿童等于没法上课，测弱网下是静音/后补/还是卡住。
- 连续开课资源句柄不完全释放、常驻包不清：内存线性上涨，低端机连玩多课易 OOM——测连续快速进出十几节课的内存趋势。
- **内存 3GB 是硬分界**：以下机型关图片内存缓存、加载更小尺寸图。要用 2GB 和 4GB 机器对比测图糊/加载慢/翻页。
- 视频在华为机型走 Unity VideoPlayer、其他安卓走 ExoPlayer：**华为视频要单独测**（播放内核不同，行为可能不一致）。
- 跟读「播完进下一步」靠定时器不是真音频结束事件：音频加载慢/时长异常时定时器可能立即触发或永不触发，测弱网下推进时机错乱。
- 埋点本地队列 + 落盘 + 失败回滚重发：离线完课后恢复网络要能补发且顺序对；未登录状态埋点被丢弃；只有白名单事件名才上报（拼错/大小写不符静默丢），新增埋点要确认在白名单内。
- 完课本地快照提前写「已完成」、后端上报可能失败且无重试队列：会出现「本地显示已完成、后端没记上」，测完课瞬间断网/杀进程后重进的一致性。
- 视频是远程下载 + 本地缓存约 14 天：测断网能否播已缓存的、缓存过期重下、缓存里 0 字节坏文件会不会自动重下。
- 一局状态机（开始→进行→结算→退出）：快速「进-退-重进」同课测上一局动画/计时器/数据残留；结算前疯狂连点测重复结算。

## 设计用例时的抓手

- Unity 需求优先拆状态机：加载中、可操作、播放中、收音中、反馈中、结算中、退出中。
- 任何“跳过/重试/返回/切后台”都要验证回到哪个状态，而不是只写“功能正常”。
- 涉及资源时至少覆盖：资源存在、资源缺失、资源下载失败、热更后旧缓存。
- 涉及原生通信时同时验证两端：入参正确、Unity 行为正确、回传结果正确、原生落库/跳转正确。
