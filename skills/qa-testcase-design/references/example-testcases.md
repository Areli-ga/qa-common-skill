## 1. 需求理解

- 目标：闪卡跟读题接入新版原生跟读组件，并支持单词音素级红/黑/绿三色打分；已跟读单词在 Unity 单词回顾中复用同一份音素结果。
- 入口：闪卡模块跟读题、学习路径中的跟读题、Unity 单词回顾页面。
- 端范围：Android / iOS 原生组件 + Unity；H5 / Flutter 未涉及。
- 数据：ASR 返回音素分、整词结果、失败/跳过状态；埋点事件为 `lesson_speech_recognition_end`。
- 待确认：wheat 阈值、音素 payload 字段、闪卡入口课程参数空值形式、Unity 回顾数据源、AB 灰度策略。

## 2. 风险判断

本次最该测“闪卡、路径、Unity 回顾三处对同一份跟读结果的状态与数据一致性”。

- PRD 表面是 UI 接入和颜色展示，实际跨原生录音组件、ASR 音素分、Unity 展示和埋点参数。
- 如果只测正确跟读，容易漏掉失败两次跳过、无音素数据、旧组件回归和状态恢复。
- 音素阈值、payload 字段、Unity 数据源和 AB 灰度未写清，会直接影响可判定性。
- 闪卡入口参数为空口径与路径入口参数完整口径不同，埋点和回顾数据都要分入口验证。
