# H5 / WebView 代码风险库（按需读取）

用途：当 PRD 涉及 H5/WebView、bridge、离线包、manifest、缓存、i18n、音频、神策/Sentry、分享/上传时，用本文件补充 H5 与容器专项测试点。它是测试启发，不替代 PRD。

读取后只编入命中本需求的风险点；不涉及 H5/WebView 时标 N/A，不要硬塞。

## 技术边界

- 技术栈：React + TypeScript + Vite，课程 H5 通过原生 WebView 承载。
- 常见入口：课程页、活动页、AI tutor、分享页、WebView 内嵌功能。
- 常见风险来自：URL 参数、bridge 能力、manifest/离线包、缓存、音频播放、i18n、埋点、异常上报。

## 常见高风险面

| 风险面 | 触发条件 | 用例补充方向 |
|---|---|---|
| URL 参数 | PRD 依赖 course/level/unit/lesson/source 等参数 | 参数缺失、非法值、旧参数名、新旧入口兼容、刷新后参数保持 |
| Bridge 能力 | H5 调原生登录、关闭、分享、上传、播放、权限 | bridge 不存在、调用失败、回调超时、重复回调、Android/iOS 差异 |
| 离线包/manifest | 涉及 H5 发布、资源缓存、版本更新 | 首次加载、旧包升级、新包回退、manifest 缺失、资源 404 |
| WebView 生命周期 | 刷新、返回、切后台、锁屏、网络恢复 | 状态保持、音频暂停恢复、请求重试、页面白屏兜底 |
| i18n 与文案 | 多语言、地区、动态文案、长文案 | 语言切换、缺翻译 fallback、超长文案换行、RTL/特殊字符按需待确认 |
| 音频播放 | 跟读、提示音、背景音、自动播放 | 首播权限、静音、切后台暂停、多个音频抢占、弱网加载 |
| 神策埋点 | PRD 有事件/属性或旧需求复用埋点 | 事件时机、必填属性、空值、失败/跳过是否上报、重复上报 |
| Sentry/异常 | 新增复杂页面、接口/资源失败 | JS error、资源加载失败、接口异常提示、错误上下文不含敏感信息 |
| 分享/上传 | 分享海报、图片上传、文件选择 | 权限拒绝、取消、失败重试、图片尺寸/格式、回调落地 |

## 设计用例时的抓手

- H5 入口必须先列“来源入口 + URL 参数 + 容器能力”，否则用例容易只测页面展示。
- 涉及 bridge 时至少覆盖：成功、失败、无 bridge、重复点击、回调超时。
- 涉及 manifest/离线包时至少覆盖：新用户首次打开、老用户旧缓存升级、资源失败兜底。
- 涉及埋点时和用户行为绑在同一条用例里验证，不要单独写“检查埋点正常”。
