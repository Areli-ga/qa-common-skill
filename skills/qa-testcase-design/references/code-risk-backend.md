# 后端代码风险库（按需读取）

用途：当 PRD 涉及接口、奖励、计数、每日/连续、档案隔离、异步生成、多语言兜底时，用本文件补充后端与数据一致性测试点。它是测试启发，不替代 PRD。

读取后只编入命中本需求的风险点；不涉及后端时标 N/A，不要硬塞。

## 常见高风险面

| 风险面 | 触发条件 | 用例补充方向 |
|---|---|---|
| 用户档案隔离 | 涉及 child/profile/userId、家庭多账号、切换孩子 | A 档案行为不污染 B 档案；切档后进度、奖励、配置重新按当前档案读取 |
| 每日/连续计数 | 涉及 streak、daily、连续学习、签到、次数奖励 | 同一天重复触发、跨天、时区、补签、断网重试后的计数去重 |
| 奖励与库存 | 涉及金币、道具、宝箱、能量、徽章 | 发放一次性、幂等、库存不足、重复提交、失败回滚、前端展示与后端余额一致 |
| 学习进度 | 涉及课程完成、关卡完成、回顾、解锁 | 完成态写入、重复完成、跳过/失败是否算进度、下游入口是否即时刷新 |
| 配置与灰度 | 涉及 Admin 配置、AB、开关、国家/语言/版本分流 | 命中/未命中、配置缺失、灰度回退、旧版本兼容、配置缓存刷新 |
| 接口字段兼容 | PRD 出现新增字段、枚举、阈值、payload | 字段缺失/null/空数组/未知枚举；旧客户端忽略新字段；新客户端兼容旧字段 |
| 异步任务 | 涉及生成、识别、批处理、队列、回调 | pending/success/fail/timeout 全状态；轮询停止条件；重复回调幂等 |
| 多语言兜底 | 涉及文案、课程资源、国家语言 | 指定语言、缺翻译、fallback 语言、前后端语言码一致 |

## 本产品已知规律（截至 2026-07 代码扫描；是稳定的设计取舍，命中即补，不必逐行核代码）

- 业务失败普遍是 HTTP 200 + body 里的 code，不是 4xx；断言失败分支要看 body code，不能只看 HTTP 状态。
- 无 refresh token：登录态到固定期限就过期、需重新登录；测长时间挂着的页面 token 过期后的表现。
- 无会员分层：产品没有 VIP/订阅等级，涉及「会员」维度可直接 N/A，别臆测。
- **灰度分组 sticky（永久锁定）**：用户命中某分组后被缓存，之后改百分比/规则对已分组用户无效、只影响新用户。**测灰度前必须清缓存或用全新账号，否则测不准。**
- 埋点/通知/清缓存是「事务提交后才发」：事务回滚时这些副作用都不该发生；且埋点发送失败不回滚主流程——所以「埋点数 ≠ 业务数」是可接受缺口，数据核对别假设两者相等。
- 幂等主力是数据库唯一键：涉及发奖/扣次数/提交/完课的接口，重复提交或断网重试只应落一行；注意去重键（biz_key）拼装粒度是否把该区分的维度都拼进去了。
- 计数/货币走 DB 端原子累加 + 分布式锁：并发双发只成功一次；带上限的累加要测「刚好满」边界。
- 定时任务按用户时区跨天跑：每日重置/连续天数/每日限额/结算/排行榜，要验极端时区（UTC±12）和跨天归属。
- 无 DB 外键：孤儿数据、脏引用 DB 不拦，只能靠用例覆盖；删除是应用层逐层级联，测删父后子表是否清干净。
- 软删除的表：读取/统计/唯一校验都要带「未删除」过滤，测软删数据不出现在 C 端、以及软删后能否重建同一条。
- 读副本延迟：只读接口走从库，「写后立即读」可能读到旧值；测改完马上查列表/详情的一致性。
- 多语言纯 DB 行存储、缺译回退英文；内容异步翻译生成，存在「主记录已建、译文没生成」的窗口，测此时 C 端展示什么。

## 设计用例时的抓手

- 对所有“写入型接口”补充：重复点击、重试、弱网超时后再次提交、服务端返回成功但前端刷新失败。
- 对所有“读配置型接口”补充：配置为空、配置旧版本、配置被灰度关闭、配置与 PRD 冲突时进入「风险与待确认」。
- 对所有“计数/奖励型接口”补充：同一业务事件只产生一次后端效果，客户端重复上报不能重复发奖。
- 对所有“历史回归命中”补充：旧字段/旧状态是否仍被读取；旧入口是否复用同一后端逻辑。
