# 新功能执行文档索引

本目录保存从 XMind、Excel、Markdown、图片或鉴权网址转化出的可复用新功能执行文档。执行文档与 `assets/cases/giggleacademy-feature-exploratory-v0.1.md` 配合使用。

## 命名

```text
<YYYY-MM-DD>-<feature-slug>-v<major>.<minor>.md
```

示例：`2026-07-27-learning-reminder-v0.1.md`

需求、用例或入口变化时新增版本，不覆盖已执行过的版本。

## 提交检查

- 原始用例中的每条必测内容都能通过来源追踪表映射到 `F` 编号。
- 探索性检查使用独立 `E` 编号，未混入正式用例通过率。
- 首条用例场景、QA 环境、账号 / 数据 / 开关和重启恢复入口已写清。
- 不含密码、token、Cookie、完整用户标识、运行截图或设备日志。
- 执行完成后由使用者复核，再提交到 `qa-common-skill`。
