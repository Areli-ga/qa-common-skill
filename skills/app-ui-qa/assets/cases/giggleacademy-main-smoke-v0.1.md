## 范围边界

本版纳入执行范围：思维导图中“主流程冒烟”下，从“启动”到“故事书模块”“闪卡模块”“搜索课程”及其上方全部节点。

本版暂不纳入执行范围：“H5流程”“奖励中心”，以及选择分享目标、发送、发布等真实分享链路。S18 只验证闪卡结算页能否唤起分享组件、分享海报是否正常显示，以及能否安全退出；不得选择联系人/平台或实际发送。安卓渠道包冒烟和新功能探索性测试都不并入核心主流程，已拆分为独立执行文档。

语音识别策略：用例中涉及语音识别的地方默认只验证开关、跳过、流程不中断，不验证真实语音识别准确性；遇到预期可自动跳过的语音 / repeat 环节，等待 5 秒后截图检查下一状态。非语音的自动推进、展示页自动完成、完课返回等环节默认等待 2 秒后截图判断。

证据要求：每个关键点击、滑动、输入、进入页面、完成页面都必须截图进入报告；异常和风险点额外截图标注。

数据策略：Android 允许在冒烟前清除 App 数据，用于覆盖首次安装 / 新用户流程；iOS 不使用清数据方案，需要通过卸载旧 App、TestFlight 重装目标包并保持未启动来获得首次启动状态。S03 登录后的专用冒烟路径与固定账号 `523714113@qq.com` 和 kid `Areli-On` 绑定，不得使用其它账号或 kid 代替。只有最后执行的 S14 升级 Quiz 需要切换到之前的测试账号。

iOS 输入策略：通过 iPhone Mirroring + PyAutoGUI 输入孩子名字、邮箱、账号等内容前，必须先把当前 Mac 输入法切换为英文 / ABC。中文输入法会导致字符转换、重复或其它输入异常。提交前必须重新截图，核对完整可见值；发现异常时不得提交，应切回英文输入法并重置为空字段后重新输入或粘贴。

iOS 新装包策略：iOS 不像 Android 一样可以便捷地清理 App 数据。只要本轮 iOS 冒烟包含 S02，自动化开始前就应明确要求用户手动卸载旧 App，并通过 TestFlight 把目标版本准备为尚未启动的新安装包。若用户在任务开始前尚未准备，先说明卸载、TestFlight 重装和下载可能耗时较久，S01、S03 及其它自动化都不得提前启动；卸载或安装前仍需用户即时确认。

iOS S02 补测顺序：这条规则只适用于已经用合格新安装包启动自动化、但 S02 中途因真正阻断而需要重新验证的情况。此时优先在当前包上完成 S03 及所有仍可到达的后续内容，避免为补 S02 提前卸载而丢失下游覆盖。后续经用户确认卸载 App、通过 TestFlight 重装目标包，再单独补跑 S02，并把补测证据和原运行结果关联记录；不得用该规则绕过任务开始前缺少新安装包的问题。

固定前置路径：当前固定使用 `Lv1 -> unit5-当前全类型` 作为主流程课程前置路径。后续只要找不到当前用例指定的课程，必须完整重新执行 S05 重置路径；不在其它等级或单元中盲目滑动寻找。

执行顺序：必须按本文件中的出现顺序执行，不按模块编号重新排序。S14 保留原编号，但固定在 S19 完成后最后执行。

故事书策略：路径课程 S09 固定使用《正常故事书》。绘本故事模块 S16 需要自动化覆盖阅读、领读和问答三种模式；录音模式因为自动化无法完成真实录音行为，单独标记为“跳过 / 自动化能力限制”。阅读模式可使用任意故事书；领读模式固定搜索 `ipad` 并进入《Max的iPad》；问答模式固定搜索 `quiz` 并进入《Max的魔法助人帽》。

已移除 / 跳过项：领取扭蛋、S07 字母体操 1、S12 路径闪卡课程不纳入本版冒烟；S16 只跳过录音模式，阅读、领读和问答模式必须执行。

## 通用前提：S02 一次性入口与阻断恢复

S02 新手路径入口通常只会在首次安装、重新安装或清数据后的首次启动流程中出现。命中新用户欢迎页后，正常情况下应完整执行 S02，不得为了提前登录而主动重启、退出或绕过新手课程。

这不代表 S02 期间完全禁止重启。遇到真正阻断流程的问题时，应先截图记录当前页面、已尝试的页面内操作、等待时间、预期结果和实际结果，然后把重启作为恢复手段尝试一次。真正阻断包括：

- 当前界面没有可操作或可返回入口，按规定等待后仍不推进。
- 预期按钮已经通过新截图确认存在，经过合理重试仍完全无响应。
- 界面持续黑屏、卡死或所有输入均无反馈。

如果重启后一次性新用户入口消失，不得推断 S02 已完成，也不得把整个冒烟流程直接终止。应在报告中把本轮 S02 标记为未完成 / 阻塞，记录重启前后的证据和影响范围，然后继续执行所有仍可到达的后续模块。只有专门复测 S02 时，才需要重新安装或再次清数据开启新的首次启动验证。

安卓渠道包冒烟是独立范围，不要求完成主流程 S02。执行渠道包用例时，以 `giggleacademy-android-channel-smoke-v0.1.md` 中明确写出的退出或重启跳过步骤为准。

## 通用前提：完课后自动进入下一内容

路径上的任何课程完成后，包括新手课，App 可能自动进入下一课程或下一段内容；截图时当前页面可能已经不是刚完成的课程。

这条规则只适用于“已经确认课程完成后”的自动跳转恢复，不适用于课程进行中。尤其新手课程进行中，不能为了推进流程主动点击左上角返回、退出或主页入口。

如果新手课完成后出现类似 loading / 课程开场的过渡画面，或者进入“颜色飞溅”“颜色配对”“颜色 1”等明显属于新课程的内容，不应把它当作新手课继续执行。此时应立即截图记录自动进入状态，并按恢复策略回到主界面学习路径。

完课后自动进入下一内容属于正常业务逻辑，不应直接判定为用例失败或 App 缺陷。如果当前界面明显不符合当前用例或课程类型，必须先截图记录“自动进入 / 跑偏状态”，不要继续在该界面探索非用例内容。

如果课程完成后进入排行榜 / “学习之星”界面，应先截图记录完课结果，再点击继续 / 下一步按钮回到主界面学习路径；这属于正常完课路径，不应直接判定为阻塞或缺陷。

课程完成后的“继续 / 下一步 / 右箭头”等按钮不得用延迟坐标点击。每次点击前必须重新截图确认按钮仍在预期页面；如果 App 已经自动回到主界面学习路径，则跳过该点击，避免误触主界面课程或其他功能入口。

恢复策略：优先点击左上角返回、退出或暂停入口，必要时确认退出，回到主界面学习路径；如果路径位置不确定或找不到指定课程，完整执行 S05 学习中心 -> Lv1 -> `unit5-当前全类型` 路径重置后，再继续后续 case。非语音自动推进场景等待 2 秒后就应截图判断，避免等待过久导致坐标过期。

## 通用前提：引导弹窗处理

如果出现非当前用例目标的应用内引导弹窗 / coachmark，应先截图记录。由于 App 内多数引导弹窗可通过点击空白处关闭，优先点击不命中高亮区域、卡片、课程入口或 CTA 的安全空白区域；如果无效，再尝试可见的关闭、返回或继续按钮。处理方式需要写入报告。

## 全局检查点

- App 不应崩溃、卡死、黑屏、白屏、花屏或长时间 loading。
- 关键入口、按钮、标题、学习路径、故事书页面应可见且可操作。
- 进入和退出 Unity / Flutter / H5 / 原生混合页面时要检查加载时长和画面异常。
- 任何系统权限、隐私弹窗、通知弹窗、登录失效、网络异常、强制升级都要截图并记录处理方式。
- iOS 首次安装启动时，广告追踪、网络 / 本地网络访问等系统授权弹窗统一选择“允许”；每层弹窗都要在处理前后截图，不得因未授权误判启动或后续流程阻塞。
- iOS 路线包含 S02 时，自动化开始前必须确认用户已手动卸载旧 App，并通过 TestFlight 准备好尚未启动的目标新安装包；若未准备好，先停止自动化并说明重装下载耗时。
- iOS iPhone Mirroring 文本输入前必须确认 Mac 输入法为英文 / ABC，并在提交前截图核对完整可见值；中文输入法造成的字符异常不得提交。
- S03 登录必须使用固定账号 `523714113@qq.com` 和 kid `Areli-On`；密码仅在安全输入阶段使用，报告不得重复明文。该账号不得在 S14 之前被替换。
- UI 自动化所需权限默认全部允许。遇到应用内“确定 / 好的 / 同意 / 继续”等权限说明页时，先截图，再点击确认以触发系统权限弹窗；随后在系统弹窗中选择“允许”。不得把尚未完成授权的页面误判为课程阻塞或用例外内容。
- 完课后如自动进入下一内容，先按通用前提截图并回到主路径，不要追跑用例外内容；课程进行中不得把左上角退出当作推进手段。
- 完课后如进入排行榜 / “学习之星”，点击继续 / 下一步回到主界面后再继续后续用例。
- 课程完成后的继续 / 下一步 / 右箭头点击前必须重新截图确认目标按钮仍可见；如果已经自动回到主页则跳过点击。
- 非当前用例目标的引导弹窗优先尝试点击安全空白区域关闭，并记录截图和处理方式。
- 日志只用于辅助判断，报告中不得暴露密码、token、完整 child_id、IP、音频 URL 等敏感字段。

### S16 故事书模块：播放模式验证

本模块自动化验证阅读、领读和问答三种可执行模式。录音模式需要真实录音行为，当前自动化路线无法可靠完成，只将该项标记为“跳过 / 自动化能力限制”，不得把它记为产品失败，也不得因此跳过其它三种模式。

阅读模式可以选择任意一本故事书。播放菜单中的功能需要逐项验证；如果点击某项后菜单自动收起，下一项操作前重新点击右侧三个点展开菜单。分享只验证组件能否唤起和安全返回，不选择联系人、平台或发送目标。

每种模式播放完成后的结算页都有约 5 秒倒计时并自动进入下一本故事书。由于截图时机可能错过结算页，只要前序内容已经完成且随后能看到下一本故事书正常进入，就可以把“结算与续播”判定为通过，并在报告中说明证据时机。
