## 摘要

V1.30.0 新用户 Onboarding 价值传递:针对"孩子首次使用多由家长陪伴",在新人路径(启动 → 欢迎 → 试玩)中增加**面向家长的产品价值传递** + 体验优化,目标提升次留/七留、降低不信任流失。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 1. 启动 → 欢迎页流程
- 闪屏启动 **2s**(静态图);闪屏后接**轮播图**(同时开始启动技术服务加载)。
- 加载结束 + 弹窗授权 → 进欢迎页。轮播图:**播完第一轮则继续轮播;未播完也正常进入**欢迎页。
- 中英文版本见 figma;**样式升级,无其他改动**。

### 2. 试玩课 —— 增加 Loading 与总结
- 进首页展示地图,Hello 课**选中状态**引导点击。若前置需求改为直接静默打开,则维持前置需求表现。
- Hello 课撒花结束 → 新增**总结页**:
  - **Hello 单词卡**(课程不支持添加,**本期写死**)。
  - 进页面播 max 音频:中「宝贝学会了用 Hello 向世界问好」/ 英「Baby's first "Hello" to the world」(总结页实际文案见图:"这是宝贝第一次开口,勇敢尝试的 Hello 是向世界的初次问好")。
  - **宝贝首节课发音音频**:点击播放用户**原声**(录音最好存本地,避免网络影响);**无发音音频则不展示音频图标**。
  - 关闭 → 回首页,继续首节课星星动效,**自动打开扭蛋**。

### 3. ⚠️【本期先不上】课程模块增加介绍
等 1.29 上线看单元卡点击数据再上。点击 Unit1 卡片看介绍;学完 Hello **自动进刷牙,不自动进卡片介绍**。Lv1 的 8 个 Unit 介绍卡(本期测试);展示 Unit名称(后台配置)/标签(剑桥 Starter 核心内容,写死)/适合学员(0 基础,写死)/阶段目标/核心单词;关闭→回首页并展示推荐刷牙课选中态。

### 边界 / 坑
- iOS 比竞品**多一个弹窗**(神策 id 收集,**必须**);启动时长 iOS≈10s / 安卓≈5s,iOS 到欢迎页数据持续偏低。
- 整体完课率 86%,**主要流失在最前端 loading 页(约 4%)**。

## 不在本期范围 / 背景
- 课程模块介绍卡(本期先不上,见上)。
- 背景数据(可不看,非功能点):试玩率 70%+、完课率 86%、iOS 启动慢与弹窗分析。
