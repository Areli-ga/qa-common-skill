## 摘要
挑战课答题模板**只有线索、没有题干**：孩子进题只听到一段线索音频（一个音素或一个单词），「起始音 / 结尾音」这类考察题和普通「图片配对」**听起来没区别**。本期做两件事：① **题干语音 + 线索语音拼接播放** —— Admin 题目编辑新增 **【语音拼接】开关（默认关）**，开启后 App 按 **「题干语音 → 停顿 → 线索语音 1 →（停顿 → 线索语音 N）」** 播放，**进题自动播、重听按钮重播完整序列**，编辑器预览可试听拼接效果，**【线索】可关联多个单词**；② **挑战课模板新增【配对题】【判断题】【跟读题】**，Admin 支持手动创建。另给出 **24 条按教学技能划分的题干模板**（多语言 key 命名 `quiz_<question_type>_<teaching_skill>`，中 / 英 / 印尼三语，逐条标明是否需要拼接），Quiz 包详情的题目列表与搜索新增**【题目 ID】**，题目 Key 下拉新增 **`other`（固定排最末）**。

### 1. 【语音拼接】开关
| 元素 | 规则 / 逻辑 |
|---|---|
| **开关** | **默认【关闭】**；**【开启】：App 按「题干语音 → 停顿 → 线索语音 1 →（停顿 → 线索语音 N）」播放**；**【关闭】：按【线索】类型决定是否播线索音频，与现状一致** |
| **拼接语音 - 试听** | 播放完整拼接后的语音 |

**线索类型 × 语音拼接 播放结果**：
| 线索类型 | 拼接 **开启** | 拼接 **关闭** |
|---|---|---|
| 无 | **题干语音** | **无任何语音** |
| 文字 | 题干语音 | 无任何语音 |
| 图片 | 题干语音 | 无任何语音 |
| 音频 | **题干语音 → 停顿 → 线索音频** | **线索音频** |
| 文字 + 音频 | 题干语音 → 停顿 → 线索音频 | 线索音频 |
| 图片 + 音频 | 题干语音 → 停顿 → 线索音频 | 线索音频 |
- Admin 原型（图读出）：预览区下方「**试听拼接效果**（本次新增）」，时间轴示例 **`题干语音 2.3s` + 停顿 `0.4s` + `s 0.9s` = 总时长 3.6s**，说明「点播放，听到的就是 App 端孩子听到的完整序列」；**停顿时长原文正文没写，原型示例为 0.4s**。
- 线索配置（图读出）：线索类型 Tab `无 / 文字 / 图片 / 音频 / 文字+音频 / 图片+音频`；**音频线索「可关联多个单词」**，每条线索标「单词卡 / AI 生成」，可「生成语音」「添加音频」；线索类型为「无」时提示「**这道题没有任何线索音频——题干语音是唯一的音频。不开语音拼接，孩子拿到的是一屏静默的卡片**」。
- **考察知识点（本次新增）**：从单词库选择一个单词，**只作记录、不影响 App 端展示**（⚠️ 正文写「从【学习资源】中选择」，原型写「从单词库选择」，叫法不一）。

### 2. 题干模板（按教学技能，节选关键列）
多语言 Key 命名规则：**`quiz_<question_type>_<teaching_skill>`**；每条有英 / 中 / 印尼三语题干。
| 教学技能 | Key | 拼接 | 英文题干 | 线索语音 |
|---|---|---|---|---|
| Letter Recognition | `quiz_single_choice_letter_recognition` | 否 | Find the letter. | 字母音 "mmm" |
| Letter–Sound Awareness | `quiz_single_choice_letter_sound_awareness` | 否 | Tap the letter that makes the sound. | 音素 /m/ |
| Beginning Sounds | `quiz_single_choice_beginning_sounds` | **是** | Tap the picture that starts with the sound. | 音素 /m/ |
| Beginning Sounds | **`quiz_true_false_beginning_sounds`** | **是** | Do they start with the same sound? | **单词 A 音频 + 单词 B 音频** |
| Word–Picture Association | `quiz_single_choice_word_picture_association` | 否 | Tap the picture. | 目标单词音频 |
| Matching & Sorting Skills | **`quiz_sorting_matching_and_sorting_skills`** | 否 | Sort the pictures. | 无 |
| Color Recognition | `quiz_single_choice_color_recognition` | 否 | Tap the color. | 目标单词音频 |
| Rhyming and Word Families | `quiz_single_choice_rhyming_and_word_families` | **是** | What word rhymes with this word? | 目标单词音频 |
| Rhyming and Word Families | **`quiz_true_false_rhyming_and_word_families`** | **是** | Do they rhyme？ | 单词 A + 单词 B 音频 |
| Syllables and Aural Patterns | `quiz_single_choice_syllables_and_aural_patterns` | **是** | How many syllables？ | 目标单词音频 |
| Upper and Lower Case | `quiz_single_choice_lowercase_letters` / `quiz_single_choice_capital_letters` | **是** | Tap the lowercase / capital letter. | 音素 /m/ |
| Initial and Ending Sounds | `quiz_single_choice_initial_sounds` / `quiz_single_choice_ending_sounds` | **是** | Tap the sound you hear first / last. | 目标单词音频 |
| Blending and Segmenting of CVC | `quiz_single_choice_cvc_blending_and_segmenting` | **是** | Listen and tap the word. | `/s/ … /a/ … /t/` |
| Blending and Segmenting of CVC | `quiz_single_choice_cvc_blending` | **是** | Tap the missing letter. | 目标单词音频 + **提示文本 `__at`** |
| Reading and Spelling of CVC | `quiz_single_choice_cvc_reading_and_spelling` | 否 | Tap the word you hear. | 目标单词音频 |
| Reading and Spelling of CVC | **`quiz_repeat_cvc_reading_and_spelling`** | 否 | Repeat this word. | 目标单词音频 |
| Visual Discrimination | `quiz_single_choice_visual_discrimination` | 否 | Tap the picture. | 目标单词音频 |
| Auditory Discrimination | `quiz_single_choice_auditory_discrimination` | 否 | Tap the picture you hear. | 目标单词音频 |
| Auditory Discrimination | **`quiz_true_false_auditory_discrimination`** | **是** | Do these words rhyme? | 单词 A + 单词 B 音频 |
| Letter Formation | `quiz_single_choice_letter_formation` | （空） | Choose the correct letter shape. | 音素 /m/ —— **暂时没有该题型模板** |
| Concepts of Print | **`quiz_matching_concepts_of_print`** | 否 | Match the capital and lowercase letters. | 无 |
| Prepositional Language | `quiz_single_choice_prepositional_language` | 否 | Tap the picture. | 目标单词音频（如 under） |
- 新 question_type 出现了 **`true_false`（判断）、`sorting`（分类）、`matching`（配对）、`repeat`（跟读）**；需求范围只提「配对 / 判断 / 跟读」三种，**`sorting` 分类题（Sort the pictures）是否本期实现未说明**。
- ⚠️ **模板文案疑点**：
  - `quiz_true_false_auditory_discrimination`（听觉辨别）的题干写的是「**Do these words rhyme?** / 这些单词押韵吗？」，和押韵题重复，疑似复制错；
  - 印尼语 `quiz_single_choice_auditory_discrimination` 写「Dengarkan dan ketuk **kata** yang kamu dengar」（点击你听到的**单词**），中英文是「点击对应的**图片**」；
  - `quiz_single_choice_cvc_blending` 的模板是「Tap the missing letter.」，但配图（img-16）写的是「**Tap the correct picture.**」且选项是图片（猫 / 月亮 / 帽子），与「点缺失字母」不符；
  - Letter Formation 的「是否拼接」留空。

### 3. Admin：新增【配对题】手动配置
| 元素 | 规则 |
|---|---|
| 题干 | 配置题干文本 |
| 知识点 | 从【学习资源】中选择一个知识点，记录这道题实际考察的知识点 |
| **配对组数** | **支持 2-3 组** |
| 每组结构 | **左项 ↔ 右项，互为正确答案** |
| 配对内容类型 | **全部选项为【文本】或【图片】**（整题统一一种） |
| 添加 | 「+ 添加一组」在列表末尾追加空行；**最多 3 组** |
| 删除 | 每行末尾垃圾桶；**剩 2 组时禁止删除并提示「配对题至少保留 2 组」** |
| **排序** | **App 端随机排序：左边选项为第一排随机，右边选项为第二排随机** |

### 4. Admin：新增【判断题】手动配置
| 元素 | 规则 |
|---|---|
| 题干 / 知识点 | 同配对题 |
| 线索模块 | **与其他题型结构一致；配置的多条线索按配置顺序在 App 端展示** |
| **正确答案** | **是（Yes）/ 否（No）二选一**；**无默认值，初始未选中**；**未选择时禁止保存，提示「请选择正确答案」** |
- ⚠️ 判断题模板（如押韵 / 同起始音）需要「**单词 A + 单词 B**」两段线索，但原型（img-26）只配了 1 条线索 `cat`、App 预览也只显示一个词卡 `cat` + ✓ / ✗。

### ⚠️ 测试关注 / 回归点
- **播放矩阵**：6 种线索类型 × 拼接开 / 关 → 播什么；**多条线索音频之间也要插停顿**；进题自动播 + 重听重播完整序列；拼接中途点选项 / 退出 / 切题时音频是否打断。
- **存量题默认关闭** → 线上老题表现与现状一致（关闭态下「无 / 文字 / 图片」线索 = 静默卡片）。
- **配对题**：2–3 组边界、删到 2 组拦截、文本 / 图片统一、App 两排各自随机且答案关系不乱。
- **判断题**：未选正确答案拦截保存；多线索按顺序展示。
- **与 V1.37 / V1.39 交叉**：按 Clue 类型渲染、图片 + 音频线索、「是否使用题干信息」开关与「语音拼接」开关的叠加关系。
