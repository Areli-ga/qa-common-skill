## 摘要
把散在各业务后台的单词数据收敛成**一套知识库**：**让单词成为实体 —— 多业务引用同一份知识点 ID，消灭自由文本和冗余文本列**，并打通**反查**（从知识点查到哪些内容在用它）。做法是把「学习资产列表」提升为 **知识体系 / 学习资产列表**（每条记录叫**知识点**，含单词 / 短语 / 句型），新增**标签管理**（主题 / 体系 / 级别三类标签，左侧分组是**按字段现算的视图、不是实体树**）、**变体与音频**（复数、过去式等形态各自挂标准发音）、**状态（待上架 / 已上架 / 已下架）与完整度（5 项检查、实时算不落库）**、**引用反查 8 个类目**，并提供一个通用 **【关联知识点】选择组件**给各业务后台调用。接入优先级 **P1 主路径课程 + 绘本；P2 游戏大厅 / 小 Mai / 每日复习；P3 闪卡 / MiniPlan**；课程侧把单元编辑里的【从素材库选择】换成【选择知识点】，**历史学习数据不计算掌握度，从更换后开始**。

## 功能信息（逻辑 / 状态 / 边界 / 字段）

### 背景与目标
- 问题：① 做学习效果外化与知识体系时，最底层要的是**一个知识点（单词 / 句式 / 短语）的学习掌握度**；② **单词数据分散在各业务后台数据库**，掌握度无法归到同一数据源（课程里的 red 和闪卡里的 red 是两份）；③ **单词没有 id，全靠文字匹配 —— `apple` 和 `Apple` 是两个单词**。
- 目标：**让单词成为实体**（多业务引用同一知识点 ID）+ **打通反查**。
- 优先级：**P1 量最大的课程内容 —— 主路径课程、绘本**；**P2 游戏大厅、小 Mai、每日复习**；**P3 闪卡、MiniPlan**。

| 课程路径 - 游戏列表 | — | — | — |
| **MiniPlan - 复习游戏** | **纯自由文本**（dog, cat, bird, fish） | 无 | — |

### 1. 学习资产列表（知识体系 · 主列表）
**1.1 入口调整**：学习资产列表**拎出来放到「知识体系」下**；新增**标签管理**入口（维护给知识点打的标签）。**列表里每个单独 id 叫「知识点」，包含单词 / 短语 / 句型**。

**1.2 分组选择器（左侧）**
- 分组方式从**标签管理**读取，本期配 **主题 / 体系 / 级别**，**默认选「主题」**。
- **关键概念：这一列是「算出来的视图」，不是一棵实体树** —— 一个词身上只挂着**主题 / 级别 / 体系三个普通字段**，左侧是按其中一个字段**现场聚合**的结果；切换分组只是换个字段重算，**词的归属不变，也不需要为了在两个视图都出现而存两份**。
- 交互：切换分组后**默认选中【全部知识点】**；点二级分类刷新右侧列表；点「全部知识点」清空分组、右侧展示全部。

**1.3 列表七列**
| # | 列 | 内容与规则 |
|---|---|---|
| 1 | 知识点 | 知识点**原形**，点击进详情；**下方灰色小字为 15 位 ID**；**知识点后 `+N` 角标 = 非原形变体数**，无变体不显示 |
| 2 | **主题（新增）** | 来自标签管理；本期先上已有主题；未归属显示灰色**「无主题」** |
| 3 | **级别（新增）** | 来自标签管理；取值举例 **主线 L1–L20 / 拼读 Ph 1–Ph 4 / 阅读 A–C**；未定级显示灰色**「未定级」** |
| 4 | 剑桥体系 | 来自标签管理，本期先配 **Pre-A1 / A1 / A2** |
| 5 | 状态 | **已上架 / 待上架 / 已下架**；**已上架但不完整的，状态后挂红色 `!`** |
| 6 | 完整度 | **完整 / 缺 N**；**系统实时算，不落库、不可手改**（判定见 §1.5.3） |

**1.4 新增 / 编辑知识点**
- 新建与编辑**同一个页面**，差异只有四处：入口（列表右上「+ 新建知识点」 vs 行操作「编辑」/ 详情页右上「编辑」）、面包屑、标题（`新建知识点` vs `编辑：{知识点}`）、**变体卡 / 标签卡（新建出占位文案；编辑时变体只读、标签可增删）**。
- **字段规则**

| # | 字段 | 控件 | 必填 | 规则 |
|---|---|---|---|---|
| 1 | 知识点 (EN) | 单行输入 0/100 | **是** | 现有；**保存后即为原形**；原形的音标与音频**不在此维护，在详情页发音栏** |
| 2 | 翻译 | 只读文案 + 圆形「文A」按钮 | — | **新增**，沿用现有本地化文案系统 |
| 3 | 知识点类型 | 下拉单选 | **是** | 现有，**维持 7 个枚举不改名不拆分**：单词 / 自然拼读模式 / 句型 / 短语 / 专有名词 / 非英语资产 / 其他；默认「单词」 |
| 4 | 词性 | 下拉单选 | 否 | 未标注 / noun / verb / adjective / preposition |
| 5 | **主题** | 下拉单选 | 否 | **新增**，首项「（无主题）」，**单值**，选项来自标签管理 |
| 6 | **所属体系** | 下拉单选 | **是** | **新增**，主线课程 / 自然拼读 / 分级阅读，**无空值，默认主线课程** |
| 7 | **级别** | 下拉单选 | 否 | **新增**，**选项随体系联动**，首项「（暂不定级）」 |
| 8 | 蓝思等级 | −/+ 步进器 | 否 | 已有；**留空 = 未评估，不进完整度** |
| 9–11 | 剑桥体系 / 状态 / 完整度 | 灰底只读 | — | — |
| 12 | 素材 | 四槽 | **图片必填** | 见下 |

- **素材（四槽）**：一行四槽 **图片 / 音频 / 动画 / 音效**，每槽「预览框 + 从素材库选择 + 清除」，**不在此上传**。**「音频」槽 = 原形的标准发音**，也就是完整度查的那一条；**迁移时把现有单词卡那条音频导成「原形 · 标准发音」**；**各变体的发音在详情页按变体维护**。**动画与音效不进完整度判定**（质量项，缺了不影响孩子端正确使用）。
- **必填门槛（保存）= 知识点 + 知识点类型 + 所属体系 + 图片 + 主题 + 发音**，其他可留空；**未填齐不可保存**。
- **历史数据**：现存 **322 条中 68 条存在缺漏**（**缺主题 12 / 缺图片 21 / 缺原形发音 59，去重后 68**），本次需要补上；**其中 49 条已上架 —— 意味着有人只想改一个错别字，也得先把发音补上才能保存**。这 68 条**恰好就是当前的不完整集合**，所以规则的真实效果是「**任何一次编辑都会顺手把这条知识点变完整**」。原文给了替代方案：**必填只对新建强制，编辑历史数据时给警告但允许保存 —— 需要拍板**。
- **保存行为**：**保存不改状态**（新建 → 待上架；编辑 → 保持原状态，**上下架只在详情页发生**）；**保存不做完整度校验**；**改主题需二次确认** —— 编辑一条**已上架且有引用**的知识点的主题时，**弹窗列出受影响引用条数**，确认后才写入（原型此处为占位）；**变体在编辑页只读**，底部按钮是「到详情页管理变体与音频」（避免同一条变体两个入口两套校验）。

**1.5 知识点详情**（img-09）
- **头部**：知识点 + 15 位 ID + 体系标签 + 状态标签 + 完整度标签；翻译（是否本地化开启）；**发音栏（灰底条）= 知识点音标 + 音频**（**原形就是知识点本身**）；右上两个按钮 **上架 / 下架（随状态变文案）+ 编辑**。
- **基本信息顺序**与新增/编辑页一致：知识点类型 / 词性 → 主题 / 所属体系 → 级别 / 蓝思等级 → 剑桥体系 / 变体 → 标签 / 素材 → 更新时间。**变体数不含原形**；**标签在详情页可增删（列表页只读），标签主要做辅助备注、不一定成体系**；素材**已配显示绿底**。
- **状态（线性生命周期，3 值）**：`待上架 ──（完整才可）──▶ 已上架 ──（下架）──▶ 已下架 ──（完整才可）──▶ 已上架`。
- **完整度 5 项检查**

| # | 检查项 | 精确判定式 |
|---|---|---|
| 1 | 已有主题 | `topic` 非空 |
| 2 | 已定级别 | `level` 非空 |
| 3 | 已配图片 | `img` 存在**且非「待生成」占位** |
| 4 | 原形有发音 | **原形那条音频的状态 = 已上线** |
| 5 | 启用变体均有发音 | **所有状态 = 启用的非原形变体，各自那条音频都是已上线** |

**1.5.4 变体管理**（img-10 新增变体弹窗）
| # | 字段 | 说明 |
|---|---|---|
| 1 | 形态 | 手动输入单词；**同一知识点内不可重复，原形不在此新增** |
| 2 | 变体类型 | **新增枚举**：复数 / 第三人称单数 / 进行式 / 过去式 / 过去分词 / 比较级 / 最高级 / 口语昵称 / 拼写变体；**同形的情况（如 sheep）不新建变体，在原形上标注** |
| 3 | 词性 | 未标注 / noun / verb / adjective / preposition；**默认继承知识点词性**；**要去掉音标和描述**（正文），设计稿里仍有音标（留空则按形态生成占位，**不进完整度判定**）与描述（0/200） |
| 4 | 状态 | **启用 / 草稿**；**新增默认草稿**（避免半成品立刻计入完整度）；**启用 = 内容侧可引用、且要求有标准发音** |
| 5 | 音频 | **从素材库选择**（设计稿还有 **「TTS 生成」** 按钮）；**缺这条 → 启用后整条知识点算不完整**；**标准发音挂在形态上不是挂在知识点上**（`dog` 与 `dogs` 读音不同必须各有一条），**保存时一起写入** |
- **删除变体**：**有引用 → 二次确认，说明这些内容会回落到原形**；无引用 → 通用二次确认。

### 2. 标签管理
- 本期 **3 个 tab：主题、体系、级别**；**两级树状结构**即可，功能上线后由产品自行编辑。
- 取值：**主题**（见产品维护的 Google Doc）；**课程体系：主线 L1–L20 / 拼读 Ph 1–Ph 4 / 阅读 L0–L4**；**剑桥级别 Pre-A1 / A1 / A2**。
- **字段（内嵌表 tmqMD6）**：`文本名`（文本）；**`key 标识`（如 `animals` / `main` / `L1`，等宽字体展示、不可改 —— 改 key 等于换一个标签）**；`知识点数量`（**实时统计，不落库**）；**`删除`（有知识点的标签不可删除）**；`编辑`。
- 实拍（img-11）：主题 tab 标注「**身份标签 · 单值 · 几乎不变 · 改动影响内容侧归类**」，提示条写明「**主题是知识点的身份归属，单值且几乎不变。改名或合并会改变内容侧归类与筛选口径，需走数据迁移与人工复核。级别、体系这类属性标签改了不影响引用。**」

### 3. 关联知识点组件（通用）
后台任何内容要选知识点时**统一用这个组件**（img-12，标题形如「选择知识点 · Word Review– Pets」）。布局（内嵌表 eZDI2f）：
| 区 | 内容 |
|---|---|
| 左侧 | **与列表页同一套分组选择器**（分组方式下拉：主题 / 级别 / 剑桥体系 + 全部知识点 + 扁平值列表带计数）；**不是另一棵树** |
| 右上 | **七个筛选**：知识点·ID / **引用形态** / 词性 / 状态 / 主题 / 级别 / 体系 + 重置；**引用形态默认选中「原形」，可切换** |
| 中间 | 「**已选（N）**」chip 区，每枚 chip 是 `#ID 形态 ×`（**蓝色 = 指定了非原形**） |
| 右下 | 候选表：✓ / ID / 知识点 / **引用形态（下拉可选原形或某个变体）** / 图片 / 词性 / 主题 / 级别 |
| 底部 | **共 N 个知识点（当前分组）· M 个指定了非原形** + 取消 / **确认（N）** |
> 实拍细节：无变体的词（`fish`）引用形态列显示 **`fish 仅原形`** 且不可选；状态筛选默认 **「已上架」**；底部统计是**当前分组下的 262 个**（全库 322）。

### 4. 各业务接入
**课程路径（主课程）**：单元编辑里把原有的**【从素材库】选择按钮 → 改成【选择知识点】**，点击呼出关联组件（img-14 before / img-15 after，after 里 `单元目标` 下已选 chips 形如 `#789303802252293 green ×`）。
现有课程数据处理：**维护一批映射关系** —— ① **课程单词需要映射到学习资源列表**；② 学习资源列表里已有的资源没问题。**历史学习的数据不计算掌握度，从更换后开始。**

**闪卡（P3）**：把闪卡库与学习资产的单词**逐一对比，一致的做替换合并；闪卡独有的添加进学习资产库重新映射关联**。现有闪卡 id 关联到学习资产表；**闪卡的公共属性与业务属性会独立**。

**课程单词**：目前主要用在 gamelist；**一致的单词合并，并把线稿加到知识库素材中**，后续调用直接用知识库。**需开发协作梳理还有哪些地方在用，后续不再维护和新增这块单词**。

**MiniPlan（学习计划改名）**：**复习游戏和证书的单词改为从知识库选择**。

**题库管理**：**quiz 和跳转课的题目目前已全部关联到学习资产表**，需与 Aaron 确认是否全部。

**绘本**：目前独立，**可直接在字段中增加一个「核心知识点关联」**（img-21 红框标的位置）。

**AI 小麦**：部分接入 AI 互动课 —— **词汇加一个关联到单词表，后续支持从知识库选择**。
