## 摘要
针对微信群反馈（**自动续播、点击暂停 / 继续、翻页**三类，典型是**非常小龄用户**：模式选择面板会打断连续收看、孩子只会乱点、家长得在旁边帮点 play），做四项优化：① **入口页播放模式面板主题化（小狗吃骨头）+ `Auto Play` checkbox：勾选后 3 秒倒计时按所选模式自动开播，前端记住勾选状态**；② **播放页图文 viewer 通用区域点击 = 暂停 / 继续**，可交互区域（加粗单词、蒙版）保持原行为且**点击始终暂停播放**；③ **自动翻页前加 1s 前置等待**（无音频页不等、手动翻页不等；Read / Guide / Quiz 模式）；④ **翻译改为 Read / Guide 主操作按钮、常驻右下角、按住显示目标语言、松手取消**，**自动播放时按住翻译不翻页**，并**删除翻译状态的前端缓存**。埋点：`StoryBookStart` 新增 `play_trigger`（auto / manual），新增 `storybook_translate_hold`（替代原 `subtitle_on` 开关统计）。

### 1. 入口页播放模式面板：记忆 + 自动进入
- **主题化设计**：贴合阅读进度的故事化表达，定义**小狗吃骨头**主题（小龄家长可以直接说「点那只小狗播放故事」，而不是点按钮）。
  - ⚠️ 原文遗留问题：**平面设计给的是腊肠狗，故事里的动画是哈巴狗**，需统一成同一种狗（@董大杰，未定哪份素材改）。
- 功能：
  - **check box，文案 `Auto Play`**；主题化按钮 **`Play`**；
  - **勾选 checkbox = 自动进入故事播放：3 秒倒计时后按选中的模式自动开始**；
  - **每次勾选为选中时，按钮立即进入倒计时，每次选中都从 3 秒重新开始**；
  - **每次取消选中，倒计时取消，按钮变回 `Play`**；
  - **前端记住当前的勾选状态**（⚠️ 原文只说记「勾选状态」；摘要 / 需求范围写「记忆上次模式」—— 是否同时记住所选模式需确认）。
- 动画时序参考：
| 状态 | 默认 / 触发前 | 触发后 |
|---|---|---|
| **状态 1：手动点 Play** | 默认摇尾巴 | 点击后**抛射骨头 → 狗狗移动追骨头 → 面板消失 → 翻页** |
| **状态 2：勾选 checkbox** | 勾选后**疯狂摇尾巴、脚脚风火轮** | **倒计时结束后抛射骨头 → 狗狗疯狂追骨头 → 面板消失 → 翻页** |

### 2. 播放页：暂停 / 继续优化
- **增加图文 viewer 区域的通用点击控制：点击触发播放的暂停 / 继续**。
- **画面中的可交互区域遵从之前逻辑不变**：**点击加粗单词**、**点击蒙版区域**。
- 修改后的点击行为：
  - **点击通用无交互事件区域 → 切换播放 / 暂停状态**；
  - **点击可交互区域 → 每次都触发该区域既定行为，并且点击始终暂停当前内容播放**。
- 背景备注：原先「暂停 / 继续」只放在可交互对象上，点击时唤起单独组件并暂停播放流。

### 3. Read 模式翻页速度优化
- 目标：**一页音频播放完毕后不要太快进入下一页**，留给用户观察、思考、跟读的时间。
- 翻页拆为两段：**播放完音频后的等待时间 + 翻页动画**；**本需求只改前置等待时间，不改翻页动画**。
- 规则：
  - **自动播放翻页：增加前置等待时间 1S**；
  - **一页没有音频时，不启用等待时间**；
  - **手动翻页（无论往前、往后）均无前置等待，直接触发翻页动画**；
  - **需求所在模式：Read、Guide、Quiz**（⚠️ 标题写「Read 模式」，正文范围是三个模式）。
- ⚠️ **参数未定**：「需要拿真实的故事书去测，测完以后再决定时间参数」—— 1S 只是初值。

### 4. 翻译功能优化
- 背景：当前翻译与英文字幕存在干扰；参考竞品，限定范围：**用户始终在学英语，中文仅作暂时辅助**。
- **翻译作为 Read、Guide 模式的主操作按钮，放到可交互区域右下角**。
- **翻译目标语言（如中文）的位置和字体样式完全与原始语言（英文）保持一致**。
- **翻译后文本溢出原始文本框时，始终往文本框右下方扩展**；看开发成本考虑**动态文本**，避免目标语言过长时字符溢出。
- 交互：
  - **按钮常驻**；
  - **按住翻译，松手取消**；
  - **删除当前翻译状态的前端缓存，始终由用户长按触发**（即不再记住「翻译开启」）；
  - **自动播放模式下，持续按住翻译按钮就不会自动翻页；松开后恢复自动翻页**（demo review 之后新增）。
