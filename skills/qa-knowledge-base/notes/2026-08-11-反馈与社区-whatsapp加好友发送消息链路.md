### 1. 需求范围

1. **游客 / 登录用户菜单栏 banner 支持根据国家 IP 配置展示**。
2. 对接 WA 商业账号:**APP 与 WA 的用户 ID 绑定**,**根据 KidID 发送互动消息**并给用户打标;非中国以外国家配置了 WA 社群后,**直接跳转到商业账号互动后获得群链接**。
3. **后台支持配置不同国家的群链接**。
- **国家取值规则**:**注册用户取注册国家(注册时的国家 IP);游客走实时 IP**。

### 2. 进群子页面(按国家分流)

- 二维码和按钮逻辑**根据群管理页面读取配置信息**:
  - **中国 → 微信二维码**,点击按钮**保存微信图片**;
  - **印尼 → WA 二维码(印尼群二维码)**,点击按钮**进入商业账号互动**。
- 配置后台改成**国家群配置**:后续若配置越南等国家的群二维码,**越南用户进群子页面展示越南群二维码**,点击按钮进入商业账号互动,**GA 同步告知 WA 该用户为越南用户,发送越南群链接**。
- **联系我们**入口在**配置中心**配置(img-04:微信号 `tinadexia` 可复制 / WhatsApp「马上添加」/ 反馈入口 / 商务合作邮箱 `info@giggleacademy.com`);配置后台**需要后端替换**(@Ben)。

### 3. Admin 配置后台

**3.1 Banner 配置**
- banner 配置支持**下拉选择展示国家**(@cdarren @ray,原接口返回);有 uuid、有 token,**直接加一个 banner 配置位置**。

**3.2 新增「群链接管理」后台(img-06 / img-10 原型)**

### 6. WA 互动话术链路(暂不开发,记录备查)

- **已下载 WhatsApp 时引导用户发送消息**:① **默认带一条"用户同意接收信息"的话术**方便用户直接发送;② 默认回复可考虑引导进入社群。
- 预填话术(img-08,印尼语):`Halo Kak! Saya tertarik bergabung program Teman Belajar (Study Buddy) Giggle Academy`。
- **WA 系统回复**(中/印尼双语):「太棒了!学习报告我们会定期发给你 📊 另外,我们还有一个家长社群,里面有老师解读孩子进度、同龄家长交流经验。要一起加入吗?👇」
- **推送分国家**:**中国不走 WA 链路,依然走微信群二维码**;印尼 → 印尼群(**只针对印尼用户曝光,其他国家暂时屏蔽入口**);越南、菲律宾待配。按**用户的国家 IP + 手机区号**推送不同国家的群(@ray)。
  - **若越南用户跳到 WA 商业账号但后台没配越南群链接 → 不发送群链接,但依然可以通过 WA 互动**。
  - **WA 互动文案支持本地化**。
- **家长社群钩子(核心链路)**:APP 与 WA 用户 ID 绑定,**根据 KIDID 发送互动消息**。
  - APP 入口跳转 WA,自带固定话术「我想加入家长社群接受孩子报告」;
  - WA 回复【群链接】+「想要通过学习报告了解到孩子的学习情况吗?**回复 1**,接受孩子学习报告」;
  - 用户回复后:「孩子每天的学习情况,我们将通知你」;之后推送【报告链接】,**点击跳转到 APP 中报告 H5 页面**。
- **首次互动后 18 小时**的分支话术:
  - **有完课行为**:「【宝贝昵称】在 Giggle Academy 完成了【3】节课,开口了【5】次。想要听一听孩子英文说的怎么样吗?回复 1,查看详细的学习报告」→ 回复后发【报告链接】,**点击跳转 APP 并打开报告页(不需要家长验证即可查看)**。
  - **无完课行为**:「今天计划学习的【单元名称】孩子不喜欢吗?还没有开始学习。没关系,让我给你介绍更多功能?」+ 三个数字选项 → 按回复推送对应 APP 功能页链接(**是否可推送 APP 链接待 @shengling 确认**)。
  - **选项按天轮换**:day2 后 18h 无完课 = 绘本故事 / 歌曲 / 推送今天的学习计划;day4 后 18h 无完课 = 闪卡 / 绘画 / 推送今天的学习计划;day1 = 自然拼读 / AI 对话课 / 推送学习计划。
  - day2、day3 有完课行为的话术与 day1 相同。
- **先采用 24 小时被动消息回复限制**(WA 客服窗口规则),再看有多少用户与官方账号互动、进入社群。
