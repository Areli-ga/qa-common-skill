## 摘要

V1.38.0 单元结算页新增**句式卡样式**：句式与单词混排（**句式在前、单词在后**），左侧数据面板四项指标为 0 时隐藏，新增**关键词 key word**（取该词得分最高的一次音频 + 发音次数）；音频来源覆盖课程内跟读与跟读挑战课的单词与短句，**同一单词多次跟读只留最高分音频**。

## 功能信息（逻辑/状态/边界/字段）

### 1. 卡片混排规则

- **句式和单词混排，优先展示句式，再展示单词。**
- **有空位就排在后面。**
- 短句在前端页面的**展示卡片样式与单词卡有区分**（img-01 中句式卡为宽卡：卡面句子文本 + 插画，左上角 `x10` 角标，右上角绿色喇叭按钮）。

### 2. 数据指标（img-01 左侧面板）

- 面板头为单元名（示例 `Unit 2`），四项指标：**学习句式 / 学习单词 / 开口次数 / 互动次数**（示例值 8 / 8 / 28 / 123）。
- **以上数据指标为 0 为空，则隐藏。**

### 3. 关键词 key word

- **若该单元有配置关键词，则展示，否则缺省。**
- **该关键词音频，展示得分最高的一次。**
- 展示**关键词的发音次数**。

### 4. 课程音频来源

| 来源 | 内容 |
|---|---|
| **课程内跟读** | 单词、**短句**（短句在前端展示卡片样式有区分） |
| **跟读挑战课** | 单词、**短句**（同样有样式区分） |

### 5. 取数与存储

- **取单元的单词，`unit_goal`，和课程回顾的取值一样。**
- **语音识别要上传**，统计到 **level、单元 id、用户、单词** 四个维度。
- **如果有多次跟读，取用户单词跟读最高的音频；根据评分刷新存储新的最高分音频。**

### 6. 课程节点与句式来源（img-03「课程节点设计文档」）

课程节点表列：单元 / 主题 / 目标单词·句型 / **课程类型** / 截图 / **类型** / 模版类型 / 模版名称。

- 每个单元的节点序列为：`Vocabulary Word` → `High Frequency Word` → **`Sentence`** → `Say the Sentence` → `Review`。
- **`Sentence` 节点的「类型」标为「非模版」**；`Vocabulary Word` 节点可为「模版」（示例：单元 20 Actions 1-1 的 `Eat, drink, draw, read`，模版类型 `word only`，模版名称 `Penalty shootout`）。
- 示例句型：单元 19 Face 1-1 `I have a __.`；单元 20 Actions 1-1 `I can __.`；单元 23 Body 2-1 `You have __.`。

### 7. 后台词卡（img-02）

- Admin「**选择单词卡（多选）**」弹窗：筛选项 词元 / 词性 / 状态（启用）/ 资源；列表列 ID / 词元 / 图片 / 音频 / 动画 / 音效 / 词性 / **类型**。
- **「类型」字段区分 `word` 与 `sentence`** —— 句式作为一条词卡录入（示例 `i like blue.` 类型 = `sentence`，有图片、无音频/动画/音效/词性）。
- 已选择示例：`toothbrush / toothpaste / water / soap / wash`（带 `#7893038…` 形式的 ID）；库内共 688 条。

### ⚠️ 待确认（写用例前需拉齐）

1. **混排的容量与换行规则未定义**：只写「优先句式再单词，有空位就排在后面」—— 一屏能放几张、句式卡（宽卡）与单词卡混排如何对齐、超出是否滚动或分页，全无说明。「有空位」指哪一层的空位也不明确。
2. **关键词的配置入口不存在**：正文说「若该单元有配置关键词则展示」，但 img-02 的词卡后台只有 词元/词性/状态/资源/类型，**没有「关键词」字段**；关键词在哪配、按单元还是按课程配，需确认。
3. **「否则缺省」指什么**：关键词未配置时是整块隐藏、显示占位，还是取第一个单词兜底，未定义。
4. **「关键词的发音次数」与「开口次数」的关系**：两个都是次数指标，口径是否一致（是否都含未通过的跟读、是否含跟读挑战课）未说明。
5. **四项指标全为 0 时的表现**：单项为 0 隐藏，那四项全 0（例如纯互动课）时左侧面板是空白框还是整块隐藏，未写。
6. **单词卡样式没有对照图**：正文强调「短句卡片样式会有区分」，但只给了纯句式排版图（img-01），**混排态与单词卡样式没有设计稿**。
7. **`unit_goal` 字段来源未定义**：只说「和课程回顾的取值一样」，具体取哪张表/哪个接口需与研发确认。
8. **句式的最高分音频规则未写**：「多次跟读取最高分」只写了「单词跟读」，**句式是否同样只留最高分**、句式的评分口径（句子级还是逐词）未说明。
9. **跨来源的最高分如何合并**：同一单词在「课程内跟读」和「跟读挑战课」都跟读过，最高分音频是全局取一条还是分来源各留一条（关系到 level/单元/用户/单词四维度的唯一键）。
10. **分数相同的处理**：「根据评分刷新存储新的最高分音频」—— 新音频分数与旧音频**相同**时是否替换，未写。
11. **录音上传的授权与存储边界**：本需求要求语音识别音频上传并长期存储（用于结算页回放），需确认与 V1.35《故事书跟读组件优化》提出的「完课结算页上传授权」前置是否已具备，以及音频保留时长。
12. **`x10` 角标含义未在正文说明**：img-01 句式卡左上角有 `x10` 角标，**正文没有任何说明**（可能是发音次数，但文档未定义，不作推断）。
13. **无埋点**：新增卡片样式、关键词模块、音频回放均无事件定义，效果无法验证。
14. **句式卡是否可点击播放**：卡片右上有喇叭图标，但正文未描述点击行为（播最高分录音还是标准音频）。
