## 摘要

V1.37.0 为「自然拼读从主课程拆出」做**后台与数据侧的配套**：Admin 路径等级配置新增**主课程 / 自然拼读双分支 Tab**，两个分支**各有一套独立的 Level number 命名空间**（主课程 `Level n`、自然拼读 **`Phonics n`**）；App 搜索结果角标按结果所属分支渲染 `Lv n` 或 `Phonics n`，排序规则改为**主课程 > 自然拼读 > 同分支内 Level 低→高**；**所有带 `Level_Number` / `speech_level_number` 的埋点事件统一新增 `branch_code`（main/phonics）与 `branch_number` 两个参数**（影响面覆盖全量埋点，原文列了约 400 个事件名）。

> 本篇是同版本《单元内连续学习 + 单元数据结算》里「自然拼读体系拆出来（全局改，不 AB）」的**后台 + 数据配套实现**（原文注明「详情 Sunny 的需求」）。

## 功能信息（逻辑 / 状态 / 边界 / 字段）

### 0. 基本信息

- 产品 Owner：**Cloud**；**优先级：高**；文档「版本号」字段 **v1.37.0**（与主人给定一致）。
- 修订记录：**2026-08-11 —— Set n 还是改名为 Phonics n**。
- ⚠️ 「主要特性」章节为空；资源列表（UI 设计稿 / 动画 / 声音 / 其他）**全部为空**。

### 1. 背景与目标

- 背景：新版本会把**老的 Lv6-10 等级的内容划分成自然拼读内容**，然后制作**新的 Lv6-10 内容放在主课程**这里（详情见 Sunny 的需求）。
- 目标：
  1. 后台路径配置中**添加 level 类型选择**，区分主课程和 phonics 课程；**支持一条路径配置对应主课程分支以及自然拼读分支**，各自分支各有一套 Level number 类型 —— **主课程命名为 `Level n`，自然拼读命名为 `Phonics n`**。
  2. 更新**搜索模块中 level 角标的显示逻辑**，适配新的双路径系统（以前只展示 `Lv n`，新版需展示 **`Lv n` 或 `Phonics n`**）。

**需求范围**

| # | 模块 | 说明 | 状态 |
|---|---|---|---|
| 1 | **admin** | 路径配置中等级配置**新增分支 tab** | 本期需求 |
| 2 | **Unity** | 搜索模块展示课程内容的**角标更新** | 本期需求 |

### 2. Admin 路径等级配置新增分支 Tab

- 等级列表上方加一排 **Tab**，支持当前编辑等级内容切换到**主课程 / 自然拼读**。
- 规则：
  - **「新建等级」继承当前 Tab 的分支作为默认值**；
  - **切 Tab 只切数据展示**；
  - **空分支引导态**：「该分支下还没有等级。**新建的第一个等级将是 Phonics 1**。」
- 界面（图 1）：Tab 显示各分支等级数（示例 `主课程 9` / `自然拼读 0`），列表列 = 序号 / ID / 等级 ID / 等级名称 / 目标标题 / 按单元分组单词 / 统计（N 个单元、N 个部分、N 个内容）/ 操作（编辑 · 配置 · 删除）；右上角另有「**课程体系迁移**（新）」「刷新」「克隆等级」「+ 添加等级」。

### 3. 创建等级弹窗

| 字段 | 现状 | 本期改动 |
|---|---|---|
| **课程分支** | — | **新增。放在最上面**（它决定后面两个字段的默认值），**单选卡：主课程 / 自然拼读**。**必填，默认取当前 Tab** |
| **等级编号** | 数字，**路径内唯一**，新建/编辑直接插入到对应编号，原编号后移 | 默认值改为**该分支内 `max(level_number) + 1`**；**校验改为分支内唯一**；**切换分支时重算**；新建/编辑直接插入到对应编号，原编号后移 |
| **等级名称** | 自由文本 100 字 | **自动带出 `Level {n}` / `Phonics {n}`**；**运营可覆盖**；**只要用户没手改过，跟着分支/编号联动**；**一旦手改，停止联动**（避免覆盖运营输入） |
| 目标标题 / 目标内容 / 学习目标简介 / 标签 / 按单元分组单词卡 | 现状 | **不变** |

**联动细节（原文示例）**
- 切分支 **主课程 → 自然拼读**：编号 **10 → 5**（自然拼读现有 4 级），名称 **`Level 10` → `Phonics 5`**，**角标预览同步**；
- 手改名称为「拼读进阶」后再切编号 → **名称不再被覆盖，仍是「拼读进阶」**。

**编辑等级弹窗**
- **课程分支：可改**；**更改课程分支时 Level ID 不会改变**。
- **等级编号：可改**，仍走**分支内唯一**校验。

- ⚠️ 设计稿（图 2）与正文冲突两处：① 分支卡说明写「分支决定**编号命名空间**与**角标配色**，并决定它在列表里归到哪个 Tab。**创建后不可修改。**」← 与正文「编辑弹窗课程分支**可改**」矛盾；② 自然拼读分支卡上的标签仍是 **`Set n`**（修订记录 08-11 已改名 `Phonics n`），设计稿未更新。
- 图 2 另补充：等级名称字段下方注「**该名称会直接作为 C 端角标展示**。随分支与编号自动带出，可随时改。」；各文本字段带**翻译按钮（文A）**与字数上限（目标标题 200 / 目标内容 500 / 学习目标简介 150 / 标签 512，标签提示「英文逗号分隔，如 Phonics,Vocabulary」）。

### 4. App 端搜索结果角标同步

| 场景 | 现状 | 本期 |
|---|---|---|
| **结果卡角标** | 展示 `Lv {n}`，**n 取路径内全局编号** | **按结果所属等级的分支渲染 `Lv n` 或 `Phonics n`** |
| **结果排序** | 见下方「现状规则」 | **大部分不变**，仅变更同相关性排序：**按 主课程 > 自然拼读，同分支内 Level 低→高，类型 课程 → 故事书 → 歌曲，Name a→z** |

**搜索排序现状规则（原文保留，作为回归基线）**
- **相关性排序（必须展示 i、ii、iii 的内容）**：
  - **i** 名称完全匹配（检索 EN 课程名、本地化后课程名，按 app 语言）；
  - **ii** 名称包含关键词（检索 EN 课程名、本地化后课程名，如 `a → apple`、`an → banana`，**忽略空格**）；
  - **iii** 课程关联标签、专题包含关键词（检索 EN 普通标签/专题名、本地化后的）；
  - **iv** AI 关联内容（教案/故事书查询，**去重 i、ii、iii 的结果**）。
- **同相关性排序**：原为「Level 低→高，类型 课程→故事书→歌曲，Name a→z」→ **本期在最前面加「主课程 > 自然拼读」**。
- **分段查找**：i/ii/iii 与 iv 分段 —— 若 i/ii/iii 已返回而 iv 未返回，**先展示 i/ii/iii 并在结果后展示「搜索中」图标/状态**，等 iv 返回后移除该状态、追加展示。
- **分组标题**：i、ii 的内容**无需标题**；iii 标题为「**相关主题 (Related Topics)**」；iv 标题为「**相关推荐 (Related Recommendations)**」，**支持多语言**。**仅当该 Title 下有搜索结果时才展示对应 Title**；若 i、ii（名称匹配）无结果，**直接展示 iii、iv 部分的 Title 和内容**。

### 6. 待确认项

1. **「课程分支创建后可否修改」正文与设计稿直接冲突**：正文「编辑等级弹窗 —— 课程分支**可改**，更改时 Level ID 不变」；设计稿弹窗说明「分支决定编号命名空间与角标配色…**创建后不可修改**」。这条决定了**是否需要测「已有内容的等级换分支」这一整条路径**（换分支后编号重排、名称联动、角标、已学用户进度、埋点 branch_code 全部要跟着变）。
2. **设计稿仍是旧命名 `Set n`**（修订记录 08-11 已定为 `Phonics n`），UI 需重出图；且**角标配色**在正文完全没定义（只在设计稿说明里出现）。
3. **`branch_number` 没有取值定义**：表里「值」列直接写了 `branch_number`（自我指代），说明是「后端方案新增」但没说它与 `Level_Number` 的关系（是分支内序号？还是分支 id？）。**这是全量埋点改造的关键字段，必须先定义**。
4. **埋点影响面极大但无灰度/兼容方案**：约 400 个事件统一加参数，**存量数据与新数据如何区分**、老版本 App 不带 `branch_code` 时报表如何兜底、是否需要过渡期双写，均未说明。
5. **「所有带 `Level_Number`、`speech_level_number` 的事件」这个圈定方式不可执行**：原文给的 400 个事件名列表里明显包含**不带 Level_Number 的事件**（如 `AppPaused` / `AppResumed` / `app_page_view` / `auth_*` / `retention_d1` 等），需要开发按实际参数表逐个核对，**QA 无法凭本文档确定应测范围**。
6. **搜索角标的历史数据兼容**：现状角标 `n` 取「路径内全局编号」，改为分支内编号后 —— **老的 Lv6–Lv9 内容迁到自然拼读后角标从 `Lv 6` 变成 `Phonics 1`**，搜索结果、收藏、历史记录、分享链接里的旧角标如何处理未说明。
7. **`Phonics n` 的多语言**：`Level n` / `Phonics n` 是否需要本地化（中文课、印尼语），角标空间是否够（`Phonics 10` 比 `Lv 10` 长很多）。
8. **与「课程体系迁移」按钮的关系**：图 1 右上角有「课程体系迁移（新）」入口，**正文完全没提** —— 迁移工具是本期交付还是另一需求，迁移与本篇的分支 Tab 是什么关系。
9. **空分支引导文案写死了 `Phonics 1`**：主课程分支为空时应该提示 `Level 1`，原文只写了 Phonics 版本。
10. **等级编号「插入后原编号后移」在双分支下的影响面**：分支内插入会让后续等级编号整体后移，**已在学用户的 Level 定位、埋点历史数据、搜索角标**是否会错位，未说明。
11. **无验收标准**；也没有搜索 iv 段超时（AI 关联内容一直不返回）的兜底时限。
