## 摘要

V1.34.0 把跟读固定倒计时升级为「开口宽限 + 动态录音 + 自适应尾静音」防截断,给 lesson_speech_recognition_end 新增单词会话级字段(session_id + 最终结果)统计"一次会话最终有没有读对",并优化 VAD/音频回流分析剔除噪音误触。

## 功能信息(逻辑/状态/边界/字段)

### 背景(线上 A/B 已实证的问题)
- **采集截断**:固定倒计时下,反应慢的低龄孩子、多音节长词(strawberry/watermelon)还没说完就停止收音。
- **评分结果截断(主因)**:孩子已说完,但 GiggleSpeech 本地评分没在等待窗内返回;对照组用 cancel 直接丢弃结果,错记 0 星/unknown。
- 影响:满分跟读被错记、识别成功率被压低;多次重试逐条上报无法统计"单词一次会话最终是否读对";`is_speech_detected` 被噪音误触、开口率失真。

### 需求一:跟读计时调整(自适应端点)
采集拆成两段,支持**参数化配置下发**:
1. **开口宽限窗**(onset_grace = **6s**):进入聆听起计,等首次有效发声;超时按原逻辑未发声重试(回到领读);检测到有效发声进入录音窗。沿用 1.33 抢答逻辑。
2. **录音窗**:持续收音,只要还在发声就继续;触达**录音安全上限**(max_record = **6s + 0.5s ×(音节数−1),封顶 10s**)强制结束并获取结果。安全上限仅兜底,非正常关闭手段。
- ⚠️ **闪卡需同样处理对接**(见 [[2026-07-13-语音识别-闪卡跟读与音素打分]])。

### 需求二:单词单次会话识别成功率统计
`lesson_speech_recognition_end` 事件新增字段:

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| speech_session_id | string | 进入某节课程的同一单词/句子本次会话所有重试共享同一值;换词或重进课节生成新值 |
| speech_session_result | enum | 本次会话最终结果:success / fail / skip(点了跳过) |

- **移除 `speech_skip` 参数**(已被会话结果字段包含)。
- `speech_session_id` 生成规则:
  - 客户端在某单词本次进入课程后**首次领读开始时**生成;该词所有重试复用;
  - 进入下一词 / 退出后重进课节 → 生成新值;
  - **切后台再回前台续读 → 续用同一 id,不新开**。
- ⚠️ **字段命名文档内不一致(待确认)**:产品目标段写 `word_session_id` / `speech_word_result`,需求详情表写 `speech_session_id` / `speech_session_result`;正文"移除speech_skip"一句又提到"已被speech_word_result包含"。以实际埋点上报为准。

### 需求三:开口检测降噪与音频回流分析
- 端上优化 VAD **或** 后端音频回流分析(方案二选一,文档未定稿细节),目标是剔除噪音误触、统计"真实开口"。
