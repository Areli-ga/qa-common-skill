## 摘要

V1.38.0 在任务中心新增任务类型「**每日复习 Daily Review**」：每天从孩子已学（learned）单词里按**掌握度 L0–L5 + 遗忘曲线**挑 4–6 题（前 4 道图片音频配对 + 后 2 道跟读），答完给正确率环与星级，用间隔重复缓解「学了就忘」。

## 功能信息（逻辑/状态/边界/字段）

### 基本信息与目标

- 产品 Owner：Aaron；优先级：高；文档版本 v1.38.0；文档日期 2026-08-12。
- 背景：「学了就忘」是近期用户反馈最集中的问题 —— 现有课程是「持续学新内容」的线性设计，学完新单元后隔一段时间容易遗忘前面学过的单词与句子，缺少系统化复习巩固机制。
- 现有基础：上个版本已在 App **首页左下角**上线「任务中心」，本次在任务中心新增任务类型「每日复习」。
- **产品目标：参与【每日复习】的用户完成率达到 80%**；间接观察：参与用户群体在**前两周的高活跃留存比率**。
- UI：`https://www.figma.com/design/ILqThciQTufJKCFPmIuDVH/1.38.0?node-id=52015-4`
- 交互原型：`https://claude.ai/code/artifact/f222b605-e760-4866-a4a5-d053579e5762`（⚠️ 非 Figma/飞书链接）

### 名词

| 名词 | 说明 |
|---|---|
| 已学单词 | 孩子在已完成的课程中学习过的单词（学习状态为 **learned**） |
| 任务中心 | App 首页左下角入口，提供日常任务与奖励 |
| 每日复习 | 本次新增的任务类型：每天从已学内容中挑一批做轻量复习 |
| 掌握度 | 单词的复习表现（复习次数、正确率、最近复习时间），用于「选词优先级」 |
| 间隔重复 | 按遗忘规律安排复习时机的机制 |

### 需求范围（5 条）

1. 【任务中心】新增「每日复习」任务卡片：卡片展示、完成状态、每日刷新；
2. 复习内容选取逻辑：已学范围、**选词优先级**、**每日数量**；
3. 复习题型：图片配对题、录音跟读题；
4. 完成与奖励：接入任务中心奖励体系，**每日限次、中途退出可续做**；
5. 数据落库：**复习记录**、单词掌握度、数据埋点。

### 1. 任务中心 · 【每日复习】任务卡

| 元素 | 规则 |
|---|---|
| 卡片构成 | 卡片图片设计 + 任务标题文案 `Daily Review` |
| 状态机 | 当天完成过【每日复习】→ 任务卡片**收纳到【已完成任务】列表** |
| 每日刷新 | **用户本地时间 0 点**任务重置刷新 |
| 出现条件 | **已学单词数 ≥ 4**（已学单词来源：课程路径配置；完成过 Quiz 题 —— 测验题目对应的知识考查点）+ **非用户使用首日** |
| 点击卡片 | 跳转至【每日复习答题】第 1 题 |

### 2. 出题逻辑

- **候选池：只从已学过的单词里选（学习状态 learned）**；每个已学单词维护一条「记忆状态」记录（见下表）。
- ⚠️ 该表其余四行（状态机 / 每日刷新 / 任务卡片出现条件 / 点击任务卡片）与上面「任务卡」表**完全重复**，疑为复制粘贴；**需求范围里承诺的「选词优先级」「每日数量」规则在文档中缺失**（仅在题量处写了 4–6 题）。

### 3. 记忆状态维护表（参考闪卡设计）

| 字段 | 含义 | 取值 | 何时写 | 驱动什么 |
|---|---|---|---|---|
| `user_id`+`word_id` | 主键：谁 + 学哪个词 | id | 首次学习时创建 | 首次学习记录 |
| `last_reviewed_at` | 上次学习/复习该词的时间 | 时间戳 | **用户每答完一道题（在「每日复习」里点了图片选项、完成了跟读）就更新** | 下次应复习时间的计算基准 |
| `review_count` | 累计学习+复习次数 | int | 每次学习或复习 +1。场景：（1）**课程路径**：记忆卡片配对、单元测验答题、升级测验答题；（2）**每日复习答题** | 判断新词/老词 |
| `correct_count` | 累计答对次数 | int | 答题正确 +1 | 单词掌握度 |
| `wrong_count` | 累计答错次数 | int | 答题错误 +1 | 易错词识别 |
| `streak_correct` | 连续答对 | int | 连续答对：correct+1，wrong=0 | 升档依据 |
| `streak_wrong` | 连续答错 | int | 连续答错：wrong+1，correct=0 | 降档依据 |
| `last_result` | 上次答题结果 | enum | 每次答题后更新（正确/错误） | 出题优先级 |
| `mastery_level` | 掌握程度（核心档位） | **L0–L5** | 见下 | 决定间隔长短、决定题型 |

**mastery_level 规则**

- 存储：每条 `(user_id, word_id)` **持久化一个值（存储态，不实时推算）**；初始值：首次学会该词时 = **L0**。
- 状态转移：**答对 `min(5, level+1)`；答错 `max(0, level-2)`**。
- 等价枚举：L0 →对 L1 / 错 L0；L1 →对 L2 / 错 L0；L2 →对 L3 / 错 L0；L3 →对 L4 / 错 L1；L4 →对 L5 / 错 L2；L5 →对 L5 / 错 L3。（与公式一致）
- **遗忘曲线（档位决定复习间隔）**：L0 = 1 天 / L1 = 2 天 / L2 = 4 天 / L3 = 7 天 / L4 = 15 天 / L5 = 30 天。

### 4. 复习答题过程

- 顶部「返回」按钮：退出复习返回任务中心。
- **按顺序答题**：一套复习题**最低 4 道、最多 6 道** —— **前 4 道是图片音频配对题，后 2 道是跟读题**。
- 答题交互：**进入题目时自动播放**需要选择或跟读的单词。
- **图片配对题**：
  - 目标考核单词 —— 单词类型：单词文本 + 音频；字母类型：仅音频；
  - 选项 **三选一**，**位置随机**，三个选项中**必有一个目标考核单词**，另外两个从用户已学（learned）单词中**随机抽取**；
  - 完成判定：**用户点击一次选项**。
- **跟读题**：
  - 目标考核单词 —— 单词类型：单词文本 + 音频；字母类型：仅音频；
  - 完成判定：**用户完成一次跟读**。

### 5. 结算页

- **正确率环**：环形进度 = 正确数 / 总题数；中心显示百分比 + 「答对 x/N」。
- **星级**：满分 = 3★；正确率 **> 30%** = 2★；正确率 **≤ 30%** = 1★。

### 数据埋点

| 事件 | 定义 | 属性 |
|---|---|---|
| `task_card_impression` | 【每日复习】任务卡片曝光 | `task_status`：`completed` / `incomplete` |
| `daily_review_start` | 点击任务卡片进入复习题 | `learned_word_count`（**注释写的是「需要复习的题目数」**） |
| `daily_review_exit` | 退出复习题 | `exit_type`：`completed`（完成）/ `quit`（中途主动退出）；`duration`（**原文「记录从退出到开始这一次的时长」**）；`star_level`：0（中途退出）/1/2/3；`accuracy_percent`（本次答题总正确率） |
| `daily_review_answer` | 每完成一道题记录答题结果 | `question_type`：`image_choice`（音频-图片配对）/ `read_aloud`（语音跟读）；`is_correct`：true/false（**跟读题 1 星或没星记 false，2 星或 3 星记 true**）；`knowledge_point`（本次考察的知识点） |

### ⚠️ 待确认（写用例前需拉齐）

1. **「选词优先级」和「每日数量」规则缺失（最关键）**：需求范围第 2 条明确要求，但「出题逻辑」表里只有「候选池」一行有效内容，其余四行是从任务卡表复制过来的重复内容。掌握度、遗忘曲线间隔究竟如何转成"今天出哪几个词"，文档没写。
2. **题量 4 / 5 / 6 的取值规则未写**：只说「最低 4 最多 6，前 4 图片 + 后 2 跟读」，那 5 道题时是 4+1 还是 3+2？到期复习词不足 4 个时如何凑（用未到期词还是不出任务）？
3. **「已学单词」定义两处不同**：任务卡出现条件写「来源：**课程路径配置；完成过 Quiz 题**（测验题目对应的知识考查点）」，出题逻辑表写「来源：**学习状态为 learned**」。两者是否等价、Quiz 考查点算不算 learned 需确认。
4. **「档位决定题型」无规则**：`mastery_level` 的作用写着「决定间隔长短、**决定题型**」，但题型分配写死为「前 4 图片 + 后 2 跟读」，档位怎么影响题型没写。
5. **`last_reviewed_at` 与 `review_count` 的写入时机不一致**：`review_count` 明确包含**课程路径**场景（记忆卡片配对、单元测验、升级测验），而 `last_reviewed_at` 只写了「在每日复习里答题」时更新。若课程侧答题不更新 `last_reviewed_at`，遗忘曲线的计算基准会与实际复习行为脱节 —— 需确认课程路径答题是否也更新该字段。
6. **课程侧改造范围未圈定**：`review_count` 要在记忆卡片配对 / 单元测验 / 升级测验三处累加，等于本需求会改动课程主链路，但文档没有对应的功能描述与验收点。
7. **跟读题的星级标准未定义**：埋点按「1 星/无星 = false，2–3 星 = true」判对错，但正文没写跟读判定用哪套语音识别阈值（是否沿用现有跟读组件的 40/70 星级线）。
8. **「每日限次、中途退出可续做」只在需求范围出现，功能描述里没有对应规则**：续做是从第几题继续、当天重进是否重新出题、已答题的记忆状态是否重复写入，全未定义。
9. **「复习记录」表未定义**：需求范围第 5 条要求落库复习记录，文档只给了「记忆状态」表。
10. **奖励未定义**：需求范围第 4 条写「接入任务中心奖励体系」，但没写复习任务发什么奖励、由谁配置（《任务 2.0》里 Daily Review 是后台可配的「可选任务」，两篇需对齐）。
11. **埋点两处表述问题**：`learned_word_count` 命名与含义不符（实际是题目数）；`daily_review_exit.duration` 写成「从退出到开始这一次的时长」，语序倒置。
12. **交互原型链接是 `claude.ai/code/artifact`**，非公司 Figma/飞书，QA 是否有权限访问需确认。
13. **星级与正确率环的口径**：跟读题按星级折算 true/false 后，正确率环的「正确数」是否把跟读题的 2–3 星计为正确，文档未明说。
