### 0. 文首结论

> 「在小麦克风的音频输入里,需要定一个阈值:**取 70%**」

- ⚠️ **「70%」与正文建议值对不上(已入待确认)**:正文第五部分与参数表给的是 **Noise 8 / Speech 15 / Reading 25(~35) / Very Loud 70**(SDK 0~100 的绝对刻度,不是百分比);唯一出现 70 的是 **Very Loud 门限**。「取 70%」指的是哪个量、用在哪一步,文档未说明。

### 1. 噪音阈值该怎么定义(第一部分)

儿童英语口语产品建议定**两个阈值**:

**① Noise Floor(环境噪音)** —— 判断当前环境是否安静、哪些声音直接忽略。
真实麦克风输入的一般参考:
- `<35 dBA`:认为安静
- `35~45 dBA`:正常家庭
- `>55 dBA`:开始提示环境较吵
- `>65 dBA`:建议提醒用户换环境

**但是**:**App 几乎测不到真正意义上的 dBA**,手机没有校准,**更多应采用相对能量**。

**② Speech Threshold(说话阈值)** —— 真正决定「**AI 是否开始识别**」。
- 成年人正常说话(距手机 20cm 左右):约 **60~65 dBA**;
- **儿童**:一般 **55~65 dBA**;
- **大声朗读**:**70~80 dBA**。
- 建议:若课程希望孩子「大声朗读」,**目标定在相当于 60~65 dBA**,**不要要求 70 dB —— 孩子会累**。

**环境 SPL 参考表(内嵌 Sheet)**

| 场景 | 大约 SPL(dBA) |
|---|---|
| 非常安静房间 | 25~30 dB |
| 家里正常环境 | 35~45 dB |
| 教室 | 45~55 dB |
| 客厅有人聊天 | 55~65 dB |
| 马路边 | 70~80 dB |

**人声等级参考表(内嵌 Sheet)**

| 等级 | SPL |
|---|---|
| 太轻 | `<50 dBA` |
| 正常讲话 | `55~65 dBA` |
| 大声朗读 | `65~75 dBA` |
| 喊叫 | `>80 dBA` |

### 2. 手机里的 0~100 是什么(第二 / 三部分)

- SDK 常给 `volume = 0~100`、`0~255` 或 `0~32767`,**它们都不是 dB**,而是**当前 PCM 振幅(Amplitude)**;开发者一般会 Normalize 到 0~100。
- **为什么不是 dB**:同一个人距手机 5cm 与 50cm,真实 SPL 可能都是 65 dBA,但**麦克风采集值可能差 20 dB** —— 手机无法知道真实世界的分贝。
- **Amplitude 与 dB 的关系**:`dB = 20 × log10(amplitude / reference)`;Amplitude 100 → ≈40 dB,Amplitude 1000 → ≈60 dB;**振幅增加十倍,dB 只增加 20 dB,两者不是线性关系**。
- 📌 这条直接影响测试方法:**不能用分贝计对着手机验收阈值**,只能读 SDK 上报的相对值。

### 3. SDK 0~100 的经验对应(第四部分,内嵌 Sheet)

> 适用于 Agora / 腾讯 RTC / 声网等提供 `volume = 0~100` 的 SDK。**注意:不是 dB,只是经验对应**。

| SDK Volume | 大概状态 |
|---|---|
| 0~5 | 静音 |
| 5~10 | 环境噪音 |
| 10~20 | 很轻讲话 |
| 20~40 | 正常讲话 |
| 40~60 | 较大声 |
| 60~80 | 很大声 |
| 80~100 | 基本喊叫 |

### 4. 推荐做法:不要直接使用 dB(第五部分)

大部分 AI 陪练产品**不会定义「必须 >60 dBA」**(根本测不到),而是定义相对阈值:

| 参数 | 建议初始值 | 作用 |
|---|---|---|
| **Noise Floor** | SDK 音量 **8** 左右 | **低于此值视为环境噪音,不触发语音识别** |
| **Speech Trigger** | SDK 音量 **15** 左右 | **超过此值才认为用户开始讲话** |
| **Good Reading** | SDK 音量 **25 到 35** | **达到后认为朗读声音清晰、积极,可给予鼓励** |
| **Very Loud** | SDK 音量 **70 以上** | **认为音量过大,可限制或提醒无需喊叫** |

- 配套 UI:**音量条**(`□□□□■■■■□□□□`)或 **`😊 Speak louder!`** 式提示 —— 孩子容易理解。

### 5. 对测试的意义

- **验收只能看 SDK 相对值**,不能用分贝计;需要研发暴露实时 volume 值或日志才可验。
- **四档要分别构造**:静音(<8)、环境噪音(8~15 之间不触发识别)、正常讲话(15~25 触发但不鼓励)、清晰朗读(25~35 给鼓励)、喊叫(>70 提示无需喊叫)。
- **距离是关键变量**:同样音量在 5cm 与 50cm 下 SDK 读数差异极大,**测试必须固定并记录测试距离**,否则结论不可复现。
- **机型差异**:不同手机麦克风增益不同,同一档位在不同机型上表现可能跨档,**需多机型抽测**。
