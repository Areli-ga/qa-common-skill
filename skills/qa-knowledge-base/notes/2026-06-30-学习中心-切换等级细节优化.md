## 摘要

V1.32.0 补充学习中心「切换等级」走查细节:点击未解锁等级进入升级测试,关闭测试页或中途点左上角关闭都返回首页;升级测试结束后点击「探索 Lv6」或失败状态也回首页;再次进入切换等级时需选中当前等级。同时补充课程介绍 / 切换等级卡片的多语言适配问题:可能出现中英混排、字体展示异常,选中卡片后可上下滑动查看长文案。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 1. 切换等级与升级测试返回路径
- 在「切换等级」中点击未解锁等级,进入升级测试。
- 点击【开始测试】后,关闭后续测试页面,应返回首页。
- 升级测试中途点击左上角关闭,应返回首页。原文标注:已验证。
- 升级测试结束后点击【探索 Lv6】,应回到首页。原文标注:已验证。
- 升级测试失败状态也应回到首页。⚠️ 原文备注「不确定是什么按钮,测试验证一下」,测试时核对失败页实际按钮文案与跳转。
- 再次进入切换等级页时,需要选中当前等级。原文标注:已验证。

### 2. 切换等级选中态
- 学习中心弹窗内有「切换等级 / 课程介绍」两个 Tab。
- 进入切换等级时,当前等级卡片应处于选中态:
  - 当前等级卡片有高亮边框。
  - 当前等级卡片展示主按钮「继续学习」。
  - 顶部显示当前级别与方向,如 `Pre A1 · 口语积累`。
- 横向等级卡片中,后续等级可展示奖杯 / 主题 / 标签 / 单元数 / 单词数等信息。

### 3. 多语言适配
- 原文记录:可能出现「一些英文、一些中文」,不确定是否网络问题。
- 图中示例:
  - Lv1 卡片为中文标题、中文标签、中文介绍。
  - Lv2 卡片出现英文标题 `Learning New Words`、英文标签 `Animals / Actions / Family / Transport`、英文介绍,但底部仍显示中文 `8 单元 / 60 单词`。
- 需要回归不同语言 / 地区下:
  - Tab、等级标题、标签、介绍、单元数、单词数是否同语言。
  - 网络异常或本地化资源未加载时是否出现中英混排。
  - 已选中 / 未选中卡片的文案是否一致走本地化。

### 4. 文案展示与滚动
- 原文记录:多语言后字体展示不出来;已验证选中卡片后可以上下滑动。
- 长文案卡片需要支持滚动查看,避免英文长句或本地化长文案被截断后无法读取。
- 图中 Lv2 英文介绍出现省略截断:`Understands and uses simple words in familiar everyday t...`;测试需覆盖选中卡片后的上下滑动查看。

### 关联依赖(回归注意)
- 与「学习中心-课程介绍优化」强相关:该文档是学习中心切换等级 / 课程介绍弹窗的细节补充。
- 与「首页布局优化」相关:升级测试入口最早来自首页切换等级逻辑,关闭 / 完成 / 失败后均应回首页。
- 与多语言 / 本地化资源相关:需覆盖中英混排、字体缺失、长文案滚动。
