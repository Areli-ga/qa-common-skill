## 摘要

把课程侧 **1.33.0 跟读组件已验证的体验搬到故事书**:**全流程自动**(翻页→自动领读→自动录音→自动判定→自动翻页,通过路径**零点击**)、**取消全部人声/TTS 反馈改为动画反馈**、**通过后回放孩子自己的录音**、**失败自动重领读**、**音量条改为真实音量驱动**;并新增故事书特有的**完课结算页封面回放录音合集 + 分享**,以及**弱网/短句路由自研模型**。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 0. 背景:现存 7 个问题

1. **手动操作负担重、易误触**:开始录音、提交、翻页全靠点击;**mic 激活与提交是同一按钮的两次点击**,低龄用户连点会产生**空录音**(本期通过收音全自动化从交互上根除)。
2. **语音反馈与正文混淆**:反馈话术是英文人声,小朋友分不清哪些是故事正文,会把 `Excellent` `Sorry I didn't catch that` **也当成正文跟读**。
3. **正反馈需加强**:课程侧已验证「**读对后回放孩子自己的录音**」是强正反馈(孩子非常喜欢听自己的声音),故事书侧不会自动播放;且跟读模式完成后**没有途径播放"用户自己读的这本书"**。
4. **失败无引导**:读错或没读时没有温柔的重试引导,需手动点重播,**孩子容易卡在一页上**。
5. **手动翻页负担**:读对后还要手动点翻页,**打断阅读心流**。
6. **收音反馈是假的**:录音时的音量条/波形是**静态循环动画**,不随真实输入变化。
7. **云端识别在弱网/短句下体验差**:弱网等待长、易超时;**短句本可用端上自研模型低延迟完成**。

- 产品 Owner:**Cloud**;优先级:**高**;文档版本号 `v1.35.0`;Figma `1.35.0` node `44719-36725`。

### 1. 需求一 · 全流程自动(核心)

**每翻到一页跟读页(手动翻页与自动翻页均适用)的完整时序**:

```
自动播放领读原声
   ↓ 领读结束
自动开始录音(音量条随真实输入实时抖动)
   ↓ 录音结束(自动判断语音识别结束 = wheat 上期功能;录音中点 mic 可提前提交,原有逻辑)
识别评分(弱网/短句路由自研模型;不走 stop 走 cancel 上报埋点,沿用 1.34.0 原则)
   ├── 通过(2、3 星)→ 成功动画反馈(无系统人声赞赏)
   │      → 回放用户录音(剪前导静音)
   │      → 回放结束停留 ~0.5s → 自动翻到下一页,重新进入本循环
   └── 未通过 / 未发声(0、1 星)→ 错误反馈 → 自动重领读 → 重领读结束自动开始录音
          (与首次跟读时序、参数完全一致)
          ├── 重试通过 → 走通过分支
          └── 重试仍未通过/未发声 → 错误动画反馈 → 翻页键高亮引导手动翻页
                 (高亮同时自动触发重领读 → 自动录音,成功照常)
```

**翻页与状态规则**
- **自动翻页到达新页后**,按需求一自动衔接「领读 → 自动录音」,形成**整本连续心流**。
- **用户手动翻回之前的页面**:**未通过、未录音的页 → 自动播放原声并进入录音流程**;**已通过的页 → 不自动播放 + 不录音**。
- **自动翻页前用户手动翻页**:**立即翻页,取消后续自动翻页动作**(防止自动与手动同时触发、**重复翻两页**)。
- **自动翻页动效与手动翻页一致**。
- **最后一页通过:不翻页,进入完课结算页**。

**mic 按钮职责收敛**(测试重点,原来的误触根源)
- **录音中点击 = 提前提交**(提前结束采集送评分);
- **领读中点击 = 提前开始录音**;
- **原 0.5s 防误触需求保留**,避免用户反复点击。

### 2. 需求二 · 取消语音反馈,改为动画反馈

- **移除跟读结果的全部人声/TTS 反馈话术**(`Excellent!`、`Sorry, I didn't catch that.` 等),**含成功与失败两类**。
- **改为动画反馈**:
  - **通过**:欢庆类正反馈动画,衔接录音回放(需求三);**连续 3 次 2 星以上会触发全屏庆祝动画,随机播放、不连续重复**;
  - **未通过/未发声**:衔接重领读。
- **反馈中不得出现任何英文可读语音**(孩子会把反馈人声当正文跟读);**允许保留非语言音效**(叮咚、欢呼等,**无语义、不可"跟读"**)。
- 设计稿细化(img-01):**得星打分后触发 max 动效**;弹出基础庆祝反馈 = **缩小版 Max 动效(复用语音跟读课资源,仅缩小 + 水平翻转)**,**共 7 种动作状态,每次打分随机展示其一**。

### 3. 需求三 · 通过后回放用户录音

- 判定通过后,**自动播放用户本次跟读的录音**。
- **回放期间用户头像播放缩放动效 + 绿色边框**;设计稿(img-02)标注 **scale 动效 `1 → 1.1 → 0.0 → 1 倍`**,回放用户声音。
- 回放的录音应用**前导静音裁剪**(需求四)。

### 4. 需求四 · 回放录音剪掉前导静音(**可选**)

- 回放用户录音(**含单页回放与完课结算页回放**)时剪掉开头无声段:**以 VAD 检测的首个有效发声起始点为回放起点,向前保留 ~0.2s padding**(防止首音节被削)。
- **实现建议为回放起点偏移,不改写原始音频文件**。
- 对**需求三(单页回放)与结算页回放/分享同时生效**;**连播场景尤其重要**(多段拼接时静音累积明显)。
- **本需求为可选**:若本期排期紧张可后置,**不阻塞其他需求上线**。

### 5. 需求五 · 完课结算页封面回放录音合集 + 分享

**出现条件(两者同时满足)**
1. 用户**完成一本故事书的跟读模式**(走到完课结算页);
2. **本次会话中至少有 1 页录制成功**(存在成功录音)。
→ 结算页故事书**封面呈可播放态**(带播放标识,样式以设计稿为准)。
- **0 页成功录音**:封面为**普通展示态,无播放标识、点击不触发回放**。

**封面回放交互**
- 点击封面 → **按页面顺序连续播放各页成功录音**,**未录制(未成功)的页面直接跳过**;
- **不返回故事书页面**:全程停留在完课结算页,**纯音频播放**(封面配轻量播放中状态:播放/暂停标识、进度表现,以设计稿为准);
- **纯播放音频,无故事书内页面展示**;
- 每段录音应用**前导静音裁剪**;**段间衔接间隔建议 ~0.3s**;
- **播放中再次点击封面:暂停/继续**;播放完毕恢复可播放态,**可重复播放**;
- **用户离开结算页即停止播放**;
- 实现可考虑**直接本地文件播放**。

**分享(也可以不改)**
- 结算页提供分享入口(**封面回放可用时展示,即 ≥1 页成功录音**);
- **分享物形态:纯封面 + 用户音频** —— 接收方打开后看到**故事书封面静态画面**,播放用户录音合集,**无故事书内页画面**;
- 实现载体:**封面图 + 音频合成的 H5 落地页**,或**合成视频(封面静帧 + 音轨)**;
- **前置依赖:完课结算页上传授权**。

### 6. 需求六 · 音量条随真实输入音量抖动

- 录音中的音量条/波形组件**从静态循环动画改为实时音量驱动**:接入麦克风输入的**实时音量流**,UI 高低随输入实时波动 —— **静音时低平,说话时波峰随音量增高**。

### 7. 需求九 · 弱网/短句接入自研模型

**识别引擎路由策略**:满足以下**任一条件**时,本次跟读**使用自研模型评分**,否则用**云端 ASR**:
- **弱网**:网络质量探测低于阈值;
- **短句**:本页跟读文本长度(**词数/音节数**)低于阈值。
- **阈值不写死**:**弱网判定标准由 wheat 根据数据调参**。

- ⚠️ **需求编号不连续**:正文只有需求一~六和需求九,**缺需求七、八**;且需求四正文里引用「需求七(完课结算页回放/分享)」,实际对应的是**需求五** —— 编号在编辑过程中错乱,阅读时按内容对应,勿按编号索引。

### 8. 验收标准(原文给出,可直接转用例)

1. 翻到跟读页**自动播放领读**,领读结束**自动开始录音**,**自适应端点自动结束**;**正常通过路径全程零点击**(听领读→跟读→自动判定→自动翻页)。
2. 失败后**自动重领读**、重领读结束**自动开始录音重试**,全程无需点击。
3. **全流程无任何人声/TTS 反馈话术**;对/错反馈均为**动画 + 非语言音效**。
4. 通过后**回放用户本次录音**,回放毕 **+0.5s 自动翻页**并自动衔接下一页领读;最后一页进完课结算页。
5. **同页失败 ≥2 次后翻页键高亮**,高亮同时进行重领读→自动录音,通过照常自动翻页。
6. 录音中**音量条随真实输入实时波动**(静音低平/说话起伏),**非静态循环动画**。
7. 结算页:**≥1 页成功录音时封面呈可播放态**,点击后在结算页内**纯音频连播**各页成功录音、**未录页跳过**、**不返回故事书页面**;**0 页成功录音时封面不可播放**。
8. **分享物为纯封面 + 用户音频合集(无内页画面)**。
9. (若实现需求四)**单页回放与封面回放的每段录音开头无明显静音,首音节不被削**。
10. **弱网/短句场景采用自研模型识别**。
