## 摘要

V1.30.0 留存增长功能:新用户累计学习 7 个学习日,经"试学学员 → Giggle终身学员"认证,获终身免费权益(课程永久免费、多孩多设备、终身学员社群)。配 AB 实验分流,Day1 / Day2–6 / Day7 各有专属弹窗 + 认证仪式 + 学员证书分享。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 1. 核心规则
- 试学学员(首次登录/注册默认)→ 累计 **7 个学习日(非自然日)** → Giggle终身学员认证。
- 每日任务:完成 1 个 Section(学完任意一节课)。
- **边界**:每日只积累 1 天进度(多学不加速);本地时区 0:00 刷新;间断不强制连续(中断后继续累计);默认英文本地化;认证发给 **userid**,多孩账号取**最大进度**。
- ⚠️ **本期不做**:试学 30 天未完成 → 回普通学员(本期先不限制)。

### 2. AB 实验分流
- 新用户:新版本启动 App 生成游客账号后**立即分流**,整生命周期同组;游客→注册不改组。
- **仅新装此版本用户参与**;已登录老用户更新不参与;历史游客更新后不参与。

### 3. 流程(欢迎页 → Hello课 → Day1 → Day2–6 → Day7)
- 欢迎页 →【开始免费学习】→ 办理学员证(选 Avatar / 昵称默认"咯咯学员" / 年龄默认 3 岁)→【开始学习】进 Hello 课。
- Hello课:结束或中途退出 → 地图首页;不自动领扭蛋、不自动开下一节;全部进 1.29 AB 实验组。
- 试学邀请函弹窗:到首页弹出,按 Hello 完成状态两版(已完成/未完成),**无论是否完成都弹**。
- **Day1 完成**:完成任意一节课=完成今日挑战;弹窗 Day1 勾选,文案"距离获得认证还有 6 天"。
  - 未登录 →【注册登录】;已登录 →【继续学习】。
  - **优先级**:先弹此弹窗,不弹扭蛋弹窗(需手动开宝箱)。
  - 注册登录后:新用户带进度 + 保留实验组;⚠️ **老用户登录数据丢失**(本期推全量后再处理)。
  - 多孩:各自记进度,**最先完成的孩子**触发奖励、所有孩子结束。
  - 历史账号映射:历史 Section ≥ 游客 Section → 取历史天数(≥6 → Day7 认证仪式;<6 → 转化天数);否则游客进度更新到历史账号。
  - 异常:学完最后关卡瞬间杀进程 → 再回首页仍弹此弹窗。
- 首页火苗 → 试学进度(完成前 0/7,之后 打卡天数/7)。
- **Day2–6**:未完成时启动弹"欢迎回来"(文案"XX,欢迎回来,今天是试学挑战第 Y 天")。
- **Day7**:完成挑战弹窗(恭喜成为**第 X 位**Giggle终身学员,**X 从 300001 起递增**;7 天全勾选;按钮【领取学员证书】;**去掉关闭按钮,未领取一直展示**)。
  - 学员证书:头像/昵称(动态)、完成 7 天、完成 X 个 Section、掌握 Y 个新单词;可分享。
  - 生成分享图:复用线上分享组件,扫码下载同"邀请好友"。

### 4. 数据埋点
"终身学员挑战" sheet(见埋点表截图)。⚠️ 具体事件/参数在 sheet 图里、正文未展开 → 写埋点用例前需对照原 sheet。
