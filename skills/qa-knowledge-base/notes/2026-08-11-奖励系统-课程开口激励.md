## 摘要

V1.36.0 把新用户首日路径改成「**开口向**」:凡涉及开口的课程(Hello 课 / 跟读课 / 挑战课)右上角常驻**扭蛋进度徽标 x/N**,**每跟读通过一次 +1**,**进度跨节点、跨课程累计**;完课时进度**达到本轮门槛 N 就直接开扭蛋**,不够则把进度存到**首页左下角入口**下次继续攒。门槛按轮递增:**第 1 轮(Hello 课)N=3 → 第 2 轮(Color 课)N=4 → 第 3 轮起固定 N=5(封顶)**。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 0. 背景与目的

- 新用户路径体验上,**课程和激励都做「开口向」迭代**,鼓励用户开口并获得开口激励:
  - **课程侧**:① Hello 课修改;② Color 课修改;
  - **产品侧**:① **首页路径增加开口激励的入口**;② **口语课结算开扭蛋**。
- 目的:**强化开口的教学和收获**,帮助用户**在首日更快获得学习成就感**,进而提升长期留存。
- UI:Figma **`1.36原型— Leah`**(文件 `exEw6pITDo0ThlBkQQyo6L`)node `126-14030`。

### 1. 开口进度徽标(Hello 课 + Color 课改造)

- 进入涉及开口的课程/环节,**屏幕右上角常驻开口进度徽标**:**扭蛋图标 + `x/N` 数字**(N 为本轮扭蛋门槛),**外圈进度环随次数填充**。
- **涉及开口的课程包括:Hello 课、跟读课、挑战课**(流程图进一步注明**全 Level / 全 Unit**,不限于 Hello 与 Color)。
- 到跟读节点时,**画面进入跟读模式,与目前一致**。
- **用户点击开口按钮并出声跟读**:
  - **判定通过** → 画面出现 **1 颗星星**;
    - **用户点击星星** → 右上角**进度 +1**,徽标数字与进度环**即时更新**,播放**正反馈动效/音效**;
    - **用户不点击** → 约 **2s 后星星自动飞到右上角**,触发上述同一套动画;
  - **判定未通过** → **不计数,允许重试;不打断课程流程**。
- **进度跨节点、跨课程累计**:本节课攒的与其他开口课程攒的**合并进同一进度**,**未攒满时保留**,下次遇到开口课程继续累积;**进度展示在首页左下角的扭蛋处**。

### 2. 结算与扭蛋

- **达标即开**:在涉及开口的课程里跟读**达到本轮门槛 N** → **该课完课后直接开扭蛋**。
- **未达标即攒**:完课时进度 **< N** → **不开扭蛋**,把当前进度记录在**首页左下角入口(`x/N`)**,直到**下次再遇到开口课程时继续累积**,攒够后**在那次完课后开**。
- **开扭蛋交互**:完课结算页展示**扭蛋机** → 用户点击 → **开扭蛋动效** → **展示掉落奖励** → **领取**。
- **同一次完课最多开 1 次扭蛋**。
- **2 次扭蛋开出 2 个家具**(奖励内容)。

|---|---|---|
| 第 1 轮 | **Hello 课** | **3** |
| 第 2 轮 | **Color 课** | **4** |
| **第 3 轮起** | — | **固定 5(封顶)** |

- 📌 正文只写了「Hello 课开口 3 次开扭蛋、color 课 4 次开扭蛋」,**「第 3 轮起固定 5」只在流程图里** —— 这是本篇最容易漏掉的规则。

### 4. 完整状态机(流程图 img-01)

```
首页开口奖励入口(显示当前进度 x/N)
   ↓ Go · 进课
进入开口课程(全 Level / 全 Unit)
   ↓
跟读环节出声开口(每通过 1 次 +1)
   ↓
完课时 进度 ≥ N?
   ├── 达标 ≥N → 完课后开扭蛋 → 掉落奖励·领取 → 进度清零,进入下一轮 ──┐
   └── 未达标 → 存首页,下次继续攒 ───────────────────────────────┘(循环)
```

- **达标后进度清零并进入下一轮**(门槛按序列递增)。

### 5. 测试重点(由规则推导)

- **星星的两条计数路径**:手动点击 vs **2s 后自动飞入** —— 两条都要 +1 且只 +1;**在 2s 内点击**不能重复计数。
- **跨课程累计**:Hello 课攒 2 次 → 退出 → 进 Color 课再攒 1 次 → 达到 N=3 时,**是在 Color 课完课后开扭蛋**(门槛按"轮次"而非按课程走)。
- ⚠️ **门槛归属存在歧义(已入待确认)**:门槛序列写「第 1 轮 Hello 课 N=3、第 2 轮 Color 课 N=4」,把**轮次与具体课程绑定**;但累计规则是**跨课程**的。若用户第 1 轮没在 Hello 课攒够、跑去 Color 课攒满,**这一轮算 N=3 还是 N=4**,文档未说明。
- **判定未通过不计数**,与跟读打分星级挂钩 —— **几星算"通过"未定义**(V1.35 故事书篇是 2/3 星通过)。
- **同一次完课最多开 1 次扭蛋**:若一次完课的进度**超过 N 很多**(如攒了 8 次、N=3),多余次数如何处理(顺延到下一轮 or 丢弃)未说明。
