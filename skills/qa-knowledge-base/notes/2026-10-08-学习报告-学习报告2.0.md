## 摘要
学习报告整体重做，目标是「**家长能看到孩子阶段性收获**」并作为**私域召回抓手**：入口 = **家长中心（不变）+ 学习中心新增入口**，默认进**横版总结页**（头像形象 + **当前 Level 单词点亮圆环** + **Word Progress 四阶段词数** + **Extra Learning：绘本 / 小麦对话 / 磨耳朵**），点 `View Full Report` 进**竖版完整报告（Daily / Weekly 双 Tab，默认日报）**：日报 = **高光时刻（5 级优先级取 1）+ Word Progress + Learning Progress（unit 进度）+ Extra Learning Progress（Storybooks / Speaking Practice / Listening）+ Next Theme**；周报按**孩子账号所属地区时区的周一 00:00 切周、独立按周事件聚合（不是 7 天日报相加，绘本 / 专辑跨天去重）**，Word Progress 显示**较上周 `+d`**。另有**单词库（Explore My Words）、跟读绘本卡片、unit 状态弹窗、报告分享（二维码可看分享当日 / 当周报告）**，以及**老用户升级弹窗 + 底部 `View Old Report`**。数据口径强依赖同版本《单词书1.0》的四阶段；**周期类数据只从新版上线日开始生成**。站外 H5 链接**暂时不做**。

## 功能信息（逻辑 / 状态 / 边界 / 字段）

### 基本信息
- 产品：**Leah**；UI：figma `1.40.0` node `60117-3567`；完整 demo：`Giggle_学习报告_全新设计_20260909.html`（附件，未抓取）。
- 头部核心：**本周的 Highlight 表现 + 汇总学习数据**；重点功能：**词汇掌握、口语录音、小麦、绘本、磨耳朵**。
- 数据指标：**功能的留存、使用频次；看过学习报告用户的次周留存**。
- 关联：《学习中心修改样式 + 单词书1.0》（四阶段口径、单词书、`View Words` 跳转目标）；外链文档《**学习报告埋点**》《**分享文案**》均**未入库**。

### 1. 报告入口
- **家长中心入口不变**，点击进入。
- **学习中心新增学习报告入口**（单词书那篇的 `Learning report` 卡片），点击进入**横版总结页**。

### 2. 横版总结页（All-time overview）
- 从外部入口点【学习报告】**默认进这一页**；页面**左右滑动**，从左至右：**人物形象 → 单词圆环 → 单词进度 → 拓展学习**。
- **`View Words` → 当前 Level 的单词书**；**`View Full Report` → 完整报告，默认选中日报**。
- 字段：
  - **用户昵称**：从用户中心读**当前孩子最新的昵称**；**用户形象**：读当前 Avatar；**用户级别**：当前主路径级别。
  - **单词进度圆环**：进度 = **当前 Level 已点亮（达到 Heard）词数 / 当前 Level 所有词数**；
    - 顶部文案：`{n} words lit up！{m} words said independently`（n = 当前 Level Heard 词数，m = 当前 Level Said 词数）；**m 和 n 为 0 时不展示此文案**（⚠️ 原文未说清是「都为 0」还是「任一为 0」）；
    - 中间：`{Heard 数} / {总数}` + `Lv {X} words`。
  - **Word Progress**：**用户已学所有 Level** 的词汇数据，从单词书读 Heard / Understood / Repeat / Said 各阶段词数（图上标 `All level`）。
  - **Extra Learning**：
    - Storybook：`{x} books read，{y} books recorded`（x = **今日**阅读绘本数，y = **今日**开口跟读绘本数）；
    - Speaking：`{z} chats with Mai` = **和小 Mai 的对话次数 + Mtown 的对话总次数**；
    - Listening：n = **今天使用 Giggle TV、Giggle Cast 的时间**（**< 100 min 显示 min；> 100 min 显示 `X h Y min`**，⚠️ 恰好 100 min 未定义）；m = 今日听过的专辑数量；
    - **3 个模块都无数据 → 右侧显示 `No data yet`**。
  - ⚠️ 横版页标题是「All-time overview」，但 Extra Learning 的口径全是「**今日**」，混合口径需确认。
- **缺省状态**：
  - **未学主线课程、但学了绘本 / Speaking / Listening** → **左侧圆环和 Word Progress 隐藏**，展示缺省页，文案 `Hi [Name], your report starts after Lesson 1.`；右侧照常展示 Extra Learning 数据。
  - **未学习任何内容** → 固定一张静态图，文案 `Hi [Name], nothing here yet — Lesson 1 starts your report.`。
  - ⚠️ 缺省原型图（img-05）上写的是中文「hi, Rara 你还没有开始学习课程」+ `Let's Go` 按钮，与正文英文文案、且正文未提 `Let's Go` 按钮，不一致。

### 3. 日报（Daily）
- 交互：**Daily / Weekly Tab，默认 Daily**；**分享 → 分享当前选中的报告，生成学习报告小图**；点日期 → 展开日历选择器。
- **高光时刻【需本地化】**：按优先级取最高的一条，**都不命中则不展示此模块**（⚠️ 但下面又给了「通用兜底（无高光时）」文案，二者矛盾）：
| 优先级 | 条件 | 标题（两行） | 详情条 | 播放键 |
|---|---|---|---|---|
| **1** | **今日新增 Said ≥ 1** | `Said` / `{n} words solo!` | 🗣 今日新增 Said 的词，**最多 3 个，多出 `+{k} more`** | **有：播孩子说这几个词的录音，顺序播；点单个词只播那个** |
| **2** | **今日新增 Heard（点亮）≥ 1** | `Lit up` / `{n} core words!` | 🗣 今日新增点亮的词，最多 3 个，多出 `+{k} more` | **有：播标准发音（点亮 = Heard，没有孩子录音）** |
| **3** | **今日完成跟读绘本 ≥ 1** | `Finished` / `reading {n} books!` | 📖 第一本封面 + 书名；**n > 1 时书名后接 `+{n-1} more`** | **有：播该本孩子的跟读录音** |
| **4** | **今日完成 Unit ≥ 1** | `Completed` / `{n} units!` | 🏅 Unit 名，**最多 2 个**，多出 `+{k} more` | 无 |
| **5** | **今日完课 ≥ 1** | `Completed` / `{n} lessons!` | 🐰 课程名，最多 3 个，多出 `+{k} more` | 无 |
  - 通用兜底：`{Name} showed up for English today.`（今天又学英语了）/ `Week {n} with Giggle. Still going!`（跟 Giggle 学的第 {n} 周）。
  - ⚠️ 日报原型（img-06）高光写的是 **`Can say 2 Words now!`** + 播放一句 **"This is my father."**（句子而非单词），与优先级 1 的 `{n} words solo!` 文案不一致。
- **Word Progress【需本地化】**：**截止目前**，从单词书读四阶段词数（图上每项带 `+n` 增量，日报的增量口径原文未写）。
- **Learning Progress【需本地化】**：
  - 当前级别 = **截止报告生成当日**的主路径级别；**跨级别展示当前最新的首页等级**；
  - 课程进度 = **当前级别已完成 unit 数 / 当前级别 unit 总数**；
  - 示意 4 个 unit：**最新完成的 2 个 + 1 个进行中 + 1 个即将开始**；**没有最新完成或没有即将开始的，展示另外 2 条**；按状态展示已完成 / 进行中 / 未开始。
- **Extra Learning Progress【需本地化】**：
  - 汇总：`{a} books, {b} chats, {c} min Listening time`（a = 当日阅读 + 跟读绘本数，**需要去重**；b = 小 Mai 对话次数 + Mtown 对话次数；c = 今日 Giggle TV + Giggle Cast 时长，min / `X h Y min` 规则同上）；
  - **Storybooks**：① `{x} books read，{y} books recorded`；② **今日跟读绘本：左右滑动，展示得分最高的 3 本**；③ **今日阅读绘本：时间倒序，最多 3 条**；④ **阅读或跟读为 0 → 不展示对应总结句和模块；两者都为 0 → 不展示 Storybooks**；
  - **Speaking Practice**：① `{z} English chats with Mai`，z = **和小麦英文对话的开口次数（只记英文）+ M town 英文开口次数**；② 句子 = **M town 用户开口的英语句子，得分最高 3 条**（**pending：确认是否打分**）；③ **只有小麦对话、没有 M town → 不展示句子，只展示固定文案**；
  - **Listening**：`{n} minutes · {m} activities`（n = 今日 Giggle TV / Cast 时长，m = 今日听过的专辑数）；
  - ⚠️ 「chats」口径前后不一：横版页 / 汇总写「**对话次数**」，Speaking Practice 写「**英文开口次数**」。
- **Next Theme**：`Let's Explore {theme}` —— 推荐学习 unit 的主题名 + 核心单词。
- **切换日历**：**今日之后的日期不可点**；**日历起点 = 第一条学习记录产生的日期**；**老用户日历起点 = 从上线时刻开始**。
- **无数据**：本日 / 本周无任何学习数据样式一致；**头部和周选择器保留**；正文缺省图 + `No learning data for this day.` / `No learning data for this week.`。

### 4. 周报（Weekly）
- 交互：**切 Weekly 默认展示本周（进行中）**；分享同日报；**`<` `>` 切上周 / 下周；最早一周、最晚一周时对应按钮置灰**。
- **周期：周一 00:00 — 下周一 00:00，用孩子账号所属地区的时区**；**本周进行中每次打开重算；周一 00:00 冻结为上周周报**。
- **周报独立按本周事件聚合，不是 7 天日报相加 —— 绘本、专辑要跨天去重**。
- **本周进展（周报头部，替代日报高光时刻）**：标题优先级 ① **本周首次完成 Unit ≥ 1：`Completed {n} units this week`**；② **无新完成 Unit：`Learning "{unit}"`**（正在学的 unit 名）。
  - **阶段台阶**：当前级别映射三段 **L1–L2（Discover）/ L3–L5（Build）/ L6 起（Express）**，当前阶段高亮，**台阶不可点**。
  - 课程进度 = 当前级别学到的 unit 数 / 总 unit 数；**Unit 示意规则同日报（最新完成 2 + 进行中 1 + 即将开始 1）**。
  - ⚠️ 周报原型（img-15）头部写的是 **`This Week · Said 2 Words solo!`**，不是正文规定的 `Completed {n} units this week` / `Learning "{unit}"`。
- **Word Progress**：**截止本周末（进行中则截止现在）**的四阶段词数；每项下方展示**较上周变化**：有变化 `+{d}`；**持平和无上周数据不展示**；**上周值取上周周报冻结后的数字**。
- **Weekly Progress 汇总**：`{d} / 7 days   {n} books   {c} min Listening time`
  - d = **本周有任一学习行为（主课、绘本、Speaking、Listening）的自然日数，按报告时区切日**；n = 本周阅读 + 跟读绘本数（去重）；c = 本周 Giggle TV / Cast 时长。
  - ⚠️ 原型第三项写的是「**Learning time**」，正文是「Listening time」。
  - **Storybooks**：`{x} books read, {y} books recorded`（**各自去重**）；**本周跟读绘本：得分最高 3 本，同一本多次跟读取最高分那次**；**本周阅读绘本：按最近阅读时间倒序最多 3 条；同一本既阅读又跟读只出现在跟读列表**；为 0 不展示规则同日报。
  - **Speaking Practice**：`{z} chats with Mai`，z = 本周小麦**英文**开口次数 + M town 开口次数；句子 = 本周 M town 英语句子最高分 3 条；只有小麦对话不展示句子。
  - **Listening**：`{n} minutes · {m} activities`（m = 本周听过的专辑数，**去重**）。
  - **三个模块都无数据 → 不展示 Extra Learning Progress**。
- **Next Week's Theme**：`Let's Explore {theme}`；展示**推荐 unit（下一个 unit）的核心单词**；**已到当前级别最后一个 unit → 取下一级别第一个**；**无可取则不展示**。

### 5. 通用组件
- **单词库（Explore My Words）**：日报 / 周报点击进入 `Word Book` 页；**默认选中 Heard**，Tab 切换四状态；展示用户所有单词库中各状态的词；**按单词达成该状态的时间升序**。
- **跟读绘本卡片**：点跟读绘本弹窗展示**封面、书名、作者名、跟读得星、播放按钮**；**用户未上传语音等情况不展示播放按钮和得星**。
- **unit 状态**：点课程进度中的 unit 查看状态 —— **已完成：unit 卡片 / 名称 / Level 和 unit / 已完成状态 / 任务勋章**；**学习中：… / 学习中状态 / unit 进度**；**未开始：原文写的也是「学习中状态、unit 进度」**（⚠️ 疑似复制粘贴未改）。
- **报告分享**：页面**右上角分享，顶部固定吸顶**；分享**当前选中页面**的信息；**分享渠道复用目前**（图上：Messenger / TikTok / Wechat / Moments / WhatsApp / Fa… + Save / Copy link / More）；
  - **扫卡片二维码可查看用户完整学习报告，展示报告名称和时间，不可切换时间，只能看分享当日 / 当周**；
  - **分享文案按不同高光时刻从《分享文案》文档随机取一条，支持用户刷新切换**。
- **站外访问学习报告 H5 —— 暂时不做**（设想：H5 单独发，访问进登录页，登录后网页看报告；浏览器有登录 token 可直接访问）。

### 6. 旧版学习报告升级
- 升级后进入新学习报告；**老用户同时满足 2 个条件**才看到升级弹窗：① **此版本发布前注册的 uid（游客 + 正式）**；② **uid 有超过 1 个 unit 的学习记录**。
- 弹窗：`Learning Report upgraded!` —— 1. New data goes into the new report. 2. Your old report stays at the bottom, but won't update. —— **点 `Got it` 关闭**；**每个 kid 推一次**。
- 新报告底部一行小字 **`View Old Report`** → 进入旧版学习报告页面（⚠️ 原文未说新用户 / 不满足条件的老用户是否也有此入口）。

### 7. 历史数据处理规则
- **累计类数据老用户完整（单词书需求需要统一刷数据）**：
  1. **Word Progress 四阶段、点亮数、课程进度、累计绘本数**等各模块的当前值**与上线时间无关**；**基于老用户完成的级别，直接判断已完成 unit 之前所有单词的状态**；**首次进新版横版总结页即有完整数据**；
  2. 横版总结页：**绘本 read 和 record 每日量需要刷数据**；
  3. **小麦数据、Giggle TV 和 Giggle song：待 @cris 确认后补充**（⚠️ 未定）。
- **周期类数据只从上线日开始**：**日报、周报、高光时刻、Extra Learning Progress 只对新版上线日及之后生成**；**日历和周选择器起点 = max(第一条学习记录日期, 新版上线日)**。
- **上线后第一周无「较上周」**：Word Progress 不展示对比增加数据。

### ⚠️ 测试关注 / 缺口
- **时区与切周**：周报按孩子账号所属地区时区切周，周一 00:00 冻结；跨时区账号、进行中周每次重算、冻结后的上周值作为 `+d` 基准。
- **去重矩阵**：绘本「阅读 + 跟读」同一本只进跟读列表；周报绘本 / 专辑跨天去重；同一本多次跟读取最高分。
- **老用户数据回刷**：按完成级别反推已完成 unit 之前所有单词状态 —— 与《单词书1.0》四阶段推导规则联动回归；首次进入即有完整数据。
- **多处原型与正文不一致**：高光文案（`Can say … now!` vs `{n} words solo!`）、周报头部（`Said 2 Words solo!` vs unit 进展）、`Learning time` vs `Listening time`、缺省页中英文案、「无高光不展示」vs「通用兜底」。
- **单词库四阶段说明文案（img-16）**：「自己说 = **没有跟读示范，也能自己说出**」，与《单词书1.0》内嵌表「Said = **跟读 3 次后点亮**」口径不同，需对齐。
- **埋点**：本篇无埋点表，指向《学习报告埋点》（wiki `VvCMwFKpMio728k9wuRlaAO0gPK`，未入库）；分享文案在《分享文案》（`OA27w29UciOZilkUVnnlX7pKgyO`，未入库）。
