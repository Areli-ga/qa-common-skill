## 摘要

V1.37.0 给课程游戏模板新增标准字段组件 **WordDisplayMode（单词呈现方式）**：**仅图片 / 仅单词名 / 图文随机混用**，**作用于该模板内全部词槽、一节课一个值**；主题侧只勾选「有没有这个字段」，取值在课程配置页单选，**默认值与抽签算法写死在端上包内**；同时联动词卡「原画图片」的必填态、加 Generate 前置校验（缺图阻断），打包 JSON 新增 `word_display` 节点。

## 功能信息（逻辑 / 状态 / 边界 / 字段）

### 0. 基本信息

- 产品 Owner：**Cloud**；优先级：中；文档「版本号」字段 **v1.37.0**（与主人给定一致）。
- ⚠️ **修订记录是模板占位 `2026-mm-dd:`**（未填）；**资源列表 4 项（UI 设计稿 / 动画文件 / 声音文件 / 其他资源）全部为空**；**「主要特性」章节也是空的**。
- 老需求文档：《Lv10 课程游戏模板》。

### 1. 需求背景

- 以前的游戏模板课程中**单词都会展示单词图片**；但随着**等级的上升**，有些课程会让这些单词**仅展示单词名**，或者**部分展示单词名、部分展示单词图片（随机）**。
- 所以课程游戏模板需要新增一个模板配置字段，控制这个模板内的**目标单词、干扰词、起始词**的展示模式（展示单词图片 / 单词名 / 随机混用）。

### 2. 产品目标

1. 给**字段组件库**新增标准组件 **`WordDisplayMode`（单词呈现方式）**：仅图片 / 仅单词名 / 图文随机混用，**作用于该模板内全部词槽**。
2. **模板参数配置项（admin）**：只勾选「**这个主题有没有这个字段**」（同 `PlayMode` 等既有组件），**不在此配置任何取值**。
3. **课程游戏模板配置（admin）**：**单选一个值**（仅图片 / 仅单词名 / 图文随机混用）→ **落库、随课程包下发**。
4. **端上包内常量**：`WordDisplayMode` 默认值、**文字卡样式**、**单词图文展示抽签算法**、**字号策略**。

### 3. 需求范围

| # | 模块 | 说明 | 状态 |
|---|---|---|---|
| 1 | **admin** | ① 游戏模板管理：字段组件库新增 `WordDisplayMode` 组件，**只有勾选与是否必填**；② 课程游戏模板配置：模板配置该字段时新增下拉单选（三选一）；**联动词卡面板内「原画图片」的必填态**；**Generate 前置校验（缺图阻断）**；③ 课程包打包：**JSON 新增 `word_display` 节点** | **本期需求** |
| 2 | **Unity** | 包内常量：默认值 / **各主题文字卡样式** / **`image_ratio`** / 抽签算法 / 字号策略；文字卡渲染（**字号自适应**） | **随课程制作** |

### 4. 路径一：Admin → Lesson Series → 课程游戏模板管理

- 新增字段 **`WordDisplayMode`**：
  - **下拉单选，作用于参数组外，一节课一个值**；
  - **此处不配置可选项、不配置默认值** —— 取值在课程配置里选，**默认值写在端上包内**；
  - **勾选** → 课程游戏模板配置展示该下拉单选项；
  - **不勾选** → 不展示此选项，**端上走包内默认值**。
- 界面补充（图 1「编辑主题配置」）：主题 ID `GameTemplate_Switcheroo`、主题名称 `Switcheroo`、模板 `T04 单词变体 (course_template_04)`、`YooAssetPackageName` = `SingleAssemblyPackage01`、`YooAssetTagName` = `Switcheroo`。**字段组件库**共 5 项：

| # | 组件 | 归属 | 类型 | 必填 |
|---|---|---|---|---|
| #1 | Target Words（目标单词） | 组内 | `word_multi_select` | ✅ |
| #2 | Distractor Words（干扰词） | 组内 | `word_multi_select` | — |
| #3 | Starting Word（起始词，题干位） | 组内 | `word_multi_select` | — |
| #4 | Play Mode（播放模式，顺序/随机出现） | **独立** | `single_select` | — |
| **#5** | **Word Display Mode（单词呈现方式）【本次新增】** | **独立** | `single_select` | ✅ |

- 组件说明原文：**控制本模板内所有词槽（目标单词 / 干扰词 / 起始词 / **场景全量词库**）的呈现形态。取值在「课程配置」页选；**可选项、默认值、文字卡样式由端上包内写死，此处不配置**。**

### 5. 路径二：Admin → CoursesList → 具体课程 → Configure → Course Template

- 模板配置了 `WordDisplayMode` 字段时，新增该组件展示：**下拉单选，值 = 仅图片 / 仅单词名 / 图文随机混用**。
- **展示在配置组外、最顶部设置（与 playmode 同级）；它决定了下面所有词卡面板的必填态。**
- **联动词卡面板内「美术资源」的必填态**，规则如下：

| 主字段取值 | 词卡面板内「原画图片」 | Spine（闲置态、激活态） | 切换时的既有数据 |
|---|---|---|---|
| **`IMAGE_ONLY` 仅图片** | **必填** | 选填 | — |
| **`MIXED` 图文随机混用** | **必填** | 选填 | — |
| **`TEXT_ONLY` 仅单词名** | **选填** | 选填 | **不清空，仅放宽校验** |

- 界面补充（图 2「Course Template Configuration」）：
  - 三步向导：**① 模板与主题（✓）→ ② 参数配置 → ③ 生成与发布**；
  - 「当前主题字段结构」区：**每组字段**＝目标单词（必填）/ 干扰词 / 起始词；**独立字段**＝播放模式 / **单词呈现方式（NEW）**；
  - 「独立字段」区标注 **「作用于整节课 · 不随配置组复制」**；
  - 「单词呈现方式」下拉当前值 `仅图片`，下方说明：**「所有词以美术资源（原画）呈现 —— 等于今天的行为。作用于本课全部词槽；同屏候选项必须同源，故不按角色分开配置。」**
  - 「播放模式」说明：控制配置组的触发顺序（**既有字段，本次不改**）；
  - 配置组 A 的目标单词卡片字段：**美术资源\*** / Spine 资源 / **默认读音\*** / 特殊读音 / 音效（示例词 `ID-789303802252293 pot`，美术资源 `pot.png`）。

### 6. 统一传参 JSON 增量

1. **新增单词文本**（可能现在已经传了）：**打包时从词库取的 `lemma` 快照**。
2. **新增 `WordDisplayMode` 传参**：若从后台获取到游戏模板配置参数，则**根据本字段配置决定游戏模板内单词的展示形式**。
- 打包节点名：**`word_display`**（见需求范围表）。

### 7. 后续（Unity 与产品对齐包内参数）

包含 **`WordDisplayMode` 默认值**（仅图片 / 仅单词名 / 图文随机混用）、**文字卡样式**、**单词图文展示抽签算法**、**字号策略**等逻辑。

### 8. 待确认项

1. **命名三处不统一**：正文用中文「仅图片 / 仅单词名 / 图文随机混用」，联动规则表用 **`IMAGE_ONLY` / `MIXED` / `TEXT_ONLY`**，打包节点叫 **`word_display`** 而组件叫 **`WordDisplayMode`**。落库枚举值、JSON key、端上常量名需一次性对齐。
2. **「图文随机混用」的抽签算法写死在端上包内、Admin 不可配**：`image_ratio` 是**每个主题一个值**还是全局一个值？**QA 如何验证随机分布**（没有 Admin 入口、没有埋点、没有可复现的种子）—— 这是本篇最难测的点。
3. **`MIXED` 下「原画图片必填」与需求初衷可能矛盾**：混用模式要求每个词都配图（即使部分词最终只显示文字），是刻意为之（保证抽签任意结果都有资源）还是可放宽，需确认。
4. **`TEXT_ONLY` 切换「不清空，仅放宽校验」的反向切换未定义**：从 `TEXT_ONLY` 切回 `IMAGE_ONLY` / `MIXED` 时，历史上缺图的词卡会被 Generate 阻断 —— 是否有**批量提示 / 缺图清单 / 定位跳转**？
5. **「同屏候选项必须同源，故不按角色分开配置」与背景描述冲突**：背景写「控制**目标单词、干扰词、起始词**的展示模式」，实际实现是**一课一值、不按角色分开** —— 背景描述是否过时需确认（影响用例设计粒度）。
6. **`image_ratio` 全文只在需求范围表里出现一次**，正文无任何定义（取值范围、默认值、是否可按主题覆盖）。
7. **「场景全量词库」只在图 1 的组件说明里出现**，正文作用范围只写了目标单词/干扰词/起始词三类 —— 第四类词槽是否也受控。
8. **Generate 前置校验「缺图阻断」的提示形态未定义**：阻断在哪一步（保存 / Generate / 发布）、错误文案、能否定位到具体词卡。
9. **`lemma` 快照的必要性与冲突处理**：「可能现在已经传了」需与后端确认；**`lemma` 与词卡显示名不一致时以哪个渲染**（文字卡显示的是 lemma 还是配置名）。
10. **不勾选该字段时「端上走包内默认值」，但默认值当前是什么没写** —— 若默认不是「仅图片」，会改变所有存量课程的表现。
11. **Unity 侧标注「随课程制作」而非本期**：本期只交付 Admin 配置 + 打包，**端上渲染（文字卡样式、字号自适应、抽签）何时可测**需确认，否则本期只能测到 JSON 产物。
12. **全篇无数据埋点、无验收标准**；也没有文字卡在超长单词 / 多语言（中文课）下的字号与截断规则。
