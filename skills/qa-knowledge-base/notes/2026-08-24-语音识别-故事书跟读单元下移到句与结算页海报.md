## 摘要

V1.37.0 把故事书跟读的**基本单元从「图页」下移到「句」** —— 因为新内容会出现「同一图页两个音色（角色 + 旁白）」和「同一图页多句正文」，按页模型会直接坏掉（领读播哪段、录音评哪句、存哪个 key、封面回放播哪条、星级怎么算全部失效）；同时**结算页新增同系列下一本推荐位**（仅故事书模块入口，路径入口不动）解决「读完就退出」的断头路，并把分享海报从「品牌海报」改成**孩子的「跟读作品卡」**（书封 + 谁读的 + 成就 + 语义化二维码「扫码听 TA 读的这本书」）。

> 本篇是 V1.35《故事书跟读组件优化》的直接续作，正文多处引用并沿用 1.35.0 的逻辑；同时跨到**故事书**模块（结算页 / 分享）。

### 0. 基本信息

- 产品 Owner：**Cloud**；**优先级：高**；文档「版本号」字段 **v1.37.0**（与主人给定一致）。
- UI 设计稿：Figma `1.37.0` node-id=47024-15183。
- ⚠️ **修订记录是模板占位 `2026-mm-dd:`**；**「主要特性」章节为空**；资源列表中**动画文件 / 声音文件 / 其他资源均为空**。

### 1. 需求背景（三个问题）

1. **结算页是断头路**：跟读完一本书，结算页只有整本星级 + 可回放用户录音 + 分享 + 退出，**没有「下一步读什么」**。普通故事书结算页已有推荐位（Libin 设计，默认推荐下一本故事书），**跟读模式没有跟上**。结果：孩子读完一本就退出，**单次会话只消费 1 本**，刚建立的跟读节奏断在结算页。
2. **分享海报体现不出「这是孩子的作品」**：跟读版故事书分享沿用 App 通用分享组件，**分享出去的东西看起来像一条 App 广告**。
3. **故事书内容形态升级（本期改造的根因）**：过去跟读版故事书是**特意挑选的精简本** —— 一个图页只有一个音色、只有一句短句，所以「**跟读单元 = 图页**」这个隐含假设一直成立。接下来的内容会出现：
   - **同一图页两个音色**（典型是 1 个角色语音 + 旁白语音）→ 同页两段音频；
   - **同一图页多句正文**。
   - 在现有按页模型下会**直接坏掉**：一页两段音频无法确定**领读播哪一段、录音评的是哪一句、录音存到哪个 key、封面回放播哪一条、星级怎么算、进度怎么显示**。→ **跟读单元必须从图页下移到句。**

### 2. 产品目标

1. **跟读单元改为句**：按句推进，同图页多句时「下一步」**只切句、不换图画**；整本星级、跟读进度与统计改为「**已跟读句 / 总可跟读句**」。
2. **结算页对齐普通故事书**：新增推荐位（沿用 Libin 的普通故事书结算页设计）。**仅「故事书模块」入口展示，且只推当前书所属系列的下一本**；**路径入口结算页保持现状不动**。
3. **分享物从「品牌海报」改成「作品卡」**：卡面主体 = **书封 + 谁读的 + 成就 + 语义化二维码「扫码听 TA 读的这本书」**。

### 3. 跟读单元从「图页」改为「句」

**3.1 维度更新**
- 故事书跟读组件的**翻页 / 统计判断颗粒度**从「图页」改为「句」，需按句拆分。
- **进入跟读模式时一次性构建「可跟读句序列」**（进入时先剔除不需要跟读的部分，只是粒度由页改为句）；**后续所有推进、进度、分母、星级、封面回放都基于这个序列**。

**3.2 页面呈现（同图页多句）**
- **整页正文常驻显示**，用状态区分句：

| 状态 | 表现 |
|---|---|
| **当前句** | 高亮激活（**放大 / 加深 / 底色均可**），**领读时逐词卡拉 OK 高亮** |
| **已通过句** | 弱化 + 已完成状态 |
| **未到 / 已跳过句** | 灰化 |

- 设计稿状态序列（图 2，句 1 三态 → 句 2 三态）：领读态（喇叭 + 黄色图标）→ 录音态（绿色环 + 方块停止键）→ **通过态（绿色对勾 + 3 颗星 + 单词染色**，如 `This` 蓝 / `is` 粉 / `a runner` 绿）；进入句 2 后，句 1 整体转为绿色弱化态。

**3.3 推进与翻页键**
- 「下一步」按钮保持**同一个按钮、同一个位置、同一个图标**，行为统一为「**推进到下一个可跟读句**」：
  - **下一句在当前图页** → **只切句，不换图画、不播翻页动效**（改用**句高亮转移 + 淡入上浮**）；
  - **下一句在下一图页** → 换图页 + 走原有翻页动效。
- 「上一步」同理 = 回到上一个可跟读句：
  - **回到已通过的句：不自动领读、不自动录音**（沿用 1.35.0）；
  - **回到未通过 / 未录的句：自动走领读 → 自动录音**。
- **1.35.0 失败兜底的高亮对象 = 这同一个按钮**（第 2 次失败后高亮，语义为「跳过这句往下走」）；⚠️ **同页切句场景也要能高亮**（不因为不换图页就不高亮）。
- **录音中点击「下一步」**：沿用旧逻辑 —— **自动结束录音并取评分记录到当前句**，然后推进。
- **最后一个可跟读句通过 → 不再推进，进入完课结算页**（判定从「最后一页」改为「最后一句」）。若该句之后还有**纯插图页 / 非跟读页**，**不强制孩子翻完，但允许手动继续翻看**（结算页可从末页手动进入，沿用现有口径）。

**3.4 统计与进度口径**

| 口径 | 定义 |
|---|---|
| **总可跟读句（分母）** | 进入时构建的可跟读句序列长度 |
| **已通过句** | 判定通过（有成功录音）的句数 |
| **已推进句** | 已经走过的句数（**含失败跳过**） |
| **已尝试句** | **有有效发声但未通过** |

- 跟读中的进度显示：由「**第 3 页 / 共 8 页**」改为「**{已跟读} / {总可跟读句}**」（如 `3 / 12`）。
- **整本评星：算法粒度下移，公式不变**。
- **单句星级算法（单词绿/红 → 句得分 → 星级区间）完全沿用旧逻辑，不改。**

**3.5 录音留存与封面回放（粒度下移）**
- **每句仅保留最终通过那一次的成功录音**（原为每页）；**未通过句不留录音**。
- **重复跟读同一句**（往回翻再读通过）→ **覆盖为最新成功版**。
- **封面回放**：按可跟读句顺序**连播各句成功录音，未成功的句直接跳过**（原为「未录页跳过」）。
- **封面可播放态判定：≥1 句成功录音**（原为 ≥1 页）。

**新旧口径对照表（原文完整给出，逐条都是回归点）**

| 原口径（页） | 新口径（句） |
|---|---|
| 仅跟读「同时有音频且有文字」的**页**，其余剔除 | 仅跟读「同时有音频且有文字」的**句**，其余**不计入分母（页仍可展示）** |
| 所有需跟读页的星级平均、四舍五入，未跟读页算 0 | 所有可跟读**句**的星级平均、四舍五入，**未通过句算 0** |
| 录音中点下一页 → 结束录音、评分记到该页 | 录音中点下一步 → 结束录音、评分记到该**句** |
| 翻到跟读页自动领读 → 自动录音 | 进入每个可跟读**句**自动领读 → 自动录音（**同页切句同样触发**） |
| 每页仅保留最终通过的成功录音 | 每**句**仅保留最终通过的成功录音 |
| 同页失败 ≥2 次 → 翻页键高亮 | **同句**失败 ≥2 次 → 「下一步」键高亮 |
| 通过后自动翻页 | 通过后自动推进（**同页只切句、不换图画、不播翻页动效**） |
| 封面回放按页连播、未录页跳过、≥1 页成功录音可播 | 封面回放按**句**连播、未成功句跳过、≥1 句成功录音可播；**同页句间 0.2s / 跨页 0.4s** |
| 前导静音裁剪 optional | **建议提为 P1**（句数变多，连播静音累积更明显） |
| 第 N 页 / 共 M 页 | **已跟读句 / 总可跟读句** |
| `page` / 页码 | **`sentence_id` + `sentence_index`**（v1.24.0 埋点 `sentence_record` 已有 `sentence_id`，**数据侧本就是句维度，本次是产品呈现与统计对齐数据**） |

### 7. 验收标准（原文完整给出，可直接转用例）

**按句跟读**
1. 同图页多句故事书可正常跟读：**逐句领读 → 自动录音 → 判定 → 推进**；**同页切句不换图画、不播翻页动效**。
2. **同页两个音色各自播放自己的音频**；当前句高亮、**已通过句打勾**、未到句灰化，**整页正文常驻可读**。
3. 「下一步」键在**同页切句场景同样可用、失败 2 次后同样高亮**；**录音中点击 = 结束录音并把评分记到当前句**。
4. 跟读进度显示为 **已跟读句 / 总可跟读句**；整本星级 = **可跟读句星级平均四舍五入（未通过句算 0）**。
5. **录音按句留存**（每句仅存最终通过版）；**封面回放按句连播、未成功句跳过、≥1 句成功录音即可播**。
6. **存量单句页故事书行为与现状完全一致（零回归）。**
7. **最后一个可跟读句通过后进入完课结算页。**

**结算页**
8. 从**故事书模块**进入时，结算页出现推荐位，且内容为**当前书所属系列的下一本**；**系列最后一本 / 无系列 / 下一本不可用时整体不渲染且布局无空洞**。
9. **推荐位视觉权重低于封面回放；无跳动 / 闪烁动效；不自动跳转。**
10. 从**课程路径**进入时，展示**无推荐位**新版结算页。
11. **点推荐位可直接进入系列下一本的跟读模式，不再二次选模式。**

**海报**
12. 新版海报更新。

### 8. 待确认项

1. **与同版本《故事书使用方式引导和 gigglecast 升级》直接冲突（最高优先级）**：本篇验收标准第 11 条要求「点推荐位**直接进入下一本的跟读模式，不再二次选模式**」，而那篇要求「**用户每次打开故事书都可以唤起模式选择组件**」「Ending Page 点击封面或重播 → 回到上一本书的入口页模式选择、**下一本书播放时进入模式选择**」。两篇是同一版本、同一入口，必须先对齐。
2. **音色与句的绑定关系没定义**：验收标准写「同页两个音色**各自播放自己的音频**」，但正文只说「按句拆分」—— **一句对应一个音色**，还是一句可能跨音色？角色语音与旁白语音在同一句里如何处理，未写。
3. **录音存储 key 的迁移未说明**：从页 key 改为句 key，而验收又要求**存量单句页故事书「零回归」** —— 存量按页存的录音如何兼容/迁移（封面回放要能播到旧录音）。
4. **「可跟读句序列」一次性构建的稳定性**：会话中若发生资源热更、句子内容变更，序列是否重建？**同一本书两次进入的序列是否稳定**（直接影响录音 key 与封面回放顺序）。
5. **口径表里没有「已跟读句」这一项**，但进度公式写的是 `{已跟读} / {总可跟读句}` —— 「已跟读」到底等于**已通过句**还是**已推进句**？（两者在有失败跳过时数值不同，直接影响进度条表现。）
6. **「已推进句」「已尝试句」定义了却没说用在哪**（进度用「已跟读」、星级用「已通过」），是预留还是遗漏。
7. **前导静音裁剪第二次悬空**：V1.35 篇标注「可选、可后置」，本篇写「**建议提为 P1**」但仍未拍板 —— 句数变多后连播静音累积更明显，本期做不做需定。
8. **封面回放间隔 `同页句间 0.2s / 跨页 0.4s`** 只在对照表里出现一次，无来源与设计依据说明。
9. **推荐位的「系列」数据与降级表现**：复用 Libin 的接口，但**「当前书所属系列」的数据从哪来**、系列最后一本 / 无系列 / 下一本不可用时「整体不渲染且**布局无空洞**」的具体表现**没有设计稿**。
10. **海报二维码的安全与隐私边界**：「扫码听 TA 读的这本书」意味着**孩子录音要对外可访问** —— 是否公开、有无有效期 / 撤回 / 隐私开关？V1.35 篇提到的「分享依赖完课结算页**上传授权**」这一前置是否已具备，需确认。
11. **分享文案的可变性与多语言**：面板有刷新按钮（暗示多套文案），但正文只给了一条英文；中文 / 印尼语版本与 Tolgee key 未给。
12. **埋点细节不在本篇**（指向另一篇文档）：`sentence_index` 起始值（0 还是 1）、与 `sentence_id` 的关系、页码字段是否保留，均需去那篇核对。
13. **文档模板残留**：修订记录 `2026-mm-dd:`、「主要特性」空章节、动画 / 声音 / 其他资源全空。
