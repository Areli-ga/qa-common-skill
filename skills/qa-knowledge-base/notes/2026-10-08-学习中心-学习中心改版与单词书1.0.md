## 摘要
基于 1.39 已做好的知识库后台，把 C 端单词体系改成**「听得懂 → 说得出」四阶段成长视图（Heard / Understood / Repeat / Said）**，孩子在课程、Quiz、口语里的单词成果汇总成**一本可翻的「单词书（Wordbook，贴纸书）」**：**书架（按级别 / 按主题）→ 单册（级别视图 / 主题视图）→ 单词详情四阶段徽章 + 点亮时机追溯**；同时**学习中心改版**（顶部加头像昵称、去掉课程介绍、新增「Learning report / Wordbook」两个大入口、主课程 / 自然拼读分段切换），**单元结算页改为「Unit {n} Complete」单词卡（开口次数 / 正确次数 + Core 标签）**，**课程结算弹窗改为「Today's stickers are yours」**，并给**核心单词加 `Core` tag**。**AB 测：`default_wordbookv1`**（对照组 = 旧版学习中心入口、无单词书、旧版路径动画）。**本期范围只做「课程主路径 + 鹦鹉学舌」**。

### 四阶段定义（全局口径，来自内嵌 Sheet）
| 阶段 | 英文 | 定义 / **本期触发** | 后续扩展来源 |
|---|---|---|---|
| 听过 | **Heard** | 定义：该词标准音频**作为新词呈现且完整播放 1 次**；**本期：课程中听到这个单词，完成该 unit 的任意一节课，即认为听过** | 闪卡、小麦 Mtown、绘本、家园、miniplan |
| 听懂 | **Understood** | 听到单词后在课程 Quiz 中能选出对应图片；**本期：Quiz 答对更新状态** | 同上 |
| 会跟读 | **Repeat** | 听过示范后能跟着正确读出；**本期：跟读课完成后更新 repeat 状态**（跟读鼓励模式与知识点统计）；**每个单词需单独记开口次数、正确次数（大于 80 分）**；需记入统计的场景：**跟读题（哪些地方有待确认）、鹦鹉学舌、Mtown、跟读绘本** | — |
| 自己说 | **Said** | **跟读 3 次后点亮 Said**；跟读场景包含**主路径 + 鹦鹉学舌** | — |

**推导规则（测试重点）**：
- **Heard 是其余三阶段的前置**：达成 Understood / Repeat / Said **任一项时，Heard 同时记为达成**。
- **Understood、Repeat、Said 各自独立、互不推导、不自动补齐**。
- 「**点亮知识点**」= 单词的**任一状态达成**。
- **语音「通过」复用语音模块规则，单词书不另设分数**（⚠️ 但 Sheet 里 Repeat 行又写「正确次数（大于 80 分）」，两处口径需对齐）。
- **同一阶段多次达成只增加学习记录，不重复加词数**。
- ⚠️ **Said 定义存疑**：Sheet 写「**跟读 3 次后**点亮 Said」，单词详情又写「**开口次数达到 X 次**，轻松点亮」（X 未定），且未说明 3 次是否要求「正确」。

### 4. 单册 · 级别视图
- 入口：学习中心「单词书」进入，**默认选中当前主路径级别**；左侧级别页签**支持切换 Level 1～6**；**待定：Level 6 是句式，没有剪影**。
- **Level 单词贴纸表**：展示**该 Level 下所有 unit 的核心单词**，**默认展示卡槽（剪影）**，收集点亮后展示单词图片并描边；**后台标注 core 的单词卡左上角显示 `Core`**。
- **贴纸详情（右侧）**：播放按钮、单词文本、**剑桥体系标签**、单词主题、单词图片；
  - 点音频按钮 → 播放**单词库内此单词音频**；
  - 点右上角**跟读音频** → 播放**孩子最新一次跟读的音频**；
  - 点四阶段徽章 → 查看阶段文案；
  - **点未点亮贴纸 → 展示剪影**。
- **点亮时机文案**：
  - Heard / Understood / Repeat：`YYYY-MM-DD，在unit X 点亮`
  - Said：`开口次数达到X次，轻松点亮`

### 6. 单元路径结算（Unit Complete）
- 原文注：**单元结算流程 Sunny 本期有修改，流程参考 Sunny 文档**（本篇的流程画板未抓取，见下）。
- 交互：**单元最后一课完成后进入此页**，标题 **`Unit {n} Complete`**；左上 ✕ 关闭 → 回学习路径（**路径动画维持线上**）；**右上单词书角标 = 当前 Level + `{a} / {b}`**，点击进单词书该 Level；**单词卡横排，超过 4 个横向滚动**；**`Bookshelf` 进单词书并定位本级别；`Next` 进单元后续流程、回学习路径**。
  - ⚠️ 原型图（img-11）里只看到 ✕ / 角标 / `Next`，**没有画 `Bookshelf` 按钮**。
- 单词卡数据：
  1. **词集合 = 本单元实际学习的词，取课程绑定的知识点 id**（原文注：此条 Cloud 老师有专门需求）；
  2. **Core 标签：该词在当前 Level 为必学词时显示**（同上，Cloud 老师专门需求）；
  3. 图片、英文：读知识库当前词形素材；
  4. **开口次数 = 本单元轮次内该词的有效语音尝试数**，**跟读 + 独立表达都算**；**按尝试去重，空录音和重复上传不计**；
  5. **正确次数 = 上述尝试中收到目标词通过的次数；判定中不计；正确次数 ≤ 开口次数**；
  6. **次数只算本轮；重进本页、重复上报不加；新一轮单元重新计数**。
- 缺省：**本轮开口 0 → 开口次数 0 · 正确次数 0，卡片照常展示**。
