## 摘要

V1.31.0 后台 Question Editor 支持给一道 Quiz 题挂**多个 Skill 标签**(原只能挂 1 个),让学员技能评估更准确、提高题目复用。数据结构 `skill`(单值)→ `skills`(数组),Skill 字段由单选下拉改为多选标签输入。产品 Owner: Aaron;优先级:中。

> ✅ **版本已确认 V1.31.0**(主人确认,2026-07-01):文档「版本号」字段为 **1.32.0**,但本库按 **V1.31.0** 入库。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 背景
- 当前一道 Quiz 题只能挂 1 个 Skill 标签;实际一道题常覆盖多技能(如「Tap the color」同时训练 Color Recognition-L1 / Visual Discrimination-L1 / Word-Picture Association-L1)。

### 改造内容
- **Question Editor UI**:Skill 字段「单选下拉」→「**多选标签输入**」(支持搜索已有 Skill、添加多个、单个标签 × 删除)。
- 字段名建议 `Skill` → `Skills`(保留旧 label「Skill」也可,统一团队规范)。
- **至少 1 个 Skill 标签必填**(不允许空)。

### 数据结构(测试重点)
| 字段 | 改造前 | 改造后 |
|---|---|---|
| 字段名 | `skill` | `skills` |
| 类型 | `string`(单值) | `string[]`(数组) |
| 示例 | `"Visual Discrimination-L1"` | `["Color Recognition-L1","Visual Discrimination-L1","Word-Picture Association-L1"]` |
| 必填 | 是 | 是(**数组长度 ≥ 1**) |

- **存量数据迁移**:历史 `skill` 单值 → 包装为长度为 1 的数组写入 `skills`。

### 验收标准(测试重点)
- 可添加多个 Skill 标签(至少 1 个,无上限或按业务上限设定)。
- 每个 Skill 标签可独立删除;**删除后保存仍能正常落库**。
- 保存后 Question JSON 中 `skills` 为数组结构。
- **存量历史题目(原 skill 单值)自动迁移为 skills 数组、长度为 1,且页面正常回显**。
