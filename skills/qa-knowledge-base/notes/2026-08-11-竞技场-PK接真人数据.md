## 摘要

V1.36.0 把 1.35 收集到的**真人对局数据**接入 PK:按历史得分把真人分成 **L1–L4 四档**(对应 P25 / P50 / P75 分位),匹配时**若该档位真人记录总数 > 100 就随机选一条真人记录 PK,≤ 100 仍打机器人**;回放只用「**答对答错 + 答题时间**」两类数据,**不取本人的历史记录**。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 0. 背景

- 1.35 版上线了**真人 PK 机器人**,保证用户能匹配到对手,同时**记录了用户的答题数据**,为「真人 PK 另一真人的历史数据」打好基础。
- 真人 PK 能带来更多真实互动感,**甚至可以再互访、点赞**,鼓励用户长期留下。

### 1. 真人历史数据分档

把 1.35 收集到的真人得分**分成 4 档**,与机器人档位一一对应:

| 档位 | 定位 | 历史真人得分 |
|---|---|---|
| **L1 陪练** | 连败保护 | **< P25** |
| **L2 普通** | 默认对手 | **P25–P50** |
| **L3 较强** | 进阶 | **P50–P75** |
| **L4 劲敌** | 连胜挑战 | **> P75** |

- **比例可以不实时计算**:基于 **1.35 的真人数据划定一个初步分数线**,后续沿用。
- **历史数据只用两项:答对答错、答题时间**(即 1.35「本期记录数据」表里的 `answer_result` 与 `answer_time_ms`)。

### 2. 机器人与真人的匹配规则

- 1.36 上线后,用户匹配时**先按原选档规则定出本局档位**,然后:
  - 该**档位的真人记录总数 > 100** → **随机选择一条真人记录 PK**;
  - 该**档位的真人记录总数 ≤ 100** → **匹配机器人**。
- **不取本人的历史学习记录**(原文用了三个感叹号强调)——**自己不能和自己打**。

### 3. 前端处理配合

- 原文只有一句:「**中途暂停,要开始计时**」。
- ⚠️ **表述不完整(已入待确认)**:未说明是谁中途暂停(用户 App 切后台?对手回放暂停?)、暂停后计时从何时起算、是否影响单题倒计时与本局判定。真人数据是**离线回放**的,一旦本端暂停,回放时间轴与本端计时如何对齐是核心问题,需向产品/研发确认后才能定用例。

### 4. 由此推导的测试重点

- **档位边界**:P25 / P50 / P75 三个分位点上下的用户各落哪一档;分数线是**基于 1.35 数据固定的初值**,不随实时数据变。
- **100 条阈值切换**:同一档位记录数在 100 附近时,**匹配结果会在真人/机器人之间切换** —— 需构造刚好 100 与 101 两种数据态。
- **对手来源不可见**:1.35 已定「机器人身份对用户不暴露」,现在真人也走同一套展示;**埋点 `opponent_type` 必须能区分 `robot` / `real`**(1.35 埋点表已预留 `real`,注明"1.36 起")。
- **排除本人**:反复 PK 时不应匹配到自己的历史局。
- **入池过滤**:1.35 已定「仅完赛局入池」「任一题用时 <500ms 整局标异常不入池」,本期真人对手全部来自该池 —— **异常局不应被选中回放**。

### 关联依赖(回归注意)

- **直接前置 = [竞技场（Arena）1.0 随机PK](2026-08-11-竞技场-竞技场Arena1.0随机PK.md)(V1.35.0)**:本期消费的正是那篇「本期记录数据」表(`battle_id` / `is_complete` / `is_abnormal` / `battle_level` / `rule_version` / `question_index` / `answer_result` / `answer_time_ms`);其中 **`rule_version` 规定"改版后旧局不再回放"** —— 若 1.36 改了题数/计时/计分,1.35 采集的数据会整体失效,**这是本需求能否成立的前提**。
- **档位定义沿用 [PK 机器人规则](2026-08-11-竞技场-PK机器人规则.md)(V1.35.0)** 的 L1–L4 与选档规则(连胜/连败/wr20);本期只是把「选到某档后生成机器人行为」换成「选到某档后取一条真人记录回放」,**选档逻辑本身不变**。
  - ⚠️ 机器人规则里的**硬性约束**(如「除 L1 防碾压兜底外禁止根据用户表现调整」「answerTimeMs ≥ 1800ms」「6 题用时不得全等」)对**真人数据是否同样适用**需确认 —— 真实用户完全可能出现 <1800ms 的作答。
  - ⚠️ **L1 陪练档的防碾压兜底**(第 4 题落后 300 分则后三题强制答错)在真人回放下是否还生效?若生效,等于篡改真人数据。
- **真人历史局的采集质量**决定本期体验:1.35 若采集有缺失,1.36 直接没对手可用(会回落到机器人)。
- 后续规划提到的「互访、点赞」与 [家园好友串门社交测试](2026-08-11-奖励中心-家园好友串门社交测试.md)(V1.35.0)的好友互动能力可复用。
