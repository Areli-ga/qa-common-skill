## 摘要
在 V1.39《[知识体系后台改造方案](2026-09-20-知识体系-知识体系后台改造方案.md)》的英语知识库之上新增「**学科**」维度（**英语 / 数学**）。两科共用**同一张表、同一套 15 位 ID**，但**知识点完全隔离、不可跨学科引用**；**现有学习资产全部刷为英语**。学习资产列表顶部加学科切换（各带知识点数，默认英语，**按账号记住上次停留的学科**，切换时清空搜索 / 筛选 / 分组 / 勾选并回到第 1 页）。数学知识点的列为「知识点 / 类型 / 数值 / 级别 / 状态 / 操作」，**知识点类型 7 种**（数字 / 图形 / 方位 / 比较 / 属性 / 运算 / 句子；本批次运算、句子为 0 条）。左侧分组有两个轴：知识点类型（默认）和级别。新建 / 编辑页字段：知识点 (EN)、只读翻译、类型、数值（类型 = 数字时必填）、体系 - 级别（数学主线 + Foundations / Level 1 / Level 2…）、四槽素材。⚠️ 需求背景里列的「数学详情、数学体系树、选择知识点弹窗按学科锁定」**正文没有展开**；唯一性范围和素材校验口径，设计稿与正文 / V1.39 互相矛盾。

## 功能信息（逻辑 / 状态 / 边界 / 字段）

### 需求背景与范围
- 在英语知识库之外支持数学学科：新增「学科」，学科之间知识点完全隔离。
- 背景段列出的范围：**学科切换、数学知识点新建 / 编辑、数学列表与详情、数学体系树、选择知识点弹窗按学科锁定**。
- ⚠️ 正文实际只写了**列表页、新建 / 编辑页、类型枚举**三块；**数学详情页、数学体系树（标签管理里的数学主线）、选择知识点弹窗怎么按学科锁定**，都没有展开。

### 1. 新增学科
- 知识库新增「学科」：**英语 / 数学**。
- **同一张表、同一套 15 位 ID**；学科之间知识点**完全隔离，不可跨学科引用**。
- **现有学习资产全部刷为英语**（存量数据迁移）。
- 设计稿顶栏提示：「学科之间知识点完全隔离 · **同名不冲突** · 不可跨学科引用」（同一个词，比如 `in`，可以在英语和数学里各有一条）。

### 2. 学习资产列表 · 学科切换与数学列表（img-01）
**交互说明**
- 列表页顶部展示学科切换：**英语 / 数学，各带知识点数**（原型：英语 322 / 数学 41）；**默认选中英语**。
- **按账号记住上次停留的学科**，下次进入直接停在该学科。
- **切换学科**：**清空搜索、筛选、分组选中、勾选，回到第 1 页**；切换后展示该学科全部数据（列表、分组、筛选、计数都只算当前学科）。
- 点知识点名称或「详情」→ 数学知识点详情页；点「编辑」→ 编辑页。
- 点「+ 新建知识点」→ 新建页，**学科继承当前 tab**。
- 左侧分组方式下拉：**知识点类型 / 级别**，**默认知识点类型**（英语默认是「主题」，见 V1.39）。
- 点分组值筛出该组，再次点击取消；点「全部知识点」取消分组。
- **分组与上方筛选可叠加**；叠加条件以标签形式展示在列表上方（原型：「已叠加 1 个条件 · 知识点类型：方位 ×」），点 × 单独移除。

**数据说明 · 列表**
| 列 | 规则 |
|---|---|
| 知识点 | 名称，下方小字为 15 位 ID |
| 类型 | 数字 / 图形 / 方位 / 比较 / 属性 / 运算 / 句子 |
| 数值 | **类型 = 数字时展示整数，其余类型展示「—」** |
| 级别 | Foundations / Level 1 / Level 2… |
| 状态 | 待上架 / 已上架 / 已下架 |
| 操作 | 详情 / 编辑（原型） |

- **排序：按 ID 正序**。
- 标题旁「共 {n} 项」，n = **当前分组 + 筛选后**的条数。

**筛选**
- 搜索：按知识点名称或 ID **模糊匹配**。
- 类型：全部类型 + 7 个类型值。
- 状态：全部状态 / 已上架 / 待上架 / 已下架。

**分组**
1. 全部知识点：{n}，n = 数学知识点总数。
2. 按知识点类型：每组展示类型名 + 条数，**按条数倒序**。原型：方位 12 / 数字 11 / 属性 9 / 比较 5 / 图形 4（合计 41）。
3. 按级别：每组展示级别名 + 条数。原型：Foundations 24 / Level 1 12 / Level 2 5（合计 41）。
4. **条数为 0 的类型不出现在分组里**；运算、句子本批次为 0。但**枚举值保留，新建时可选**（设计稿注释）。
- 设计稿左栏注释：分组列是**按「知识点类型」算出来的视图，切换分组不移动任何数据**；**数学只有类型和级别两个分组轴**；体系只有「数学主线」一条，不做分组轴。
- ⚠️ 按类型分组条数相同时的次序、按级别分组的排列顺序，原文没写。

**缺省状态**
- 数学学科下没有任何知识点：列表展示「**暂无匹配的知识点**」，分组只剩「全部知识点 0」。
- 筛选或分组后无结果：列表展示「暂无匹配的知识点」。

- ⚠️ 原型顶部有「导出」「批量导入」按钮（沿用英语列表），**数学下导出 / 批量导入的字段和模板正文没写**。批量导入怎么指定学科、导出是否只导当前学科，也没写。

### 3. 新建 / 编辑数学知识点（img-02 + 内嵌表 hzW7xq）
| # | 字段 | 必填 | 控件 | 取值 / 说明 |
|---|---|---|---|---|
| 1 | 知识点 (EN) | ✅ | 文本，≤ 100 | 如 three / circle / more / in。**数学学科内唯一** |
| 2 | 翻译 | — | 只读 | **本地化系统维护，此处不可填** |
| 3 | 知识点类型 | ✅ | 下拉单选 | 数字 / 图形 / 方位 / 比较 / 属性 / 运算 / 句子 |
| 4 | 数值 | **类型 = 数字时 ✅** | 整数 | three → 3、zero → 0；**非数字类型不展示** |
| 5 | 体系 - 级别 | ✅ | 级联 | 体系 = **数学主线**；级别 = Foundations / Level 1 / Level 2…（原文：「级别先写个 Level 1～2」） |
| 6 | 素材 | 部分必填 | — | 图片、音频上架必备 |

- 设计稿页面标题「新建数学知识点」，分「基本信息」「素材」两块，底部「取消 / 保存」。
- **素材四槽**：图片 / 音频 / 动画 / 音效，**一律「从素材库选择」，不在此上传**，每槽带「清除」。设计稿注释：「**与英语规则一致：图片 = 上架必需（可以先存，上架时校验）；音频 = 硬校验（没有不能保存）；动画、音效非必填**」。
- ⚠️ **唯一性范围三处说法**：内嵌表「**数学学科内唯一**」、设计稿输入框提示「three / circle / more / in。**全库唯一**」、顶栏「学科之间同名不冲突」。按隔离原则应为学科内唯一，设计稿提示需要改。
- ⚠️ **素材校验口径冲突**：内嵌表写「图片、音频**上架必备**」（都是上架时校验），设计稿写音频是「**硬校验，没有不能保存**」。设计稿又说「与英语规则一致」，但 V1.39 写的是英语「**保存不做完整度校验**」「图片必填」，原形音频在详情页发音栏维护。三处说法互相冲突。
- ⚠️ 数值：内嵌表「非数字类型**不展示**」 vs 设计稿「非数字类型**留空**」；编辑时把类型从数字改成其他，已填的数值是清空还是保留，没写。
- ⚠️ 编辑页能否改**学科**（数学知识点改成英语），原文没写；按隔离原则应不可改。
- ⚠️ 数学知识点有没有英语那套**变体**（复数、过去式）、词性、主题、蓝思、剑桥体系字段：新建页里都没有，应是不适用，但原文没明说。

### 4. 知识点类型枚举（本批次，原文称「目前暂时给的版本，后续也是类似」）
| 值 | 中文 | 本批次实际词 | 条数 |
|---|---|---|---|
| number | 数字 | zero one two three four five six seven eight nine ten | 11 |
| shape | 图形 | circle square triangle rectangle | 4 |
| position | 方位 | in on under up down left right next to over off out between | ~12 |
| comparison | 比较 | more fewer equal same different | 5 |
| attribute | 属性 | big small / red blue yellow orange purple green pink | ~9 |
| operation | 运算 | plus minus altogether（加减法课用，本批次暂未落地） | 0 |
| sentence | 句子 | 整句台词卡（本批次 72 课未用到，预留） | 0 |

- 合计 41 条，与原型数学 tab 的「41」一致。
- 本批次对应 **72 课**（「句子」一行提到）。

### 5. 状态与上下架
- 状态沿用英语的三态 **待上架 / 已上架 / 已下架**。V1.39 规则：新建为待上架；**上下架只在详情页发生**；从待上架或已下架到已上架**要求知识点完整**。
- ⚠️ 数学知识点的「完整」怎么判定，正文没写。V1.39 英语的完整度检查项含「已定级别」「原形有发音」「启用变体均有发音」等，数学不适用的项（变体）怎么处理需确认。原型里 Level 2 的 `over` / `off` 是「待上架」。

### 与往期的关系
- V1.39《[知识体系后台改造方案](2026-09-20-知识体系-知识体系后台改造方案.md)》是英语知识库的现行规则：15 位 ID、左侧分组是现算视图而非实体树、标签管理（主题 / 体系 / 级别）、四槽素材、状态生命周期，以及**全后台统一的「选择知识点」组件**。本篇的「选择知识点弹窗按学科锁定」改的就是这个组件，凡是调用它的业务后台（题库、课程单词、闪卡等）都受影响，但**谁来决定锁哪个学科，原文没写**。
- 「现有学习资产全部刷为英语」：V1.39 列表 322 条，原型英语 tab 也是 322，刷数后英语计数应保持不变。

### 测试关注点（基于正文，供写用例参考）
1. **学科隔离**：同名词（如 `in`）在英语、数学各建一条都能保存；数学内重名被拦；搜索、计数、分组、导出都不串学科；业务侧选择知识点时不能跨学科选。
2. **学科切换**：默认英语；按账号记住上次学科（换账号、清缓存、重新登录）；切换时清空搜索、筛选、分组、勾选并回第 1 页；新建继承当前学科。
3. **列表**：按 ID 正序；数值列只有数字类型显示整数；「共 n 项」随分组 + 筛选变化；叠加条件标签单独移除。
4. **分组**：类型按条数倒序；0 条类型不出现在分组里，但新建时可选；新建第一条运算类知识点后，分组里出现「运算 1」。
5. **新建 / 编辑**：知识点 ≤ 100 字符；类型 = 数字时数值必填且为整数（负数、小数、非数字）；类型改来改去时数值的处理；翻译只读；体系 - 级别级联。
6. **素材**：先拿到统一口径（音频是硬校验还是上架校验），再测「无音频能否保存」「无图片能否上架」。
7. **存量刷数**：上线后英语 322 条学科都为英语，英语侧列表、详情、引用、反查行为不变（回归 V1.39）。
8. **空态**：数学 0 条时的列表与分组；筛选无结果。
