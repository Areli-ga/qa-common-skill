## 摘要

V1.33.0 新增满意度弹窗,引导忠实用户去应用市场写好评:弹「Having fun with Giggle Academy?」,选「送小红花(Rate us)」→ 调起原生评分;选「吐槽一下(Send feedback)」→ 进反馈。用频控避免打扰。产品 Owner: Sunny;优先级:高。(文档版本字段残留 V1.0,figma 为 1.33.0,实际 **V1.33.0**。)

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 弹窗内容
- 满意度卡:「Having fun with Giggle Academy?」(中文「喜欢咯咯学院这款应用吗?」)。
- 两按钮:**Send feedback(吐槽一下)** / **Rate us(送小红花)**。

### 弹窗优先级
- **P1:孩子年龄确认(Unity)** —— 即「修改孩子年龄」的年龄确认弹窗,优先级高于好评弹窗。
- **P2:好评弹窗(原生)**。

### 频控规则(测试重点)
1. 同一用户 **30 天触发 1 次**满意度卡。
2. 选「吐槽一下」后,**90 天内不再弹**。
3. 选「送小红花」→ 调起原生评分,**90 天不再弹**。
4. **新用户冷启 7 天内不弹**(避免还没体验就要好评)。

### 平台区分(测试重点)
- **苹果商店、谷歌应用商店**:可直接出**应用内评分弹窗**。
- 其他不支持应用内评分的市场:需**跳转应用市场**。

### 字段
- 多语言 key:`rate_prompt_title` / `rate_prompt_positive` / `rate_prompt_negative`。

### 关联依赖(回归注意)
- 弹窗优先级与「账号与设置/孩子年龄」的年龄确认弹窗(Unity,P1)互斥排队——回归两弹窗同时满足条件时的先后。
- 「吐槽一下」路径与「反馈与社区/反馈收集」衔接。
