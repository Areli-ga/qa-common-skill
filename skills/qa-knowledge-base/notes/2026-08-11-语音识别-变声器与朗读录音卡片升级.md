## 摘要

用**声音滤镜(变声器)**刺激孩子开口:朗读录音卡片**说完自动提交 + 自动变声回放**,**6 种滤镜**(原声/小松鼠/大狗熊/机器人/外星人/大山谷)可随时切换、**切滤镜即以新滤镜重放**;新用户由 Mai 走一段 Onboarding 分镜引导选滤镜;子游戏(I Spy / Story Island / M Town Talk)的单词卡与句子卡都带滤镜;**Collection 从"看过的单词列表"变成"好玩的声音收藏册"**,可回听、重录、**每个单词单独换音色**。目标是把 **50%–60% 的卡片手动关闭率**打下来。

⚠️ **版本**:文档「版本号」字段写「**待填,来源于产品规划迭代 Roadmap**」,Figma 为 **`1.36.0`** node `47246-244254`;按主人给的 **V1.36.0** 入库。产品 Owner:**Libin**;优先级:**高(朗读开口率)**。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 0. 背景与设计原则

- **当前朗读体验不好**:**手动关闭朗读录音卡片的比例高达 50%–60%**,且**新老用户差异不大** —— 新用户不愿开口(**并非受挫后不愿开口**),老用户则是**朗读疲劳**。
- **设计原则**:给朗读增加多样化设计,让朗读过程像游戏一样好玩;**不引入传统勋章式激励或更复杂的游戏剧情**,而是通过**录音模块本身的体验(声音滤镜/变声器)**来刺激开口。
- **核心洞察**:孩子听到自己变成小松鼠/外星人的声音会觉得好笑、**想再听一遍、想再录一遍** ——「**想听自己搞笑的声音**」本身就是开口动机。
- **目标**:卡片关闭率显著下降;通过换滤镜重听/重录**制造重复开口**;**零学习成本**(内嵌现有卡片流程,不加新任务或界面)。
- 建议指标:卡片关闭率、朗读提交率、人均重听次数、人均重录次数、滤镜切换次数、Collection 回听率。

### 2. 核心模型(理解本篇的关键)

- **真实的变声效果只有用户自己听得到**;**小Mai AI 不需要理解变声后的音频**。
- **小Mai 仍旧解读用户原声**,**外加变声参数**,由此**推测出用户变声后的声音并给出情感化反馈**。
- 📌 因此**变声不影响录音识别与打分结果**(见验收标准),识别链路吃的始终是原声。

### 3. 滤镜集(6 种)

**原声 😊 / 小松鼠 🐿️ / 大狗熊 🐻 / 机器人 🤖 / 外星人 👽 / 大山谷 🏔️**
埋点 enum:`original` / `squirrel` / `bear` / `robot` / `alien` / **`valley`**。

- ⚠️ **第 6 个滤镜名称三处不一致(已入待确认)**:正文叫**「大山谷 🏔️」**、埋点 enum 是 **`valley`**、但设计稿 img-01 左侧面板写 **`Echo`**、右侧面板与 img-04 写 **`Cow`(牛)**。**同一份稿里就有两种叫法**,需确认最终是哪一个。

### 4. 主流程与 Onboarding

```
新用户 onboarding 环节
   ↓ 小麦引导用户选择并使用小工具(变声器)
   ↓ 小工具的使用演示(用滤镜声朗读体验)
   ↓ 进入子游戏环节,调用朗读录音卡片
   ↓ 应用小工具(用户带滤镜朗读)
   ↓ 进入 Collection,可重复收听(含重录)
   ↓ 结束
```

### 5. 声音滤镜设置(入口与选择条)

- **主对话显示 mic 入口**,**提供动态效果吸引用户点击并预告内部功能**;
- 点击打开**滤镜选择条**,**同步播放小Mai 的引导提示音**;
- **选择声音滤镜时播放预置内容**,小Mai 需要对用户的当前选择给出反馈;
- 点击**下一步**进入朗读卡片的使用教学。

**设计稿补充规格(img-01)**
- **首次唤起**:用户点麦克风上的**音色 icon** 呼出音色选择面板,同时 Mai 说「选择你喜欢的声音,我们来做个小游戏。」;**下一步箭头每隔 3s 弹动一下**;**点击除 original 之外的每个音色头像会发出 `Hello, nice to meet you.`**;**选择器底部波纹缓缓移动**。
- **非首次唤起**:Mai 说「咦,我刚刚是不是听到了一个小松鼠的声音?」;**点击 mic 切换唤起选择卡**;**点击选项时可以立即切换并关闭 popover**;**点击 mask 区域关闭 popover**。
- **mic 入口动效**:`Scale 1.25` 左右晃动 → 复原;有明确的点击区域设定。
- **mic 图标随所选滤镜换主题**:如「松鼠主题麦克风」「小熊主题麦克风」。

### 7. 朗读录音卡片交互规则(8.2,核心)

- 小Mai 给出朗读引导 → **打开朗读录音卡** → **打开麦克风时给出"滴"的提示音**;
- **录音过程中出现波形提示**(表达录制中状态);
- **用户说完之后自动提交**,并**自动进行一次变声回放**;
- **点击 🔉 扬声器** → **关闭 mic,播放标准录音**;**播放完成之后"滴"一声重新进入录制模式**
  (设计意图:*"我们做大胆的假设,用户听标准录音一定意味着自己的当前录音有问题,需要做覆盖"*);
- **点击主题头像(如小松鼠)可不断收听变声后的声音**,同时**关闭 mic**;
- **后置**:小Mai 拿到**用户的原始录音**给出反馈(评价或下一步),并通过**下一步**推进流程;
- **支持点击返回或关闭,退出设置、重新选择滤声器**。
- 卡片入场规格(img-02):**Mai 说完引导 → "滴"特效音 → 跟读卡片从下方入场 → 入场后即开启录制模式**。
- 卡片三态(img-02):① **录音中**(左侧绿色波形动画,自动提交逻辑);② **播放标准录音**(纯文字态);③ **播放变声录音**(左侧显示所选滤镜头像,文字变彩色)。句子卡样式同理(如 `My name is Simon`)。

### 8. 子游戏内应用

- **I Spy / Story Island 类**:**单词卡(如 cat)和句子(I can see a cat.)朗读时附带滤镜**;朗读完成 → **变声回放** → **收入 Collection**;流程遵循朗读录音卡片交互规则。
- **M Town Talk(场景对话)类**:**单词卡、句子卡同样适用**,流程同上。
- **Mai 的额外反馈**:当用户用到变声器时,小Mai 在当前的鼓励/反馈基础上**随机增加**滤镜评价,如「我刚刚听到一个奇怪的声音」「你的声音好搞笑」。
- ⚠️ 验收标准提到「**子游戏内滤镜按随机策略出现**」,但正文功能描述里**没有定义这个随机策略**(概率、频次、哪些点位)——需确认。

### 9. Collection 沉淀与回听

- **Collection 从「看过的单词列表」变成「好玩的声音收藏册」**,制造复访与重复开口。
- 已收集的单词进入 Collection(图鉴);**详情页提供播放(回听自己的变声录音)与录制(重录)**;
- **没有变声的时候,隐藏变声录音播放按钮**;
- **支持切换声音滤镜**;**一个 Collection 中的单词支持录制不同的声音**。
- **单词书详情页四类点击(img-04)**:
  a. **点击单词播放 icon** → 播放**标准录音**;
  b. **点击图片/波形图** → 播放**滤镜后的音效 + 该动物的动画**;
  c. **点击 mic 旁边的切换** → **唤起滤镜切换器**;
  d. **点击 mic** → **进入录制模式**(mic 变红色停止按钮)。
- **切换音色时**:点击选项可立即切换、关闭 popover,**并且播放一遍滤镜后的声音**。
- **后端约定(07-28)**:**一个用户同一时刻只有一个语音设置(存在前端)**;**Collection 的变声执行精细到单词级别**,系统记住每个单词的**原始声音 + 声音滤镜**,**不受卸载和升级影响**。

### 11. 验收标准(原文给出,可直接转用例)

1. **6 种滤镜变声回放正常**,**切换滤镜且已有录音时立即以新滤镜重放**。
2. **录音红点提示、说完自动提交并自动单次回放**;播放按钮可反复收听。
3. **录音/朗读组件与「下一步」按钮同时出现**,**重听不阻断流程推进**。
4. Onboarding 分镜按台词脚本执行,**结束导流到小岛游戏**。
5. **子游戏内滤镜按随机策略出现**;I Spy 单词卡与对话句子卡均可用。
6. Collection 详情页可回听变声录音、可重录。
7. **变声不影响录音识别与打分结果**。
8. 埋点齐全,**可回算卡片关闭率变化**。

- ⚠️ 验收第 2 条写「**录音红点提示**」,但功能描述里写的是「**波形提示**」——两处术语不一致。
