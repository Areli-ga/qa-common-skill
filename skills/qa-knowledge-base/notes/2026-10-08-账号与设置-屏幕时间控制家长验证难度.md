## 摘要
屏幕时间控制的「家长验证」原来只有一道**一位数加减乘**题（如 2+3），**6 岁以上孩子自己就能算出来解锁**，且同一道题在**中国和印尼**两个市场难度不同。本期在**设置中心 → 屏幕时间**新增**「验证模式」分段控件：简单 / 困难**（**点击即保存、无二次确认，下一次验证即生效**）：**简单 = 一位数加减乘（现状不变，适合 0–3 岁）**；**困难 = 含括号的两步组合算式 `(a ○ b) × c` 或 `c × (a ○ b)`（适合 4–8 岁）**；**每次验证随机出题，答错换新题不重复**。**新用户与存量用户默认都是简单模式**。家长验证页**改为原生弹窗**。新增埋点 `parent_verify_result`（`verify_mode` easy / hard，`result` success / failure）。

## 功能信息（逻辑 / 状态 / 边界 / 字段）

### 基本信息
- 产品 Owner：**Aaron**；优先级 **中**；版本 **v1.40.0**；文档日期 **2026-09-10**；UI：figma `1.40.0` node `60497-58285`。
- 现状：**家长在设置中心设定每日可用时长 → 时长用尽弹出锁定页 → 页面出一道简单四则运算题，答对即解除锁定、继续使用**。
- 遇到的问题：① **孩子越大，门槛越形同虚设**；② **一道题的难度服务不了两个市场**（中国和印尼同龄孩子数学进度与入学年龄不同）。
- 产品目标：**让家长自己选择验证难度，把解锁门槛抬到孩子的能力之上**。

### 1. 设置 - 屏幕时间控制
| 元素 | 规则 / 逻辑 |
|---|---|
| **验证模式** | **分段控件，两档二选一：简单 / 困难；单选** |
| 简单模式 | 一位数加减乘，与现状一致；右侧说明文案「**一位数加减乘，适合 0–3 岁**」（图上示例 `3 × 4 = ?`） |
| 困难模式 | 含括号的组合算式；右侧说明文案「**组合算式，适合 4–8 岁**」（图上示例 `(9 - 7)×3 = ?`，英文「Mixed arithmetic operations. For ages 4–8.」） |
| **切换生效** | **点击即保存，无二次确认**；**下一次触发家长验证时使用新模式** |
| **默认值** | **新用户默认简单模式；存量用户升级后保持简单模式** |
- 页面其余元素（图读出）：屏幕时间总开关、**每日限制 `−` `45 分钟` `+`**、「XX 今天已使用了每日限额中的 N 分钟」（英文版加「Limits reset daily.」）、**提示：① 如果你正在游戏中，我们会在你返回主屏幕时提醒你；② 时间到后，所有游戏和故事将暂停，电台和家长区仍可使用**、「为了保护眼睛，学习时可以尝试投屏到电视 · 如何投屏?」。

### 2. 家长验证（原生弹窗）出题规则
| 项 | 简单 | 困难 |
|---|---|---|
| 题型 | **一位数加减乘** | **含括号的两步组合算式** |
| 取值 | **加数、乘数 1–9** | **`(a ○ b) × c` 或 `c × (a ○ b)`**；**括号内 a、b 为 1–9；括号外乘数 c 为 2–9** |
| 约束 | **减法结果不为负** | **括号内运算结果为正整数；排除 ×1** |
| 答案位数 | **1–2 位** | **2–3 位** |
| 生成方式 | **每次验证随机生成** | **每次验证随机生成** |
| 答错处理 | **换一道新题，不重复同一题** | **换一道新题，不重复同一题** |
- 弹窗 UI（图读出）：左上 ✕；左侧「**仅限家长 / 请完成家长验证**」（英文 Parents Only / Please complete parent verification.）；右侧算式 + 输入框 + 数字键盘 + 删除键；**简单模式弹窗右上角有「简单模式」标签**。
- ⚠️ **困难模式答案位数与取值规则矛盾**：按「括号内结果为正整数、c 为 2–9」，最小可到 `(a ○ b) = 2`、`c = 2` → 答案 4（1 位）；**原型示例 `(9 - 7)×3 = 6` 本身就是 1 位答案**，与「答案位数 2–3 位」冲突。需确认是否额外过滤 1 位答案。
- ⚠️ 「排除 ×1」只写了一句：c 已限定 2–9，所以实际要排除的应是**括号内结果 = 1**（如 `(5 - 4) × c`）或括号内含 `×1`，原文未说清。
- ⚠️ `○` 是否包含 `×`、`÷`：原文未写（`(a × b) × c` 最大 729，正好是 3 位上限，推测包含乘、不含除）。
- ⚠️ 简单模式文案写「适合 0–3 岁」，但背景说的是 **6 岁以上**能自己算出来 —— 适龄文案与问题描述不对应，仅供核对。
- ⚠️ **作用范围未写**：难度设置是否同时作用于 App 内**其他家长验证入口**（家长中心、WA 联系我们、付费 / 外链等），还是只作用于屏幕时间锁定，原文没说。

### 3. 数据埋点
| 事件 | 触发时机 | 参数 |
|---|---|---|
| **`parent_verify_result`** | **家长验证结束时上报** | **`verify_mode`**（验证模式）：`easy`（简单）/ `hard`（困难）；**`result`**（验证结果）：`success`（通过）/ `failure`（失败） |
- ⚠️ 「验证结束」的定义未写：答错一题换新题算不算一次 `failure` 上报、点 ✕ 关闭弹窗是否上报 `failure`。

### ⚠️ 测试关注
- **切换即生效**：设置后不退出直接触发验证；验证弹窗打开期间切换难度（下一次才生效）。
- **默认值**：新装 / 升级用户均为简单；切到困难后重装 / 换设备 / 换 kid 是否保留（原文未写存储维度）。
- **出题随机性与边界**：简单减法不为负、乘数 1–9；困难括号内为正整数、c ∈ [2, 9]、答案位数；**答错后新题不重复**。
- **弹窗化**：原全屏锁定页改原生弹窗后，在游戏中 / 故事书中 / 锁屏后返回主屏的触发时机，与提示文案「游戏中返回主屏幕时提醒」一致性。
- 关联往期**带家长验证的入口**（确认是否受新难度影响）：《修改孩子年龄》、《whatsapp加好友发送消息链路》、V1.37《WA推送体系接入》（游客模式【联系我们】）、《绘本跟读配音大赛（九月活动）》。
