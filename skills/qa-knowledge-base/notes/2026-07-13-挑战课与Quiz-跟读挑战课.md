## 摘要

V1.34.0 新增测验类型「跟读挑战课(跟读对战)」,补齐测验矩阵缺失的「开口说」维度:用**语音识别判定"开口读对单词"**,包装成 Max/Lily 兄妹友谊赛(Boss 对战外壳)——孩子开局选「帮谁赢」,读对单词=帮所选角色充能命中对手,3 连对触发「龟派气功」必杀。零挫败、三结局全正向。**走 gamelist 模板(非 Quiz)**,复用 gamelist 埋点 + 语音识别埋点;一套引擎换词表即生成任意主题跟读测试。Demo: https://word-battle-demo.pages.dev/

⚠️ **版本**:文档「版本号」字段写 `v1.33.0`,figma `1.34.0`;按主人给的 **V1.34.0** 入库。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 0. 关键决策 / 语句变更(修订记录,易踩)
- **2026-06-30**:因兼容性,最终**走 gamelist 模板**,触发 gamelist 埋点 + 语音识别业务埋点(不是独立挑战课类型)。
- **2026-07-03 文案更换**(测试以新文案为准):
  - `Who do you want to help?` → **`Who will you help?`**
  - `Let's spar!` → **`Game on!`**
  - `You're a bit stronger!` → **`You're getting stronger!`**
  - `Looks like I'm still stronger!` → **`I'm strong today!`**
- `"What is this?"` **仅在第一次卡片出现时播放**,后续不再播放。

### 1. 角色与心智
- 两位切磋选手 **Max + Lily 兄妹**(既有角色、穿格斗服),均友好、无反派。
- 「被帮者」= 所选角色 = champion,恒定站**左台**(player 槽);「对手」= 未选那位 = opponent,恒定站**右台**;下一局可反过来帮对手。
- 玩家 = 助攻教练/啦啦队:「读对单词 = 帮我选中的伙伴充能」。零挫败、无失败惩罚、无丑化。

### 2. 核心交互流程(脚本)
1. **进入选择屏**:背景渲染完成 + 两张角色大卡入场落定 → 本地化标题 + 自动播语音「Who will you help?」,两卡同步打招呼动画。
2. **过场**:点击确认后(选中卡放大上浮、另一卡淡出)→ 卡变竞技场角色,移入竞技场。
3. **登场**:选中角色落左台;另一角色从传送门蹦出 + 出场特效 + 震屏,播语音「Game on! / 来切磋一场吧!」。顶部双血条、底部铺开单词卡组(=弹药)。
4. **出题(看图开口)**:牌组弹出一张卡——**仅显示单词图片**;语音提示「What is this?」(仅首题)。立即自动进入语音识别。
5. **开口(自动识别充能)**:说话时卡片亮色光边随音量起伏,化身做攻击起手式 + 吸能光波;语音识别持续进行。
6. **判定 → 分支**(见第 3 节)。
7. **推进**:每词完成(无论成败)→ 牌组 −1;全部解决或一方血空 → 结算(星级)。

### 3. 反馈分支逻辑
| 分支 | 触发 | 表现 | 后续 |
| --- | --- | --- | --- |
| ✅ 正确 | 读对 | 卡片特效被吸入 → 用户角色出招命中 → 对手 **−1 血** | 连击 +1(用挑战课同款 combo);下一词 |
| 🔥 连击/必杀 | 连续 ≥3 对 | 「龟派气功」漫画横幅特写(蓄力+速度线+`SUPER!`)→ 全屏光波命中+震屏,对手 **−2 血** | 演出强化 |
| 🟡 错 1 次 | 首次未读对 | 卡片红描边轻抖;**单词名出现并高亮闪烁几下(无语音、无文案)** | 再次自动进入语音识别 |
| 🔊 错 2 次 | 再次未读对 | 卡片红描边轻抖;**语音领读一遍单词** + 单词名高亮闪烁 | 再次自动进入语音识别 |
| ❌ 错 3 次(保底) | 同词连错 3 次 | 对手友好回敬一招击中用户(**用户 −1 血** + 轻震屏),该卡跳过 | 对手说「Nice try!」;记错;自动下一词(**永不卡死**) |

- ⚠️ **超时不触发红色波纹边框**(只有真正未读对才触发红描边)。

### 4. 数值设定(测试重点)
- **对手血量 = 配置目标单词数 − 1**(血条与"剩余卡片"近乎同步下降)。
- 普通命中 **−1**;3 连必杀 **−2**;用户 **HP = 3**(三振出局)。
- **连击规则**:错 3 次保底算连击中断;词内提示重试(错1/错2)**不打断连击**——提示后读对仍计连击。
- 连击断 → 重置必杀触发计数与 combo 数;完成一次必杀 → **只重置必杀触发计数,不重置 combo**。即每 3 次连对触发一次必杀,combo 可无限累计(理论 ≤15 道题)。

### 5. 三种结局(全正向)
- 🏆 **3★ 胜利**:对手血见底 → 对手崇拜「Wow, you're so strong!」+ 胜利姿势 + 满屏彩带。
- 😜 **2★ 超越**:牌组用完但对手仍有血 → 对手鬼脸「You're getting stronger!」。
- 💪 **1★ 好棒的一局**:用户血清空 → 对手「I'm strong today!」(友好鼓励,不羞辱)。

### 6. 回放设定
- 点击单词卡片 → 重播领读 1 遍 + 重置本次跟读倒计时。
- **聆听时可点击卡片**;**领读与打分时不可点击**;可点击时右上角展示喇叭图案。

### 7. 需求范围(端)
- **App 端**:gamelist 新增「跟读挑战课」模板;全程语音识别;跟读对战核心组件(看图开口读→自动识别→充能命中,递进提示,错3保底跳过);友谊赛外壳与三结局;Max/Lily 格斗服成套姿态。
- **admin**:路径内容配置新增该模板;gamelist 支持 **course word / learning asset 二选一**取值——选 course word 与原逻辑一致,选 learning asset 则调起【词库】选择组件选目标词;**此类型不可选 quiz**。
- **后端**:跟读挑战课 / learning asset 模式返回格式**需与原 gamelist 格式一致**。

### 8. 数据埋点
- 作为一种 gamelist 课:正常 gamelist 埋点 `app_game_play` / `app_game_interaction` / `app_game_pause` / `app_game_quit` / `app_game_complete` + **语音识别埋点 `lesson_speech_recognition_end`**。

## 验收核心(原文)
- Max、Lily 均格斗服、动画不穿模;开口读对=充能命中;提示递进(图→显词→领读);错 3 次必保底跳过;3 连对触发龟派特写必杀;三结局齐备;埋点上报正常。

## 回归 / 风险重点(现算)
- **语音识别判定**:开口读对/错的判定准确性、超时与未读对区分(超时不触发红边)、自动识别持续进行,复用语音识别组件(关联 [跟读组件改版与单词回顾卡]、[麦克风授权与跟读反馈优化]、[降噪增益])。
- **gamelist 模板兼容**:走 gamelist 而非 Quiz,course word / learning asset 两种取值路径、learning asset 调词库选组件、后端返回格式一致(关联 [单词配置新增字段与默认值]、[素材库升级] 的词库/learning asset)。
- **数值边界**:目标单词数=1 时对手血量=0 的边界;combo 累计与必杀计数重置规则;用户 3 血三振;错3保底后连击中断。
- **不卡死**:同词错 3 次必跳过,任何分支都能推进到结算。
- **本地化文案/语音**:4 处改后文案 + "What is this?" 仅首题,多语言播报正确,勿残留旧文案。
- **埋点双通道**:gamelist 5 事件 + `lesson_speech_recognition_end` 均上报(关联 [App神策全埋点]、挑战课 [挑战课Quiz改版] 的 combo 复用)。
