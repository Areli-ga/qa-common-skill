## 摘要
给近几版路径 AB 实验**收口**：**下掉 `homepage_reward_giggles`（V1.34 扭蛋 / 宝箱实验），保留实验组（路径无扭蛋宝箱）**；**下掉 `homepage_learning_order`（V1.35 解锁规则与学习顺序实验），保留对照组（按天解锁 + 已解锁可跳学），但把实验组的「单元勋章」迁到对照组**。配套：**单元结算流程**重排（最后一课 → 连续打卡 / 排行榜轮播 → 回地图自动开**单元结算页** → 学习中心单元勋章看板 → 再出其他引导）、**点勋章可重看单元总结**、**老单元宝箱点开升级为新结算样式（宝箱保留）**；**老用户路径扭蛋 / 宝箱的老数据处理**（已解锁 Level 的保留、升级到新 Level 后不再有宝箱扭蛋改为勋章）；**连续打卡去掉 TTS 只留音效、动画缩短、播完 2 秒自动回地图**；**去掉路径单元分割线**；**新增路径「运营节点」（Map Operation Node）Admin 配置**（素材 / Spin 动画 / 跳转 / 用户标签 / AB key / 绑定 Level·Unit / 关联单元进度门槛 + 三语 TTS）。附完课结算与运营位埋点。

  - **近期测试的解锁规则和学习顺序，以及单元勋章，需做老数据处理**；参考《【数据复盘】解锁规则和学习顺序》（wiki `Da0PwxVtPij6fSkX7PYl8KAegp6`，未入库）。
- **AB 收口结论**：
| AB key | 来源 | 处理 |
|---|---|---|
| **`homepage_reward_giggles`** | V1.34《路径奖励AB测试》 | **去掉 key，保留实验组**（扭蛋和宝箱的实验 → 路径无扭蛋宝箱） |
| **`homepage_learning_order`** | V1.35《解锁规则和学习顺序测试》 | **去掉 key，保留对照组**；**但实验组中的单元勋章功能需要迁移到对照组** |

### 1. 解锁规则（保留对照组 `homepage_learning_order`）
- **对照组（不变）**：**只要前一天有学习行为（完成任意一节课），次日都会解锁新 part 内容**；**若用户把前一 part 的内容都完成，可以继续解锁新 part**。
- 实验组（原文仍列出，作对照）：去掉按天解锁、按完成单元解锁；**首次进入地图解锁 Hello 课程 + 前两个单元**；**完成已解锁的最后一个单元（第 2 个）继续解锁两个单元**，解锁动画沿用线上资源。
- 原文结论句：「**发版本之后，全用户所有版本，都用新的解锁方式**」。
- ⚠️ **口径冲突**：标题写「保留对照组」，但结论句说「都用**新的**解锁方式」—— 而「新的解锁方式」在 V1.35 语境里指实验组（按单元解锁）。结合第 2 节「老用户采用新的解锁方式（**对照组**）」推断这里的「新」= 本版统一后的方式 = 对照组，**但原文没写死，需与产品确认**。

### 2. 学习顺序（保留对照组 `homepage_learning_order`）
- **对照组（不变）：已解锁的课程用户可以跳着学习**。
- 实验组（原文仍列出）：**单元内必须按顺序学**（点已解锁未完成的第一节课可正常进入；点**已解锁未完成的非第一节课** → 「课程无法进入反馈动画 + 推荐课程动画」）；**单元间可以跳着学**（可选第一或第二单元首节课开始），已解锁的每个单元未完成的第一节课都有课程引导动画；**点未解锁单元 → 动画引导定位到最新解锁单元的第一节未完成课程**。
- 原文结论句：「**发版本之后，用户升级到新版本之后，老用户，就会采用新的解锁方式（对照组）**」。
- ⚠️ 原 V1.35 实验组用户（已习惯按单元解锁 / 单元内顺序学）切回对照组后的**进度与已解锁内容如何承接**，原文未写。

### 3. 单元勋章与单元结算流程
单元结算流程改动：
1. **单元最后一节课结束，若有连续打卡、排行榜页面，则依次轮播**；
2. **结束后回到地图，会自动打开单元结算页面**（本期 Leah 优化样式，见《学习中心修改样式 + 单词书1.0》的 `Unit {n} Complete`）**→ 学习中心单元勋章进度看板**（本期 Leah 也优化了样式）；
3. **若有其他单元结束的弹窗和引导，在第 2 步流程完毕后再出现**，例如**任务看板的焦点引导、奖励中心购买引导弹窗**；
4. **路径中保留单元勋章**：**升级到新 Level 后，新 Level 路径中会出现勋章**；**不影响目前已经解锁的路径 —— 已解锁的路径一开始没有勋章的，上线后不需要新增**；
5. **点击勋章，可以重复查看单元学习总结页面**；
6. **以前的单元宝箱，点击后【单元结算页面】升级成新样式，宝箱依然保留**；**新样式中如果没有开口次数以及正确次数，则隐藏相关数据**。

### 4. 路径中扭蛋、宝箱老数据处理
- **对于路径依然有宝箱的老用户：Level 升级后，删除新 Level 的宝箱、扭蛋**；**已经解锁的 Level 的宝箱，无论是否解锁以及是否打开奖励，都保留**。
- **升级到新 Level 后，新 Level 路径中会出现勋章，并且不再有宝箱和扭蛋，会有新增的单元勋章**。

### 5. 连续打卡语音和交互优化
- 问题：打卡语音「Daily fire keep your fame, com back every day to keep your streak alive」→ **去掉该 TTS，仅保留音效，且动画时间适当缩短**。
- **新增逻辑：daily streak 动画播完，2 秒后自动关闭回到地图**。
- ⚠️ 埋点表里 `app_finish_daystreak_next` 的说明写「**3 秒**自动进入下一页页面」，与正文「**2 秒**后自动关闭」不一致。

### 6. UI：去掉单元分割线
- **已经有单元卡片和单元奖章代表一个单元，去掉单元的分割线**。

### 7. 新增路径运营节点（Map Operation Node）
在指定单元的学习路径上挂一个可点击的运营位。**运营后台配置字段**：
| 字段 | 说明 |
|---|---|
| 运营素材 | **解锁前图片**、**打开之后的动画（Spin 压缩包）**、**解锁后图片** |
| 跳转链接 | **支持内部 H5 和原生页面链接跳转**（图上示例：内部深链 `giggle://rewardcenter` / `giggle://playzone` / `giggle://featureplaza`、外部链接 `https://act.giggle.../call`） |
| 用户标签 | **默认对全部用户展示；配置了用户标签则只展示给对应人群** |
| AB key | **支持配置 AB key，根据实验控制是否展示该 banner** |
| 投放位置 | **关联某个 Level、某个单元**；**不选 pathway 就是全部 path，选择 pathway 就指定 path**；图上另有「**插入位序**」（单元末尾等），**位序超出实际节点数时客户端自动降级为单元末尾** |
| 关联单元学习进度 | **开关打开 = 完课后才能点击跳转；未完成时播配置的 TTS，完成后才可点击跳转**；**开关关闭 = 无论单元完课与否都可点击跳转** |
- Admin 原型补充（图读出，原文正文未写）：
  - 菜单：**学习路径 → 运营节点配置（NEW）**，同级有地图布局、解锁规则；列表筛选 Level / 状态 / 人群 / AB；列：跳转、解锁门槛、人群（Aaron）、AB、**生效时间**、**状态（生效中 / 待生效 / 已过期 / 已下线）**、操作（编辑 / 复制 / 上线 / 下线 / 删除 / 查看）；
  - **规则约束：同一 Level + Unit 在生效时间上有重叠的配置只允许 1 条（保存时拦截）；每个 Unit 最多渲染 1 个运营节点**；
  - **配置生效顺序：人群圈选（Aaron）→ AB 分流 → 生效时间校验 → 下发客户端**；**对照组用户服务端直接不下发配置，客户端不会渲染节点，避免污染实验数据**；
  - 基础信息：**配置名称 1-50 字符、同环境内唯一**；备注；
  - 解锁门槛：**完成判定口径（默认取「整单元完课」，与完课结算的单元完成口径一致；可选「该 Unit 完课数 ≥ N 节」）**；**未完成时行为：点击播放语音提示（不跳转）/ 置灰不可点**；**TTS 提示文案 EN / ID / ZH 三语**（示例「Finish this unit first, then your gift is waiting for you!」）；
  - 另一版列表原型（img-04，挂在「课程系列」菜单下）列出投放位置「Level 2 · Unit 2 · 单元末尾 · 应用到所有路径」、跳转目标「家长中心问卷调查 / 自然拼读」、解锁门槛「无门槛 / 整单元完课 · 点击播放语音提示（不跳转）」、目标人群「所有用户 · 未绑定」，操作含「**转回草稿**」—— **两版原型菜单位置与字段不同，以哪版为准未说明**。

### ⚠️ 测试关注 / 回归点
- **AB 下线后的用户迁移**：V1.34 对照组（有扭蛋宝箱）用户、V1.35 实验组（按单元解锁、单元内顺序学）用户升级后的表现；**单元勋章迁到原对照组**。
- **老数据**：已解锁 Level 的宝箱 / 扭蛋保留（无论是否打开）、升 Level 后新 Level 无宝箱扭蛋 + 有勋章、已解锁路径不补勋章；老宝箱点开 = 新结算样式且缺开口 / 正确次数时隐藏。
- **结算流程顺序**：连续打卡 → 排行榜 → 回地图 → 单元结算页 → 勋章看板 → 任务看板焦点引导 / 奖励中心购买引导弹窗，与 V1.37《单元内连续学习与单元结算》、V1.34 Giggles 购买引导弹窗交叉回归。
- **运营节点**：人群 × AB × 生效时间 × 进度门槛四重条件；同 Level+Unit 时间重叠拦截；每 Unit 只渲染 1 个；对照组不下发；位序超界降级；三语 TTS；曝光以「滑动露出」为准。
- **连续打卡**：2 秒 vs 3 秒自动关闭口径冲突；TTS 去除后仅音效。
