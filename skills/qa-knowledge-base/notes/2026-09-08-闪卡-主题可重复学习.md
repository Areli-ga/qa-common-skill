## 摘要

修复「闪卡主题学完后点击无法进入」的客诉：**闪卡主题卡在所有状态下都可点击进入**，已学完的主题**从第 1 张卡开始完整重学一遍**该主题全部单词，复习模块（每日复习）本次不改动。

## 功能信息（逻辑/状态/边界/字段）

### 基本信息

- 产品 Owner：**Aaron**；优先级：**高**；版本 v1.38.0；文档日期 2026-08-20。

### 背景与目标

- **用户反馈**：闪卡下某一主题（如「海洋动物」）的单词全部学完后，再次点击该主题**无法进入学习**，出现「点了没反应 / 无法再学」。
- **现有逻辑**：主题内单词学完（状态 `learned`）后，这些单词**只在「复习」模块中再次出现**，闪卡主题入口本身不再支持进入学习。
- **问题与机会**：低龄启蒙高度依赖「重复看、反复认」，孩子常想对熟悉/喜欢的主题反复学，却被「**学完即锁**」挡住，体验割裂并产生客诉。
- 目标：
  - 修复「主题学完后点击无法进入学习」—— **闪卡主题始终可点击、可进入**；
  - 支持对已学完主题**反复学习该主题下的全部单词**；
  - 定量：闪卡主题的**重复进入率 / 人均学习时长**提升；相关客诉、反馈下降（**基线待补充**）；
  - 定性：满足「重复学习」需求，闪卡体验顺畅、**无「死路」**。

### 名词

| 名词 | 说明 |
|---|---|
| 闪卡 | 按主题（交通工具 / 鸟类 / 海洋动物…）组织的**单词图卡学习模块** |
| 主题 | 闪卡下的一个单词集合 |
| 学完（learned） | 主题下**所有单词均已学习过** |
| 重复学习 | **本次新增**：主题学完后再次进入，**从头再学一遍该主题全部单词** |
| 复习模块 | 现有的对已学单词做间隔复习的模块（如「**每日复习**」），**本次不改动** |

### 需求范围

仅一条：**已学完主题再次进入 → 重新学习该主题全部单词（可反复）**。

### 一、主题入口与状态

**闪卡主题卡在所有状态下均可点击进入；不再因「已学完」而禁用或无响应。**

| 主题状态 | 展示 | 点击进入行为 |
|---|---|---|
| 未学习 | 常规样式 | 进入，**从第 1 张卡开始学** |
| 学习中（部分学过） | 常规样式（**可选**进度标识） | 进入，学习该主题单词（**续做未学习的单词**） |
| 已学完 | 常规样式，**可加「已学完 ✓」标识**（**不置灰、不拦截**） | 进入，**从第 1 张卡开始，完整重学一遍** |

### 二、重复学习流程

点击已学完主题 → 进入该主题闪卡序列（全部单词）→ **根据闪卡学习规则推荐一组主题下的单词** → 学完到达结束页。

- **卡片范围：该主题下全部单词（与首次学习一致）。**

### 数据埋点

⚠️ **全篇无埋点章节**，而定量目标是「重复进入率 / 人均学习时长」—— 缺少区分「首次学习」与「重复学习」的事件或属性，目标无法验证。

### ⚠️ 待确认（写用例前需拉齐）

1. **「全部单词」与「推荐一组」自相矛盾**：流程写「进入该主题闪卡序列（全部单词）→ **根据闪卡学习规则推荐一组主题下的单词**」，卡片范围又写「该主题下**全部单词**（与首次学习一致）」。到底是一次学完全部，还是按现有闪卡规则每次只推一组，直接决定用例怎么写。
2. **重学是否写入单词状态与记忆数据**：文档只说「复习模块本次不改动」，但没说重学时是否更新 `learned` 状态、是否写《每日复习》的 `review_count` / `last_reviewed_at` / `mastery_level`。若写入，会改变遗忘曲线；若不写，重学对复习体系完全不可见 —— 两种都需明确。
3. **重学是否发奖励**：首次学习是否有 Giggles / 星星 / 任务进度（《任务 2.0》里有「学习一本绘本」这类日常任务），重复学习是否重复发放、是否有防刷限制，全未提及。
4. **两个「可选/可加」都没拍板**：「学习中」状态的进度标识、「已学完」状态的 `✓` 标识都写成「可选 / 可加」，做不做需确认，否则三种状态在 UI 上无法区分。
5. **「部分学过」与「学完」的判定边界**：续做未学习单词 vs 从头重学，切换点依赖「主题下所有单词均已学习过」的判定；单词在**其他模块**（课程、每日复习）学过是否计入闪卡主题的 learned，未说明。
6. **结束页表现未描述**：正文写到「学完到达结束页」就结束了，重学的结束页与首次是否一致、是否提示「已重学一遍」，无内容。
7. **无 UI 稿与资源列表**（文档没有 Figma 链接、无设计稿）。
8. **定量基线「待补充」**：重复进入率、人均学习时长、客诉量的当前基线都没给，无法判断是否达成。
9. **无埋点**（见上）。
