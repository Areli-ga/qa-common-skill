## 摘要

在现有**变形 + 单图片对话课**能力上让小Mai 支持中文学习:**上线 2 个岛屿、6 个课程**;主对话背景/岛屿/Scene id **按学习语言各配一套**(中文界面下 Mr. Dog 变「**狗狗店长**」中式装修与服装);**已学单词 memory 中英文分开存储**、每日 word play 改成**猜汉字**;而 **Onboarding、电量与积分系统是全局的**(一个 kid id 一套,中英文共用);**中文不启用打分**,改用 **ASR 文本匹配**;埋点新增全局用户属性 **`learn_language`**。

产品 Owner:**Libin**;优先级:**高**;Figma **`1.36.0`** node `47091-121439`。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 0. 目标与范围

- **目标**:在当前的**变形和单图片对话课能力下支持中文学习**;**上线 2 个岛屿、6 个课程**。
- **包括**:
  1. 对接 APP 的入口,**提供主场景中英文的切换入口**;
  2. 中英文界面下**提供明显的"正在学习的语言"标识**,并且**小Mai 知道当前处于什么学习语言环境中**;
  3. **定义明确的小Mai 功能边界 —— 全局功能 / 学习语言独立**;
  4. 中文对话岛屿和课程配置。
- **不包括**:**场景内镜头切换**。

### 1. 全局 vs 学习语言独立(本篇最重要的划分)

| 能力 | 归属 | 说明 |
|---|---|---|
| **主对话背景、M 小镇/中文课岛屿、Scene id** | **语言独立** | 各学习语言下配置独立的一套 |
| **课程内容与角色皮肤** | **语言独立** | **Mr. Dog 在中文界面下为中国的装修主题、穿着中文衣服、姓名为「狗狗店长」** |
| **小Mai Onboarding(唤醒 + 自我介绍)** | **【全局】** | **一个 kid id 只出现一次**;英文课主对话中做的自我介绍、捕捉到的**个人姓名通用于中英文主对话**;**先不考虑按学习语言起名**(Lily Zhang vs 张美丽) |
| **已学单词 memory** | **语言独立** | **中英文已学词汇分开存储**;在当前学习语言下加载相匹配的"已学过"词汇进行复习 |
| **电量和积分系统** | **【全局】** | **不做切割、不区分学习计划**,**kid id 下只有一套电量控制系统**,**中英语学习共用一套电量** |
| **变声模块** | 接入 | 接入变声能力 |

### 2. daily word play(中文版:猜汉字)

**脚本**:
> 「我们现在来玩一个游戏好不好?你知道吗?**中文是世界上唯一被广泛使用的象形文字**,我相信你看到一个东西,就立马知道它的中文是什么!」

- **新用户 onboarding 的词汇:山、人、目**(三个象形字)。
- 展示汉字(如「山」)让用户猜,**三条应答分支**:
  1. **用户读出了「山」** → **鼓励用户,并猜下一个**;
  2. **用户理解了、猜到是 mountain,但没有读出中文** → **仍旧告诉用户答案是「山」,并邀请用户朗读一次「山」**;
  3. **用户说不知道或答错** → **把字变形为「⛰️」**,告诉用户答案是「山」,并**阐述汉字「山」它真的像一座山**,邀请用户朗读一次「山」。
- 然后**推进下一个题目**或**完成并进入游戏岛屿**。
- 参考现有「看图片猜单词并给出首字母变形」的效果;demo 见文档内链。

### 3. daily quiz

- 在**学习语言设定下**,根据**已学单词 memory** 进行 quiz 练习。

### 4. 已学单词 memory 与素材

- **用户的中英文已学词汇分开存储**;
- 在当前学习语言下**加载相匹配的"已经学过"单词/词汇并复习**;
- ⚠️ **需要补充中文学习内容的 SVG 文件**,**中文按「字」来进行矢量图形的制作**(与英文按"单词"不同)。

### 5. 通知

- **岛屿更新后收到的通知 link,区分中英文学习**,**点击直接进入到对应学习环境中**。

### 6. AI 能力与打分策略(测试关键)

- 包括 **LLM、TTS、STT(ASR)**。
- **打分能力不做要求**:
  - **使用 ASR 文本匹配的方案**;
  - **不启用打分**。
- **中文打分调研(未解决,故本期不做)**:**中文多音字**、**音调**等。
- 📌 这意味着**中文课的"读对没读对"只有"匹配/不匹配"两种结果,没有星级**——与英文侧的打分体系完全不同,**跟读反馈、鼓励文案、以及依赖星级的下游逻辑都要单独确认**。

### 7. 数据埋点

- **全局公共参数**:在**用户属性**中增加 key-value ——
  - **key:`learn_language`**
  - **value:`chinese` / `english`**
- **对所有小Mai 侧的事件(《Mai - AI Tutor 埋点》)有效**。
- ⚠️ 这是**用户属性(User)而非事件属性**,意味着**同一用户切换语言后历史事件的归属**需确认(用户属性通常是"最新值覆盖")。

### 8. 灰度规则(需要给到主 APP)

按语言灰度:**中文、印尼语、英文……**(原文列举未尽)。
- ⚠️ **只列了语言维度,没给具体灰度比例、名单或开关口径**。
