## 摘要

V1.30.0 Quiz 答题交互简化:**非学校场景**下,从「选选项 → 点 Submit → 提交」改为「**点击选项即自动提交**」,降低低龄用户操作成本;并优化答题错误反馈。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 交互改动
- 旧:选选项 → 点 Submit 按钮 → 提交。
- 新:**点击选项即自动提交**(少一步确认)。

### 答题场景(测试重点 · 注意例外)
| 场景 | 交互 |
|---|---|
| 挑战课 - Quiz | 点击即提交 |
| 单元测验 - Quiz | 点击即提交 |
| Level Up - Quiz | 点击即提交 |
| 专项计划 - Quiz | 点击即提交 |
| Ai Tutor - Quiz | 点击即提交 |
| **学校系统 - 课堂模式 - Quiz** | ⚠️ **仍点 Submit 提交**(唯一例外) |

### 答题错误反馈优化
- **去掉答题错误语音反馈**,改用**动画**:答错时选项**边框变红 + 抖动**。
