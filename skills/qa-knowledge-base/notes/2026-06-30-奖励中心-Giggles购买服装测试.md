## 摘要

V1.31.0 在**奖励中心 V2.0 新增商城模块**(AB 测试):用 Giggles 购买服装装扮(两套:魔术师 + 宇航员),验证用户购买意愿(购买率/复购率)与对留存的影响。背景:当前 Giggles 消耗隐蔽(仅趣玩乐园且需注册登录),用户感知不到 Giggles 价值。产品 Owner: Sunny;优先级:高。⚠️ 文档版本字段残留 `V1.0`(模板),figma 为 1.31.0,实际 **V1.31.0**。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 背景数据(4/1 起)
- 首次启动设备总数 166,326;1 天内触发 `play_zone`(`app_game_play` 且 `scene='play_zone'`)仅 3,988(**2.4%**);1 天内触发抽奖(`APP_Reffering_Activity_draw`)5,426(**3.26%**);首启→首次趣玩乐园 25 分 14 秒,首启→首次抽奖 18 分 11 秒。

### 需求范围
- 奖励中心 V2.0 新增**商城模块**测试。
- 配置两套服装,标签【商城测试】+ 物品价格;**本期先不做后台配置**(写死)。
- 购买模块引导定位 + 整体商城 **AB 测试**。

### 商城展示
- 在奖励中心新增 Giggles 展示,放在**商城 tab**。
- 两套服装:**魔术师 + 宇航员**,各含 帽子 / 上衣 / 裤子 / 鞋子(**真实非剪影,但不可穿戴**);每个物品单独展示价格(如 200 Giggles)。

### 购买交互(测试重点)
- 点商品 → 购买按钮:
  - **数量足够** → 购买确认 → 成功后 **Giggles 数量变化动画** + 物品获得状态 + **按钮变为"可穿戴(Wear)"**。
  - **数量不足** → 语音提示「**哎呀,还差一点点!完课可以获得 Giggles**」。
- 已获取后:与正常穿戴交互一致,**不用通过弹窗穿戴**。
- **tab 定位引导**:商城上线后,用户未访问商城则进奖励中心时商城 tab 有**更新图标**吸引点击;进入一次后引导消失、变正常图标。

### AB 测试与埋点
- **Feature key: `new_reward_center_shop`**(reward_shop_center)。实验组可见商城购买,**对照组不展示**。
- 埋点:`reward_shop_center`,key `new_reward_center_shop` **作为 AB 属性存到用户属性身上**(与 AB Test 优化的用户属性分流一致)。
- **核心验证指标**:购买率(实际购买人数 / 看到购买人数)、复购率(第二次购买 / 第一次购买)、实验组 vs 对照组留存对比。
