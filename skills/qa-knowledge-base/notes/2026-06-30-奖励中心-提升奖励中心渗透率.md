## 摘要

V1.33.0 做奖励中心渗透率测试:针对新用户 day2 启动和老奖励中心升级到新奖励中心的用户展示奖励中心 / 家园引导弹窗,测试用户体验奖励中心核心玩法后是否能降低 day2 → day3 流失。新用户 day2 走 AB 实验 `reward_day2_homeinrto`;老用户升级引导跳过实验 key。产品 Owner:Sunny;优先级:高。⚠️ 文档「版本号」字段为 **V1.0** 模板残留,本笔记按主人给定 **V1.33.0** 录入。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 1. 背景与目标
- 背景:奖励中心经过几轮迭代后,V2.0 留存已有较大提升,当前新用户次日留存约 18%。
- 本次目标:让更多用户进入奖励中心体验,验证体验奖励中心核心玩法后是否能降低 day2 → day3 流失率。
- V1.32 已在测试首日第一个 part 强引入奖励中心。
- V1.33 针对首日未进入奖励中心的用户,在第二天做奖励中心强引入,测试能否提升第三天留存。

### 2. 需求范围
- 对第二天启动 App 的用户展示奖励中心引导弹窗,并根据测试结果判断效果。
- 对老奖励中心升级到新奖励中心的用户展示引导弹窗。

### 3. 新用户 day2 引导 AB
- 实验 key:`reward_day2_homeinrto`。
- 实验组:day2 家园弹窗展示。
- 对照组:无弹窗。
- 覆盖用户:新用户 day2。
- 对比指标:Day3 留存数据。
- 判断条件:
  - 老版本升级首日:`isOldUpgrade=True`,跳过 AB,弹窗展示。
  - 新用户次日:`isSecondDay=True` 且 AB 命中 true,弹窗展示。
  - 新用户次日:`isSecondDay=True` 但 AB 命中 false,不弹窗(AB 拦截)。
  - 新用户首日:day 条件不满足,不弹窗。
  - 已弹过的 kid:不再弹(本地标记)。

### 4. 新用户 day2 弹窗路径
- 新用户 day2 按安装时间判断。
- 如果有次日 hook,直接针对次日 hook 引导进入奖励中心。
- 如果没有次日奖励 hook,通过家园弹窗引导点击,进入家园引入动画,再到奖励中心。
- 有 hook 宝箱引导时:
  - 展示宝箱弹窗。
  - 开出头饰。
  - 点击宝箱领取。
  - 奖品飞入奖励中心后,再出现【家园弹窗】。
- 没有次日 hook 时:
  - day2 直接触发【家园弹窗】。
  - 弹窗语音文案:`欢迎回来，解锁你的家园`。
- 游客一致性:
  - day2 继续游客状态 → 弹窗。
  - day2 注册新账号 → 弹窗。
  - 登录已有账号除外。

### 5. 老用户升级引导
- 老用户升级奖励中心引导弹窗不判断实验 key。
- 评审后条件:低版本升级到 1.33 版本就弹出弹窗。
- 直接安装 1.33 版本,不弹窗。
- 跟随老用户升级引导逻辑:
  - 用户从奖励中心 1.0 升级到 2.0 / 2.1 后,首次进入触发弹窗。
  - 若家园全量后,针对所有老用户都弹出该引导弹窗。

### 6. 奖励中心 1.0 全量升级 2.1
- `new_reward_center_2` 在 AB 后台全量实验组后,代码层面可去掉 key,让用户升级到 2.1。
- 奖励中心 V1.0 → V2.1:key `new_reward_center_2`,全量实验组后去掉 key。
- 奖励中心 V2.0 → V2.1:key `reward_homeplay_test`,全量实验组后去掉 key。
- Nextday hook 全量实验组后,保留 Next hook 能力,key `reward_nextday_hook132` 去掉 key。
- `reward_shop_center` 在 AB 后台全量配置后,代码去掉 key,对全部用户开放,相关埋点也去掉。
- 菜单栏 banner 配置由产品去掉配置;主路径保留贴纸抽奖;后端调整贴纸获取比例。
- 前端展示贴纸模块装扮入口,扭蛋入口依然隐藏。

### 7. 数据埋点
- 实验 key:`reward_day2_homeinrto` 同步到用户属性中。
- 新增 / 关注事件:
  - 弹窗曝光:`reward_secordday_popshow`,属性 `/`。
  - 弹窗点击:`reward_secordday_popclick`,属性 `/`。
  - 次日 hook 引导曝光:已有埋点。
  - 次日 hook 引导点击进入奖励中心:正文未给事件名。
- ⚠️ 字段拼写按原文保留:`homeinrto` / `secordday` 疑似拼写错误,但测试和埋点核对时应以实际实现为准。

### 关联依赖(回归注意)
- 与「家园引入介绍+室内装扮」强相关:本次复用家园弹窗、家园引入动画、V2.1 家园装扮能力。
- 与「新单元奖励 / 次日 hook」相关:day2 有 hook 时先走宝箱开头饰,再出现家园弹窗。
