## 摘要

V1.34.0 对 v1.32.0 已跑通的「AI 音频生成 + 双维度审核 + 音色预设」体系做 Admin 侧优化,解决试用暴露的三个痛点:① Admin 支持在已有课程中**直接单条新建语音 Key**并级联生成翻译/音频(不必重走批量模板);② 引入 `order` 字段让**导入顺序=管理顺序=导出顺序**,音频组按序作业不再错位;③ 新增爸爸/妈妈/爷爷/奶奶**四个家庭音色预设**。附一批音频管理 bug 修复。

⚠️ **版本**:文档字段 `v1.34.0`,与主人给的 **V1.34.0** 一致(原料 2026-07-01 抓取时未传版本、meta 记 null,本次按 V1.34.0 落库)。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 1. 新建 Key(English Review Tab,核心)(图1)
- **入口**:English Review Tab 工具栏左组新增「+ 新建 Key」按钮(紧邻 Import)→ 打开「新建语音 Key」弹窗。
- **弹窗字段**:`Key`(必填)、`English Text`(必填)、`Voice Model`(下拉,默认「全局默认(Narrator-F)」;为空走全局默认,不支持目标语言的音色将禁用并提示)。
- **弹窗提示**:保存后自动生成英文音频,同步生成中文翻译+中文音频;其他多语种需在 Chinese Tab 手动触发 **Batch Translate**。
- **弹窗按钮**:保存(保存当前条 → 关闭弹窗,列表定位并高亮新行)/ 取消(放弃未保存内容)。
- **校验规则**(前端即时反馈 + 后端二次兜底防并发重复建 Key):
  - **Key 唯一性**:与当前课程已有 Key 比对,重复行内报错「该 Key 已存在」,阻止保存。
  - **Key 命名**:不符合字符规则(字母/数字/`_`/`-`)即时报错。
  - **English Text 非空**:空值阻止保存。
- **保存后行为**:执行「EN 生成 → 同步 ZH 翻译+音频 → 其他多语种手动」;
  - **排序落位**:新建 Key 的 `order = 当前课程最大 order + 1`(追加到列表末尾)。
  - **三 Tab 表现**:EN Tab 立即出现新行;ZH Tab 因已自动级联翻译立即出现新行;**Other Lang Tab 暂不出现**,待用户手动触发翻译后出现。

### 2. JSON 导入排序一致(order 字段)
- **导入即所见**:JSON 里 Key 的先后顺序 = 表格展示 = 导出 = ZIP 打包顺序,形成「导入顺序=管理顺序=导出顺序」闭环。
- ⚠️ **本期不支持导入后手动拖拽重排**(已确认);顺序唯一真相来源是导入的 JSON。
- **排序字段**:新增 `order`(整数,按课程维度,作用于 Key 粒度)。表格默认 `order` 升序(EN/ZH/Other 三 Tab 一致)。
- **Other Lang Tab** 每行是 `(key, target_language)`:主排序按所属 Key 的 `order`,次排序按 language 固定既定顺序 —— 同一 Key 的多语种聚拢且稳定。
- **导入解析规则**:解析 JSON 时按 Key 出现顺序依次赋 `order = 0,1,2,…`。

### 3. 新语音模型接入(家庭音色预设)
- 新增 **爸爸 / 妈妈 / 爷爷 / 奶奶** 四个音色预设(原只覆盖 Max 家族儿童/旁白角色)。
- 音频组为每个家庭音色提供:干净音频样本(时长按 Ryan 要求)、角色描述(性别/年龄段/性格/情感基调)或音色参数、展示名。
- Ryan 在 **GiggleAITool** 完成克隆,每个预设产出唯一 `voice_model_id` + 展示名 + 支持语言清单(如 `['en','zh',…]`)。
- 后端拉取预设清单 → 三个 Tab 的 Voice Model 下拉自动出现新音色;「可用音色预设」信息弹窗展示新增项(展示名 + 支持语言)。

### 4. Bug 修复及其他优化
- **批量音色掉音色**:选批量音色模型时经常掉音色(选了但刷新后部分没改成功)。接口 `voiceModel/batchUpdate`。
- **重新生成外漏**:该功能常用,现需「更多→重新生成→确认弹窗」太繁琐,按钮外漏到列表界面;**二次弹框保留、不去掉**。
- **多语言生成错误**:部分语种生成错误(如日语有时生成的不是对应内容的语音)。
- **导出 ZIP 不全**:仍有导出音频 ZIP 内容不全(如 `Bedroom1-1 IntroVO`、`Family1-3 PracticeVO` 缺失部分语音文件)。接口 `export-from-course?courseId=xxx`。
- **已完成(done)**:单音频下载不再跳转页面(原下载完返回会清空页面);下载文件命名 `name_key` 格式;英文音频支持拖动上传(原只中文可拖);Key 搜索支持回车。

## 回归 / 风险重点(现算)
- **新建 Key 级联链**:EN 生成→ZH 翻译+音频自动、Other 需手动,三 Tab 出现时机不同;级联失败时的行状态与重试。
- **order 全链一致**:导入/展示/导出/ZIP 四处顺序必须一致;新建 Key 追加到末尾(最大 order+1);Other Lang 二级排序(Key order + language 固定序)稳定(关联 [单词短句多语言音频库] 的音频中台/审核流)。
- **校验兜底**:前端即时校验 + 后端防并发重复建 Key,并发下唯一性不被击穿。
- **音色预设**:新增 4 家庭音色的支持语言清单正确、不支持语言的音色在对应 Tab 禁用并提示。
- **bug 回归**:批量音色不再掉、重新生成外漏后仍保留二次确认、多语种生成内容正确、ZIP 导出完整(重点验历史缺失样例)。
