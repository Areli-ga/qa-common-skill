## 摘要

V1.38.0 在 V1.37 新人任务体系之上扩出**常规任务（每日）**和**回归任务（14 天未活跃召回，30 天内学 3 天领 3 份奖励）**，新人任务加 5 天时限并按 Onboarding 的家长/孩子动机动态生成任务 2、3，同时把任务全量搬进后台 **Campaign 配置**（触发条件 / 结束条件 / 频率 / 奖励 / DeepLink 均可配），目标是提升 2 周及以后的留存。

**进入常规任务的三种时机**（均展示「Now new tasks every day / See new tasks」云弹窗，img-06 / img-07）：

1. **用户注册 day 6 启动** → 直接看到此弹窗；
2. **用户完成新人任务并点击领取奖励后** → 看到此弹窗，点「查看任务」有**任务面板过渡弹窗**，再展开常规任务面板；
3. **回归任务结束（完成 3 天学习）后** → 同样展示此弹窗；
4. **本期上线后被命中 AB 实验的老用户** → 看到此弹窗，点击查看任务展开任务面板。

**面板与打卡规则（img-08）**

- 用户完成 Daily Task 后，**右侧日历打勾，且火苗点亮**。
- **每日必做任务完成后，日历才打勾**。
- **每日任务（对应后台「必做任务」）**：完成一节主路径课程；点击 Go，弹窗关闭，跳转到主路径上对应该学习的课程。
- **Bonus Task（对应后台「可选任务」）**：基于后台配置展示，**不影响日历打卡**。
- **Daily Review**：复习功能，会在后台配置成一个**可选任务**（参考文档《App - 新增任务【每日复习】》）。
- 面板样式：左侧 `Daily Task：` / `Bonus task：` 两组任务卡（每张带 `GO >` 与礼物图标），右侧月历（示例 August 2026）+ 火苗连胜天数（示例 252 Day），已完成日期为绿色✓，当天带红色三角标记。
- 面板切换动效（img-17 规格卡，**低分辨率截图，放大后仅大意可辨，数字建议以 Figma 原件核对**）：触发条件=点击 `See new tasks` 按钮；动画=按钮压下后弹窗向左侧任务板方向缩小淡出，旧任务内容同步退场，面板保持左侧位置，再向右展开为日常大面板，任务列表与日历依次出现、已完成日期逐个点亮；节奏≈按钮回弹 0.15s + 弹窗收起 0.35s、蒙层淡出 0.3s（同时）+ 旧内容淡出 0.25s + 面板展开 0.5s（错开 0.15s）+ 弹窗回弹 0.12s + 任务与日历滑入各 0.25s + 日期点亮 0.35s，**总时长约 1.6s，一次性播放**。

### 5. 回归任务（Win-back）

- **用户 14 天未启动过 App，启动 App 被命中回归任务。14 天可配置。**
- **14 天不活跃的定义：未使用主路径课程、小麦、聚合入口功能、家园。**
- 弹窗（img-09）：`Welcome back` + 副文案 `Learn 3 days in a row for a special gift back` + `Start` 按钮；**点 Start 进入用户上次未学的课程**。
- **回归任务关联到 kid，切换 kid 弹出回归任务弹窗；新建 kid 触发新人任务。**
- **3 天的任务都是学习，展示在顶部，完成 1 天领取 1 天的奖励。**
- **任务的完成时间不是 3 天内，30 天内完成 3 天学习任务即可**；**30 天对应后台的【任务窗口期】字段**。
- **同一个用户只命中一次同一个回归任务。**
- 三天奖励（正文）：Day 1 一套魔法服装 / Day 2 Giggles / Day 3 一套魔法家具。
- **命中回归任务的用户 day2、day3 启动 App 都直接展开面板。**
- 完成任务后**直接打开任务面板，晃动今日待领取的奖励**（正文另注「修改图片为无【已完成任务】」）。
- 点击可以收下奖励 → 点击收下后 **Max 出现**：「明天再来学习，Max 还会给你新的奖品。」CTA：「好的，明天见」。
- 领奖弹窗（img-15）：`New Award` + 奖励物品 + `Take it`；背景面板标题为 `Learn 3 days, get a gift`，任务卡 `Finish 3 days of lessons`，下方三天进度点（1/2/3，各带礼物图标）。
- **点击 `Try something new` 体验近期上线的新功能，点击后跳转到对应的功能**（面板内蓝色卡片，副文案 `Have a look around`）。

- V1.37 的既有入口逻辑（img-18 引用截图）：
  - **新用户任务引入（AB）**：入口固定展示，点击进入任务面板；完成第一个单元触发任务面板入口，引导用户点击进入奖励中心领取奖品；**实验组删除原本的 Giggles 购买弹窗引导**，改由完成单元任务触发引导。

**任务类型枚举**：体验功能、完成课程、完成复习、打开通知权限、邀请好友、查看功能。

- **完成课程**类型支持选择任意或指定一节课，细化字段（img-24）：`任意` + 单位下拉（**Unit / 节课**）+ `数量`。
- **非完成课程**类型：目前不涉及更细字段，基于行为判定即可。

**频率枚举**：

- **完成 1 次**：活动生效期内完成 1 次，奖励发放一次；
- **每日 1 次**：活动生效期内每日完成 1 次，配置的奖励每日发放一次；
- **累计完成 N 天**：活动生效期内累计完成 N 天任务（如回归任务），N 可配；选择此模式后出现「目标天数」和每日任务配置（img-26）——「目标天数」注「窗口期内需完成的总天数」，下方「按天安排」表按 Day 1/2/3 逐天配置任务与奖励。
- 每日奖励配置表（img-23）注：**行数跟随上方「目标天数」，用户每完成一天获得对应奖励，不要求连续**；示例 Day1 服装/春日围裙、Day2 Giggles 50、Day3 家具/三件套沙发。
