## 摘要

V1.37.0 在 V1.35 `homepage_learning_order` **实验组**基础上（**不新开 AB**）新增「完课中间过渡页（引导连续刷下一节）+ 单元结算页（开口/互动/单词录音回放）」；同时**全局不 AB** 把自然拼读从主课程 L6–L9 拆成独立课程主题（主课程收窄为 L1–L5，新 L6–L9 挂 coming soon），并对已解锁 L6+ 的老用户冷启动弹「教学体系更新」弹窗（优先级高于其他弹窗）。

> 本篇跨模块：主线在**学习路径**，但改动实际落在 **Phonics / 学习中心 / 奖励系统 / 奖励中心 / 课程加载（离线）/ 账号与设置 / 单词回顾（单词卡）** 上，检索这些模块时请用关键词兜底（`phonics`、`自然拼读`、`unit_summary`、`learn_continue`）。

## 功能信息（逻辑 / 状态 / 边界 / 字段）

- 目标：让孩子不被主页其他功能入口打断，养成**刷课心流**，测「持续完课提升完课深度」是否能提升留存。
- **不单独做 AB**：直接叠加在 V1.35 `homepage_learning_order` 的**实验组**之上（该实验组本身又跑在 V1.34 `homepage_reward_giggles` 实验组「路径无奖励」形态之上，三层叠加）。
- V1.35 实验组规则（本期沿用，作为前置状态）：
  - **解锁**：一次解锁两个单元；按完课行为解锁，完成一个单元解锁后面的单元（对照组是「前一天有学习行为按天解锁 / 完成 part 全部内容后继续解锁」）。
  - **学习顺序**：单元内按顺序学；已解锁的单元间可跳着学（对照组可任意跳学）。
- 设计稿：Figma `1.37.0` node-id=49102-3796。

  - **自然拼读解锁规则**：采用**继承解锁状态**方案 —— 新用户从第一个单元开始解锁、与主路径**并行**；老用户按**原 level ID 继承**解锁状态，主路径已完成部分保持不变。

### 1. 单元内连续完课（新增中间过渡页）

- **现状**：完课后回到地图中结算。
- **改动**：完课后新增**中间过渡页**，引导用户直接进入下一节课；**打星与 Giggles 发放动画搬到中间页**完成。要求「**短平快、不能拖沓**」。
- 过渡页分镜顺序（见图 1）：学习回顾页 →（无缝转场）当前学习课程 icon → 打星 & Giggles 飞入动画（如 +20）→ 出现下一节课程 icon 及进入下一节按钮（Next Lesson）→（无缝转场）下一节课程加载页（Lessons Name）。
- **是否自动进入下一节**：
  - 下一节**未完课** → **自动进入**。
  - 下一节**已完课** → **不再自动进入**。
- **退出定位规则（关键边界）**：
  - 连续完课**中途退出** → 定位到**当前退出的那节未完成课程**，该课程页面居中。
  - 连续完课**直到单元结算** → 定位到**地图单元勋章奖励**，该单元的勋章奖励页面居中。
  - 两种定位下都要正确处理这几件事：
    - **课程打星**：重复学习时可能**无打星动画**（本次星数 ≤ 历史星数则不播）。
    - **Giggles 动画**：重复学习时可能**无 Giggles 发放动画**（不重复发放）。
    - **排行榜结算**：若命中则展示。
- 回到路径中点击勋章奖状 → 进入**单元学习总结**；单元勋章面板发放动画；**若用户单元完成但未点击单元勋章，学习中心的勋章和进度静默更新**。

### 2. 新增单元结算页面（两态）

统计口径均为**单元维度**，且**重复学习累计**。

**态 A：该单元有单词开口**（见图 4）
- 顶部统计：**开口次数**（重复学习累计）、**互动次数**（重复学习累计）。
- 单词卡列表：学过的单词 + **孩子自己的跟读录音（可点播回放，带波形/时长）** + 单词图片 + **该单词的开口次数**（如 7x）。
- 单词图片取值：取单元的单词 `unit_goal`，**与课程回顾（单词回顾）取值一致**。
- 音频存储规则：
  - 语音识别**要上传**，统计到 **level / 单元 id / 用户 / 单词** 四个维度。
  - 同一单词多次跟读 → **取最高分的那条音频**；**按评分刷新存储新的最高分音频**。
  - 展示时取该单词**开口分数最高的一次**。

**态 B：该单元无单词开口**（见图 5）
- 顶部统计：**只有互动次数**（无开口次数）。
- 单词卡取**单元维度的配置**，**音频取教学音频**（不是孩子录音）。

**开口次数判定规则（跨篇口径，务必对齐）**
- `lesson_speech_recognition_end` 且 `is_speech_detected = true` 的**数量** = 该用户的开口次数。
- 用于区分维度的字段（见图 3/15 红框）：`speech_level_number`（关卡号）、`speech_unit_number`（单元号）、`speech_part_number`（part 号）、`speech_part_id`（sectionId，必填）。前三者**无值时不上报**。
- 同一事件的其余字段（V1.31.0 起的既有定义）：`speech_mode`（word/sentence/free）、`speech_engine`（gigglespeech/azure/tencent/unknown）、`reference_text`（free 模式不上报）、`recognized_text`、`speech_score`、`duration_ms`、`is_success`、`failure_reason`、`is_network_available`、`is_speech_detected`、`ns_enabled`、`agc_enabled`、`speech_star`（阈值 40/70 → 1/2/3 星）、`speech_retry_count`、`speech_course_id/name/type`（game/music/其他）。

**开口次数的来源范围**
- 课程内跟读：单词（现有）、短句（未来会有）。
- 跟读挑战课：单词、短句。
- 故事书跟读：**通过埋点统计进单元总开口次数**。
- 闪卡跟读：通过埋点统计进单元总开口次数，但**目前线上没有配置**；文档写明「本期来不及可以后面提需求加」→ 本期是否包含**待确认**。
- 后端单词音频获取逻辑：文档只留标题，**无细节**。

- 学习中心新增 **L6–L9 主线课程介绍**，状态为**「正在研发 coming soon」**。
- 学习中心「课程体系介绍」页改为**双 tab：主课程 / 自然拼读**（见图 6–9，中英双版）：
  - 主课程：`Pre A1 · 口语积累`，5 个等级，卡片含等级名、主题标签、目标描述、单元数 + 单词数、当前等级带定位标 + 「开始学习」、每级右上奖杯（已获得亮/未获得灰）。示例：Lv1 介绍核心词汇 17 单元 60 单词、Lv2 学习新词汇 15 单元 58 单词、Lv3 扩充词汇 16 单元 60 单词、Lv4 谈论世界 16 单元 64 单词。

### 4. 学习进度与奖励数据确认（全局改，回归清单）

- 原 L6（自然拼读）与新增 L6（后续新增的主线）**同名不同物**，奖励与学习进度数据**不得受 Level 切换影响**。
- 记录口径：**把用户完成升级 Quiz 的 level 记录下来，以 Level ID 记录**；单元完成状态**以后端记录为准**，**单元下课程变更不影响该单元的完课状态**。
- 需确认的四类数据（Level 切换后必须正常）：
  1. **奖励中心的奖杯、Level 地图末尾的奖杯**：用户已获得的原 L6–L9 奖杯（变成自然拼读 Level 的奖杯）**依然保留**；未来主线 Level 升级后可获得新奖杯（**待配置**），取决于用户是否完成当前 Level 的升级 Quiz。
     - 奖杯获取规则改为：**判断用户是否完成当前 Level 的 Quiz**。
  2. **路径中的扭蛋、宝箱、单元证书**：取决于后端记录的对应 **unit ID** 奖励是否被领取；**解锁状态也换到后端记录**。宝箱三态：未解锁 / 已解锁未领取 / 已解锁已领取。
  3. **学习中心的单元勋章**：取决于用户当前 unit id 的完课进度，完成后获得；**若课程新增变动导致用户未完成该勋章，则刷新**。
  4. **奖励中心的单元套装和勋章头饰奖励**：单元服装奖励**取决于用户是否已获得，与完成状态无关**。
