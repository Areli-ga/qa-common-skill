## 摘要

V1.31.0 新增 Colors1-2 Speaking 跟读游戏课(主题 **Ice Breaker 破冰**:单词卡冰封,跟读正确逐步破冰)。核心是完整 7 步游戏流程 + ASR 三分支判定。⚠️ **本课调整了语音识别判定逻辑**:移除「1 星通过」和「最多 2 次重试保底通过」,替换 Max 聆听动画,新增非 0 星重播用户录音、未识别 Max 反馈动画——与「麦克风授权与跟读反馈」篇逻辑有演进/冲突关系,回归重点。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 游戏流程(方案 2,共 7 步)
1. **初始化**:显示背景图;加载当前关卡配置(读取 N 张卡片的内容列表)。
2. **卡片入场**:卡片坠落动画;播放冰渣特效与音效。
3. **半解封展示**:停顿 0.5s → 文字发热动画 → 切换至**半透冰封**状态。
4. **标准音示范**:Max 出现,播放**两次**目标单词音频。
5. **开启监听**:Max 大耳朵变大动画;调起麦克风开启语音识别;显示并激活收音 UI 波形。
6. **ASR 判定分支(已有录音评分组件)**:
   - **分支 A · 识别成功(2/3 星)**:关麦 → 显星数 → 播用户录音(**仅本课临时缓存,退出清除**)→ Max 欢呼 → 播英语+本地化读音 → **冰封终极破碎**动画 → 停 0.5s → 卡片滑走退场 → 步骤 7。
   - **分支 B · 识别失败(1 星)**:麦克风闪红 → 播用户录音 → Max 疑惑 → 进入重试,错误计数 +1;**错误 ≥ 2 次显示 Skip 按钮**(第二次重试时出现)。
   - **分支 C · 未识别语音(0 星)**:Max 疑惑 → 进入重试,错误计数 +1;错误 ≥ 2 次显示 Skip。
   - ⚠️ **逻辑变更(测试重点)**:移除「1 星通过逻辑」+「最多 2 次重试保底通过逻辑」;替换 Max 聆听动画;新增非 0 星时重播用户录音、未识别时 Max 反馈动画。
7. **循环与结算**:卡片队列空?否 → 取下一张返回步骤 2;是 → 全屏结算(星星/宝箱/撒花特效),游戏结束。

### 回归注意
- 与「麦克风授权与跟读反馈」篇的 C1/C2/保底通过逻辑**直接冲突/演进**:那篇是"第 2 次失败保底通过 0 星",本课"移除保底通过+移除 1 星通过"——测试时按课程类型区分两套逻辑适用范围(本课 Speaking vs 通用跟读)。
- 用户录音仅本课临时缓存、退出清除——回归覆盖中途退出/重进的缓存清理。
