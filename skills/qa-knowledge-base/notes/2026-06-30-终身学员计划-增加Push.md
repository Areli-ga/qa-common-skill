## 摘要

V1.31.0 为终身学员计划建立完整 **Push 触达体系**:① 引导开启 push 弹窗(数据显示授权率 73%,接受度高);② 终身学员 Day1–7 未打卡/未认证的推送文案策略;③ Push 数据追踪打通(后台查每条 push 触达/打开)。前置需求:「Giggle终身学员」计划 PRD。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 背景与现状
- 现 push 触发时机仅剩「**登录选择小孩后**」(原"第二天打开课程触发"因 1.30 取消课程限制已不再引导)。

### Push 文案安全标准(机型适配,测试重点)
- 标题 **≤ 15 中文 / 30 英文**(满足所有机型折叠态可见);正文 **≤ 25 中文 / 50 英文**(OPPO/vivo 折叠态可见)。
- **核心钩子前置**:塞到**前 15 字符**(OPPO / Dynamic Island 截断阈值)。
- emoji **≤ 2 个、不放标题开头**(vivo 拒绝纯 emoji)。
- 变量 `${child_name}` 按 **8 字**算(预留替换空间)。
- 各机型字符限制详见 img-03(iOS / Dynamic Island / Android / 三星 One UI / 小米 MIUI / 华为 EMUI / OPPO ColorOS / vivo OriginOS)。

### 需求一:引导开启 push 弹窗
- **触发逻辑**:仅对**未开启提醒**的用户弹;引导弹窗 → 系统授权弹窗;**终身学员用户不弹通用引导弹窗**。
- **通用引导**:完成**第 4 节课后**(约触达 50% 用户)。文案 ZH「完成4节课学习!开启学习提醒,max明天提醒你打卡吧～」按钮 立即开启/稍后再说(EN: Turn On Reminders / Not Now)。
- **终身学员引导**:完成**首日挑战弹窗后**。文案 ZH「7天拿下终身学员认证,开启学习提醒,轻松搞定认证～」(EN: Lifetime Member in 7 days! 🏆)。

### 需求二:终身学员 Push 发送策略(仅针对参加终身学员的用户)
- **Day1–7 推送时间线**:Day1 入学(+1天权益)→ Day2–6 每天 **19:00** 对未完成触发 push → Day7 认证日 **09:00** → 终身学员。
- 未打卡/未认证文案(中文 + 印尼语,含 `{child_name}` 变量),倒计时递进:
  - 第2天「距离认证还有5天!🎓」… 第4天「已完成一半!还剩3天 🔥」… 第6天「明天就是认证日!🎓」… 第7天「今天是认证日!🎉」。
  - 前一天未打卡补打推送「你的进度已保存 🐰 ……你还有一次补打机会」。
- **推送规则(测试重点)**:主路径按 Day1–7 顺序推;**某天打卡中断 → 次日早 10:00 推未打卡推送**;**未打卡推送推 3 天挽回,未回归不再推送**;用户中途回来 → 停止挽回推送、回正常打卡推送。
- **累计制规则**:打卡进度累计、**不要求连续**(已打 N 天 + 回来继续打 7-N 天 = 认证完成);用户中断后回来**从当前进度继续,无需补签**。

### 需求三:Push 数据追踪打通(通用)
- 线上 push 也需支持;按 Push 梳理表格检查是否全部 push 在内。
- 后台查询每条 push 的:**圈中人数 / 实际触达人数 / 打开人数**;push 范围 = 后端下发 + 人工配置;**能识别用户从哪条 push 点开 App**。

### 关联依赖(回归注意)
- **前置 = 「Giggle终身学员」计划 PRD**(7 学习日认证流程);Push 文案中的"认证倒计时"与 PRD 的认证天数逻辑必须一致。
- 引导开启 push 与「新用户引导」的授权流程相关;Push 数据追踪与「数据埋点」体系相关。
