## 摘要

V1.31.0 后台新建独立 **Material（Assets）模块**,把素材管理从"只有文件名+缩略图、粗分类、搜索只匹配名"升级为:列表视图铺开元数据、多级文件夹(无层级上限)、三类资产(原画/动画/音频)差异化能力、搜索覆盖名称+标签+路径+Spine动作+AI关联。产品 Owner: Cloud;优先级:**高**。⚠️ 本期只做**后台 admin**,存量素材**迁移留下一期**;AI 语义搜索**本期先不做**。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 1. 组织结构 · Types Management
- 后台 Material → Types Management 维护 **4 种基础 Type**,决定文件夹类型与上传校验规则。
- **关键约束(测试重点)**:
  - 一级文件夹**创建时必须选 Type**;子文件夹**自动继承父级 Type、不可改**。
  - 层级**无硬性上限**;**跨 Type 移动禁止**。
  - 文件上传**按文件夹 Type 校验扩展名**。
  - Public/Private 沿用 **Type 级开关**(最上级展示两大分类 Public / Private)。
  - **同级同名不可重复**。
- Demo: material-library-prototype.pages.dev

### 2. 列表视图
- 列:☐多选 / 缩略图 / 名称 / 类型(Image·PSD·Audio·Spine·Document·Folder) / 元信息·预览 / 标签(手动输入) / 已确认(✅/⚪) / 上传人 / 时间(默认倒序)。
- **单击行**:文件夹→进入;其它→开 Edit 弹窗。
- **元信息列差异化**:Image=尺寸·格式·大小;PSD=尺寸·图层数·大小;Audio=行内迷你播放器(▶+时长+进度条)+格式;Spine=动作名(前3 + +N,命中高亮)+皮肤数;Document=PDF·页数·大小;Folder=内容数。
- **行内音频试听**:▶/⏸ 一键播放、时间实时、进度同步;**互斥(同时仅一段,切换自动停上一段)**。
- **Spine 动作展示**:行内最多 3 个,超出折叠 +N,悬浮弹气泡完整列出;命中搜索词高亮。

### 3. 统一 Upload 弹窗
- 入口:当前文件夹新增=右上角 ⬆ 上传("新增"流程);替换=Edit 弹窗内 📤 替换区("替换"流程,**保持 ID 不变**)。
- 关键交互(测试重点):
  - 类型不匹配**立即标红拒绝,不阻塞其它文件**。
  - 同名冲突:**替换原文件(保 ID)** 或 **保留两者(自动加 (n) 后缀)**。
  - **关闭弹窗 = 后台继续上传**,右下角悬浮进度入口。
  - 批量上传后可**一键加统一标签**。
- **替换流程**:Edit 弹窗 📤 区拖入新文件→自动校验;**Spine 新版本缺失被引用动作 → 强制二次确认 + 列出受影响课程**;ID/URL 不变,下游引用无感(课程游戏模板、Course word 用 **ID 关联**);替换保存后自动标 **admin-edited**。

### 4. 统一 Edit 弹窗
- 所有非文件夹素材点击行即开;改名/打标/替换/移动/删除/标记审核统一在弹窗内。
- **引用分区**(默认折叠+计数徽章):3 段路径【Subject】-【Level】-【课程名】对应 Admin Course List 三级;Course words 引用展示【单词名】-【单词id】;0 条显示「暂无引用」;适用音频/原画/动画。
- 类型专属字段:Audio=紫底预览+迷你播放器·时长/采样率;Image=大图预览(min-height 360px);PSD=左预览+右图层面板;Spine=预览+动作列表+皮肤列表+命名规范白名单;Folder=Type 角标+内含数。
- **「已确认」(admin-edited)**:Edit 弹窗内保存→自动设已确认;列表行点 ⚪→✅;点 ✅→切回 ⚪(**仅 admin 可取消**);悬浮显示标记人与时间。下游:课程配置选择器可勾「仅已确认」过滤(不强制)。
- **行为约束(测试重点)**:保存名称=同文件夹不可重名;移动=**仅同 Type 内**;替换=类型必须一致+引用影响提示;删除=引用检查+二次确认;任意成功保存自动设"已确认"。

### 5. 原画(PSD)
- 上传:支持 **PNG、PSD**;PSD **单文件上限 500MB**。
- PSD 上传后**自动解析图层树并入库**(前端处理)。下载规则:所有图层默认勾选 + 3 个统一下载:
  - ⬇ 下载选中 PSD — 勾选图层重打包为 PSD(**前端 PSDjs 库只读不能编辑**)。
  - ⬇ 下载选中 PNG — 勾选图层合并导出单张 PNG。
  - ⬇ 选中打包 ZIP — 每个勾选图层独立 PNG 打 ZIP。
- 全选=全文件,去掉不需要的图层即可定制下载。普通 PNG/JPG:Edit 弹窗单按钮 ⬇ 下载 PNG。

### 6. 动画(Spine)
- 上传:**.skel.bytes + .atlas + .png 三件套**校验。
- 动作列表:列表元信息列前 3 动作 + +N;悬浮 +N 完整列表;Edit 弹窗完整列表(**暂不支持皮肤切换**,能快速实现则一起做),可点单动作触发预览播放。
- 动作搜索:输入 walk→命中所有含 walk 动作的 Spine,命中名**黄色高亮**。
- **命名规范(软校验)**:字符集=全小写英文+数字+下划线;文件名 `{category}_{subject}_{variant}.zip`;动作名标准优先;皮肤 default 必备。
  - 类目前缀:人物 `character_`、单词 `word_`、物品 `object_`、背景 `background_`(如 `character_cat_default.zip`)。
  - 动作必备:人物/单词/物品=`idle`、`play`;背景=`idle`(+各类推荐动作)。

### 7. 音频(Audio)
- 格式:**.wav、.mp3、.ogg、.m4a**。三子用途:Songs/BGM、音效 SFX、语音 VO(旁白/教师指令/单词发音)。
- 操作:播放暂停(行内迷你播放器·互斥)、上传(⬆)、替换(Edit 📤)、下载/批量下载、重命名、复制 URL(Edit 🔗→📋)、已确认标记。

### 8. 搜索与筛选
- 点搜索结果→进目标文件夹 + 开详情弹窗。
- **搜索权重**(关键词匹配):素材名 **5** / 标签 **4** / 文件夹路径 **3** / Spine 动作名 **2**(仅 Spine)。
- **AI 语义识别 = 这期先不做**:AI 向量搜索(素材名+动作名)权重 1,独立分组,原画/动画/音频全支持。

### 9. 批量操作
- 移动到(仅同 Type)、批量打标(去重追加)、批量下载(ZIP;**>10 项异步**)、批量标记已确认(可逆)、批量删除(引用检查,**被引用项逐个确认**)。

### 10. 课程配置 / Course word 选择器适配
- Admin → course list → config 课程游戏模板配置中,单词原画/动画的**资源选择器更新**:spine/音频/文件列表展示,spine 展示内含全部动作名(样式同资源库),图片缩略大图。
- 分类下拉支持多级文件夹:原只有 CourseSpine 一项,现按缩进列出该 Type 下所有层级;选任一项=过滤为该文件夹内+子文件夹内资源(不展示子文件夹本身);父级含全部子级,子级仅显示自身。
- **「仅已确认」toggle**:与主列表 ✅ 联动,勾选后 AI 区和主列表只显示已确认素材;**默认勾选**(避免选到未审视素材)。
