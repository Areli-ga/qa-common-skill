## 摘要

V1.37.0 补齐 **Lv2～Lv9 单元卡片点击后无反应**的缺口：点击单元卡片弹出**单元介绍卡**（Unit 名称 / 标签 / 介绍 / 核心单词可播放音频 / 关闭回首页），其中**标签从写死改为后台可配置**（Unit 配置下新增 `unit tags` 字段）；同时**下掉学习中心单词卡里的旧学习路径入口**。

## 功能信息（逻辑 / 状态 / 边界 / 字段）

### 1. 需求背景

用户留存提升后，更多人学到更高的级别，**发现单元卡片点击后无反应**，因此需要增加。

### 2. Unit 卡片 L2～L9 支持

- 范围：**线上 Lv2 起**的单元 Unit 卡片**增加介绍卡**（点击单元卡片触发）。
- 介绍卡展示信息：

| 项 | 来源 / 规则 |
|---|---|
| **Unit 名称** | 后台配置 |
| **标签** | 原本线上是**写死**，本期改为**可配置** —— 在 unit 配置下增加一个标签字段：**`unit tags`** |
| **介绍** | 目前在后台配置 |
| **核心单词** | 取本 Unit 的核心单词，**点击播放按钮可播放音频** |
| **关闭按钮** | 点击后**回到首页** |

- 卡片形态（图 1）：左侧 `Unit 1` 角标 + 单元名（`Daily Routines`）+ 标签行（`Pre A1` / `Listening` / `Speaking`）+ 介绍段；右侧 `Core Vocabulary` 单词卡网格，每张带喇叭图标可播放。

### 3. 各级别标签对照表（原文表格）

| 级别 | 主题 | 标签 |
|---|---|---|
| LV1 | 颜色·五官·玩具·家庭 | Pre A1, Listening, Speaking |
| LV2 | 宠物·家庭成员·交通工具 | Pre A1, Speaking, Vocabulary |
| LV3 | 天气·海洋生物·交通工具 | Pre A1, Speaking, Storytelling |
| LV4 | 动物·食物·职业 | Pre A1, Speaking, Free Talk |
| LV5 | 词汇巩固 + 核心句型整合 | Pre A1, Speaking, Sentence Patterns |
| LV6 | 字母音形第一组（s·a·t·p·h） | Pre A1, Phonics |
| LV7 | 字母音形第二组（c·r·i·m·n） | Pre A1, Phonics, Reading |
| LV8 | 字母音形第三组（d·e·l·k·f） | Pre A1, Phonics, Reading |

- ⚠️ 需求范围写 **L2～L9**，但表格**只到 LV8，缺 LV9**。
- ⚠️ 原文表格**无表头**，第一列（主题词）与第二列（真正显示在卡片上的标签）需与开发确认哪一列写进 `unit tags`。

### 4. 学习中心单词卡：下掉旧学习路径入口

- 学习中心的单词卡**下掉旧的「学习路径」入口**（图 4 右上角绿色「学习路径」按钮）。
- 🔗 这条与同版本《单元内连续学习 + 单元数据结算》里「单词卡中把学习路径入口去掉（Leah 已提需求，我们 check 一下）」是**同一件事**，本篇即需求本体。

### 5. 后台字段（Admin）

- 路径：**Curriculum Paths → Edit Unit**。
- 新增区块 **`Unit Tags`**（图 2 红框，带 `NEW` 标记）：输入框提示「**输入标签，用逗号分隔，如：phonics, beginner, story-based**」。
- 同一弹窗既有字段（图 2 / 图 3）：Unit Goals（Words + 词表 + `Select from Asset List` + 目标描述 + 带 ID 的词条 chip，如 `#789303802252293 green`）、`+ Add Goal`、`* Status`（Disable ⇄ Enable）、Cancel / Save；描述字段带**翻译按钮（译 / 27/27 字数计数）**。

### 6. 待确认项

1. **标签表缺 LV9**：需求范围是 L2～L9，表格只给到 LV8。
2. **标签表无表头**：两列（主题 vs 标签）哪一列是 `unit tags` 的实际取值需确认；且表内标签均为英文，**是否需要多语言/本地化**未说明（Edit Unit 里描述字段有翻译按钮，标签字段没有）。
3. **`unit tags` 为自由文本输入（逗号分隔）**，无枚举校验、无数量上限、无长度限制；写死改可配后，**存量单元的标签如何回填**未说明。
4. **Lv1 是否也走新介绍卡**：原文写「线上 Lv2 起单元的 Unit 卡片增加介绍卡」，而示例图用的是 `Unit 1`，Lv1 现有形态与新卡是否一致需确认。
5. **无埋点**：全篇没有数据埋点需求（介绍卡曝光、核心单词音频点击都无事件）。
6. **核心单词取值口径**：只写「取本 Unit 的核心单词」，与《单元内连续学习》里单元结算页「取单元的单词 `unit_goal`，和课程回顾的取值一样」是否同一份数据源需确认。
7. **无验收标准、无异常态**（后台没配标签/介绍/核心单词时卡片如何展示，音频缺失时的表现均未定义）。
