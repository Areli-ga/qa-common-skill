## 摘要

让 Mai 基于**全局单词本(用户已学单词)动态生成 Quiz**:用户**从游戏回主路径**且**已学词 ≥ 5** 时由 Mai 引导发起,**一天只触发一次**;题型只有**单选(1 目标词 + 2 干扰项)**,**闭麦 + Mai 音色读题 + 点击作答**,每题最多 **3 次机会**,题量 **3–10 题**(超 10 按学习顺序从新到旧取 10);全部答完回主对话由 Mai 评价,形成「学—测—补」闭环。

⚠️ **版本**:文档「版本号」字段与 Figma 均为 **`1.34.0`**(node `42199-56376`,与其他篇的 1.35.0 稿不同域),修订记录初版日期 2026-06-12;按主人给的 **V1.35.0** 入库 —— 疑为 **V1.34 延后到 V1.35** 的需求,若需追溯排期请以主人口径为准。产品 Owner:**Libin**;优先级:**中**。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 0. 背景与目标

- 孩子在对话课 / 游戏中持续积累「全局单词本」,但**缺少独立的「考核 / 复习验证」环节** —— 无法确认学过的单词是否真正掌握,也缺少主动复习触点。
- 目标:**验证学习效果**、**强化记忆(识别薄弱词)**、**自然融入**(由 Mai 在主路径合适时机引导发起,不打断、不突兀)。
- 定量指标待补埋点复盘:Quiz 发起率、完成率、平均正确率、薄弱词复习回访率。

### 1. 范围

**范围内**:基于全局单词本动态生成题目;**单选题(1 题 = 1 目标词 + 3 选项 = 1 正确 + 2 干扰)**;从游戏回主路径时由 Mai 引导发起(前置**已学词 ≥ 5**);**闭麦**作答、Mai 读题、点击提交、**每题最多 3 次机会**;答完关闭 Quiz 回主对话由 Mai 评价;**进入时一次性加载本次全部文本/音频/图片资源**。

**范围外(本期不做)**:
- **多题型**(填空、连线、拼写等)—— 本期**仅单选题**;
- **错题的长期间隔复习调度(次日复习)**—— 与学习进度控制联动为后续。

**依赖与前置**:全局单词本数据可读(已学单词集合及其图片/语音);Mai 同款 TTS 音色可用于题干/提示/评价;图片语音**复用小麦系统,不另做**;Quiz 外壳(`quiz-simulator`)可被主程序唤起与回收;**已学单词数 ≥ 5**。

### 2. 触发与流程

| # | 流程 | 说明 |
|---|---|---|
| 1 | **触发引导** | 用户**从游戏回主路径**,且**已学词 ≥ 5**;**一套 Quiz 一天只触发一次**,在用户**第一次满足前置条件时生成**;Mai 用引导语发起 |
| 2 | 进入加载 | 进入 Quiz 模块,**一次性加载**本次题目的文本 / 音频 / 图片资源 |
| 3 | 出题 | 播放题目(**Mai 音色朗读**)+ **提示语音按钮**(点击重复播目标词) |
| 4 | 作答 | 用户**闭麦**,从 3 个选项点选;点对 → 成功动画;点错 → 错误提示并可重试;**连续答对产生连击效果** |
| 5 | 机会控制 | **每题最多 3 次机会**;**已答错的选项保持错误提示并禁止重复点击** |
| 6 | 收尾评价 | 全部答完关闭 Quiz,回主对话,**Mai 评价表现并鼓励** |

- 引导语示例:「今天学到了什么?我们快速做几个题复习一下好不好?」
- ⚠️ **触发条件疑似笔误(已入待确认)**:原文写「**且用户当天打开过 Quiz**(一套 Quiz 一天只触发一次)」——按语义应为「当天**未**打开过」,否则与"一天只触发一次"自相矛盾。
- ⚠️ **3 次机会用尽后的行为口径不一致(已入待确认)**:流程表第 5 条写「**直到被答对**进入下一题」,而 8.1 作答反馈与验收标准均写「**用尽或答对**进入下一题」。3 选 1 场景下第 3 次必然答对,差异有限,但需明确"用尽仍未答对"是否可能出现及如何处理。

### 3. 核心元件

| 元件 | 规则 / 逻辑 |
|---|---|
| **Quiz 模块(外壳)** | 独立模块,被主程序唤起;进入时**一次性加载全部资源**;结束**回收并返回主对话** |
| **题目卡(题干)** | 一道单选题:目标单词 + Mai 音色朗读,如「从下面三个选项里选择 Apple」 |
| **提示按钮** | 一个语音播放按钮,**每次点击重复播放目标单词读音** |
| **选项(3 选 1)** | 3 个选项(图片/对象),1 正确 + 2 干扰;**干扰项取自全局单词本其他已学词** |
| **作答反馈** | 点对 → 成功动画;点错 → 错误提示并保留重试;**当前题目的答错状态标记并维持、禁用** |
| **连对效果** | 连击效果,见 img-01(1x Nice / 2x Good / 3x Super / 4x Super / **5x Awesome!**,视觉逐级增强) |
| **闭麦机制** | Quiz 期间**用户闭麦,仅点击交互**;朗读由 Mai 音色完成 |
| **评价** | 全部结束后 Mai 基于作答结果做**总结评价 + 鼓励**,衔接回主对话 |

### 4. 题目生成规则

- **取词范围**:用户全局单词本中「**已学 / 已结束**」的单词。
- **每题**:随机取 1 个目标词为正确答案,从已学词中取 **2 个干扰项**(**尽量不易混淆**)。
- **题量**:**最少 3 题、最多 10 题**;**与用户已学单词数量相符**。
- **抽取逻辑**:**超出 10 题时,按学习顺序从新到旧抽取 10 个出题**。
- 形式:闭麦 + Mai 读题 + 点击提交。
- 资源:题干/提示/选项所需文本、音频、图片**进入时加载完毕**。
- 📌 边界:已学词 **5–9 个**时题量 = 已学词数(但下限 3);**恰好 5 个词**时,一题的 2 个干扰项也从这 5 个里取 —— **同一批词会在多题中重复出现**,需确认是否允许。

### 5. 结算页与按钮

- **进度指示**:题组进行中,**右上角显示进度**(如 `3/10`)。
- **关闭按钮(X)**:**左上角常驻,可随时退出 Quiz 模块、返回主对话**。
- **部分答对(未满分)**:弹窗 `Great job!` + 成绩 `x/10` + `You completed today's challenge!` + **「Try Again」按钮(点击重做整套题组)**。
- **全部答对(满分)**:**卷轴奖励** + 成绩 `10/10` + `Wonderful!`,**更强的奖励表现**。
- ⚠️ **结算页与设计稿冲突(已入待确认)**:设计稿(img-02)两态**都只有一个蓝色 `Close` 按钮**,**没有 Try Again**;满分态也**没有卷轴奖励**,只是横幅文案从 `Great job!` 变 `Wonderful`。埋点表同样只定义了「结算页点击 **Close**」。

### 6. 数据埋点

> 术语:一次「整套题目(今日挑战)」= 一个**题组**(`challenge_id`),由多道 **Quiz 单题**(`quiz_id`)组成。

| 事件 | 触发时机 | 参数 | 说明 |
|---|---|---|---|
| `MaiQuizStart` | 进入 Quiz 模块、开始一整套题组 | `challenge_id`、`question_count` | **题组级**;`question_count` = 本套题数;**按完成出题、界面显示第一道题目计** |
| `MaiQuizAnswer` | **每道单题无论对错**作答提交 | `challenge_id`、`quiz_id`、`attempts`、`is_correct` | **单题级**;`attempts` = 该题截止当前已用几次机会(**1-3**) |
| `MaiQuizComplete` | 一整套题组完成(结算页) | `challenge_id`、`correct_count`、`total` | **题组级**,对应结算页 correct_count / total |
| `MaiQuizClose` | **结算页点击「Close」** | `challenge_id` | — |

- 数据观测:Quiz 发起率 / 完成率 / 平均正确率,以及**各单词正确率(识别薄弱词)**。
- ⚠️ **埋点缺口**:`MaiQuizClose` 只覆盖**结算页**的 Close;而左上角 **X 是常驻的、可随时中途退出**,**中途退出无任何上报** —— 完成率的分母会失真(退出的人既无 Complete 也无 Close)。
- ⚠️ `MaiQuizAnswer` 无目标词字段,而观测目标要求算"各单词正确率" —— **靠 `quiz_id` 能否反查目标词需确认**。

### 7. 其他要求

- **多语言**:题干 / 引导 / 评价**默认中文(Mai 母语引导)**,需支持多语言。
- **数据兼容**:**全局单词本口径需与对话课 / 单词本一致**;新增 Quiz **不影响既有学习数据**。
- **异常兜底**:**资源加载失败 / 无网络**时给出友好提示并**可重试**;**已学词不足 5 个时不唤起 Quiz**。

### 8. 验收标准(原文给出,可直接转用例)

1. 已学词 ≥ 5 时从游戏回主路径能被 Mai 正确引导发起;**不足 5 个不唤起**。
2. 题目基于已学词动态生成,单选 1 正确 + 2 干扰,**进入时资源加载完整**。
3. 用户闭麦,Mai 音色读题;**提示按钮可重复播放目标词**;点击提交生效。
4. 点对播成功动画;点错给错误提示并可重试,**每题最多 3 次机会,用尽或答对进入下一题**。
5. 全部答完关闭 Quiz 回主对话,Mai 给出评价与鼓励。
6. **引导 / 读题 / 评价音色与图片、语音素材均与 Mai 小麦系统一致**。
