## 摘要

V1.30.0 把「单元挑战课」「每日 Quiz」从"外挂表单式做题"重构为"**沉浸式游戏交互**"(全程不切场景、零切屏)。目标:降低跳出率、提升完课率。**Quiz 先暂停(优先级低)**,本期重点是单元挑战课重构。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 1. 单元挑战课重构(本期重点)
- **子弹时间出题**:Max 跑酷遇障碍(陷阱/怪物)**不切场景**,时间流速变缓(定格/慢动作),屏幕上方出现关键词+选项。课长约 2–3 分钟,4–12 个障碍。
- **答对**:Max 跨越障碍(空翻);答题卡化特效击中 Max,**免伤 2s**;自动下一题。
- **答错第 1 次**:错误选项**左右摇晃 ±4px ×3 次** + narrator 疑问 tts("horse?");Max 接触陷阱/怪物掉落出屏 → 翻开正确答案+播 tts+narrator 表情变化("lion!");**减 1 层加速 buff**;角色**重生至障碍物前 3–5 秒**,重新该题子弹时间。
- **答错第 2 次(保底跳过)**:同一障碍连错 2 次 → Max **重生至障碍物后方 1 秒**,恢复正常跑酷;结算记为错误。
- **Combo**:连对 ≥2 题触发,速度 **×1.15**,最多叠 3 次(1.15³≈**1.52**);答错**减 1 层**。加速特效需做 3 个版本(1.15/1.32/1.52)。
- **天空主题特殊**:不卡障碍物,均匀分散点位触发(无实体),云团状答题卡;答对→卡化特效击中 Max 免伤 2s;**答错→乌云雷电劈落 Max,重生至 3–5 秒前重新答题**。

### 2. 题型 / 答题交互
- 对接现有路径配置(quiz 库题目),**只接入选择题**;题干**不展示文本、不播题干音频**,直接展示目标单词+读音,点目标单词可重听。
- 点答案卡播该单词发音(**无论选对选错**);选项**每次随机排列**。

### 3. Quiz 重构(⚠️ 先暂停,优先级低)
- 心智:"我帮 Max 收集卡片"(非考试)。弃纯白底,用沉浸式 2D 背景+换肤(预设 **4–8 套皮肤**)。
- **换肤配置(img-01)**:Admin → Lesson Series → Curriculum Paths → 等级 → Unit Edit,AI Quiz 加 **Skin 下拉**切皮肤;背景/气泡/收集板素材读 admin 路径 JSON 动态替换。另有 **Unit Review**(复习逻辑自动出题)、**Show Correct Answer**(答错 2 次后显示正确答案)开关。
- 答对(<1.5s 演出):庆祝动画+音效,单词飞入顶部**收集板**槽位+再播标准发音→自动下一题。
- 答错 1 次:错选闪红+抖动,Max 挠头"再想想"。答错 2 次:高亮正确+再播发音,记错,下一题。
- **星级**:全对=3 星+满屏彩蛋;错 1–2 题=2 星;错 ≥3 题=1 星。

### 4. 体验优化(@jack)
- 沙漠挑战课**移除沙丘加速**逻辑;所有地图**长度拉长 1.25x**;Giggles 一次收完后再进变气泡/场景元素(触碰有动画无收集);选载具后出现光化变身动画。

### 5. 数据埋点(测试重点)
- `app_enter_quiz`(进入测验/触发时间冻结)、`app_complete_quiz`(完成本题/结束时间冻结)。
- 关键参数:`type`(Challenge/Quiz/Mini_Plans/Classroom)、`scene`(course/AI quiz/Challenge/level_upgrade)、`quiz_name`、`duration`、`accuracy`、`Level_Number`/`Unit_Number`/`Course_ID`/`Part_Number`。
- **新增**:`Number`(地图第几个 Quiz,重试仍上报同值)、`RetryTime`(第几次重试,0=首次)、`answer_correct`(true/false,本题对错)。
