## 摘要

V1.31.0 优化网络异常体验(**前置需求:课程预加载**):已做预加载但用户感知不到可离线学习。改造为——进首页检测离线时,**若已有缓存内容则弹新断网弹窗**(告知"已保存课程可继续学"),点 Okay 进入**离线模式**(只露已缓存课程、隐藏需联网功能)。产品 Owner: Leah。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 网络异常弹窗修改
- **触发条件**:进入首页时检测到设备离线。
- **分支(测试重点)**:
  - **已有缓存内容** → 改为**新弹窗**(`Connection Error / We've saved your lessons. You can keep learning anytime! / Okay`),点 Okay 进离线模式。
  - **未缓存任何内容** → **沿用原弹窗**。
- **交互逻辑**:点 Okay → 加载本地缓存内容、进离线模式;**留当前页每 30s 重试一次网络**;网络恢复 → **自动关弹窗、恢复正常流程**。

### 离线模式(测试重点)
- ⚠️ **因首页在做 AB 测,离线模式本期需做两套 UI**:
  - **实验组**:新地图(右上角 `Offline` 标识)。
  - **对照组**:现有首页调整,右上角注明 offline,**需联网的入口隐藏**。
- 需网络的功能**不可点击或隐藏**——**明确需隐藏:单词库、AI tutor、搜索**。
- **已缓存(在下载内容中)可学课程高亮,其他课程不可点击**。
- playzone / 绘本 / 闪卡 / miniplan 哪些可缓存待定,需联网的隐藏。
- 本页每 30s 重试网络,恢复后**自动退出离线模式回正常**。

### 关联依赖(回归注意)
- **前置 = 课程预加载**:离线可学的前提是预加载已缓存内容;回归需联动验证"预加载了哪些 → 离线模式露出哪些"。
- 与**首页布局优化**强相关:离线模式两套 UI 对应首页 AB 的实验组/对照组。
- 隐藏项含 **AI tutor / 搜索 / 单词库**,与对应模块联动。
