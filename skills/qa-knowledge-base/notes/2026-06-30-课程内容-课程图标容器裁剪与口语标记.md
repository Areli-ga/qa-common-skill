## 摘要

V1.32.0 统一课程图标资产与展示规则:设计侧只输出一张方形原始图,前端按使用场景裁剪为方形 / 圆形容器并统一外轮廓描边;同时 Admin 路径配置新增 **课程标记** 字段,支持将单个 Content 标记为「口语」,客户端课程路径节点展示口语角标,并处理口语标记与课程图标上 Avatar 的位置互斥。产品 Owner:Cloud;优先级:中。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 1. 图标资产与裁剪规则
- 设计侧仅输出**方形原始图**。
- 图标主体必须落在绝对安全区红线内;红线外为可裁剪区域,不得放关键内容。
- 前端根据场景裁剪,场景与形状强绑定,不可配置:
  - **Phonics 课程**:方形容器,本期固定使用。
  - **课程路径**:圆形容器,本期固定使用。
  - **六边形**:预留形状,本期不使用。
- 裁剪后统一采用**外轮廓描边**,描边叠加在形状外侧。
- 外描边原因:内描边会侵占内部显示区域,细描边显空、粗描边遮挡主体;外描边不影响内部内容尺寸。
- 描边颜色 / 粗细以 Figma「添加外轮廓描边」设计规范为准。

### 2. Admin 课程标记配置
- 入口:Admin → Lesson Series → Curriculum Paths 路径配置页,Part 下每个课程内容(Content)行内。
- 内容配置区新增「课程标记」下拉框。
- 字段定义:
  - 字段:课程标记。
  - 类型:枚举。
  - 取值:`NONE`(无) / `ORAL`(口语)。
  - 默认值:`NONE`。
  - 必填:否。
- 下拉默认选中「无」,表示该课程不展示任何标记。
- 选择「口语」后保存生效,客户端课程路径上该课程节点展示口语标记。
- 配置粒度为单个课程内容(Content),与现有 Part / Content 结构一致,随「Save Content」一并保存。
- **关联课程同步**:标记要触发内容「链接」同步逻辑;若一节被关联的课程修改该标记,其他使用同一个 `contentID` 的关联课程也要同步修改。
- Phonics 类内容本期不展示课程标记,也不开放配置。
- 字段设计需保留扩展能力,但本期 Admin 仅露出「无 / 口语」。

### 3. 后端与接口
- 在路径内容(Content)的保存 / 查询结构中增加「课程标记」字段。
- 枚举值:`NONE` / `ORAL`。
- 客户端获取路径数据时返回该字段,用于决定是否渲染口语标记。

### 4. 客户端口语标记展示
- 当课程路径节点对应内容 `课程标记 = ORAL` 时,在该课程圆形图标上叠加口语标记角标。
- 角标样式 / 位置以 Figma 为准。
- `课程标记 = NONE` 或未配置时,不展示口语标记。
- 口语标记仅作用于**课程路径场景**;Phonics 场景本期不展示口语标记。

### 5. Avatar 与口语标记互斥
- 已有机制会在课程图标上展示 Avatar,位置与口语标记冲突。
- 优先级:**Avatar > 口语标记**。
- 展示矩阵:
  - Avatar 展示 + `ORAL` → 仅展示 Avatar,隐藏口语标记。
  - Avatar 不展示 + `ORAL` → 展示口语标记。
  - Avatar 展示 + 非 `ORAL` → 仅展示 Avatar。
  - Avatar 不展示 + 非 `ORAL` → 二者均不展示。
- 互斥判断需对 Avatar 出现 / 消失实时响应,例如进度变化导致 Avatar 移动到或离开该节点时,口语标记也要随之隐藏 / 恢复。

### 关联依赖(回归注意)
- 与「首页布局优化」相关:课程路径节点展示、Avatar 位置和学习路径视觉一致性需回归。
- 与「Phonics」相关:同一方形原始图在 Phonics 中裁剪为方形,且 Phonics 本期不展示 / 不配置课程标记。
- 与「素材库 / Admin 课程配置」相关:Admin Content 级字段保存、查询、同 `contentID` 链接课程同步需要回归。
- 与「课程内容 / Speaking 跟读课」相关:口语标记用于标识口语类课程,但标记本身不应改变课程玩法、ASR、完课逻辑。
