## 摘要

V1.36.0 把连胜激励做成榜单,**将学习天数变成厌恶损失**:在**竞技场 - 排行榜新增「连续打卡榜」tab**,左侧展示自己的连胜天数 + 「你已超过 XX% 的小朋友」(按天数档位取值),右侧展示**全球连胜前 100 名**;**注册 Day 3 起每天首次完成主路径关卡触发连胜打卡动效**(去掉冰封道具、保留 Giggles),点 Continue 后**有排行榜动效就接着播,没有就回首页并晃动课程图标 3s 后自动进下一关**。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 0. 背景

- 针对**更长期的用户**,把连胜激励的榜单展示出来,**将学习天数变成厌恶损失**。
- UI:Figma **`1.36.0`** node `47034-88234`。

### 1. 连续打卡的线上数据兼容

- **连续打卡的整体逻辑依然按照目前的**:**完成学习行为后即认为完成打卡**。
- ⚠️ 原文自问「目前的认为打卡完成:**完成任意学习行为?**」——流程图(img-01)给出的定义是「**当天完成学习 = 完成 1 个互动游戏**」,以图为准。
- **冰封道具(线上逻辑)**:**目前不再发放新的冰封道具**,但**有少量用户仍然持有**;**APP 内无展示入口**,**用户断打卡后会自动触发**(即自动消耗、自动续上连胜)。
  - 📌 测试要注意:**存量持有冰封道具的用户断卡时行为与普通用户不同**,且入口不可见、只能靠数据构造。

### 2. 连续学习奖励规则(img-01)

- **以 7 天为一个周期**:
  - **连续 3 天学习 → 获得 20 Giggles**;
  - **连续 7 天学习 → 获得 50 Giggles**。
- 流程:开始 → 当天完成学习(完成 1 个互动游戏)→ 判断「达成连续学习挑战?」
  - **连续学习保持** → 记录连胜天数 → 展示连续学习激励页面 → 判断「达成挑战目标?」→ **达成**则获得挑战 Giggles 奖励 → 结束;**未达成**直接结束;
  - **连续学习中断** → **重新挑战** → 结束。

### 3. 连胜打卡动效(改造)

- **注册 Day 3 起**,**每天首次完成主路径的关卡后**,触发连胜打卡的动效;**动效可以使用以前的**。
- **相对原版的变化**:**去掉右上角的冰封道具**,**保留 Giggles**。
- **保留老版 day3、day7 有额外 Giggles 的设定**。
- **点击 Continue 后的分支**:
  - **如果有排行榜动效** → **继续展示排行榜动效**;
  - **如果没有排行榜动效** → **返回首页,晃动课程图标,3s 后自动进入下一关**。
- 动效页形态(img-02):浅绿背景,中央橙色火焰内显示连胜数字(如 `3`),下方 `Day Streak`,左侧蓝兔举手;下方 **Day 1 … Day 9 的 Giggles 打卡序列**(已完成为黄色高亮、未来为灰色),**当天节点上方标 `+20`**;右上角 Giggles 余额(`1200`);底部绿色 `Continue` 按钮。

### 4. 连续打卡榜(核心新增)

**入口**:**竞技场 - 排行榜 - 增加连续打卡榜**(与「学习之星」并列的 tab,img-04/05 顶部可见 `学习之星` / `🔥 连续打卡榜`)。

**左侧(自己)**
- 火焰图标 + **`XX 天连胜`**;
- 文案 **「你已超过 **XX%** 的小朋友」**;
- 下方 **Day N 的 Giggles 打卡序列**(如 Day 47…Day 53,当天节点标 `+20`);
- 底部说明:**「*仅显示全球前 100 名小朋友数据」**;正文另给的完整文案为「**仅展示全球前100名小朋友,每天凌晨更新数据**」。

**百分比取档规则(img-06 完整档位表)**

> 取**所处档位**,不是精确百分比。原文举例:**47 天 → 落在 45 那一档 → 90%;55 天还是 90%;60 天才跳到 93%**。

| 天数 ≥ | 显示 % |  | 天数 ≥ | 显示 % |
|---|---|---|---|---|
| 1 | 28 |  | 21 | 82 |
| 2 | 38 |  | 30 | 86 |
| 3 | 47 |  | 45 | 90 |
| 5 | 58 |  | 60 | 93 |
| 7 | 65 |  | 80 | 96 |
| 10 | 71 |  | 120 | 98 |
| 14 | 76 |  | **200+** | **99** |

- ⚠️ **设计稿百分比与档位表对不上(已入待确认)**:img-04 显示「**52 天 → 98%**」(按表应为 **90%**),img-05 显示「**2 天 → 80%**」(按表应为 **38%**)。设计稿数字疑为占位,**以档位表为准**。

**右侧(榜单)**
- 展示**平台全球连胜前 100 名**用户,信息:**头像、昵称、IP 所在地国旗、连胜天数**。
- **更新规则**:**用户完成学习后再进入,实时刷新排名**(与左侧文案「每天凌晨更新数据」并存 —— ⚠️ **两处更新口径不一致,需确认**)。
- **同分排序**:**连胜天数一致时,先触发打卡的用户排在前面**。
- **上榜**(img-04):在榜上**高亮标注用户位置**(黄色高亮行,如 `5 Dimas (me) 🔥52`)。
- **未上榜**(img-05):**在最底部展示用户的名次**(独立固定条,如 `107 Youki (me) 🔥2`);**如果在 999 后则展示 `999+`**。
