## 摘要

V1.31.0 后台新增 **Quiz 手动出题流程**(与现有 AI 生成入口并存):Word Bank 单词库已建完(每词配图 + 标准发音),教研可手动挑单词、组题型快速产高质量题,无需 AI 从教学文档推理。本期**仅支持单选题(choice)**,选项固定 3 张图片,素材默认从词库拉取。产品 Owner: Aaron;优先级:中。

> ✅ **版本已确认 V1.31.0**(主人确认,2026-07-01):文档「版本号」字段为 **1.32.0**,但本库按 **V1.31.0** 入库。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 手动创建流程(4 步)
1. **进入**:题库管理页点「Manual Create Question」(与「AI Generate Questions」**两入口并存、互不影响**)。
2. **填表单**:题型(仅 choice)+ 知识点(词库选单词)+ Skills(多选)+ Difficulty。
3. **题目配置**:(1) 选题干模板;(2) 选线索格式(6 选 1)+ 词库选提示单词(无须线索可不选);(3) 配 3 个图片选项(词库取 1 正解 + 2 干扰,标正确答案)。
4. **预览 + 提交**:预览与学生侧渲染一致;Submit 落库。

### 表单字段定义(测试重点)
| 字段 | 控件 | 必填 | 说明 |
|---|---|---|---|
| Question Type | 单选下拉 | 是 | 本期仅 `choice` |
| Difficulty | 单选下拉 | 是 | L1–L10 |
| Knowledge Point | 文本输入 + Word Bank 按钮 | 是 | 可手输单词/词组(red / red flower / Hello);或点 Word Bank 内联弹词库(按类别分组)选词自动填入 + 记录 `wordRef` 供选项自动填充;**手动改写输入框 → 自动解除 Word Bank 引用**(选项需手动挑) |
| Skills | 多选标签 + 搜索 | 是(**≥1**) | 搜索 Skill 库、加多个、单个可删(承接「Quiz 对应多个技能标签」的 skills 数组) |
| Stem 题干 | 单选下拉 | 是 | 来自 **22 个英文题干模板** |
| Clue Format 线索格式 | 单选 6 项 | 是 | Audio / Audio+Text / Text / Image / Image+Audio / None |
| Clue Word 线索单词 | Word Bank picker | **Clue≠None 时必填** | 从词库单选 1 词,作音频/图片/文本素材源 |
| Options 选项 | 3 个图片选项 | 是 | 固定 3;KP 词库来源时自动填充、手输时人工挑;图片均来自 Word Bank |
| Correct Answer 正解 | 单选 | 是 | 3 选项标 1 正确;**首个被选中的默认作正解,可切换** |

### 题干模板(22 个,命名规则 `quiz_<question_type>_<teaching_skill>`)
- 覆盖教学技能:Letter Recognition、Letter–Sound Awareness、Beginning Sounds、Word–Picture Association、Matching & Sorting、Color Recognition、Rhyming & Word Families、Syllables、Upper/Lower Case、Initial/Ending Sounds、CVC Blending & Segmenting、CVC Reading & Spelling、Visual Discrimination、Auditory Discrimination、Letter Formation(**暂无模板**)、Concepts of Print、Prepositional Language。
- 每模板含 题干中/英/印尼语 + 线索语音(目标单词音频 / 音素如 /m/ / 字母音 / 单词A+B音频等)。例:`quiz_single_choice_color_recognition` = "Tap the color." / 点击这个颜色。/ Ketuk warnanya。
- 部分技能含 true_false / sorting / matching / repeat 变体(如 `quiz_repeat_cvc_reading_and_spelling` = "Repeat this word." 跟读)。

### 线索格式(6 选 1,素材默认取自词库)
- 语音(标准发音)/ 语音+文本 / 文本 / 图片 / 图片+语音 / 无。

### 选项配置 & 校验
- 本期固定 **3 个图片选项**,人工从词库选,**必须标记 1 个正解**。
- **校验**:所有必填字段未填 或 未标正确答案 → Submit 置灰;点击时提示具体缺失项。

### 验收标准(测试重点)
- 两入口(Manual / AI)互不影响,**AI 流程功能完全不受本次改造影响**。
- 线索 6 种格式切换 → 对应素材按格式自动呈现、默认从词库拉取。
- 存量与提交:提交后所有必填字段(题型/知识点/skills/difficulty/stem/clue/options/correct_answer)非空;预览态与学生侧渲染一致。

### 关联依赖(回归注意)
- 与「Quiz 对应多个技能标签」(skills 多选数组)同属 Quiz 后台、强相关。
- 素材源自 Word Bank 单词库(图片 + 标准发音)——与「音频库(多语言音频)」「素材库(原画)」联动。
