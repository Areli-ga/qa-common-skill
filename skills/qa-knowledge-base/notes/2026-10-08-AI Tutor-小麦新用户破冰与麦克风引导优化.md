## 摘要
小麦新用户唤醒率只有 **70%**，**最大卡点是麦克风授权**：触发新用户仪式的用户里 **35.6% 没有麦克风权限**；H5 内麦克风授权成功率 **46.2%**（系统弹窗 Requestable 授权率 87.8%、占流量 84.5%；**需前往设置 Settings Required 授权率仅 2.6%**、占 15.5%）。本期**把麦克风从「进入小麦的前置条件」改为「用到语音时才授权」**：① **没有麦克风权限也能进入小麦**，可打招呼、进 Sense 场景列表玩 Sense Game、进 Sticker Island 收集贴纸，**只有点到主对话麦克风 / 消息列表入口、Sense Game 麦克风或朗读胶囊、Sticker Island 麦克风时才唤起授权**；② **新用户破冰仪式不再依赖麦克风**，改为轻量交互完成见面仪式，并新增「**百变小麦**」变形转场；③ **主界面小麦入口加描边放大**，新用户用「变戏法进袋子、每次出来变不同形状（猫 / 狗 / 鱼 SVG + 小麦眼睛）」的新主题；④ Prompt 改为「百变小麦」开场 + 排查**首轮变形不稳定** bug；⑤ **小麦主题的麦克风授权组件**（Requestable / Settings Required 两套语音 + 弹窗文案），**Settings Required 的「暂不」改为关闭弹窗**。目标：**新用户小麦进入率提到 99.8%**、提升次日留存。**无埋点**。

### 1. Unity 主界面小麦入口：描边 + 新老用户区分
- 现状：小麦在主界面背景里不够突出 → **通过描边、放大或增加动效让它更突出**；**全局增加描边、尺寸变大一些**。
- **新老用户定义：按当前用户有没有跟小麦「完成首轮电话」**（⚠️ 原文用词，疑指首轮对话）。
- **新用户**：新主题 —— **小麦像变戏法一样进入袋子，每次出来都会变成不同形状**；取小麦默认状态 + **3 个写死单词 SVG：猫、狗、鱼**，**单词 SVG 与小麦的 👀 眼睛组合为变形后的形象**；**保留眼球跟随**。
- **老用户**：走当前的**清醒、睡着、冰冻**设计（见 V1.37《小麦的作息陪伴 + 冻结解救》）。
- ⚠️ **新用户判定口径两处不同**：第 1 项按「是否完成首轮电话」，第 2 项按「**是否完成 onboarding**」—— 两个条件可能不一致（如完成 onboarding 但没完成首轮对话），需确认以哪个为准、是否同一个标记。

### 2. 新用户交朋友仪式视觉增强 + 唤醒动画
- **只要用户没有完成 onboarding 都进入此流程，不再依赖麦克风权限**。
- 重新设计唤醒界面视觉：**不再需要麦克风，允许通过轻量交互完成见面仪式**（具体交互在画板 / figma，正文未写）。
- 新增「**百变小麦**」转场动画：例如**小麦睁眼 → 旋转、快速形变 → 变成默认状态**的过渡。

### 3. Prompt 更新 + 首轮变形不稳定 bug
- **Prompt 文案改为「百变小麦」开场**（流程图截图里的开场白：「Hello，我是百变小麦，你叫什么名字？我们可以做好朋友。」）。
- **当前首轮变形不稳定：小麦会以为自己变形成功了但终究失败** → 需要**高频测试、提高变形稳定性**（没有给出验收标准 / 成功率目标）。

### 4. 无麦克风权限的使用流程
- **无麦克风权限用户可以**：**小麦打招呼**；**访问 Sense 场景按钮的列表页，打开一个 Sense Game**；**进入 Sticker Island 收集贴纸**。
- **点击以下入口时唤起麦克风授权流程**：
  1. **主对话麦克风组件和消息列表入口**；
  2. **Sense Game 中的麦克风，或小麦唤起了朗读胶囊组件**；
  3. **Story Island 的麦克风，包括贴纸完成页和贴纸书的详情页**（⚠️ 原文写「Story Island」，上文是「Sticker Island」，按上下文应为贴纸岛）。
- **修改：需前往设置授权（Settings Required）弹窗的「暂不」按钮 → 改为关闭弹窗**（流程图便签：「点击【暂不】关闭弹窗」）。
- ⚠️ 无麦用户在 Sense Game / 贴纸岛里**原本需要开口的环节如何降级**（跳过？只能点选？）原文没写；无麦用户进入后**是否消耗电量**也没写。

### 5. 麦克风授权组件（小麦主题）
- 覆盖两种授权状态：**可请求授权（Requestable）**、**需前往设置授权（Settings Required）**。
- **能获取用户当前授权状态，并在 greeting 话术里给出最合适的回复**。
- **触发：用户没有授权麦克风，但点击页面内的语音输入功能时**；**按授权类型播放对应的小麦语音**。
