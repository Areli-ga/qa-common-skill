## 摘要

V1.33.0 把主页右上角的聚合入口升级为「**功能广场**」(unionhub):恒展示 **12 入口**(4 已上线 + 8 新功能/测试页),移除 Playzone,新增磨耳朵/Songs/Art/Worksheets/Bedtime 真实模块,并对未上线功能用 **Soon 标 + 假门落地页**(以触发广场的人群为分母量化新功能需求度、指导排期)。配新功能 AB 分桶 + 曝光机制 + Admin 配置。产品 Owner: Cloud;优先级:高。(文档版本字段 v1.32.0,figma 1.33.0,按主人指定 **V1.33.0**。)

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 入口与分桶
- 广场恒展示 **12 入口**(不分组,统一大图标 + 标题):
  - **4 固定(已上线,仅收口、页面不改)**:Storybook / Flashcards / Phonics(miniplan) / 搜索。
  - **8 新功能/测试页**:new 标真实模块(磨耳朵/Songs/Art/Worksheets/Bedtime)+ Soon 标假门(Speak / Daily Science / Family Games)。
- **AB 分桶**:2 个测试桶,**桶 A = 2 新功能 + 2 测试入口(每桶 4 个)**;不同桶看到不同的新功能/测试页。
- **标记规范**:`new` = 新功能、真实可用,**仅 1.33.0 版本生效、之后移除**;`Soon` = 未上线,点击进假门页。
- ⚠️ **命名不一致(按最终 Figma / 实现验收)**:正文/埋点写假门为 Speak / Daily Science / Family Games,但广场总览图(img-01)显示为 **Speaking / Fun Facts / Family Games**——疑设计迭代中命名未统一。

### 各新模块设计(测试重点)
- **Bedtime**:睡前故事着陆页(已有,直接链接)。**磨耳朵(GiggleCast)**:复用以前做好的页面。
- **Songs**:类目 Nursery Rhymes / Giggle Songs;卡片 = 视频封面 + 播放键;看过标「✓ 已看」+ 进度条。**后端记时间戳**,再进从对应节点续播;**剩余 ≤ 5s 或上次完整看完 → 从头播放**。
- **Art**:类目(动物/植物/水果/陆海空载具/爬虫);卡片线稿封面,涂过 → 彩色成品 +「✓ 已完成」;**再次进入已涂作品不恢复之前图像**;优先后端存储,无则用本地文件。
- **Worksheets**:封面 = 多张纸叠起(一卡 = 一练习包);点开**下载 PDF**;**PDF 自动加水印**(浅色图用灰色水印、深色图用白色水印)。
- **Speak / Daily Science / Family Games(Soon 假门)**:落地页【Which one do you want?】**支持多选**,后端保存所有选择供再次进入展示;**单个 kid 对单个假门页只记 1 次**(点任意项目该假门页 kid 数 +1,点多个也只 +1)。

### 曝光机制(测试重点)
| 对象 | 形式 | 触发 | 频率 |
|---|---|---|---|
| 老用户 | 聚合入口气泡引导(聚光灯 + 气泡指向) | 功能上线后进主页 | **仅一次** |
| 所有用户 | 聚合按钮小动效(原脉冲呼吸 → 改为**聚合图标内 icon 轮换动画**) | 在主页 | 打开广场一次后不再提醒 |
| 全部 | **闲置吸引**:广场展开后 **10s 未操作** → 图标挨个播小动画(旋转扭动),任意操作重新计时 | 广场内 | 可无限重复 |

### 新模块 Admin 配置
- App 端 Songs/Art/Worksheets 的分类、列表内容**全部来自 Admin(不写死客户端)**;Admin 侧边栏 Lesson Series 下新增 3 菜单(GiggleCast 下方):Songs / Art / Worksheets Management。
- **统一结构**:分类 → 分类下内容(两级,3 模块结构一致)。分类字段 = 名称(EN 源 + 多语言)+ 分类图标(**自行上传无预设,建议 144×144 透明 PNG ≤100KB**)+ 排序 + 状态(启用/停用);**仅启用的对 App 可见**。
- **各模块差异**:
  - **Songs**:内容 = playzone 已发布儿歌视频(选择组件选入);展示名默认 = 原名可改接多语言;封面取视频封面。
  - **Art**:内容 = course word(涂色随词带出,不需命名);按行加单词 → 失焦**自动匹配词库**(带词 ID + 线稿缩略图);**未匹配标红不可保存;词匹配但未关联线稿 → 标"缺线稿"阻止上架**。
  - **Worksheets**:内容 = 练习包 PDF;标题(EN+多语言);**PDF 上传页数自动读取;封面 = PDF 第 1 页自动生成(换 PDF 自动更新)**。
- 复用组件:Songs 选择组件(复用路径配置)、多语言组件(复用路径配置)。
- 客户端接口:按模块返回「分类(名称多语言 + 图标 + 排序)+ 内容列表(资源/封面 URL + 排序)」。

### 数据埋点
- **`unionhub_intent_want_click`**:假门页点选项 ♡ 点亮时上报。公参 `page_title=unionhub`、`page_name`=speak/daily_science/family_games、`unionhub_option`=speak_1~4 / daily_science_1~4 / family_games_1~4(如 daily_science 页点 Animals → daily_science_3)。
- **`app_page_view`**:新模块/假门页曝光。`page_title`=giggle_cast/songs/art/worksheets/bedtime/speak/daily_science/family_games;`page_name`=模块内分类名(admin 配置转小写+下划线,如 Nursery Rhymes → nursery_rhymes)。
