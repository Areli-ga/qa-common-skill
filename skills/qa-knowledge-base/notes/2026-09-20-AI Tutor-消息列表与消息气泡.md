## 摘要
把小麦的对话 UI 从「**只支持曝光一轮**（用户输入音频 → 小麦输出文字和音频）、**STT 不能被修正**」升级为一个**通用的多轮消息列表**，作为**贴纸岛猜词**与**课程路径对话课**的统一对话底座：**一个 Kids ID 一个通用消息列表，多 scene 的对话都发生在同一个列表里**（参考小红书点点），进入默认定位到当前轮次、向上滚动查阅历史；**AI 气泡**支持文本 + 扬声器重听 + 字幕对齐 + 超高文本可滚动，**用户气泡**默认波形、点击重听（**接入变声器 / 声音滤镜，且支持每个气泡绑定不同滤镜**）、STT 转文本、**仅最近一轮可点键盘改文本**；输入组件在原「点击开启 / 点击发送」之上**增加长按录制、松手发送、左滑取消**，并把**开放录音的 VAD 时间延长到 60s**；同时把 `{user.name}` **对接 AI STT 热词**修姓名识别错误。列表内对话**消耗电量并展示电量与充值入口（课程路径接入除外）**，各业务场景需**先在配置平台注册并配 prompt**。

### 1. 消息列表
- **入口进入时默认定位到当前的对话轮次**；**向上滚动可查阅消息历史**。
- **一个 Kids ID 可创建一个通用的消息列表，多 scene 对话发生在同一个消息列表之下**（参考小红书点点）。
- 提供**返回按钮**可回到入口页；以**消息气泡**形式展示消息。
- **显示电量和电量充值入口，消息列表中的对话消耗电量 —— 课程路径中的接入除外。**

### 2. 消息输入组件
集成在**主对话、子游戏**中，作为**麦克风的标准输入组件**。在当前「点击开启」「点击发送」基础上：
- **增加长按输入，松手发送**；
- **修改当前开放录音的 VAD 时间，增加到 60S**，目的是**建立用户手动点击 / 长按发送消息的习惯**；
- **保留现在的声音滤镜选择设置功能**。

设计稿三态（img-01）：
| 状态 | 表现 |
|---|---|
| **点击进入「录音模式」** | 输入条 = `×`（取消）+ 波形 + **绿色 ↑ 发送**；提示「**点击 ↑ 发送**」 |
| **长按进入「录制模式」** | 输入条 = **垃圾桶** + 波形 + **红色停止方块**；提示「**松手发送，左滑取消**」 |
| **「录制模式」手指往左滑动取消** | 同上，**背景转为粉红警示色、垃圾桶变红** |

### 3. 消息气泡
**AI 消息气泡**
- **文本显示**；**扬声器点击重听**；**字幕对齐**；**文本框最高高度，文本溢出时支持手动滑动上下翻阅**。

**用户消息气泡**
- **默认波形显示**；**点击重听，支持变声器**；**STT 转译为文本**；**修改：点击换键盘改文本，修改功能仅支持最近一轮对话**。

**出现位置**：当前小麦的主对话（**主对话时接入变声组件，点击已经发音的气泡，输出经过变声器变声后的音频**）、贴纸完成页面与贴纸书、消息列表。
（2026-09-08 修订补充：**支持每一个气泡输出绑定不同的声音滤镜**。）

### 4. 新增热词（姓名识别修正）
- **`{user.name}` 对接到 AI STT 热词**，AI 后续对话**面对相似音频输入时匹配到固化的姓名**。
- 原文备注：测试排查 bug、测试异常 case（用户和小麦的聊天界面升级），**怀疑是多个用户使用同一个 kid id**。

### 5. 入口接入与 prompt 配置
- 消息列表作为**通用对话方式**接入各业务场景；当前已有场景：**小麦主对话 / 贴纸完成页面与贴纸书 / 课程路径（见《小麦接入课程路径》）**。
- **各业务场景需要先在配置平台进行注册，并支持通过配置平台配置 prompt。**

**Prompt 配置表（原文给出的四个入口）**
| 入口 | 角色 / 任务 | 输入 | 开场 | Prompt |
|---|---|---|---|---|
| 小麦的主对话 | 延续当前主对话 | 略 | 略 | 略 |
| **贴纸 - 未解锁** | 扮演**帮助用户寻找贴纸拍一拍的助手**，通过对话引导用户在实际生活中找到这个东西；**引导难度层层递进，直到用户明确认知这是什么为止**；**但不对拍摄结果负责**（拍摄是独立流程，用户知道在哪也可能手边没有暂时拍不了） | **需要猜的目标单词** | 用户：这个东西在哪里找呀？ | **待补充** |
| **贴纸 - 结果页和已解锁** | 扮演**百科助手**解答问题 | **已解锁的单词 + 贴纸图片** | 用户：这个东西是什么呀？ | 「你作为一个百科解答助手，场景是小朋友正在用手机摄像头拍东西，你需要针对用户拍的东西和用户聊天，解答用户的疑问。同时，你的另外一个职责是扮演以 `{Language}` 的小朋友学英语助手，你可以在回答知识的时候**串入一部分符合教学大纲的学生词汇表内 `{Vocabulary}` 的英文关键词的解释**」 |
| **课程路径主 prompt** | 作为学习助手，**负责 AI 课程前后的转场**；了解用户历史学过的内容并**给出接下来的 AI 课程推荐**；**玩游戏过程不在主 Prompt、通过 Scene 驱动**；**要掌握用户学过的其他课程，进行总结，并建立下次的约定** | **当前的学习节点；用户已经学过的内容**（优先输入刚学过的，如当前在 Unit 03 Level 1 则输入 Unit 03 的单词） | — | 详见《小麦接入课程路径》 |

### 8. 风险与待决策（原文 2026-08-25 审核补充）
| 编号 | 风险 / 决策点 | 建议 |
|---|---|---|
| **D1** | **「编辑功能」的可用性**：目标用户 3–9 岁、多半识字（原文如此），**文本编辑改错字对孩子基本不可用** | **姓名修正以语音确认为主**（"你的名字是 Wais，对吗？"），**文本编辑作为大人兜底** |
| **D2** | **纠错策略需按案例分型**：已呈现四类 —— **ASR 误听 / 角色扮演假名 / 疑似多人共用 / 称呼替代真名**，**不能一律覆盖真名**（roleplay 假名不应覆盖；「Kakak（姐姐）」这类称呼应尊重意愿） | **需要确认有没有 bug，然后确定 AI 听到一个名字时写入 profile 的时机** |

### ⚠️ 待确认（写用例前需拉齐）
1. **「一个 Kids ID 一个通用消息列表、多 scene 共用」的边界**：主对话、贴纸、课程路径的消息**在同一条时间线里混排**，那么**历史回看时如何区分 scene**、切 scene 是否有分隔提示、**prompt 切换后上下文是否携带前一个 scene 的内容**，全未写 —— 这是本篇最大的设计风险。
2. **电量规则的例外**：「列表中的对话消耗电量，**课程路径中的接入除外**」——同一条消息列表里**混着计费与不计费的轮次**，电量展示与扣减口径、以及电量耗尽时课程路径对话能否继续，都没写（与 V1.36《Mai 电量系统》要对齐）。
3. **「仅最近一轮可编辑」的判定**：AI 已经回复后是否还算「最近一轮」、**编辑后是否重新触发 AI 回复**、编辑是否改写已入库的 STT 与 profile，未写。
4. **D1 与 D2 都还没拍板**，而「编辑」正是本期主要特性之一；若按 D1 走语音确认为主，**编辑功能的优先级与验收标准要重定**。
5. **姓名写入 profile 的时机未定**（D2 的结论就是「需要确认」）：听到即写、确认后写、还是累计 N 次一致才写，直接决定热词功能的用例与回归。
6. **VAD 延长到 60s 的副作用**：长时间无语音是否有兜底（超时提示、自动停止）、**60s 录音对电量与 token 成本的影响**、弱网下长录音的失败恢复，都没写。
7. **长按录制的取消手势**只有「左滑取消」，**松手后误触发**、**长按中来电 / 切后台**等中断场景未定义。
8. **声音滤镜「每个气泡绑定不同滤镜」**：滤镜是录制时固定还是重听时可切、**历史气泡回听用当时的滤镜还是当前设置**，未写。
9. **附件 / 图片能力**：范围里写了「图片、附件（封闭输入）」，但功能明细里**没有任何附件相关规则**，本期是否交付不明。
10. **本篇无埋点表**，指向另一篇《Mai - AI Tutor 埋点》；新增的长按录制、编辑、重听、滤镜是否有事件，需要去那篇核对。
11. **「地球重绘」只有一句话**，没有验收标准（尺寸 / 适配断点 / 是否只改 iPad）。
