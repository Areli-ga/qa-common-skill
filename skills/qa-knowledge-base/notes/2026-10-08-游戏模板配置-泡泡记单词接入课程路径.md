## 摘要
把 V1.39 游戏大厅的单人游戏 **泡泡单词（`bubble_word`，无尽模式、三颗心掉光结束、单局得分进排行榜）** 改造成**可配到学习路径上的课程模板**，包装为一节「**单元复习**」课，由后台配置该单元要复习的单词。**课程模式：固定题组、跳过难度选择**；**题组数 = 目标单词数（6–12 个，推荐 8–10），每个目标词恰好当一次正确答案、顺序随机**；**生命值归零不结束游戏，继续做完剩余题组（心数显示 0）**；**按主轮正确率给星（≥70% 三星 / ≥30% 两星 / 完成即一星）并接入课程统一结算页**。两条硬目标：**课程必须能走完**、**每个目标词至少考到一次**。

## 功能信息（逻辑 / 状态 / 边界 / 字段）

### 基本信息
- 产品 Owner：**Aaron**；优先级 **高**；版本 **v1.40.0**；文档日期 **2026-09-28**。正文仅约 1800 字符、**无图、无 UI 链接、无埋点表**。
- 现状：泡泡单词以单人游戏形态上线在游戏大厅，**无尽模式：没有固定局长，三颗生命值掉光即结束，成绩以单局得分进排行榜**（见 V1.39《泡泡单词单人游戏》）。
- 诉求：**教研希望把这个玩法作为课程模板配置到学习路径上，包装成一节「单元复习」课，由后台配置该单元需要复习的单词**。
- 产品目标：
  - **课程必须能走完**：无论孩子答对答错，都要能完成全部题组并拿到结算，路径正常推进；
  - **复习覆盖完整**：后台配置的每一个目标单词，在一局内至少被考到一次。

| # | 模块 | 说明 |
|---|---|---|
| 1 | 课程模式玩法 | **固定题组、跳过难度选择** |
| 2 | 主轮 | **每词考一次** |
| 3 | 星级结算 | **接入课程统一结算页** |

### 1. 单词配置数量
| 项 | 取值 | 依据 |
|---|---|---|
| **最少** | **6 个** | **简单档每组需 2 个干扰项，从 N−1 个词中选** |
| 推荐 | 8–10 个 | 单局答题时长约 1–1.5 分钟，符合复习课节奏 |
| **最多** | **12 个** | 12 组约 1.3–1.9 分钟纯答题，再多孩子注意力会流失 |
- ⚠️ 「最少 6 个」的依据只用到「从 N−1 个词里挑 2 个干扰项」，按这个算 N ≥ 3 就够，6 的来由原文没写透（可能是为了干扰项不频繁重复）。**配置少于 6 / 多于 12 时后台是否拦截、拦截文案**原文未写。
- ⚠️ 依据里提到「简单档」，但需求范围又说「**跳过难度选择**」—— 推断课程模式固定走**简单档**（V1.39 简单档 = 同屏 3 个泡泡、泡泡内容为图片），**原文没有明说固定哪一档**。

### 2. 主轮
| 项 | 规则 |
|---|---|
| **题组数** | **= 目标单词数，不可单独配置** |
| **出题** | **每个目标词恰好作为正确答案出现 1 次，出题顺序随机打乱** |
| **结束条件** | **全部题组完成** |
- ⚠️ V1.39 的「**泡泡潮**」（进度条跑满提速、连出 3 组彩色泡泡、答对补心）在课程模式里**是否保留**原文没提；若保留，会多出题组，与「题组数 = 目标单词数」冲突。
- ⚠️ 目标泡泡飘出屏幕（漏掉）后，**这一组是算答错直接进下一组，还是重出该词**？原文只写扣心，未写题组如何推进 —— 直接影响「每词至少考到一次」的判定（漏掉算不算「考到」）。

### 3. 生命值
| 项 | 规则 |
|---|---|
| 初始值 | **三颗心** |
| 扣减 | **点错任意泡泡扣 1 颗；目标泡泡飘出屏幕（漏掉）扣 1 颗** |
| **归零** | **不结束游戏，继续进行剩余题组，心数显示为 0**（与游戏大厅版「掉光即结束」相反） |
- ⚠️ 一组内点错后还能继续点直到点中目标吗（即一组可能扣多颗心）？原文未写。

### 4. 星级判定
| 星级 | 规则 |
|---|---|
| ⭐⭐⭐ | **主轮正确率 ≥ 70%** |
| ⭐⭐ | **主轮正确率 ≥ 30%** |
| ⭐ | **完成本局，主轮正确率 < 30%** |
- **主轮正确率的分子分母原文没定义**（按题组首次点击是否正确？按点击次数？漏掉的组算错？）—— 写用例前必须确认。
- 结算接入**课程统一结算页**（同版本《学习中心修改样式 + 单词书1.0》改了课程结算弹窗为 `Today's stickers are yours`，需一起回归）。

### ⚠️ 测试关注 / 缺口
- **能走完**：全错 / 心数归零 / 全部漏掉都要能到结算并推进路径；中途退出再进的进度与计分（原文未写）。
- **覆盖**：6 / 8 / 12 个词配置下，每个目标词恰好出现一次正确答案；干扰项只从其余 N−1 个词选。
- **与游戏大厅版隔离**：课程模式的成绩**是否进排行榜、是否扣费 / 消耗**原文未写（V1.39 大厅版沿用游戏大厅扣费与分享规则）；大厅版行为不应被改。
- **缺失项**：无 UI 稿、无 Admin 配置界面描述（在哪配单词、配几种词形）、**无埋点**（V1.39 的 `arena_*` 公共埋点在课程场景是否复用、`scene` 取值）。
