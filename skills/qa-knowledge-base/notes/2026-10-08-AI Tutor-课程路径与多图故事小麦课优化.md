## 摘要
多图故事小麦课的运营痛点是**流程控制**：Claude Code 里做好的 Demo 无法快速准确地搬到 App，bad case 集中在**流程 / 状态 / 时序控制**与**小麦 narration 执行准确度**。本期三件事：① **内容生成与一键发布 QA** —— **不做「demo 搬运」，Claude Code 本地播放器与 App 播放器消费同一份课程配置（唯一真源）**，链路「制作 → 本地预览 → 自动校验（verify / R1–R9，**0 warning 为发布硬门槛**）→ 一键发布 QA → 人工确认晋级生产」，**每次发布记版本与配置 diff、支持一键回滚**；② **课程路径 Mai Node 新增「直进玩法」开关 `direct_play`**（配目标玩法 `scene_id`，**绕过 AI course chat**，由玩法自身 opening 引导，**以玩法完成事件回写路径进度，中途退出 = 未完成**，**课程路径环节不消耗电量**）；③ **Mai chat 节点显式结束信号**：模型在教学目标达成或进入道别时调用 **`end_session` toolcall** → 播道别 TTS → **无弹窗，TTS 播完自动关闭**（等价左上角关闭）→ 回课程路径回写完成态；**道别期间用户再说话 → 取消结束、继续对话**。**硬前置依赖：App 端播放器目前缺三种门（gate）的执行能力，须先补齐（D1）**。无 UI、无埋点。

### 1. 内容生成与一键发布
- **机制（修正）**：**不做「demo 搬运」**；Claude Code 与 App **消费同一份课程配置**，本地播放器与 App 播放器都是这份配置的执行端 —— **调试改的是配置，发布发的也是这份配置，不存在第二份格式**，「调试结果 = 线上结果」由机制保证而非人工比对。
- **链路**：**制作（Claude Code 内容生成 + 流程编排）→ 本地预览调试 → 自动校验（复用 verify / R1–R9，0 warning 为发布硬门槛）→ 一键发布 QA → 人工确认晋级生产**。
- **发布治理**：**每次发布记录版本与配置 diff，支持一键回滚**；**QA 一键直发，生产需人工确认**；**发布权限：QA = 运营，生产 = 待定（D2）**。
- **存量收敛**：基于现有 demo → 场景配置管线（含校验闭环）收敛为**唯一官方链路，不新起并行方案**。
- 正文中有三行孤立的「How are you / Fruit / Good morning」，推测是首批要走这条链路的内容示例，原文未说明。
- ⚠️ **前置依赖（硬）**：**App 端播放器必须按配置完整执行流程 / 状态 / 时序与 narration 编排 —— 实测当前 App 后端缺三种门（gate）的执行能力，须先排期补齐（见 D1），否则本需求目标不成立**。

### 2. 课程路径 · 直进玩法节点

- **完成判定**：**以玩法自身的完成事件回写课程路径进度**；**中途退出 = 未完成，不误记**。

### 3. Mai chat 节点 · 显式结束状态
- **机制**：prompt 约定**教学目标达成**、或**语义分析进入道别**时，**模型调用 `end_session` toolcall**；App 收到信号进入结束流程。
- **结束流程**：**end 信号 → 播道别 TTS → 无弹窗 → TTS 播放完毕自动触发关闭事件（等价于左上角关闭按钮）→ 返回课程路径并回写完成态**。
- **可撤销边界**：**道别 TTS 播放期间用户再次说话 → 取消本次结束、正常接续对话**。
- ⚠️ 未定义：模型**一直不调用 `end_session`** 时的兜底（轮次 / 时长上限？）；**用户主动点左上角关闭**是否算完成；取消结束后再次结束的次数限制；**TTS 播放失败 / 断网**时是否仍自动关闭。

### 4. 数据埋点
- **无**（⚠️ `direct_play` 节点进入 / 完成、`end_session` 触发 / 被撤销都没有埋点）。

### ⚠️ 测试关注 / 回归点
- **一致性**：同一份配置在 Claude Code 本地播放器与 App 播放器的流程 / 状态 / 时序 / narration 是否一致（核心目标，依赖 D1 三种 gate 补齐）。
- **发布**：校验有 warning 时拦截发布；发布版本与 diff 记录；**一键回滚**；QA 与生产隔离。
- **直进玩法**：开 / 关开场白；完成事件回写进度；中途退出不记完成；不扣电量、不显示电量组件。
- **结束信号**：目标达成 / 道别两种触发；道别 TTS 中插话撤销；自动关闭后回写完成态并回到课程路径。
