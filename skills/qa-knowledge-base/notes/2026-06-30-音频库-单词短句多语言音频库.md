## 摘要

V1.31.0 后台新建独立 **Audio Library（音频库）中台**:为游戏模板引用的单词/短句提供与课程 Voice Localization 一致的**多语种音频**,并支持**同一单词配多条「音色 × 语气」变体**(标一条为标准音,游戏内按场景选标准音或随机变体)。与词库**解耦**,通过 `word_id` 双向映射。产品 Owner: Cloud;优先级:高。

> ✅ **版本已确认 V1.31.0,无排期风险**(主人确认,2026-07-01):文档「版本号」字段虽写 v1.30.0、标题带「延后」,本库按 V1.31.0 入库。文档名残留"单词回顾页面"为模板复制痕迹,与本需求无关。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 1. 核心数据模型(三层:条目 → 多语言文案 → 音频变体)
- **音频条目 Entry**:`entry_id`(全局唯一)、`source_text`(英文原文)、`linked_word_id`(关联词库 word_id,可空)、`created_by`(`word_bank_sync` 词库同步 / `manual_create` 手动)、`created_at/updated_at`。**不分 word/phrase,统一视为 Entry**。
- **多语言文案 Localization**:`entry_id`、`lang`(en/zh-CN/ja/es/kr…)、`text`、`text_status`(**Pending / Generated / Admin-Edited**)、`updated_at`。**每 Entry × 每语言最多 1 条**。
- **音频变体 Variant**:`entry_id+lang`、`voice_id`(引音色字典)、`tone_id`(引语气字典)、`is_standard`、`audio_status`(**Pending / Generated / Manual Upload**)、`duration_ms`。
- **约束(测试重点)**:
  - 同一 `(entry, lang, voice, tone)` 组合**唯一**,不可重复创建。
  - 每条 Localization **必须有一条 `is_standard=true`** 标准音;**删除当前标准音 → 系统要求从剩余变体指定新标准音**。

### 2. 音色字典 / 语气字典(两个全局字典表)
- **音色字典**:`voice_id`(如 Vo_001=Max、Vo_002=Tom、Vo_003=Lily)、显示名、关联 TTS 模型、状态、试听样本。
- **语气字典**:`tone_id`(standard 标准朗读 / excited 兴奋 / slow_demo 慢速示范 / questioning 疑问)、显示名、`tts_style_param` 情绪参数、试听样本、status、备注。
- **所有变体组合 = 音色 × 语气 字典叉乘**。
- 权限:产品/教研可增改停用字典项;音频组/研发额外可关联 TTS 模型、生成/上传试听样本。
- **停用(Inactive)边界**:不再出现在新建音频的选择下拉,**但已有音频不受影响**。
- 菜单:Audio Library → All Audios / Voice Dictionary / Tone Dictionary。

### 3. Admin 音频库主列表
- 列:Entry ID、Source Text、Linked Word(可跳词库)、Languages(如 **6/27**,分母=APP 支持语言数)、Voice Variants(变体总数)、Standard Preview(英文标准音播放)、Updated、Actions(Edit/Translate/Regenerate/Delete)。
- 筛选:是否关联 word_id(Linked to Word Bank / Standalone Phrase / All)、语言、Text Status、Audio Status、音色/语气、搜索(entry_id/Source Text/lemma)。
- 列表操作:
  - **新建 Entry**:关联词库(选 word_id,English 自动带入 lemma **不可改**,改需去词库) / 独立短句(手输英文)。
  - **翻译**:批量生成其他语种文案+标准音。**中文文案为空** → 先重翻中文+标准音,**需用户确认中文后再触发**其他语种;**中文不为空** → 直接读现有中文,按"英文+中文译文"语境翻译其他语种。
  - **重生成**(二档粒度):当前条目所有变体 / 仅标准音;支持批量。
  - **导出 CSV**(条目清单+变体清单)。
- **删除规则(测试重点)**:删 Entry 前**引用检查**——被任何课程游戏模板配置引用则**删除按钮禁用并提示被哪些课程引用**;无引用才可删,**级联移除所有 Localization + Variant,不可逆需确认**。

### 4. 条目详情页
- 顶部:Entry ID/Source Text/Linked Word/来源/时间戳。**独立短句可编辑 Source Text;词库关联类型 Source Text 只读**。
- 语言区(按语言折叠块):文案行(Text/Text Status/Edit)+ 变体列表(每行 音色名×语气名 / ⭐标准音 / audio_status / 播放 / Regenerate / Manual Upload / Set as Standard / Delete)+ **Add Variant**(选 voice×tone;新建变体会**为当前 Entry 所有已配置语言**生成该变体)。
- **英文文案级联更新(测试重点)**:编辑 English Text 保存时,若该 Entry 已有中文等译文 → **弹窗确认** → 确认后**强制触发中文重翻 + 生成对应标准音**,**其他语言译文与音频不处理**。

### 5. 翻译流程(复用课程 Voice Localization)
- **英文入库**:词库同步(lemma 新增自动建 Entry,`created_by=word_bank_sync`) / 手动创建独立短句。
- **AI 中文预翻译**:英文入库后自动触发,调**豆包模型**生成中文,`text_status=Generated`。**特殊规则**:Max 及家人名**不翻译**;句中音素记号(如 `'auh'`)**保留原样**,音频生成阶段由已校验音素文件替换。
- **人工审校中文** → 再手动触发其他语言翻译。
- **多语种衍生**:Translate(单条)/ Batch Translate(批量),输入 = 英文 + 审校中文 + 目标语言,同时生成文案 + 标准音;**语种范围与 v1.25.1 Voice Localization 一致**。

### 6. 词库联动
- lemma ↔ Entry **一对一**(`linked_word_id != null`),双向绑定,词库页展示"已关联音频库"可跳转。
- **历史数据迁移**:词库现有默认读音**一次性迁移**为每个 Entry 在英文下的「标准音色 × 标准语气 × is_standard=true」变体(当前生成课程语音的模型作为标准音色×标准语气);中文及其他语种上线后**分批生成**。

### 7. 游戏模板配置的引用改造(⚠️ 接 v1.28.0 课程游戏模板配置第 6 节)
- 对 **Target Words / Distractor Words / Starting Word / Word List** 字段,在"原画图片 / Spine 动画"之外新增 **Audio Variants** 区。
- 交互规则:
  - **标准音自动包含、不可取消**(展示 `is_standard=true` 那条)。
  - **附加变体**:从该 Entry 已有其他变体勾选,**勾选项形成"随机播放池"**。
  - 列表**仅展示当前课程语言下、已生成(Generated/Manual Upload)的变体;Pending 不可勾选**。
  - Distractor/Starting/Word List 默认只引用标准音、面板折叠,需要才展开。
- **Unity 播放逻辑**:非标准音(默认)每次触发**从 Additional Variants 随机抽一条**,Additional 为空则**回退 standard**;标准音场景由游戏逻辑显式调 `standard`(范读/示范/音素讲解);抽取粒度=**每次触发独立随机**(同关卡多次触发可能听到不同变体)。
- **课程包生成**:后端按勾选变体清单从音频库拉 `audio_url` 打包;**未勾选不打包**,避免包体膨胀。
