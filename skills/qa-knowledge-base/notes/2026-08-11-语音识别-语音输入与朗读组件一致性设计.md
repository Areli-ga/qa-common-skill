## 摘要

把小Mai 各游戏里**长得不一样**的对话气泡与录音交互统一掉,降低孩子的学习成本:**主对话 / 岛屿游戏列表 / M Town Talk 的母语转场气泡样式统一**(最高 3 行、超出跟随 TTS 滚动、**不再支持字幕实时高亮**);**M Town Talk 静态脚本支持 srt 字幕**;**自由麦统一为「点击启动 → 再次点击或超时发送」**并给出安静/收音中的视觉规格;接入**单词染色**。

产品 Owner:**Libin**;优先级:**中**;Figma **`1.36.0`** node `47281-180334`。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 0. 背景

- 现在**小Mai 跟 NPC 讲的话**,以及**用户这边录音的交互方案**,**在不同的游戏里面表现设计得不太一样**。
- **需要把它统一,主要目标是降低用户这边的学习成本**。

### 1. 需求列表

1. **对话气泡、转场样式统一**;
2. **提示引导支持字幕**;
3. **静态脚本需要支持字幕音频同步**;
4. **自由麦交互组件优化**;
5. **单词染色接入**。

### 2. TTS 引导性内容一致性设计

- **统一范围**:**主对话、岛屿的游戏列表,以及 M Town Talk 的小Mai 母语转场**,**气泡样式统一**。
- **既包含即时生成的,又包含预生成的静态内容**。
- **两种技术方案**(二选一,原文未定):
  1. **时间计算加平均的方式**;
  2. **接入千问的官方时间戳输出**。
- **例外**:**I Spy 游戏以及 ABC Story Island 暂时仍旧维持无气泡设计**。
- **气泡规格(img-01)**:
  - 内容定位:**非教学目标 / 本地化内容 / 非阅读性内容(小朋友的阅读能力偏弱)**;
  - **最高显示 3 行**,**超出后 Follow TTS 滚动播放**;
  - **不再支持字幕的实时高亮**,**预估当前讲的话的事件,仅仅做字幕的上下滚动**。
- 📌 「不再支持实时高亮」是**能力上的取舍**:因为面向的是**非阅读性内容**,孩子读不了,高亮无意义 —— 但这也意味着**原本有高亮的场景会失去该效果**,属于可感知的回退,回归时要确认是有意为之。

### 3. M Town Talk 静态脚本支持 srt

- **M Town Talk 的既定静态脚本需要支持 srt**(字幕与音频同步)。
- 现状(img-02 批注,@Libin Liu):**「NPC 的静态脚本,未支持高亮。」**
- 📌 与第 2 节合起来看:**NPC 静态脚本走 srt 做音画同步,但同样不做逐词高亮**。

### 4. 自由麦交互统一(各游戏保持一致)

**交互规则**
- **点击启动**;
- **再次点击,或者超时发送**。

**视觉规格(img-03「自由麦克风视觉设计调整」)**
| 状态 | 表现 |
|---|---|
| **未激活** | 白底圆形 mic 图标 |
| **无限接近于安静** | 绿色圆环 + 中间红色方块;**音量小于一个阈值时,中间的红色方块 `Scale 1.1` 跳动提示用户点击** |
| **收音中** | 绿色圆环**向外扩散的波纹动效**(附动效参考地址) |
| **结束** | 回到 mic 图标 |

- **超时自动提交逻辑保持不变**。
- 📌 「安静时红块跳动提示点击」是给**只录到静音**的孩子一个明确的"该点了"的提示 —— 与 [音量阈值设定](2026-08-11-语音识别-音量阈值设定.md) 的 **Noise Floor / Speech Trigger** 阈值直接挂钩,**这个"阈值"用的是哪一档需确认**。

### 5. 单词染色接入

- 接入**单词染色**能力。
- 示例(img-04):朗读卡片 `Hello` 中 **`He` 显示为绿色、`llo` 显示为红色**,左侧带**滤镜头像(小松鼠)**、右上蓝色 🔉 按钮 —— 即**在变声器的朗读卡片上叠加分段染色**,用颜色标出读对/读错的部分。
- ⚠️ **原文只有"单词染色接入"六个字 + 一张示意图**:**染色的判定粒度(音素/音节/字母)、颜色与分数档位的映射、哪些场景生效、中文课如何染色**全部未定义(已入待确认)。

### 6. 测试重点(由规则推导)

- **统一性本身就是用例**:主对话 / 岛屿游戏列表 / M Town Talk 三处的**气泡样式、转场、自由麦交互要逐一比对是否一致**;**I Spy 与 ABC Story Island 必须仍为无气泡**(反向验证)。
- **气泡 3 行 + 滚动**:构造超长 TTS 文本,验证滚动跟随、不出现截断或跳字;**确认不再有逐词高亮**。
- **自由麦四态**:未激活 → 安静(红块 Scale 1.1 跳动)→ 收音中(波纹)→ 结束;**点击启动/再次点击发送/超时发送**三条路径。
- **srt 同步**:M Town Talk 静态脚本的字幕与音频**不能错位**。
- **染色**:与打分结果的对应关系(待定义后补)。
