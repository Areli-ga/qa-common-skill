## 摘要

功能广场新增「鹦鹉学舌变声机」模块：**孩子说什么鹦鹉就用变声复读什么（零评分、零失败）**，在纯玩之上叠一层可选的**词卡挑战**（五种题型 + 金卡/闪电卡/大魔王卡，命中只加彩蛋不判错，三段保底梯兜底）与**单词图鉴**（5 星格熟练度），开口次数还能解锁 8 种变声药水。

## 功能信息（逻辑/状态/边界/字段）

### 基本信息与背景

- 产品 Owner：**Cloud**；优先级：**中**；版本号 v1.38.0；修订记录为空模板（`2026-mm-dd:`）。
- 背景：**现有全部语音交互都是评分制** —— 正反馈依赖「读对」，孩子读了被判 0 分 = 负反馈，越读越不想读，**缺一个开口本身就有回报的场景**。
- 品类验证：Lingokids Baby Bot（说什么复读什么）、Talking Tom（十亿下载量级）证明「角色学我说话」对小孩子有吸引力，且**零评分、零失败**。
- UI：`https://www.figma.com/design/ILqThciQTufJKCFPmIuDVH/1.38.0?node-id=52014-2`；**动画文件 / 声音文件仅标注「（Google 网盘）」，无链接**。
- Demo：`https://apps.giggletools.com/parrot-repeat-demo/`

### 需求范围（一个模块，12 项）

功能介绍/入口页 · 麦克风授权弹窗（沿用 App 现有组件）· 新手引导（Max 入场示范 + Max 呼叫按钮）· **L0 自由学舌**（自动收音 + 变声复读）· 变声药水池（基础 4 + 解锁 4 + 神秘药水）· **L1 词卡挑战**（卡包 Level·Unit + 五种题型随机）· 命中判定与三段保底梯（**含判定降级策略**）· 修饰卡（金卡 / 闪电卡 / 大魔王卡护盾两段战）· Unit 集齐结算 · 单词图鉴（四种状态 + 点击听读音）· 退出结算页（开口成绩单）· 进度持久化。

### 1. 整体流程

**首次进入**

1. 进入功能介绍页 → 点击开始游戏 → **检查麦克风权限**：
   - 已授权（**课内跟读已授权的存量用户 = 大多数**）→ 直接进模块；
   - 未授权 → 停在功能介绍页 →【开始玩】→ 系统授权弹窗；
   - **「不再提示」→ 直接出「去设置」态的语音授权弹窗**。
2. 进入模块 → 首次走引导（Max 入场示范）→ 孩子开口 → **首次成功庆祝**。
3. 之后按节奏解锁药水 / 开始词卡玩法 / 图鉴。
4. 中途点左上角退出按钮 → 触发结算页/弹窗。

**自由说话（L0）**

- 鹦鹉自动呈现聆听态；录音：**边缘光波紫 + 音波往鹦鹉耳朵聚拢**。
- **尾静音达阈值 / 达录音上限** → 判断是否有效发声：
  - 否（**VAD 未检测到人声**）→ 鹦鹉触发**贴近聆听态**（夸张凑近）；
  - 是 → **变声复读**：边缘光波绿 + **鹦鹉喙随振幅开合** → 回到聆听态；
  - **若平均音量较大 → 触发鹦鹉拍翅大声回放态**。
- **收音停止时机**：回放/反应/示范读音期间、任意浮层（图鉴/结算/选题/庆典）打开期间、**Max 客串演示期间**。
- **权限被事后关闭：每次进模块重查；模块内检测到失效 → 触发授权弹窗。**

**词卡模式（需要语音识别）**

- 进入题库 → 判定本 Unit 状态：
  - **未完成过本 Unit / 本 Unit 全部满星** → **全部学习轮**：本 Unit 所有单词随机出卡，**最后一张固定为大魔王卡**；
  - **完成过本 Unit** → **刷星学习轮**：本 Unit 内**所有未满星的词**（满星的不出现）随机出卡，最后一张固定为大魔王卡。
- 出卡（题型随机，**首轮首张固定为普通读词卡**）→ 孩子开口 → **鹦鹉变声复述（无论读对读错都先复述）** → 语音识别（**用原声进行识别**）→ 复述结束瞬间即时反馈（单词图片 + 卡片边框绿闪 + 星星飞入 + 鹦鹉赞赏动画）→ 下一张。
  - 若为 Boss 卡且仅命中 1 次 → 击碎护盾 → Boss 卡二阶段 UI → 等第 2 次命中。
- **识别未通过 → 三段保底梯**：
  1. 第一次：展示单词图片 + 示范标准读音；
  2. 第二次：**0.75 倍速慢读**；
  3. 第三次：**系统带读点亮** —— 给 **1 颗空心星**（空心星最多只可获得 1 颗）、卡片照常点亮（**但图鉴中此单词不算读对**），进入下一张。
- 完成 Unit 所有词卡 → Unit 完成结算 → 回选题页（该 Unit 标 🏆，**可重玩攒熟练度**）。

### 2. 入口页

- 页面构成：主视觉鹦鹉贴近聆听态；标题区**模块名【Kiki Talk/鹦鹉Kiki学舌】** + 一句话价值主张；三张玩法亮点卡（🗣️ Say it, hear it / 🧪 Magic voice potions / 🃏 Word cards & Collection）；主按钮【▶ Start/开始游戏】。
- **回访态**：有历史进度时显示「Welcome back! You said {N} words right — {M} are mastered.／欢迎回来！你已经读对 N 个单词（其中 M 个已熟练）」，**主按钮改为【▶ Continue/继续玩】**。
- ⚠️ 设计稿与正文有出入，见待确认 ①②。

### 4.【Max】按钮（常驻求助入口）

- 位置：**右下角常驻 Max 头像，任何时候可点**。
- 行为：Max 入场 → 说一句短句 → 鹦鹉当场复述 → `Your turn!` → 鹦鹉复述 `Your turn!` → 离场。
- **示范句池**（8 条）：`Hello, parrot!` / `I love ice cream!` / `You are so funny!` / `Good morning!` / `Yummy yummy!` / `Wow, amazing!` / `My name is Max!` / `Let us play together!`
- **演示期间停止收音，但鹦鹉依然呈现聆听态**，待 Max 说完再复述。
- **演示中鹦鹉的复述沿用孩子当前选择的药水音色。**

### 7. 词卡挑战

**卡包结构**

- 按 **Level - Unit** 分组，读取**当前路径配置的【主课程】**的 Level-Unit 信息（单词即 Unit 配置的词库单词）；**后续可能要兼容 Phonics（本期不做）**。
- 选题页按 Level 分组、**沿用等级主题色**，卡片显示：Unit 名称 + Unit 封面 + **点亮单词数 m/n** + **熟练单词数 m/n**。
- 集齐的 Unit 做对应标记且可重玩（攒图鉴熟练度）；**Unit 内所有单词都熟练则做特殊标记**。

**五种题型（随机抽取，每次首张固定普通读词卡）**

| 题型 | 卡面 | 本地化引导语 |
|---|---|---|
| 普通读词卡 | 图 + 单词 | `Can you say {word}?` / 你会说【单词读音】吗？ |
| 猜谜卡 | **只给图，隐藏单词名** | `What is this? Say it out loud!` / 这是什么呀？看图大声说出来！ |
| 悄悄话卡 | 图 + 单词 | `Let me whisper it… {word}! Now say it loud!` / 我悄悄教你这个词，【低音量单词读音】！ |
| 听音卡 | **喇叭 + 声波图标（不给图不给词）** | `Listen… {word}! Now you say it!` / 听好啦，跟着我大声说出来！【单词读音】！ |
| 剪影卡 | **图变黑色剪影，隐藏单词名** | `What is hiding in the shadow?` / 影子里藏着的是什么？ |

**卡型（题型 + 卡型混搭）**

| 卡型 | 规则 | 奖励 |
|---|---|---|
| 普通卡 | 未命中特殊卡时出现 | 星星 ×1 |
| ✨ 金卡 | **随机出现（默认 20%）** | 星星 ×2 |
| ⚡ 闪电卡 | **随机出现（默认 20%）；第一次就命中两颗星，否则后续仅获得 1 星** | 星星 ×2 |
| 👑 大魔王卡 | **每包最后一张固定**；护盾遮住卡面图案，**需命中 2 次** —— 第 1 次念对击碎护盾（碎裂 + 碎片四溅 + 震动）→ 二阶段状态（红框脉冲 + 图案狂抖）+ 本地化语音「Again! One more time!」；**第 2 次念对则通过**（⚠️ 原文此处后接一段语义损坏的句子，见待确认 ③） | 星星 ×2 |

- **复用挑战课的连击 Combo 动画**；**未命中仅清零连击，不做任何负面表现**。

### 8. 星星与熟练度

每个单词有 **5 个星格**，展示在 Unit 结算页与图鉴中。

| 概念 | 定义 |
|---|---|
| 星格总数 | 每词最多 5 格；总星数 = 各单词星格之和，是**派生值**，**重玩已满格的词只会得到 0 颗新星** |
| ⭐ 实心星 | **真实命中 1 次得 1 颗**（金卡/闪电卡/Boss 按对应规则计） |
| ☆ 空心星 | **带读点亮（保底通过）得 1 颗** —— 计入星格、**但不算读对**，**最多只可获得 1 颗** |
| 👑 熟练 | **实心星满 5 颗**（真实命中 ≥5 次），本词卡的星星全部转化为熟练星状态 |
| 空心转实心 | 后续真正读对时，**优先把该词的空心星点亮成实心** → 星格总数不变、真实度提升 |

### 9. Unit 完成结算

- 该 Unit 的卡片（**按本次出现的卡型展示**）逐张冒出、平铺展示；
- **每张单词卡冒出时播放一次单词系统标准读音**；
- 全部落定后**标题徽章砸落 + 彩带 + 口哨**；
- 回到选题页，该 Unit 状态变更。

### 10. 单词图鉴

全 Level 单词收藏册，**按 Level 分组（沿用等级主题色）**。

| 状态 | 判定 | 表现 |
|---|---|---|
| 未接触 | 从未接触过该卡 | **黑色剪影 + ???** |
| 接触过 | **卡片曝光但未读对** | 图案半透明 + 星格 |
| 实心星 ×N | 获得实心星 ≥ 1 | 点亮 + 星格 |
| 👑 熟练 | 获得实心星 ≥ 5 | **金框** + 星格 |

- 顶部统计：**已接触 N/总数 · 读对 N · 熟练 N**。
- **非「未接触」的卡点击可听标准读音**（轻量复习入口）。

### 11. HUD 与退出结算

- 顶栏常驻 **mini HUD**：🎤 本次开口 / ⭐ 本次星星 / 🔥 最高连击，**实时展示**。
- 退出结算页「**今天的开口成绩单**」：
  - **本次**：本次开口、本次收获星星、最高连击、本次集齐 Unit；
  - **累计**：累计接触单词、累计读对单词、累计熟练单词、累计星星；
  - 按钮【再玩一会】/【退出】。

### 12. 进度存储

**累计数据（跨会话永久保留，按 kid 维度）**：单词状态（图鉴四态与熟练度）、Unit 进度（点亮进度、集齐状态）、累计开口次数（药水解锁进度）、累计星星、首次引导完成状态、药水的选择状态。

**单次会话数据（可本地存储，每次退出重置）**：本次开口次数 / 星星 / 最高连击 / 集齐 Unit —— 仅供结算页「本次」区展示。

**存储与同步**：服务端按 kid 存储为准，端上做本地缓存；**弱网/离线先写本地、恢复后同步**；**冲突合并取较大值或并集**（避免多端来回覆盖导致进度倒退）。

### 13. 原画与动画清单

- **鹦鹉·主体 + 反应动画库**：待机、喝药水（**8 种药水瓶**）、常规聆听态、夸张凑近的聆听态、变声复读（与音频振幅同步）+ 鼓掌、变声复读 + 拍翅大声回放态、复读完鼓掌 + 吹口哨、天降浆果鹦鹉吃下 + 比心。
- **Max·朝着鹦鹉说话**：身体朝右向鹦鹉、张嘴、双手靠在嘴两侧做大喊姿势。
- **Max·邀请说话**（`Your turn!` 时刻）：身体朝向屏幕，大笑 + 双手掌心朝上向屏幕捧手势。
- **Max·入场/离场动效**；**题卡卡面动效**（5 种题型 + 3 种卡型，原画 UI 提供）。
