## 摘要
V1.39.0 做一次**限时 UGC 活动「绘本配音大赛 Storytelling Contest」**（**仅中国、印尼两地区**按 IP 展示入口）：孩子在活动介绍页选 **3 本不同难度的指定绘本之一**，**完全复用现有故事书逐句跟读配音能力**录完整本 → **自动合成并提交作品**（**一人限一个作品、截止前可重录覆盖**）→ 作品**立刻进入公开【作品广场】**（不分地区，全站可看可赞）并**即时发放一套活动专属套装**；作品可分享到站外生成 **H5 播放页**，**站外访客免登录、按设备 ID 限一次、不可取消**地点赞并在**点赞成功之后**才出现下载引导；活动到点同时**停止提交、停止点赞并公布榜单**（中国榜 / 印尼榜分别排名，奖品为蓝牙音箱），获奖者通过**微信（中国）/ WhatsApp（印尼）**联系工作人员填收货信息，公示两周后活动页下架。**活动入口、内容下架都要求无需发版**。

### 2. 创作与提交流程
- 入口：活动介绍页【参加活动】→ 弹 3 本不同难度绘本，**卡片展示建议年龄范围**；**已提交过作品的用户点按钮直接跳【作品详情页】**。
- 录制：**完全复用 App 现有绘本跟读页** —— 播放示范音 → 孩子跟读该句 → **自动进入下一句**；**左右箭头可回到任意一句重录，不限次数**。
- 提交：**最后一句录完后自动合成整篇音频、生成作品并提交**，进入提交成功页。提交内容 = **音频文件 + 绘本 ID + 用户 ID + 孩子 ID + 用户区域标签**。
- 奖励：提交成功**立即公开**并**按账号发一套**活动专属套装（`我的奖励页`可查看，**在个人装扮里可穿戴**）。

### 3. 站外分享 → 点赞 → 拉新漏斗
**核心设计（img-03）：点赞在下载之前 —— 先让对方完成善意行为，再邀请下载。**
漏斗 6 层，每层都有对应事件名：**ShareSent（分享送达）→ H5Opened（打开 H5，免登录免下载）→ WorkPlayed（播放作品）→ LikeSuccess（点赞成功，零门槛：不登录、不跳转、一次点击）→ DownloadCTAShown（点赞成功「之后」才出现下载引导）→ DownloadClicked**。
**每一层都带来源标记（分享者 `user_id` + 作品 id），否则拉新无法归因。**

H5 播放页规则：
- 页面元素：作品封面、绘本名、孩子昵称、点赞数、创作时间、播放器、【点赞】按钮。
- 播放：**音频与绘本画面同步播放，支持上下翻页**；⚠️ 原文明确写着「**当前官网上播放绘本会卡住，需要先解决绘本播放的问题**」——这是已知阻塞项。
- 点赞：**无须登录**；**同一设备不可重复点击**；状态仅「已点赞 / 未点赞」；**站外不可取消点赞**（与站内「可取消」不同）。
- 下载引导：**完成点赞后**弹窗引导下载；**微信内打开要先引导「在系统自带浏览器中打开」**；跳转判断 **iOS → App Store；Android → 印尼区 Google Play、中国区对应应用市场**。
- 分享卡片文案：标题 `{昵称}给你读了一本英文绘本`；描述 `点开听听TA的配音，别忘了点个赞！`；缩略图为绘本封面。
- 活动页分享卡片：标题 `绘本配音大赛开始啦`；描述 `读绘本、集点赞，赢蓝牙音箱！`；缩略图为活动主页面。

### 5. 数据埋点
**埋点事件表不在本篇** —— 原文「埋点事件」一节是一个飞书文档引用：**《故事书大赛埋点》**（`https://wsgh3q8mwfpp.sg.larksuite.com/wiki/YXUzwrU8yiF08zk8rFOlT9VGg1g`），本篇只给了观测口径与漏斗。

| 目标 | 计算口径 | 依赖事件 |
|---|---|---|
| 活动查看率 50% | 进入过活动介绍页的去重用户 ÷ 活动地区活跃用户 | `$pageview` |
| 作品提交率 30% | 提交成功的去重用户 ÷ 看过活动页的用户 | `activity_record` |
| 分享率 10% | 分享过作品的去重用户 ÷ 提交过作品的用户 | `app_share_click`（`scene = my_work`） |
| 外宣素材 ≥200 条 | **状态为「已发布」的作品总数** | `activity_record` 去重作品数 |

**完整漏斗**：入口曝光 → 进入活动页 → 点击【参加活动】→ 开始录制 → 提交成功 → 分享作品 → H5 打开 → H5 播放 → H5 点赞 → 点击下载 App。
> ⚠️ 口径里用的还是 `app_share_click`，而 V1.39《泡泡单词》那篇的 0917 埋点改造已把它改成 **`arena_share_open`**（9 款游戏共用）。本活动的分享埋点用哪个事件、`scene = my_work` 是否仍成立，要和埋点篇对齐。

7. **H5 绘本播放卡顿是已知阻塞项**（原文明写「当前官网上播放绘本会卡住，需要先解决」），这是站外漏斗的第 3 层，不解决则分享率与拉新目标都无从验证。
8. **广场「按难度筛选」缺入口**（需求范围要求，页面规则表没有）。
9. **【查看我的奖励】按钮跳转目标为空**（原文表格该行留白）。
10. **重录覆盖的副作用**：重录后作品的**点赞数是否清零、广场排序与「最近 24 小时」抽取是否按新提交时间重算、已分享出去的 H5 链接播放的是新版还是旧版**，均未写；规则文案只说「最新一次录音才是大家听到的那份」。
