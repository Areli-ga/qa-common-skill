## 摘要

V1.32.0 奖励中心 V2.0/V2.1 引入**家园系统**(室内装扮玩法):学习获得的资产(贴纸/服装/奖杯)可在家园查看、装扮玩耍,提升留存与可玩性(现 V2.0 次日留存约 13%)。含奖励中心引入引导(强/弱 AB)、家园视频转场、Avatar 换装、室内装扮、老用户升级补发、后端奖励发放规则、次日 hook。⚠️ **V1.32 直接下掉老奖励中心,所有用户进新奖励中心**。产品 Owner: Sunny。(文档版本字段残留 V1.0,figma 为 1.32.0。)

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 1. 进入奖励中心的引导时机(AB)
- 目标:提升新用户首日完课达一 part 的用户进家园的转化率。
- **一个单元一 part**:实验组 A = 回地图后**奖励中心图标放大、强制打开**(其他行为不可中断);对照组 B = 图标**一直晃动直到用户点击**才打开。
- **一个单元两 part(非一 part)**:实验组 A 强引导 = 第一 part 完成后**扭蛋自动打开、奖励飞入、图标放大强制打开**;对照组 B 弱引导 = 图标晃动直到点击。
- **奖励中心首次启动预加载**:用户进第一个 part 最后一节课时开始预加载(减少进奖励中心等待)。

### 2. 家园视频动画转场(首次仅一次)
- 所有用户首次进入家园奖励中心都播(**含老奖励中心升级到新的**)。
- **分镜**:俯视岛屿 1.5s → 拉近房子 1.5s → Avatar 招手 1s → 推进室内 1s。
- **仅首次**:本地存 `has_seen_intro` flag,二次起直接进室内。
- ⚠️ **弱网 fallback**:动画文件 > 5 秒未加载完 → 跳过直接进室内。声音:BGM 渐入,可静音(遵循全局音量)。

### 3. 家园内部引导
- **3.1 新用户首次**:引导点击换装模块。**换装调整**:展示 Level 单元信息(取课程配置字段);**未获取的服装加锁住样式 + 引导学习语音**(范围:全部 tab 下未解锁服装)。
- **3.2 老用户升级补发弹窗**:老用户升 V1.32 后直接看新家园;点补发弹窗 → 自动打开换装入口看刚获得奖励。
  - **Max 服装**:V2.0 不再展示 Max 服装,但给**有完课记录用户补发 Avatar 单元服装**。
  - **贴纸收藏集**:按获取时间**倒序**(最新在前)。
  - **连续打开天数 & 冰封道具**:连续打开天数弱化、可展示;V2.0 **不展示连续打卡保护道具**(990 道具/527 用户);V2.0 不再发放道具,**静默使用**(后端逻辑保留、前端展示去掉)。

### 4. 室内功能模块
- 拖动物品 / 粘贴纸时发单词声音。
- **家居排序**:最新获得放最前;放进垃圾桶的放最后。
- **tab 定位规则**:点背包打开面板,按子 tab 是否有新获得定位;多物品优先级 **家具 > 奖杯 > 贴纸**。
- **Giggles 明细新增**:获取「完成课程 +20」;消耗「趣玩乐园 -20、服装购买 -N」。
- 本期装扮交互:奖杯可查看+摆房间;贴纸可查看+贴墙和地板。
- 提示:学习路径获贴纸 → 进室内家具入口有 🔔;获服装 → 服装入口有 🔔。获得贴纸飞入家具入口(点进家具装扮场景定位贴纸 tab),服装飞入服装入口(进 Avatar 装扮场景定位服装 tab),抽奖机会 icon 去掉。

### 5. 后端奖励发放(测试重点)
- **奖励来源**:宝箱开**单元服装**;路径中扭蛋开 贴纸/普通服装/Giggles。
- **比例(可配置)**:V2.0 贴纸比例设 0、普通服装:Giggles = **6:4**(后改为可配置,且当前先全部开贴纸、其他暂不开);当期贴纸抽完可抽过去期。
- 100 Giggles 抽奖:把 20 Giggles 奖品概率重置 0;当期抽完可继续抽以前期贴纸(比例同路径、可配)。
- V2.0 支持从扭蛋抽出贴纸(路径扭蛋 + 扭蛋机 100 Giggles 扭蛋都可);**当期抽完抽过去期,隐藏款也可通过普通抽奖抽到**。
- 抽奖机会:**1.0 有抽奖机会,2.0 没有**(直接发具体奖励贴纸);普通抽奖必开普通贴纸、隐藏抽奖必开隐藏款(新奖励中心)。
- 菜单栏扭蛋抽奖 H5 活动、贴纸册入口保留;**单元宝箱状态后端记录**,已领取某单元 ID 宝箱状态不随课程调整改变。

### 6. 次日 hook(× 路径 part,测试重点)
- 文案:「明天再来,有惊喜等着你哦!」/「Come back tomorrow for a surprise!」(穿衣动画+音效结束后播)。
- **一个单元一 part**(新手课无扭蛋):实验组(有 hook)=宝箱开单元套装,**次日 App 启动发勋章头饰**(✅已验证);对照组(无 hook)=宝箱开单元套装+勋章头饰。
- **一个单元两 part**:1.0 有贴纸(扭蛋贴纸 Giggles=7:3),2.0 无贴纸(扭蛋普通服装 Giggles=7:3),宝箱开套装。实验组(有 hook)=宝箱开套装 + 明日奖励预告,次日开勋章头饰;对照组(无 hook)=宝箱开套装+勋章头饰。
- 音效:Giggles 发放音效替换为挑战课 Giggles 音效;单元划动音效加回。

### 7. 埋点(3 个 AB Key 上报用户公共属性)
- **`reward_entry_v132`**(引导路径 AB,渗透率/留存)、**`reward_nextday_hook132`**(次日 hook AB)、**`reward_homeplay_test`**(V2.0/V2.1 分流)。
- 事件:`reward_centerclick`(Type:click/auto)、`reward_intro_play`、`reward_intro_end`、`reward_avatar_home`、`reward_avatar_home_dress`(click/auto)、`reward_avatar_home_furniture`(tab:贴纸/奖杯/家具)、`reward_avatar_home_edit`(Type:贴纸/奖杯/家具;Action:add/move/remove;Name:来自后台配置)、`reward_box_show`/`reward_box_click`(Type:老用户升级/其他)、`reward_avatar_home_click`、`reward_back`。Avatar 装扮 V2.0/V2.1 都有,通过公共属性区分。
