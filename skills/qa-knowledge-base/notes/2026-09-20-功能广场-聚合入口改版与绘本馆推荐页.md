## 摘要
V1.39.0 把首页聚合入口从「功能罗列」改成**按级别拓展内容**（AB key **`default_feature_squarev2`**，对照组 = 旧版聚合入口）：面板重排成三区 —— **「Lv N 拓展 Expansion」**（取用户主路径级别，固定展示 **绘本 / Speaking / Phonics**，绘本位展示课程配套推荐的第一本，右上感叹号进拓展体系介绍文档）、**「语感培养」**（Giggle Cast / Giggle TV / FlashCard / MiniPlan）、**「复习工具」**（Arena / Art / Worksheets / Deskmate / Search）。配套改造绘本馆：顶部变成 **推荐 + A/B/C/D/E 共 6 个 Tab**（默认推荐页），**主路径推荐页**按 `课程配套推荐（4 本，可刷新换主题）→ 推荐绘本系列 → 随便听听（L1–L2）/ 开口跟读（L3+）` 三位排布，**自然拼读推荐页**为 `3 个系列 + 开口跟读`；**「我的声音」改名「我的作品」**，搜索 / 我的关注 / 我的收藏收进「...」菜单；**后端按表重刷全部绘本蓝思值并打 A–E 难度标签**。另含四件小改动：**FlashCard 右上角加 Word 入口、学习中心面板移除单词库**；**MiniPlan 改为全解锁**；**Giggle Cast / Giggle TV 支持 0.5–2.0 倍速 + Giggle Cast 加首页播放组件与播放列表**；**单元卡片单词下方加「打印练习册」，Admin 单元编辑支持上传关联练习册 PDF**。

## 功能信息（逻辑 / 状态 / 边界 / 字段）

### 背景与目标
- 现状数据：**点击入口约 9000 左右，日均使用功能用户约 6700，约 80% 人使用功能**（原文另一处写「实际使用功能将近 7000」）。
- **新用户占比较低，更面向老用户**，在此基础上增加拓展体系，**不影响首日用户留存**。
- 目的：提升聚合入口的**使用率**；提升聚合入口**留存和功能相关性**。
- **AB**：对照组 = 旧版聚合入口，实验组 = 新版聚合入口；**key `default_feature_squarev2`**。
- UI：figma `1.39.0` node `56423-46610`。

### 2. 绘本馆（Storybook）C 端改造
**Tab 结构**：顶部 **推荐 / A / B / C / D / E 共 6 个 Tab**，进入**默认停在【推荐页】**；推荐 Tab 下有副标题「**基于课程级别推荐**」；右上角是**我的作品入口 + 「...」菜单**。

**主路径推荐页规则（Level 1～2 与 Level 3 及以上）**
- **第一位：课程配套推荐位**
  - **本期绘本关联知识点不一定来得及做完；做不完则由产品提供一张表**（字段：课程 level、主题(unit 主题)、绘本 id、绘本名）。
  - （1）**基于用户 Level 推荐 4 本绘本**，**用户可点刷新换主题**，看该主题下推荐的绘本。
  - （2）**切换主题仅在当前主课程 level 下的主题之间切换**。
  - （3）**每本绘本学完后，若该主题还有新绘本就展示新的；若学完了不够 4 个位置，展示绘本的完成态**。
  - （4）**不需要跟用户的主题关联，在级别下随机展示即可**（⚠️ 与（1）（2）的「按主题切换」表述存在张力，见待确认）。
- **第二位：推荐绘本系列** —— 级别推荐系列（形如 `Lv1 XXXX 系列`），**点击进入查看系列可看该系列全部绘本，不用筛级别**。
- **第三位**：**Lv1～Lv2 = 「随便听听」**；**Lv3 及以上 = 「开口跟读」**。均展示 **3 本绘本 + 最后一个位置【查看更多】**，点开展示绘本列表。
  > ⚠️ 设计稿（img-04 / img-05）第三位实际画了 **4 本书卡**、且未见【查看更多】位，与「3 本 + 查看更多」不一致。

**自然拼读推荐页规则**
- **第一位：系列推荐位置，展示后台配置的 3 个系列**，点击进入系列列表页。
- **第二位：开口跟读**，展示后台配置的绘本。

**级别 Tab（A–E）**
- 本期支持 **按 A/B/C/D/E 5 个级别筛选**；筛选后**按目前推荐页的故事排列，但只展示对应级别的绘本**。
- **根据数据表重新刷蓝思值，并加上难度标签（对应 A–E）**：数据表 `wiki/TucfwkZSPia7CxklUeylZZ44gsf?sheet=U4BNIZ`。
- 现有绘本系列按级别展示的数据**不存在小于 4 本的情况，可维持现在的展示逻辑不变**；**某级别中系列绘本为 0 则隐藏此系列**。
- 点击【View ALL】进入完整列表。

**菜单与页面改名**
- **【我的声音】→【我的作品】**（展示目前「我的声音」的作品）。
- **【搜索】、【我的关注】、【我的收藏】收进「...」菜单**；**搜索页不变**。
- **我的关注 / 我的收藏**：现有页面**只改布局，其他不变**。
- **【我的作品】、【我的收藏】、【我的订阅】去掉目前线上的 spine 动画引导，改为静态缺省**。

**【后端需求】故事书刷数据**：按表 **A 列「故事书 ID」取 I 列「Target lexile_score」，替换系统内现有的 `lexile_score`**（同上数据表）。

### 3. 绘本推荐后台（Giggle Creator → Management → 推荐管理）

### 6. 磨耳朵（Giggle Cast）与 Giggle TV 倍速播放
**Giggle Cast 首页播放组件**
- 进入 Giggle Cast 时**底部播放组件不展示，用户点击开始播放后才展示**。
- **点击播放组件进入全屏播放器**；**点击其他专辑 → 播放该专辑第一首并进入全屏播放器**（目前线上如此，不变）。

**全屏播放器**：**新增倍速播放**、**新增播放列表**；**点击关闭按钮弹窗询问**（弹窗内容见原型）。

**倍速**：支持 **0.5X / 0.75X / 1.0X / 1.25X / 1.5X / 2.0X，默认 1.0**；**每次进入后倍速都重置为 1.0X**。**Giggle TV 同样增加倍速入口**，规则相同。

**播放列表**（img-23）：点击后查看**当前专辑的列表**，点歌曲可切换；**顶部展示其他专辑，可点击切换；切换后不自动播放新专辑，等用户点击该专辑的歌曲才开始播放**。实拍：标题 `播放清单 4 首`，专辑 chips `经典童谣（选中）/ 欢乐律动 / 晚安时光`，曲目带序号、封面色块与时长（`Humpty Dumpty 2:15` 高亮为当前播放、`Old MacDonald Had a Farm 3:02`、`Mary Had a Little Lamb 1:55`、`Baa Baa Black Sheep 2:08`）。

### ⚠️ 待确认（写用例前需拉齐）
1. **课程配套推荐位的规则自相矛盾**：（1）（2）说「按主题推荐、刷新切换主题、只在当前 level 的主题间切换」，（4）却说「**不需要跟用户的主题关联，在级别下随机展示即可**」。到底按主题还是按级别随机，决定刷新按钮的全部用例。

3. **第三位栏目的书本数量**：正文写「3 本 + 查看更多」，设计稿画了 4 本且没有「查看更多」位。
4. **级别 Tab 与推荐 Tab 的书卡来源关系**：级别 Tab「按推荐页的故事排列但只展示对应级别」—— 若该级别在某推荐位无书，是隐藏该位还是显示空态，未写（只写了「系列为 0 隐藏此系列」）。
