## 摘要

V1.30.0 反馈与社区:APP 内支持用户(游客 + 已登录)提交**意见反馈/举报**,并优化"加入社区(私域)"引导;配**反馈后台** + **社群码后台**。目标:用户遇问题能及时咨询/反馈。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 1. Menu 加社群引导
- **未登录**:增加【联系我们】入口(**仅中国区可见**;交互以设计为准)。
- **已登录**:Banner 原配置不改,文案增加"聊聊你的心得与疑惑"。
- 点【联系我们】/【加入社区】→ 社群欢迎落地页。

### 2. 社群欢迎落地页
- 文案(感谢早期探索者…邀请加入微信共创群);二维码后台配置、**每次进入刷新取最新**;保存图片 → 存微信二维码到本地;**未开图片授权 → 弹窗确认开启**。

### 3. 社群码后台(operations → QR Code Config)
- 配置 **Wechat(中国生效)+ WhatsApp(海外生效)** 两个二维码(PNG/JPG ≤1MB,推荐 500×500)。

### 4. 设置-反馈目录调整
- 举报不当内容 + 报告错误 **合并进【意见反馈】**;合并后【反馈】含:意见反馈、课程问卷调查、应用评价、联系我们。

### 5. 反馈收集页(测试重点 · 字段/上限)
- 加社群引导:中国区顶部加 V 引导(老师二维码,点保存直接保存);海外 WhatsApp 二维码;**地区由 APP 学习语言判定**。
- **必填**:反馈类型(功能建议/试用疑问/报告错误/举报不当内容);选"举报不当内容"→ **二级必选**(内容安全/防沉迷/隐私与信息保护/广告合规/其他)。
- 问题描述:文本 + emoji;**最多 500 字**,超出文本框不再展示;达 500 → `500/500` 进度条**标红警告**。
- **非必填**:
  - 上传文件:复用上传图片组件;**最多 3 张**;上传后以**文件名**展示(不缩略图);**单张 ≤3M**,超 → toast「图片大小超出3M,请压缩后上传」。
  - 联系方式:**≤50 字符**。
- 提交:必填未填 → **置灰、点击无反应**;填完 → 可点提交;提交后入 admin 后台 + 机器人转 cc 用户反馈群。
- **静默收集**(不展示给用户):上报 用户 id / 设备 / 网络信息 / 地区 / APP 版本。

### 6. 反馈后台(operations → User Feedback)
- 列表:反馈 id / 类型 / 内容 / 附件图 / user id / 地区 / 版本号 / 反馈时间;顶部展示总数 + 各类型数;**支持导出**;cc 机器人可主动群内下发反馈。
