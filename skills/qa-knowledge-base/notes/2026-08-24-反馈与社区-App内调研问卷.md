## 摘要

V1.37.0 在【家长中心】看板轮播广告位新增「问卷调查」入口（**登录态 + 游客态都展示**），用户 App 内答题（单选 / 多选 / 评分 / 问答 / 录音 5 种题型）后发 Giggles，配套运营后台三步向导（基本信息 → 题目设置 → 生成 H5）+ 三态发布状态机 + CSV 数据导出，目标是把用户研究周期从「线下电话访谈数周」压到 **≤ 3 天**。

> ⚠️ **本篇最大风险**：「需求范围」表写的是**接 Google 表单 + 短链 + 按 uid 名单一次性手动发 100 Giggles**，而后面的功能描述 / 交互原型 / 后台方案全是**自研问卷 H5 + 自动发 N Giggles**。两套方案并存且都没标「本期/下期」，提测范围必须先拍板（详见待确认 1）。
>
> ⚠️ **原料补抓说明**：本篇有 **4 个内嵌 Sheet（`block_type=30`）**，fetch.py 抓不到，装着**题型规则表、问卷状态机、基本信息字段表、题型配置表**。已用 `sheets/v2` API 补抓（code=0）落 `raw/App-内新增「调研问卷」功能/sheets.json`。

### 1. 需求背景与目标

- 背景：当前用户反馈主要依赖**线下电话访谈** —— 效率低、样本量小、覆盖面窄、周期长；且历史样本地区分布失衡（**大量为非目标市场用户**），难以规模化获取目标市场（如印尼）的真实反馈。
- 方案：运营侧**每隔一段时间（如两周）发布一套问卷**，面向符合条件的用户定向展示，用户 App 内作答并获得 Giggles 奖励。
- 目标：

| 类型 | 指标 |
|---|---|
| 定量 | 单期问卷「**入口曝光 → 完成」转化率 ≥ 10%** |
| 定量 | 预计单期有效回收 **11 份**（把游客看板改造成广告位后预计 **100 份**）。算法：**曝光人数 × 10%（广告点击）× 10%（问卷填写）**；定向印尼，**每天进入用户数约 280 人** → 预计回收 11 份 |
| 定量 | 单次调研从发起到回收周期 **≤ 3 天**（原线下访谈为数周） |
| 定性 | 沉淀可按**国家 / 语言 / 年龄 / 学习级别**拆分的结构化反馈 |

### 2. 主要特性

- 【家长中心】看板广告位**每月**新增「问卷调查」广告。
- 管理系统 - 广告配置**新增广告位：家长中心 - 游客模式**。
- 问卷内容**多语言**：随用户界面语言自动展示对应语言。
- **多题型**：单选、多选、录音题、问答（开放题）、评分 / 量表题。
- 完成问卷发放 Giggles（**每期奖励数可配置**）；**防重复领取 —— 每个问卷只允许答一次，后端返回问卷答题状态**。
- 运营后台：问卷配置、发布 / 下线、数据回收与导出。

### 3. 需求范围（原文 3 条，Google 表单方案）

| # | 说明 |
|---|---|
| 1 | 在【家长中心】面板的**登录和游客两个广告位**中增加「问卷调查」广告位，**配置 Google 表单**，App 内支持点击后打开 Google 表单 |
| 2 | **Google 表单中会让用户填写 uid**，后续开发**根据提供的 uid 名单一次性发放 100 Giggles** |
| 3 | 对 Google 表单进行**单独的短链封装**，用于记录链接的**点击次数 / 人数** |

### 4. 用户答题流程（流程一）

| # | 流程 | 说明 |
|---|---|---|
| 1 | 广告展示 | 家长中心看板广告位展示「问卷调查」广告（**登录 + 游客**）；**是否展示由广告位管理决定**（有效期 / 启用状态等） |
| 2 | 进入说明页 | 用户点击广告进入说明页：标题、预计时长、完成奖励 Giggles 数 |
| 3 | 逐题作答 | 支持单选 / 多选 / 录音 / 问答 / 评分；可上 / 下一题；**必答题未答不可跳过** |
| 4 | 提交 | **校验必答题是否全部完成**，通过则给出「提交成功」反馈 |
| 5 | 发放奖励 | 提交成功后 **+N Giggles**，展示奖励反馈；**标记该用户本期「已完成」，防重复领取** |

- 流程图补充（图 3，正文未写）：
  - 必答题未全部完成 → **「提示补答」** 分支回到作答。
  - 「提交成功 → 发放 +N Giggles（**游客登录后领取**）」—— **游客态奖励需登录后才能领**。
  - 说明：**「广告是否展示」= 广告位管理职责；「用户是否已完成」= 问卷功能职责，两者解耦；本流程不内建「本期未完成」判断。**
- ⚠️ 原文流程表**第 4、5 行序号与内容错位**（第 4 行说明文字与第 3 行完全相同，两行都叫「提交」），已按流程图纠正为上表。

### 5. App 端交互（对应原型）

整页布局固定，**仅题型区随题目类型变化**；文案随界面语言切换。

**入口 · 家长中心看板轮播广告位**
- 【家长中心】看板是**一个轮播广告位（非多个并列广告位）**。轮播内容按位序排列：**1 号位 =「问卷调查」广告、2 号位 = 免费学习资源**，后续位按运营配置顺延。
- 轮播交互：**自动轮播（每帧停留约 3–4s、循环）+ 底部圆点指示 + 可点圆点手动切**；**`prefers-reduced-motion` 时不自动轮播，仅手动**。
- 「问卷调查」卡元素：图标、标题（= 问卷标题）、奖励文案「**答题得 N Giggles**」、**红点（表示有新问卷）**、右箭头。点击 → 说明页。
- **登录态 / 游客均展示该轮播**：登录态上方展示当前孩子档案（如「朵朵」）；游客上方为登录 / 注册 + 第三方登录入口，**轮播照常展示，游客也可直接点击参与**。

**说明页**
- 元素：返回（‹）、**Giggles 余额**、问卷标题、副信息「预计时长（分钟）· 完成得 N Giggles」、「开始作答」按钮。
- 标题 / 时长 / 奖励数均取自后台「问卷基本信息」。
- 点「开始作答」→ 第 1 题；返回 → 回家长中心。

**答题页（逐题）**
- 顶部：返回（‹）、**进度条（随题序推进）**、Giggles 余额。
- 题目区：题型标签 + 题序（如「单选题 · 1/5」）、题干。
- 底部：「上一题」（**第 1 题隐藏**）、「下一题」；**最后一题为「提交问卷」**。
- 必答校验：**必答题未作答时「下一题/提交」置灰不可点**；选填题可直接进入下一步。可「上一题」返回修改，**答案会话内保留**。

**完成页**
- 元素：庆祝图标、标题「提交成功」、奖励条「**您已获得 N Giggles**」、致谢文案、单个「完成」按钮。
- 奖励：完成并提交成功即发放 N Giggles（**N 后台配置，原型示例 30**）；**同一用户 / 设备同一期仅发放一次**。
- 点「完成」→ 返回首页（家长中心），结束本次会话。**登录态与游客完成页一致**。

### 6. 题型规则（内嵌 Sheet `zDssx5`）

| 题型 | 作答方式 | 规则 |
|---|---|---|
| 单选 | 选一项，选中高亮（边框 + 底色 + 实心圆点） | **选择【其他】选项时，交互上需要有可输入的选项框** |
| 多选 | 可多选，选中打勾高亮 | **可配置最少 / 最多可选数** |
| 评分 | **1–5 星，两端有程度标签** | 可配置为 **NPS** 等量表 |
| 问答（开放） | 多行文本输入 | **选填**；可配置字数上限 |
| 录音 | 点麦克风开始（**计时 + 脉冲动效**），再点停止，**可重录 / 试听** | **单题限时（如 ≤ 60s，到时自动停）**；**存音频文件** |

### 7. 运营后台 · 问卷管理

**入口与列表**
- 位置：左侧菜单 **运营 → 问卷管理**。
- 列表列：问卷名称（含内部 ID）、状态、题目数、**H5 地址**、创建时间、操作；顶部含状态筛选 + 创建问卷按钮。

**状态机（三态，内嵌 Sheet `obTn8P`）**

| 状态 | 含义 · App 行为 | 列表操作 |
|---|---|---|
| **未发布** | 创建完成的默认态，**H5 已生成**；**App 不展示 / 不可填写** | 编辑 · 发布 · 删除 |
| **已发布** | App 可正常填写 | 数据导出 · 停止发布 |
| **停止发布** | **App 端不可填写** | 数据导出 · 重新发布 |

- 操作语义：发布（未发布 / 停止发布 → 已发布）、停止发布（已发布 → 停止发布）、重新发布（停止发布 → 已发布）、编辑（打开向导载入该问卷）、删除、数据导出（下载 CSV）。

**创建 / 编辑向导（3 步）**

- **Step 1 · 基本信息**（内嵌 Sheet `TjtgtL`）：

| 字段 | 规则 |
|---|---|
| 问卷名称（内部） | 必填；**仅运营可见、用于区分期次；不翻译** |
| 问卷标题（说明页展示） | 必填；**英文为源**；随界面语言由 **Tolgee** 翻译 |
| 预计填写时长 | 数字，单位分钟 |
| 完成奖励 | Giggles 数，完成并提交后发放 |

  - 校验：**名称 + 标题非空**方可下一步。

- **Step 2 · 题目设置**（三栏：题目列表 / 编辑器 / 实时预览）
  - 题目列表：添加 / 选中 / 上移 / 下移 / 删除；显示题型 + 必答标记。
  - 题型配置（内嵌 Sheet `d7baHz`）：

| 题型 | 配置项 |
|---|---|
| 单选 | 选项（英文源，增删）；**可追加一个「其他（填空）」选项** |
| 多选 | 同上 + **最少 / 最多可选数**；同样支持「其他（填空）」 |
| 评分 | 量表：**1–5 星 或 NPS 0–10** |
| 问答（开放） | 开放文本，**字数上限固定 500 字（不可配置）** |
| 录音 | **录音时长上限（秒，如 ≤ 60）** |

  - 「其他（填空）」选项：**每题最多一个**，标签可改（**默认 Other**）；App 端用户选中它需输入文本，**存为该题的开放文本答案**。
  - 通用：每题**必答 / 选填**开关。
  - **多语言：只录英文源**；编辑器顶部有 **Tolgee 说明与入口（「在 Tolgee 查看」）**；**发布后英文源同步 Tolgee 翻译**。
  - 实时预览：按 App 样式渲染当前题（英文源）。
  - 校验：**每题英文题干非空**；**单选 / 多选有效选项（含「其他」）≥ 2**。

- **Step 3 · 完成**
  - 生成问卷 H5 地址（可复制），形如 **`https://h5.giggleacademy.com/s/{id}?lang={ui_language}`**。
  - 摘要：名称、标题、题目数、**当前状态 = 未发布**、多语言（Tolgee）、时长、奖励。
  - 「完成，返回列表」→ 该问卷以**未发布**入列表。
  - 下一步提示：① 列表点「发布」上线 → ② **Tolgee 完成翻译** → ③ **Banner 管理用 H5 + 图片 + 发布周期配置投放**。

**数据导出**
- 列表「数据导出」→ 直接下载 CSV（**UTF-8 BOM，Excel 中文不乱码**），文件名 **`问卷名_responses.csv`**。
- 字段：提交时间、**用户 ID / 游客**、国家、语言、状态 + **每题一列（Q1…Qn）**；问答存文本、**录音存音频文件**、「其他」存用户填写文本。

### 8. 运营配置发布流程（流程二）

| 阶段 | 内容 |
|---|---|
| ① 问卷创建（问卷功能） | 填基本信息 → 设置题目（题型 / 必答 / 选项 + **各语言译文**）→ 创建成功生成 **问卷 H5 地址** |
| ② 广告位配置（广告位管理） | 配置广告位：**问卷 H5 地址 + 广告位图片 + 发布周期**（广告位：**家长中心看板 / 游客模式**）→ 发布（校验通过后上线） |
| ③ 回收统计（运营） | 回收 / 下架 / 数据导出统计，**按国家 / 语言 / 年龄 / 级别拆分** |

### 9. 数据埋点

- 观测目标：统计问卷的**曝光、点击、开始、完成、放弃、发奖**等，并可按**国家 / 界面语言 / 年龄段 / 学习级别**拆分。
- 实际给出的事件表**只有 2 个**：

| 事件 | 触发时机 | 参数 |
|---|---|---|
| `h5_survey_enter` | 进入问卷说明页 | `survey_name`：问卷名称 |
| `h5_survey_submit_success` | 问卷提交成功 | `survey_name`：问卷名称 |

### 10. 新增 / 修改内容

1. **奖励中心增加收入类型【问卷调查奖励】**。
2. Admin 配置平台配置时**使用通用的国际化翻译组件**，后端下发的时候就是**翻译后的内容**。

### 11. 待确认项

1. **两套方案并存、范围未拍板（最高优先级）**：「需求范围」3 条是 **Google 表单 + 短链 + 按 uid 名单手动发 100 Giggles**；「功能描述 / 交互原型 / 后台」是**自研问卷 H5 + 自动发 N Giggles + 后端返回答题状态防重复**。本期做哪套、还是先 Google 表单过渡后自研，必须先定 —— 两者的测试范围几乎无交集。
2. **奖励数额冲突**：需求范围写「一次性发放 **100** Giggles」，App 原型写「N 后台配置，示例 **30**」。
3. **游客奖励领取路径**：流程图写「+N Giggles（**游客登录后领取**）」，但 App 完成页明确「登录态与游客完成页一致（均『您已获得 N Giggles』）」—— 游客看到「已获得」却要登录才能领，**存在体验/口径矛盾**，且游客的「已完成」状态如何绑定（设备？游客 id？）未说明。
4. **埋点严重不足**：观测目标要曝光 / 点击 / 开始 / 完成 / 放弃 / 发奖 + 四维拆分，实际只给 `h5_survey_enter` 与 `h5_survey_submit_success` 两个事件、且只有 `survey_name` 一个参数 —— **转化率 ≥10% 这个核心 KPI 算不出来**（缺曝光与点击），放弃率、发奖成功率、按国家/语言/年龄/级别拆分全部无字段。
5. **「每月新增」与「每两周一期」不一致**：主要特性写「看板广告位**每月**新增问卷调查广告」，背景写「**每隔一段时间（如两周）**发布一套」。
6. **定向条件无定义**：目标写「面向命中定向条件的用户」「符合条件用户端展示入口」，但**定向维度、配置位置（广告位还是问卷侧）均未说明**；同时流程图声明「广告是否展示 = 广告位管理职责」，定向到底谁管需确认。
7. **多语言链路两处口径不同**：Step 2 写「只录英文源，**发布后**英文源同步 Tolgee 翻译」，流程二写「设置问卷题目：题型/必答/选项 + **各语言译文**」（像是创建时就要填译文）；且「下一步提示」把 **Tolgee 完成翻译放在发布之后** —— **发布后翻译未完成时 App 展示什么**未定义。
8. **录音题的落地细节缺失**：麦克风权限未授权时的表现、录音上传失败重试、导出的音频文件命名与存储位置、录音是否走既有语音识别链路均无说明。
9. **删除已发布问卷 / 已有作答的问卷**是否允许（列表操作里「删除」只出现在未发布态，但未明说已发布不可删）；**编辑已发布问卷**会不会影响已回收数据未定义。
10. **`prefers-reduced-motion`** 是 Web 语义，家长中心看板是 H5 还是原生轮播需确认（影响测试手段）。
11. **新增广告位「家长中心 - 游客模式」**与 V1.35《WhatsApp 社群导流》的家长中心 banner、V1.37《任务体系》的 `app_invite_poster_show` `source=parentscenter` 同处一块面板，**轮播位序与优先级如何协商**未说明。
12. **无验收标准**，也没有问卷 H5 加载失败 / 网络异常 / 提交超时的兜底描述。
