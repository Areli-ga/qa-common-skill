## 摘要

V1.33.0 跟读组件大改版(AB 测试):用**全屏三色光波**(紫=等待收音 / 绿=回放 / 红=读错循环,沿屏幕边缘环绕、随音量实时波动,"声音驱动画面")取代局部收音波形;**移除外显倒计时**(逻辑保留);**领读末尾音节即激活收音(抢答)**消除等待感;**失败 2 次解锁跳过按钮永不卡死**;课末新增**单词回顾卡**。配新跟读课程模板。产品 Owner: Cloud;优先级:高。

> **影响范围**:跟读组件改版影响**所有 Unity 原生包课程**;单词回顾卡影响所有新课;新跟读模板本身是一节新课。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 需求一:跟读组件变更(视觉 + 流程)
- **变更总览(旧 → 新)**:
  | 项 | 旧 | 新 |
  |---|---|---|
  | 收音反馈 | 局部收音波形组件 | **全屏三色光波**(屏幕边缘环绕粒子边框) |
  | 倒计时 | 外显进度条 | **移除外显**,倒计时逻辑隐藏保留、规则不变 |
  | 领读角色 | Max | Max 头像(左下角) |
  | 评分外露 | 星级打分 | **不外露**,仅 Max 头像做赞赏动画(连对播不同程度) |
- **Max 头像状态机**:默认静止(微笑待机)/ 领读中(嘴部开合循环)/ 聆听中(紫色光波,侧耳倾听带紫声波纹)/ 读对反馈(ASR 正确,开心大笑+粒子,连对随机不重复赞赏)/ 出场离场。

### 需求二:跟读课程模板(Unity 制作,原生可参考)
- **流程**:场景初始化(Max 左下滑入说开场语 `let's go` 后退场)→ 语音识别组件(Max 头像场景化版)+ 单词图入场 → **领读(每词循环)**。
- **领读 + 抢答(测试重点)**:单词图上方滑入 + 单词框 + 鹦鹉领读;**领读末尾音节开始识别,允许用户此时抢先发声**并触发光波:
  - **分支 1 未提前出声**:领读全程继续、动效不变;整段领读**结束后**才展示紫光波、切【侧耳倾听】。
  - **分支 2 提前发声(抢答)**:立刻弹紫光波(随音量波动);角色剩余领读语音/动画**全程不中断**;整段播完再切侧耳倾听。
- **跟读反馈(三色光波)**:
  - **发音正确** → 绿光波 + 回放用户录音 → 淡出 → 单词框消失 + Max 读对动画 → 下一词。**连对 6 档赞赏**(随机不重复,播完再随机一轮;**连对定义**:非跳过、正常通过语音识别即 +1,**跳过则重置**赞赏级别)。
  - **未发声** → 隐藏倒计时结束 → 重试(回领读);**不触发红波**,Max 重试领读一次,紫波消失片刻再现。
  - **发音错误** → **立即判错(不等倒计时)** → 红光波 → 重试(回领读)。
  - **失败 2 次(读错或超时)** → 立即出现「下一步」跳过按钮 + 继续重试。跳过按钮在识别成功时消失;**仅解锁手动下一步、不自动进入**;点跳过 → `lesson_speech_recognition_end` 上报 `speech_skip=true`;跳过的单词在回顾卡按「**跳过无录音**」展示。
- **下一词**:旧词下滑退场 → 新词入场 → 重复。
- **结尾**:最后一词完成 → 全屏撒花 → Max 结束语(Great game / Good job)→ 单词回顾卡(自由点击单词图回放 → 点箭头结束课程)。

### 需求三:单词回顾卡(测试重点)
- **跟读课版**:默认展示**带音素打分**的单词板;第 1 次点击播**用户录音**,第 2 次变**紫边单词板**播**标准读音**,往复轮换循环;**跳过的单词直接展示紫边单词板**(点击播标准音)。
- **非跟读版**:全部展示紫边单词板,点击播标准音。

### AB 测试 / 埋点
- AB key:**`course_new_voice_recognition_panel`**;分组 control(现状)/ test(白色鹦鹉气泡组件)。
- 埋点:`lesson_speech_recognition_end` 新增 `speech_skip`(true/false,用户点跳过时回传 true)。
