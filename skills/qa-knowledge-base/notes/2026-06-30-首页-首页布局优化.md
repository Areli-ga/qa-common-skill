## 摘要

V1.31.0 首页布局优化(**AB 测试**,进首页时分流:对照组=线上地图,实验组=新地图):把首页 10 个功能入口**收进右上角聚合浮窗**,突出学习路径而非功能展示(海外低端小屏、顶栏密集点击精度差);**单元卡片缩小 + 点击展示单元介绍弹窗**;首页切换等级支持**升级测试**。产品 Owner: Leah。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 需求 1 · 首页结构调整
- **入口聚合(测试重点)**:顶部 绘本 / 趣玩乐园 / 闪卡 / 专题课 / 搜索 → 收进**右上角聚合入口**(浮窗含 Storybook / FlashCard / playzone / Mini plan / Search);单词卡仍在左下角不变。点入口展开功能列表,**点击屏幕外区域关闭浮窗**。
- 底部 **I spy** 入口调整(原从 banner 位置,大小/位置待沟通 @Libin Liu)。
- 单元卡片**缩小**;模板 **welcome 去掉**(Hello 课仍在外面);背景色按 UI 更新。
- **单元介绍弹窗(测试重点)**:
  - **仅 Lv1 的 Unit 卡片**增加介绍卡(共 **8 个**);点击单元卡片 → 展示单元介绍弹窗;**L2 以上点击无反应**。
  - **无论后续课程是否解锁,都展示介绍卡片**。
  - 展示信息:Unit 名称(后台配置)、**标签(本期写死:Pre A1 / Listening / Speaking)**、介绍(取单元介绍字段,原文未进一步展开)、**核心单词**(取本 Unit 核心单词,点播放按钮播音频)、关闭按钮(点击回首页)。
- **进入二级界面**:绘本 / Flashcard / Playzone / miniplan 进入后改为**独立导航栏 + 返回**;点返回 → 回首页且**聚合入口展开**。搜索 = **仅搜索故事书**;Playzone 右上角展示 giggles。

### 需求 2 · 升级测试
- 首页切换等级功能:点击的等级 **> 当前等级** → 弹引导升级弹窗;点 **Start** 进入升级测试;升级测试通过后与现方案一致。
- 文案:「准备好挑战了吗?通关就能解锁 Lv2」/「Ready for the challenge? Win to unlock new levels」(**Lv2 = 当前级别的下一级**)。
- ⚠️ 点击**当前所在级别后续的 unit 卡片**(目前线上抖动)→ 增加语音提示「**先完成前面的关卡才会解锁哟～**」。
