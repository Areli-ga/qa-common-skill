## 摘要

V1.33.0 给后台课程游戏模板配置的单词卡片(Target/Starting/Distractor Words)新增三个音频字段(单词默认读音/特殊读音/音效),配合词库侧新增「默认动画/默认音效」,实现**选词即自动带齐插画/动画/读音/音效四类资源**(常规课"选词即完成单词资源配置",仅特殊需求手动调)。解决原读音不可见不可调、动画逐个手选 Spine 效率低、音效无法单词维度配的问题。产品 Owner: Cloud;优先级:高。(文档版本字段 v1.32.0,按主人指定 **V1.33.0**。)

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 两侧改造
- **词库侧(Libin Learning Asset List)**:单词新增「默认动画」「默认音效」配置(默认插画/读音已有)→ 每单词在词库内拥有**插画/动画/读音/音效**四类默认资源。
- **课程配置侧**:游戏模板单词卡在现有「美术资源、Spine 资源」基础上,新增三音频字段(均用**新版资源库音频选择器**);选词时自动带出。

### 五资源位字段(测试重点)
| 字段 | 默认值来源 | 必填 | 可操作 |
|---|---|---|---|
| 美术资源 | 词库默认插画自动带出(现状) | 是 | 替换 |
| Spine 资源 | 词库默认动画自动带出(**本期新增**) | 否 | 选择/替换/预览/清除 |
| **单词默认读音** | 词库默认读音自动带出(**本期新增展示**) | **是** | 选择/替换/试听 |
| **单词特殊读音** | **空(不自动带出)** | 否 | 选择/替换/试听/清除 |
| **单词音效** | 词库默认音效自动带出(**本期新增**) | 否 | 选择/替换/试听/清除 |
- 字段归属:三新字段是目标单词项子结构(与美术/Spine 同级),随主题字段结构在每个配置组内复用。

### 选词自动关联逻辑(测试重点)
- **触发**:通过「选择单词」选中/更换目标单词时触发**一次**自动带出。
- **带出映射**:默认插画→美术、默认动画→Spine、默认读音→单词默认读音、默认音效→单词音效。
- **缺省**:词库该项未配置 → 字段保持空,手动选。
- **快照(关键)**:带出即落库为本课程配置的**资源引用快照**;之后词库修改该单词默认资源,**不回溯影响**已带出的课程配置。
- **不回写**:课程配置内替换仅作用本课程本配置组,**不回写词库**默认资源。
- **更换单词**:同卡片换另一单词 → 五资源位**全部按新单词默认资源重新带出覆盖**(含已手动替换项),**特殊读音清空**(避免旧词残留错配;按原文记录)。
- 特殊读音**始终默认空、仅手动配**。

### 边界与异常(测试重点)
- 已选音频/Spine 在资源库被删除或下架 → 字段失效态;保存时必填字段失效则拦截提示。
- 存量课程(改版前已配置)打开 → 新字段为空,**不影响已发布课程线上表现**。
- 同一/多配置组选同一单词 → 各自独立带出、独立编辑、互不影响。
- 自动带出后手动替换、再打开 → 展示替换值,**不重新带出**。
- 必填字段(如默认读音)为空点保存/下一步 → 校验拦截,**提示定位到「配置组 X-单词 Y-字段 Z」**。
- 词库接口异常导致带出失败 → 选词成功但带出失败的字段保持空 + toast「默认资源带出失败,可手动配置或重选单词」。

### 业务流程
- 运营 admin → 课程系列 → 课程列表 → 课程「配置」→ 模板配置 → 第 2 步参数配置 → 点「选择单词」选中(如 green)→ 自动带四字段 → 按需微调 → 保存 → 第 3 步生成发布(沿用现有)。

### 关联依赖(回归注意)
- 与「音频库/游戏模板音频引用」深度重叠——音频库 §7 是给同样的 Target/Distractor Words 加 Audio Variants,本篇加默认读音/特殊读音/音效字段,**同一块游戏模板单词配置**,需对齐字段结构。
- 单词默认读音/特殊读音来自「音频库」音频;Spine/音效来自「素材库」;默认资源来自词库(Word Bank,见「Quiz 手动创建题目」)。
- 数据结构与保存/读取接口扩展、**存量课程兼容**是后端回归重点。
