## 摘要
V1.38《任务 2.0》的**补充说明**，只解决两件事：① **老用户重装 / 升级 App 后的路径归属** —— **老用户（此版本安装包以前已注册过的游客 id）卸载重装或升级后启动，不再走新人 Onboarding 流程**；但**原游客 id 已转正式 id 的情况，设备会新生成一个游客 id，仍要走【选年龄】+【定计划】**，退出登录回到欢迎页同理。② **按生命周期给出三条互斥的任务命中规则** —— **注册 5 天以上且不属于「14 天以上未活跃」→ 日常任务；14 天以上未活跃的老用户 → 回归任务；注册时间小于 5 天 → 新人任务且没有弹窗、直接进首页路径**；**三类任务都在 AB 测，对照组一律直接进入首页**。埋点上**给「游客 id 重新安装 App」单独加一个事件**（开发暂定 `guest_account_restore`）。

## 功能信息（逻辑 / 状态 / 边界 / 字段）

### 1. 路径说明（老用户重装 / 升级）
- **老用户卸载 APP、或更新 App 到新版本后，启动 App 不再走新人 onboarding 流程**（原文写「参考上述流程」，指向文档顶部的流程画板 —— **见下方「原料缺口」**）。
- **老用户定义：此版本安装包以前已经注册过的游客 id。**
- **正式 id 的情况**：原本的游客 id 已经变成正式 id，**所以设备会新生成一个游客 id，需要走【选年龄】+【定计划】流程**。
- **产品流程：退出登录后，再回到欢迎页，新游客 id 走【选年龄】+【定计划】流程。**

### 2. 生命周期 → 任务命中规则
| 条件 | 命中 | 备注 |
|---|---|---|
| **注册 5 天以上，但不是「14 天以上未活跃」** | **日常任务** | 对应 V1.38 的「常规任务 Daily Task」 |
| **14 天以上未活跃的老用户** | **回归任务** | 对应 V1.38 的回归任务（30 天内学 3 天领 3 份奖励） |
| **注册时间小于 5 天** | **新人任务** | **没有弹窗，直接进入首页路径** |

- **以上任务都在 AB 测；对照组：直接进入首页。**
- 与 V1.38《任务 2.0》衔接：那篇定的是「注册前 5 天启动命中新人任务，注册到 day6 新人任务结束进入常规任务」，本篇把**边界表述统一成「注册 5 天以上 / 小于 5 天」**，并补上了**「14 天未活跃」优先级高于「注册 5 天以上」**这层关系（即回归任务与日常任务互斥，先判未活跃）。
- ⚠️ 本篇明确「**新人任务没有弹窗，直接进入首页路径**」，而 V1.38 记录的是进入常规任务时有「Now new tasks every day / See new tasks」云弹窗 —— 两者作用对象不同（新人任务 vs 进入常规任务），回归时要分清。
