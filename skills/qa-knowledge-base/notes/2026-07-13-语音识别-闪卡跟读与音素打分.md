## 摘要

V1.34.0 解决「闪卡跟读体验差、组件长期未更新」:① 闪卡模块跟读题**接入新版跟读组件(max 头像版本)**并按 UI 稿调整样式;② 原生语音识别跟读组件**支持红黑绿三色音素级打分**(红=分过低、黑=正常中间、绿=高分通过,按 wheat 最新音素打分区间);③ **Unity 单词回顾卡**同步支持已跟读单词的三色音素打分展示。

⚠️ **版本**:文档字段 `v1.34.0`,与主人给的 **V1.34.0** 一致。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 1. 闪卡-跟读题接入新版跟读组件 + UI 调整(图1)
- 闪卡模块跟读题接入**原生跟读组件**(max 头像版本),UI 样式随新组件更新调整,以 UI 稿为准。
- 可触发业务埋点 **`lesson_speech_recognition_end`**。
- ⚠️ **埋点参数边界(重点)**:
  - **闪卡模块内触发**:`course_id` / `course_name` / `course_type` / `level_number` / `unit_number` / `part_number` / `part_id` 上报为**空**,其他参数正常上报。
  - **路径中触发**:全部参数正常上报。

### 2. 原生跟读组件支持红黑绿三色音素打分
- 支持**单词音素级**打分,按 wheat 最新音素打分区间划分三色:
  - 🔴 **红色** = 分过低
  - ⚫ **黑色** = 正常中间分数
  - 🟢 **绿色** = 高分通过

### 3. Unity 单词回顾卡支持三色展示
- Unity 单词回顾页面的单词回顾卡也需支持**已跟读单词**展示红黑绿三色音素打分。

## 回归 / 风险重点(现算)
- **组件替换回归**:闪卡跟读题换新组件后,原跟读交互(领读/跟读/打分/重试)不回退;UI 以设计稿为准(关联 [跟读组件改版与单词回顾卡]、[麦克风授权与跟读反馈优化]、[录音组件支持场景模式]、[降噪增益])。
- **埋点参数分场景**:同一 `lesson_speech_recognition_end` 在「闪卡内」vs「路径中」上报参数不同(闪卡内 7 个课程参数为空),两条路径都要验(关联 [App神策全埋点])。
- **音素三色阈值**:红/黑/绿区间按 wheat 最新划分,边界值(临界分)归色正确;音素级而非整词级。
- **三处一致**:闪卡跟读、原生跟读组件、Unity 单词回顾卡三处三色展示口径一致(关联 [单词回顾页面] 完课回顾弹窗、[跟读挑战课] 同用 `lesson_speech_recognition_end`)。
