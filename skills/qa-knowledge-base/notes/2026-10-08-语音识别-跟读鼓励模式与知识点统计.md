## 摘要
分年龄阈值上线后，**4 岁、母语发音都不准的孩子仍过不了跟读**，而阈值已到「不得低于噪声地板」的下限。本期两件事：① **鼓励模式**：设置 › 课程设置新增「鼓励模式 / Encourage Mode」开关（**所有用户默认关闭 = 标准模式；已有手动选择优先；按 kidId 存服务端**），**开启后有效开口（VAD 检测到发声）即放行、沉默不放行、星级打分逻辑不动**；**标准模式下同课连续 2 个会话未通过 → 下一词领读前弹「试试鼓励模式吧！」→ 家长验证后开启（下一词生效）**，弹窗**一次性**（2026-09-24 改为可勾选「不再提醒」）；② **知识点统计**：每个**单词会话**结束按「**用户 id - 课程 id - 目标词**」上报**是否开口 / 是否读对（会话星级 ≥ 2 星）**，服务端按课程定位 Level-Unit、在该 Unit 目标词中按词名匹配唯一 **wordID**，去重累计**开口次数 / 读对次数**入业务库，**鼓励放行 ≠ 读对**；用历史 `read_aloud_session_end` 计算期初值。埋点：两个语音结束事件加 `speaking_mode` / `is_mode_default`、`pass_reason` 新增 `encourage`；新增 `speaking_mode_change`、`encourage_hint_popup_show` / `_click`。正文附 **A–F 共 40 条验收清单**。

### 基本信息
- 产品 Owner：**Cloud**；优先级 **高**；版本 **1.40.0**；UI：figma `1.40.0` node `60514-122473`；动画 / 声音文件在 Google 网盘（未抓取）。
- 修订记录：**2026-09-24 一次性弹窗改为可勾选「不再提醒」弹窗**。
- 背景：① 家长群持续反馈低龄孩子被反复要求重读、没信心不愿开口；② **阈值这条路已到下限 —— 有效阈值不得低于噪声地板**，这类孩子是「差很远」而不是「差一点」；③ **知识点（单词、句型）目前只关联到 Unit、未关联到课程**；**跟读结果只有埋点、没有业务数据**，回答不了「这个孩子这个词开口过几次、读对过几次」；鼓励模式放行变松后**更需要一把不随放行变化的尺**。
- 关联往期：V1.37《语音识别超时提前提交 + 分年龄阈值》（本篇的直接前因）；同版本《学习中心修改样式 + 单词书1.0》四阶段的 **Repeat 依赖「跟读鼓励模式与知识点统计」**（单词书内嵌表原话），本篇的**开口次数 / 读对次数**就是单词书与单元结算页「开口次数 · 正确次数」的数据底座。

### 1. 鼓励模式开关（设置 › 课程设置）
- **位置**：「课程模式（Course mode）」分组**第三行**，在「跳过语音识别」「**母语语音提示**」下方；**单个开关：开 = 鼓励，关 = 标准**。
- **ⓘ 说明气泡**：「开启后，孩子开口就算通过，发音不够标准也能继续 / Once enabled, the child can continue after speaking, even if their pronunciation needs more practice.」；**所有年龄均不显示「推荐 / Recommended」标记**。
- **默认值**：**无手动设置记录 → 所有用户统一初始化为关闭（标准）**；**默认初始化不记为手动选择**；**已有手动选择按 kidId 读取并保留**，不因年龄更新 / 生日 / 年龄补全自动切换。
  - 验收 A02 透露：**存量用户有「旧年龄规则自动开启」记录**的，按新规则**关闭**，且仍算 `is_mode_default=true`（即此前存在按年龄自动开鼓励的逻辑，本期废弃）。
- **保存**：**按 kidId 保存**；**即时本地保存并反馈、无保存按钮**；后台同步；**离线保存为待同步，联网后同步，后续以服务端版本为主**。
- **生效时机**：**当前完整单词会话沿用启动时的模式；设置变更从下一个会话生效**（避免一段录音中途改判定）。
- **与「跳过语音识别」兼容**：跳过开关保留；**开启跳过时鼓励开关置灰但保留原值，ⓘ 仍可查看；关闭跳过后恢复原模式**。
- **适用范围**：**接入标准跟读组件的所有课程、闪卡、挑战课（和 Quiz）、故事书**（2.2 节原话；验收 A09 只列了课程 / 闪卡 / 故事书）。
- ⚠️ 名称不一：正文 `Encourage Mode`，原型 `Encouragement mode`。

### 2. 判定规则（会话级）
- **一次会话 = 同一个目标单词的一次完整跟读流程（`word_session_id`）**：从该词组件拉起到**成功、跳过、兜底或退出**收尾；**首读及全部重试 attempt 共用同一会话 ID**；进入下一词或重新开始该词的完整流程才创建新会话。
- **标准模式按既有规则判定；鼓励模式有效开口即算通过，不因未读准要求重读**；**数据上报仍按原星级 + 分数**。
| 正常结束情况 | 标准放行 | 鼓励放行 | 开口增量 | 读对增量 |
|---|---|---|---|---|
| **有开口，星级 ≥ 2** | 是 | 是 | 1 | 1 |
| **有开口，星级 < 2** | **否** | **是** | 1 | **0** |
| **跳过** | - | - | 0 | 0 |
| **3 次错误兜底收尾** | 是 | 是 | **取决于是否开口** | **0** |
| **未开口** | 否 | **沿用沉默 / 超时流程，不因鼓励额外放行** | 0 | 0 |
- **星级恰好 2 星计入读对**（B01 / F01）。

### 3. 课内切换提示弹窗
**触发条件（同时满足）**：
- **标准模式**；**本地当前孩子未处理过提示**；**同一课程学习过程中连续两个会话 `is_success=false`**；
- **所有年龄均可触发**（含低龄、年龄未知、年龄为 0），**年龄不再作为排除条件**；**不因沉默或跳过排除**有效的未通过会话（「跳过也算」）。

**连续计数**：
- **按完整单词会话计，首读及重试不分别累计；可跨词**；
- **重置**：**会话成功、模式变更、主动离课**；**暂停可保留**（暂停本身不增加失败）。

**弹出时机**：**第二个未通过会话收尾动效结束（中间可能还有 Unity 演出）→ 下一词领读前**弹出；此时**录音、倒计时、播放暂停**；**已离开页面则不弹，也不消耗提示机会**。

**弹窗内容**（正文中英表，⚠️ 有新旧两版并存，见下）：
| 元素 | 中文 | English |
|---|---|---|
| 标题 | **试试鼓励模式吧！** | Try Encourage Mode! |
| 正文 | 旧：请家长帮你开启，／开口读一读，就能继续学啦。<br>新：**请家长帮忙开启该功能。说出单词，即可继续学习！** | Ask a parent to turn it on. Say the word and keep learning. / Ask a parent to turn it on. Then say the word and keep learning! |
| 主按钮 | **请家长帮我开启**（需家长验证） | Ask a Parent |
| 次按钮 | 旧：按原方式继续 / 新：**暂不开启** | Continue in Standard Mode / Not now |
- ⚠️ **新旧文案混用**：1.2 节、原型图用新版（正文「请家长帮忙开启该功能…」、次按钮「暂不开启」），但**提示语音文本**与验收 **C06** 仍是旧版（「请家长帮你开启，开口读一读，就能继续学啦」、次按钮「按原方式继续」）。
- **提示语音**：**首次实际展示后播放一次本地化语音（标题 + 正文）**；**右上喇叭可重播，重播先停上一段**；**点主次按钮、系统返回或进入家长验证时停止播报**；沿用当前提示语言和声音设置。
- **家长说明（家长验证页）**：复用家长验证，说明区展示「开启后，孩子开口就算通过，不再要求重读。」「你可以随时在「设置 › 课程设置」关闭鼓励模式。」
- **文案表达约束**：面向孩子直接说「你」；**不显示「吃力」「失败次数」、分数或数据记录说明**；弹窗、家长验证、设置统一叫「鼓励模式」。
- 视觉（C06）：**暖白圆角卡片、黄色主按钮、浅紫次按钮，正文对比度 ≥ 4.5:1，主次按钮触控高度 ≥ 56px**。

**操作行为**：
| 操作 | 行为 |
|---|---|
| **主按钮** | **家长验证通过 → 保存鼓励模式，从下一词会话生效**；**验证未通过 → 停留家长验证允许重试，不自动跳下一词**（C12「用户已确认」）；**取消验证 → 维持标准，直接下一词** |
| **次按钮 / 系统返回** | **维持标准，直接下一词**（不重读刚结束的词） |
| **点击遮罩** | **不关闭**（防误触） |
| **展示中杀进程** | **不保留当前设备当前孩子的已展示状态** |
- **已结束的第二次失败保持原始未读对结果；点击切换不得增加新会话记录、不得改成读对**（C07）。

**一次性状态**：
- **本地按「设备 + 孩子档案」记录**；**弹窗实际显示并点击主按钮 / 次按钮 / 系统返回后才置 true**；**仅展示、播放或重播语音不置 true**；
- **离课、重启、登出后保留**；**换设备、重装、清理数据后可以再次提示**；不同孩子独立。
- ⚠️ **与 09-24 修订冲突**：修订说「改为可勾选【不再提醒】，勾选后任意方式结束弹窗都不再触发」—— 那么**不勾选时**是否还会再弹？而一次性状态、C08 / C09 仍按「点过任一按钮即永不再弹」写，**原型图上也没有「不再提醒」勾选框**。两套规则需定一套。

### 4. 单词回顾卡边框
- **该单词有会话跟读成功（星级 ≥ 2）→ 绿边框**；**标准模式未成功或没有跟读流程 → 紫边框**；**鼓励放行但识别未成功（星级 < 2）→ 橙色边框**。
- ⚠️ 验收 **B06** 写的是「鼓励放行但识别未成功则为**红色**边框」，与 2.3 节「**橙色**」不一致。

### 5. 知识点记录与后端储存（**只做课程**）
- **链路**：单词会话结束 → 记录是否开口 / 是否读对 → 按 **用户 id - 课程 id - 目标词** 上传（复用现有事件 `read_aloud_session_end`，**不等整节课完成，不依赖通关、奖励或结算页**）→ **服务端根据课程 id 及路径信息找到 Level-Unit** → **在该 Unit 目标词中以单词名匹配唯一 wordID** → **去重落明细并累计**入库。
- **使用内容目标词，不用识别出的文本猜词**；**重复学课、同词不同真实会话分别计数**。
- **后台统计统一用业务库，不把埋点次数与业务次数直接相加**；历史 `read_aloud_session_end` **只用于期初初始化**及明确的历史 / 旧端缺口补录（补录后同样落业务库、按会话去重）。
- **期初数据**（切换时点 T，统一时区固定边界，上线时确定）：
| 项 | 规则 |
|---|---|
| 来源与范围 | 正式环境历史 `read_aloud_session_end`，**从最早记录到会话结束时间 < T** |
| 统计对象 | **孩子档案（kid / 学习者 userId）+ wordID**，沿用课程 id + 路径 → Level-Unit → 目标词名 → 唯一 wordID 的映射 |
| 期初开口次数 | 去重后每个会话 **`is_speech_detected = true` 开口 +1** |
| 期初读对次数 | 去重后每个会话 **`speech_star` 为有效数值且 ≥ 2 读对 +1** |
- **T 前归期初；恰好 T 及之后归新增**；跨来源同会话只累计一次（F06）；**在线已有 2/1 + 期初 10/6 = 12/7，重复导入仍 12/7**（F05）。
- **退出与异常**：
| 场景 | 处理 |
|---|---|
| 结果结束后立即离课 | **先把最终事件可靠落本地队列，再退出**；已完成结果继续同步 |
| 录音中途退出、未形成最终结果 | **不记录**；之前完成的结果保留 |
| 断网完成识别 | 本地记录，联网后重传（**沿用原事件标识**） |
| 应用重启 | 恢复待上传队列，按原 kid 身份同步；**未获服务端确认前不删除** |
| 账号切换 | **队列按学习者隔离，不可用新账号身份把旧数据归到新用户** |
| 重复最终回调、并发重传 | **双层去重，最终仅累计一次** |
- ⚠️ 范围不一致：鼓励模式开关作用于**课程 / 闪卡 / 挑战课 / 故事书**，但知识点统计标题写「**只做课程**」—— 闪卡 / 故事书里的跟读不计入开口 / 读对次数。

### 7. 验收清单（原文 A–F，摘关键）
- **A 设置与默认**（A01–A09）：各年龄段默认关闭且 `is_mode_default=true`；旧年龄规则自动开启记录 → 关闭；年龄变化不自动切换；手动记录按 kid 保留不串用；离线切换待同步；会话中切换下一会话生效；跳过识别置灰保值；课程 / 闪卡 / 故事书均应用。
- **B 会话与回顾卡**（B01–B06）：见判定表；兜底放行不当读对；回顾卡三色边框。
- **C 切换提示**（C01–C12）：第二次失败才弹、可跨词；沉默 / 跳过失败计入；成功 / 切模式 / 离课重置；鼓励模式或已处理不弹；离页不弹不消耗；视觉与语音规则；验证通过下一词生效且不改写历史；取消 / 继续不重复提示；杀进程不保留状态；换设备可再提示；验证失败留在验证页重试。
- **D 知识点记录**（D01–D07）：不等课程完成即上报；同词跨 Unit 按路径映射；离课前先落队列；中途退出有结果才记；断网重传；账号隔离与去重；鼓励放行不改星级分数。
- **E 埋点**（E02–E04）；**F 期初数据**（F01–F06）：2 星边界、重复导入幂等、多 kid 隔离、未完课的历史会话照样计入、在线 + 期初合计、T 边界归属。
