## 摘要

V1.36.0 离线模式大改版:离线主页**按资源 tab 分类**(课程/歌曲/磨耳朵/闪卡/故事书)不再展示路径离线状态;**歌曲与磨耳朵页新增「离线下载」入口**(需登录、下载不可暂停);新增**设置 - Downloads 资源管理页**(按 tab 分类、单个删除无需确认、Delete All 需二次确认、显示占用与释放空间);**联网恢复时只在离线主页弹切回联网的提示**。目标是让网络不发达地区与碎片化场景也能学。

⚠️ **版本**:文档「版本号」字段写 `V1.0`(模板残留),Figma 为 **`1.36.0`** node `47024-5154`;按主人给的 **V1.36.0** 入库。产品 Owner:**Sunny**;优先级:**高**。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 0. 背景与目标

- 背景:① 让**网络不发达地区**的孩子也能正常学习;② 满足**碎片化学习场景**(坐车、在外吃饭等待等)。
- 目标:① 在**磨耳朵和歌曲**场景,有多少用户愿意**主动使用离线下载**;② 离线功能下的**学习时长、完课数量、业务活跃占比**;③ 用户**离线管理资源的使用习惯**。

### 1. 需求清单

| # | 内容 |
|---|---|
| 1 | **离线模式资源页面改版**,新增资源列表页面,**不再展示之前的路径离线状态** |
| 2 | 更多资源中,**歌曲和磨耳朵页面右上角新增离线下载功能**,可下载资源,并在设置中删除管理 |

### 2. 离线模式主页面

**2.1 进入时机(重要)**
- **课程(所有内容)中突然断网,不出离线弹窗引导**;**等用户退出课程进入首页后再出现弹窗**。
- **离线弹窗弹出的时机,只能在首页中**。

**2.2 离线模式使用路径**
- 离线模式**按资源区分 tab 展示**:**课程、歌曲、磨耳朵**,其他资源也可以先展示出来,**有资源才展示离线 tab**。
- **点击直接进入课程、体验课程,完课后直接退出**;**不记录完课状态、不发放奖励、不播放路径中的结算动画**。
- **内容来源**:
  1. **课程预制到课程包,15 节课**;
  2. **离线缓存**:用户在联网状态下**学过的课程**可缓存到本地,离线也能学。
- **内容范围**:游戏课(**普通和模版课程**)、歌曲、**故事书(flutter)**、**闪卡(JUN)**、**磨耳朵(flutter)**;
  - **暂时不支持:自然拼读、绘画、挑战课**。
- **排序规则**:课程**按路径排序**;其他类型**与联网模式的排序规则一致**。
- 离线主页 tab 实际形态(img-02):`Lesson` / `Story time` / `Songs` / `FlashCard` / `GiggleCast` / `Spe…`(置灰) + 右侧 **`Offline` 标识**;课程卡按 `Lv 1` 分组网格展示。

**2.3 退出离线模式**
- 用户在**离线模式主页面**连接网络后,**弹窗提示用户切换到联网模式**。
- **弹窗只出现在离线的主页,内容使用中不出弹窗**。

### 3. 歌曲(Unity)/ 磨耳朵(Flutter)新增离线下载

**3.1 下载入口**
- 功能上线后,用户**首次访问页面出现新手引导一次【离线下载】**;设计稿(img-05)注明:**「在 1.36.0」下载功能上线后,出现「星星新功能引导」循环动画,直至用户点击下载后**。
- **点击下载时做登录校验**:
  - **未登录** → 调起【登录页面】;
  - **已登录** → 进入离线访问模式。
- 加一个**离线状态的功能说明**:① 下载后随时随地又可以听;② 每次听都不花流量。
- **菜单栏可以新增一个主动触发离线模式**(用于观察有多少用户愿意主动探索)。

**3.2 下载模式**
- 点击下载 icon **进入下载模式**后,**每个资源下均有下载的 icon**。
- **下载模式为临时模式**:**退出当前列表后,再次访问会重置为列表模式**。
- 点击下载 icon → 进入**单个资源的下载流程**,**一旦开始下载不支持暂停**。
- **点击下载完成的 icon** → **TTS 会提示该资源已经下载**。

### 4. 离线资源管理

**4.1 模版课程与模版资源的特殊规则**
- **模版课程**(课程资源[**会共用**] + 单词资源[**必须**]):
  - **使用层面:分开展示**;
  - **资源层面:同一个 Color 下的课程合在一个包中**(Color1、Color2、Color3)。
- **模版资源(闪卡)**:
  - **使用层面:分开展示**;
  - **资源层面:只提供单词包的删除功能,模版资源不删除**。

**4.2 管理页(设置 - Downloads,img-08)**
- 按资源区分 tab:**课程、歌曲、磨耳朵**,其他资源有才展示;**点击课程进入课程子页面,按 Level 排序、连续展示**。
- **Total Storage Usage**:`Used 7.2GB` / `Remaining 100.4 GB`(**已使用 = GA 占用的手机内存;剩余 = 用户手机内存剩余**);副文案 `Offline Mode: You can still learn on the Home page!`。
- 分类列表带各自占用:`Lessons 1.7GB` / `Story time 24.3MB` / `Songs` / `FlashCard` / `GiggleCast`;**列表滚动到底部提供 `Delete All` 操作**。
- **删除交互规则**(设计稿标注):
  1. **点击单个资源直接删除,无需二次确认**;
  2. 点击 **`Delete All` 需要二次确认**;
  3. **编辑状态下点击返回,直接退出**;
  4. 点击 **`Done` 结束编辑模式,回到列表模式**。
- **二次确认弹窗**:标题 **`Delete all offline lessons?`**(评审后另给「`Delete all offline stories?` / `Delete all offline nursery songs?`」两个变体),正文 `This frees up 1.28 GB. Everything can be downloaded again whenever you need it.`,按钮 `Not now` / `Delete all`。
- **删除成功 Toast**:`All downloads deleted · 7.2 GB freed`(子类删除时为对应大小,如 `1.2 GB freed`)。
- 课程资源管理页:顶部 `Lv 1 … Lv 10` 级别 tab + 右上 **`Edit`**;进入编辑态后每张卡覆盖**垃圾桶图标**,顶部出现 `Delete All` 与 `Done`。
- **儿歌空状态文案**:`Download nursery songs to listen offline.`(⚠️ **原文注明 Figma 原文为 `Download songs to sing along offline.`,两者不一致**)。

### 6. 弱网 H5 问题清单(评审后补充的第 5 项范围)

**问题描述**(均为加载慢/无兜底):
1. Giggles 不足点击购买服饰,**没有响应**;
2. **新包首次进入奖励中心需要 6s**;
3. **打开排行榜较慢**(学完课程自动触发 **7s**),影响体验;
4. **进入闪卡模块图片加载较慢,无兜底图**;
5. **安装应用首次打开睡前时光需要 7s**;
6. **进入专题课页面较慢,并且无页面兜底展示**;
7. **安装应用首次打开 AI tutor 需要 12s**。
- **解决方案:H5 在页面中把用户网络状况呈现出来**。
- 关联 issue:`admin-ga.toolsapple.net/.../issues/cmr1havdw00bj6x0o25jkf9sd`。
- ⚠️ 只给了方向性方案(展示网络状况),**未定义具体的 loading/兜底样式与超时阈值**。
