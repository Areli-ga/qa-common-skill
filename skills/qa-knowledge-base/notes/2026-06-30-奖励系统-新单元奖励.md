## 摘要

V1.30.0 新单元奖励机制:每日学习路径终点放一个「单元大宝箱」,孩子完成当日全部课程才能开启,作为单一日终目标;开箱得【单元套装(上衣+下装+鞋子)】自动穿到虚拟形象身上,并预告次日【头饰】,以此提升首日完课深度与次日返场留存。配套奖励中心 V2.0 后端发放逻辑 + 整套数据埋点。

## 功能信息(逻辑 / 状态 / 边界 / 字段)

### 1. 单元宝箱(核心 · F1.1–F1.9)
- **逻辑**:路径终点放大宝箱;完成当日最后一节课瞬间,镜头推向宝箱、晃动吸引点击;开箱 1–1.5s 动画(光效+声效)。
- **宝箱 3 状态(图1)**:① 锁定(灰,未完成当日任务)② 可领取(橙,半开,已完成)③ 已领取(箱内含头饰)。
- **边界**:
  - 新单元结构=展示宝箱、路径扭蛋全取消;老单元结构=仍展示扭蛋。
  - 第一个单元只有 1 个 part 时,新手 hello 课程扭蛋也取消。
  - 未完成今日任务点击宝箱 → 多语言语音"完成今日任务,领取奖励"(不开箱)。
- **开箱内容**:今日单元套装 + 明日勋章预告 + 单元作品。
- ⚠️ **节数说明(原文不一致)**:需求背景写"4–5 节",路径图/语音文案写"完成全部 5 节";本库按原文同时记录,测试时覆盖对应展示与奖励触发。

### 2. 虚拟形象(Avatar)穿戴
- 默认小人**自动**穿上 上衣+下装+鞋子,站小舞台。
- ⚠️ **回归点**:由"点击穿衣"改为"**自动穿衣**"(埋点 `app_unit_rewardequipped` 同步从点击触发改为自动触发)。
- 次日返场可获【头饰】。

### 3. 解锁 / 未解锁
- 领奖回地图 → 下一单元解锁动画+音效。
- 点击未解锁课程 → 植入明日奖励内容(视频录屏+文案)。⚠️ 资源 **Sunny 待提供**,可能阻塞。

### 4. 次日返场(图3 动画时序)
- 启动 App 进地图首屏:Avatar 穿上昨天奖励 + 获得今天奖励,配温馨动画 + 中英文语音("哇,你回来啦!""今天的新装扮来啦!" / "You're back!!")。
- 动画关键帧(图3):冷启动 → 宝箱出现 → 宝箱半打开 → 角色穿衣 → 进入奖励中心(帧间约 1000ms)。

### 5. 后端发放逻辑(4.6)
- 奖励中心 **V2.0**,按单元配置结构判断发放规则。
- 完成单元 → 上衣&下装&鞋子;第二天再来 → 头饰。

### 6. 数据埋点(测试重点)
均带 `pathway` 属性 + `Level_Number` / `Unit_Number` 公参。
- 事件:`app_unit_reward`(type: lock/unlock)、`app_unit_rewardopen`、`app_unit_rewardequipped`(自动穿衣时机)、`app_unit_myworkshare`、`app_unit_share_completed`(H5 分享完成, Unity 监听)、`app_unit_finish_leave`、`daily_reward_grant`(次日补发)、`daily_reward_animation_complete`。
- 新埋点(带属性):`unit_chest_expose`、`unit_chest_click`、`unit_complete`、`unit_chest_open_start`、`unit_reward_page_view`、`unit_reward_claim`、`reward_center_guide_click`。
- 关键参数:`unit_id`、`chest_state`(locked/unlocked/claimed)、`lesson_completed_count`、`lesson_total_count`、`reward_center_version`(v1/v2)、`is_new_unit_structure`(true/false)。
- ⚠️ `unit_chest_retain_show`(中途退出挽留)标注"**先不加**"——本期不实现,勿测。
