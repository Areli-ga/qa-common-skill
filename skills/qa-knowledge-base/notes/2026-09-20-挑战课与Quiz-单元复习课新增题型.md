## 摘要
V1.39.0 给**单元复习课**补题型：此前只有【音频 - 图片配对】一种（听音频从 3 张图里选），**L6 课程需要「认识单词（选文本）」和「短句填空」**，因此新增 **4 种题型**（音频-文本、音频+文本-文本、**音频+图片-文本**、**填空题**）。落到三件事：① **线索组件优化** —— 支持**长文本自适应**与**图片 + 音频**线索（补上 V1.37 遗留的「Clue 配图片端上没实现」缺口）；② **单选题文本选项** —— 后台选项配成【文字模式】时端上渲染文本卡片，**三卡等宽、高度自适应、字号按最长选项统一降档且三项必须一致**；③ **填空题** —— 线索 = 带空格的句子文本 + 读完整句的音频（**两个独立字段**），**答对后把选中的词填进空格、展示完整句并重播线索音频**；Admin 侧新增 `Fill-in-the-Blank` 题型手动配置，并给线索配置加**「是否使用题干信息」开关**与**单独引用素材库音频**的能力。

### 1. 题型总览（本期后共 6 种）
| 线索 | 选项 | 考察什么 | 状态 |
|---|---|---|---|
| 音频 - 图片配对 | 图片 × 3 | 听力理解 | 已有 |
| 音频 + 文本 - 图片配对 | 图片 × 3 | 听力理解 | 已有 |
| **音频 - 文本配对** | 文本 × 3 | 音形对应：听到的词长什么样 | **新增** |
| **音频 + 文本 - 文本配对** | 文本 × 3 | 音形对应 | **新增** |
| **填空题：音频（完整句）+ 文本（带空格的句子）** | 文本单词 × 3 | **书面词识别 + 在语言框架中使用** | **新增** |
| **音频 + 图片 - 文本配对** | 文本 × 3 | 音形对应 | **新增** |

### 3. App 端规则
**线索 - 长文本**（img-01）：**长文本自适应，组件宽度随内容收缩**。设计稿示例线索为整句 `I am scared.` + 喇叭图标，选项是 3 张表情图片卡。

**线索 - 图片 + 音频**（img-02）：题目线索类型配置为**【图片 + 音频】**时，端上线索区渲染为**图片 + 音频**模式。设计稿：线索气泡内左侧是喇叭 + 「提示」文字标签，右侧是图片（香蕉），选项为 `pear / banana / grapes` 三个文本卡。
> 🔗 **这条直接补上了 V1.37 的遗留缺口**：《单元测验线索提示类型渲染》记录「**Clue 的 Image / Image + Audio 类型后台能配但端上无图片区，兜底不展示**」，并把「后台是否该禁止选这两类」列为待确认。本期端上实现了图片线索，**V1.37 期间按兜底逻辑配出来的存量题目，其表现会随本期上线发生变化**，要一并回归。

**单选题 - 文本选项**（img-03）：**三个选项卡片等宽、高度自适应**；**字号按最长的那个选项统一降档 —— 三个选项字号必须一致**。设计稿此图线索区只有一个喇叭（纯音频线索），选项为三个文本卡。

**填空题**（img-04 答题中 / img-05 答对后）
- 线索：**根据后台题目线索「是否使用题干信息」决定线索文本展示的是「所选单词」还是「题目配置的题干信息」**。
- 答题态：线索气泡显示 `I am ____ .`（喇叭 + 带下划线空格的句子），选项 `hungry / sad / scared`，右上进度 `0/5`。
- **答对后**：**把选中的词填入空格**（`I am sad .`，填入的词以**绿色高亮 + 绿色下划线**呈现），选中的选项卡描绿边并带 ✓ 角标，**展示完整句子并重播线索配置的音频**，进度推进到 `2/5`。

### 4. Admin 端规则（img-06）
**配置入口**：`Admin - 题库 - 创建题目 - Fill-in-the-Blank`。

**【填空题】新建 / 编辑题目字段**
| 字段 | 正文规则 | 设计稿（img-06）实际标注 |
|---|---|---|
| 题型 | 填空题 | 下拉「填空题」，标记「新题型」 |
| **Knowledge Point** | 从词库选取，**单选** | `Word Bank` 选取，提示 **「可多选」**（示例值 `sad`） |
| **题干信息** | 文本输入，`____` 下划线为特殊符号，前端展示时答对需把答案填到下划线上；**Admin 输入时采用「英文的一个下划线」** | 输入 `I am ___.`，提示 **「用 `___`（三个下划线）标记空格，前端渲染为固定长度的横线，不随目标词长短变化。填空题此项必填」**，并带 **App 端效果预览** |
| **线索音频** | 从**【素材库】或【学习资源列表】**中选取；例如完整音频 `I am sad.` | 「线索音频（完整句）」必填，示例 `i_am_sad.mp3`（来源素材库，可「更换」）；注解 **「音频读的是完整句『I am sad.』，含目标词 —— 与上方带空格的题干是两个独立字段」** |
| **选项** | **支持文字模式和图片模式**；选项均**从词库中选取** | 三个文本选项（hungry / sad / scared），注解 **「填空题选项固定为文字模式，不可选图片」** |
| 正确答案 | 选项中的一个 | 单选按钮标记 `sad` 为正确答案 |
| 操作 | — | 保存 / **在 App 端预览** / 返回列表 |

**线索配置优化（需求范围第 5 条）**：新增「**是否展示题干信息**」字段控制前端线索文本；**线索可单独引用素材库音频**（与题干文本解耦）。
> ⚠️ 原文只在「需求范围」里列了这两条，**正文没有对应的详细章节**（`详细需求` 最后一节就是 Admin 手动添加填空题），字段名、默认值、作用范围（只对填空题还是所有题型）都缺。

### ⚠️ 待确认（写用例前需拉齐）
1. **空格占位符是 1 个下划线还是 3 个**：正文写「Admin 输入时采用**英文的一个下划线**」，设计稿写「用 **`___`（三个下划线）**标记空格」。这是运营录题的硬规则，不统一会直接配错题。
2. **填空题选项能不能配图片**：正文写「选项支持文字模式和图片模式」，设计稿写「**填空题选项固定为文字模式，不可选图片**」。
3. **Knowledge Point 单选还是多选**：正文写「单选」，设计稿提示「可多选」。多选会影响复习课按知识点组题与掌握度统计。
4. **空格渲染长度**：设计稿写「渲染为**固定长度**的横线，不随目标词长短变化」，正文没写；**目标词很长 / 一句里出现多个空格**时的表现未定义（题干信息是否允许多个 `___`、多空是否支持都没说）。
5. **「是否使用题干信息」的默认值与影响面**：新增开关对**存量题目**默认取什么值、是否只作用于填空题、关闭后线索文本展示「所选单词」具体指哪个词（正确答案词还是 Knowledge Point 词），全未写。
6. **答错的交互完全缺失**：只写了答对（填词 + 重播音频 + 进度 +1），**答错怎么表现、能否重选、是否扣进度、错误后是否仍填词**都没写。
7. **线索音频与重播的时序**：答对后「重播线索音频」与答对音效、进度动画是否会叠加/打断没写；**单选题文本选项**那张图线索只有喇叭（纯 Audio 类型），进入题目是否自动播一次也没写（V1.37 就遗留过同样问题）。
8. **新题型对存量题库与 L1–L5 的影响**：本期是为 **L6** 加的，**已有单元复习课是否会混入新题型**、旧题（音频-图片配对）渲染是否受线索组件改造影响，需要回归。
9. **文本选项的多语言与超长文案**：字号「按最长选项统一降档」没给**降档档位与下限**；换到中文 / 印尼语等长词时是否会挤压或截断未说明。
10. **「学习资源列表」与「素材库」两个音频来源**的区别与优先级没写；选了资源列表里的整课音频（可能是长音频）时，端上是否需要片段截取也没提。
11. **本篇没有任何埋点章节**：新增 3 种题型和填空题的作答结果如何上报（沿用现有 Quiz 答题事件还是新增 `question_type` 枚举）完全没写，**答对率按题型拆分将无法统计**。
12. **需求范围列了 4 个新增题型，但详细需求只给了「填空题」与「文本选项」的完整规则**；`音频 + 图片 - 文本配对` 只有一句线索渲染规则，`音频 - 文本` / `音频 + 文本 - 文本` 没有独立章节 —— 需确认它们是否就是「单选题文本选项 + 不同线索类型」的组合，没有额外逻辑。
