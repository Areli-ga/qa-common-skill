## 核心设计决策(红线级;背景见 docs/ 与 SKILL.md)

- **只收飞书产品需求文档**;往期测试用例暂不纳入;不接其他来源。
- 抓取**保表格行列 + 抓内嵌 Sheet/多维表 + 下载图片 + 读图转文字**(纯文本会丢测试金矿);**内嵌表格(`block_type=30/18`)内容不在正文也不在 blocks,单独落 `raw/<slug>/sheets.json`,提炼前必读**;**超大图(>1900px)转 `.read` 缩放副本读,原图保留**。
- **读图可读性红线**:判据是**缩放比例**(`1900 ÷ 长边`),不是长宽比、也不是短边像素。**< 15% 判定不可读 → 不生成副本、不读、不猜**,笔记里如实标注「未读取」;15–25% 为存疑区,读不清同样如实标注。**严禁从布局形状推断图里的内容** —— 猜出来的描述会以事实身份进笔记,比留空危险得多。不可读的图会就地落 `img-NN.UNREADABLE.txt` 标记,**见标记即跳过,连原图也不打开**(原图会被读图工具自动压糊,打开等于白读)。
- **空间纪律**(2026-08-28 修订):归档格式为 **WebP q80**,原图转换后删除;判定不可读的图只留 1900px 占位。`.read` 派生副本是 derived、不入库、平时不留存(`scripts/read_cache.py` 重建,统一 `.read.png` —— sips 能读 WebP 但只能写 PNG);跨篇相同图用**硬链接**共享(`scripts/dedupe_images.py`)。
- **事实来源改口径**:本地已不是无损归档,而是 **q80 有损缓存 + 不可读图占位**;**真正的事实来源是飞书** —— `blocks.json` 里存着 image token,实测 2026-06-30 入库的老文档至今仍可重下,`meta.json` 的 `original`(bytes/md5/dims)可核验重下的是不是同一张。选 q80 的实测依据见 `scripts/compress_images.py` 文件头(AVIF 因读图工具不认而否决;q90 买不到保真;q60 只多省 8MB)。
- **不上向量库 / RAG、不上数据库**——纯文件。
- **不直接生成测试用例**(那是下一阶段)。
- **编译层(模块主题页 / 往回织)留 v2**,v1 预留位置、不实现。
- **分类只靠「模块」**(taxonomy 边长:新功能→新建一级、已有→归二级);**不设通用类型标签**(通用词无区分度)。
- **版本来源**:你给「版本 + 链接」时用你的(权威);没给才从文档提取(冲突标"待确认")。
- **关联 related**:只看 **同二级模块** 或 共享功能标识符;**一级模块不算关联**(模块视图已覆盖,否则大模块内全互连);排除通用词、埋点公参,以及按命名模式识别的**参数字段**(`*_id / *_name / *_type / *_count …`)。**不可用 df 上限剔通用词** —— 实测 df 最高的恰是被反复改动的埋点,是最该关注的信号。
- 数据安全:**原料层只读、永不覆盖**;笔记 / 索引可由上一层一键重建。

## 工程约定

- **所有脚本 / 模块必须带详细日志(logging)**,便于排查。
- **机械活归脚本、语义活归 Claude**(扫文件/统计/索引/关联打分 → 脚本;读懂/判断/读图/提炼 → Claude)。
- 依赖**项目级安装**,禁止全局 `-g` / `--break-system-packages`(见上级 CLAUDE.md)。
- 优先轻量:能不上的组件就别上,能用文件就别上库。
