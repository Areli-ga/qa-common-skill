学习中心修改样式 + 单词书1.0
需求背景
基于 1.39 已经做好的知识库后台，把 C 端单词体系调整为「听得懂 → 说得出」的四阶段成长视图。 头部核心：孩子在课程、Quiz、口语里产生的单词成果汇总成一本可翻的书，能看到每个词在哪学过、学到哪一步。 重点功能：书架与主题册、单词详情四阶段、课程 / 单元结算点亮单词、学习记录追溯。

需求目的
孩子在课程、Quiz、口语里产生的单词成果汇总成一本可翻的书，能看到每个词在哪学过、学到哪一步。
再结合学习报告，将孩子的学习效果外化。

四阶段定义（全局口径）
本期做课程主路径 + 鹦鹉学舌。

四阶段各自保存学习的行为数据，Heard 为其余三阶段的前置：达成 Understood、Repeat 或 Said 任一项时，Heard 同时记为达成。Understood、Repeat、Said 各自独立，可以分别达成。
后续多次用到的【点亮知识点】，指单词的任一状态达成。
语音「通过」复用语音模块规则，单词书不另设分数。
同一阶段多次达成只增加学习记录，不重复加词数。

2. Core 标签：该词在当前 Level 为必学词时显示；

3. 图片、英文：读知识库当前词形素材。
4. 开口次数：本单元轮次内该词的有效语音尝试数，跟读 + 独立表达都算；按尝试去重，空录音和重复上传不计。
