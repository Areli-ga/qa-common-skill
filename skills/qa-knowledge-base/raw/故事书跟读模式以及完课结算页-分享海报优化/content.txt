需求背景

结算页是断头路：跟读完一本书，结算页只有整本星级 + 可回放用户录音+ 分享 + 退出，没有"下一步读什么"。普通故事书结算页已有推荐位（Libin 设计，默认推荐下一本故事书），跟读模式没有跟上。结果：孩子读完一本就退出，单次会话只消费 1 本，刚建立的跟读节奏断在结算页。
分享海报体现不出"这是孩子的作品"。 跟读版故事书分享沿用 App 通用分享组件，分享出去的东西看起来像一条 App 广告
故事书内容形态升级， 过去跟读版故事书是特意挑选的精简本：一个图页只有一个音色、只有一句短句，所以「跟读单元 = 图页」这个隐含假设一直成立，为提升故事趣味性，接下来的内容会出现：
同一图页两个音色（典型是1个角色语音+旁白语音）→ 同页两段音频；
同一图页多句正文
在现有按页模型下会直接坏掉：一页两段音频无法确定领读播哪一段、录音评的是哪一句、录音存到哪个 key、封面回放播哪一条、星级怎么算、进度怎么显示。跟读单元必须从图页下移到句。





产品目标

跟读单元改为句：跟读模式按句推进，同图页多句时「下一步」只切句、不换图画；整本星级、跟读进度与统计改为「已跟读句 / 总可跟读句」
结算页对齐普通故事书：新增推荐位（沿用 Libin 的普通故事书结算页设计）。仅「故事书模块」入口展示，且只推当前书所属系列的下一本；路径入口结算页保持现状不动
分享物从"品牌海报"改成"作品卡"：卡面主体 = 书封 + 谁读的 + 成就 + 语义化二维码「扫码听 TA 读的这本书」

1.3 推进与翻页键
「下一步」按钮保持同一个按钮、同一个位置、同一个图标，行为统一为「推进到下一个可跟读句」：
下一句在当前图页 → 只切句，不换图画、不播翻页动效（改用句高亮转移 + 淡入上浮）；
下一句在下一图页 → 换图页 + 走原有翻页动效。
「上一步」同理 = 回到上一个可跟读句；回到已通过的句不自动领读、不自动录音（沿用 1.35.0「已通过的不自动播放 + 录音」）；回到未通过 / 未录的句自动走领读 → 自动录音。
1.35.0 失败兜底的高亮对象 = 这个同一个按钮（第 2 次失败后高亮，语义为"跳过这句往下走"）；同页切句场景也要能高亮（不因为不换图页就不高亮）。
录音中点击「下一步」：沿用旧逻辑 —— 自动结束录音并取评分记录到当前句，然后推进。
最后一个可跟读句通过 → 不再推进，进入完课结算页（判定从"最后一页"改为"最后一句"）。若该句之后还有纯插图页 / 非跟读页，不强制孩子翻完，但允许手动继续翻看（结算页可从末页手动进入，沿用现有口径）。

1.5 录音留存与封面回放（粒度下移）
每句仅保留最终通过那一次的成功录音（原为每页）；未通过句不留录音；
重复跟读同一句（往回翻再读通过）→ 覆盖为最新成功版；
封面回放：按可跟读句顺序连播各句成功录音，未成功的句直接跳过（原为"未录页跳过"）；
封面可播放态判定：≥1 句成功录音（原为 ≥1 页）；

 验收标准
按句跟读
同图页多句故事书可正常跟读：逐句领读 → 自动录音 → 判定 → 推进；同页切句不换图画、不播翻页动效；
同页两个音色各自播放自己的音频；当前句高亮、已通过句打勾、未到句灰化，整页正文常驻可读；
「下一步」键在同页切句场景同样可用、失败 2 次后同样高亮；录音中点击 = 结束录音并把评分记到当前句；
跟读进度显示为 已跟读句 / 总可跟读句；整本星级 = 可跟读句星级平均四舍五入（未通过句算 0）；
录音按句留存（每句仅存最终通过版）；封面回放按句连播、未成功句跳过、≥1 句成功录音即可播
存量单句页故事书行为与现状完全一致（零回归）；
最后一个可跟读句通过后进入完课结算页；

推荐位视觉权重低于封面回放；无跳动 / 闪烁动效；不自动跳转
