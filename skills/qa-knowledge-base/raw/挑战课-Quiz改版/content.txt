需求背景

在当前版本中，我们的“单元挑战课”与“每日 Quiz”虽然完成了基础知识检验的功能，但在用户体验上存在明显的割裂感。特别是在挑战课中，遇到题目时会强行切入毫无背景的蓝白底 UI 界面，这不仅打断了儿童用户的“游戏心流”，每次切屏引发的 Loading 时间也导致了较高的中途流失。
对比市面头部竞品（如 Buddy.ai 将题目化为打僵尸的武器，Studycat 在游戏画面上方直接叠层出题），我们当前的反馈机制过于单薄（答对仅“继续游戏”）。因此，需要对这两个核心复习模块进行重构，将“外挂表单式”做题升级为“沉浸式游戏交互”。





产品目标

业务目标： 降低环节跳出率，提升 L1 阶段用户的首日完课深度与挑战课/Quiz完课率
体验目标：
每日 Quiz（先暂停，优先级低）： 打造轻量、陪伴式的高频复习体验，建立“音-形-意”的强认知关联。
单元挑战课： 实现跑酷与答题的无缝融合，提供高燃的成就感与合理的挫折保底机制。

竞品做法

场景割裂

跑酷中突然切到蓝白底 UI 界面做题，做完再切回跑酷，打断玩家心流

Buddy 的单词卡是攻击僵尸的武器；Studycat 的选色直接在游戏画面上方进行，题目即游戏交互

反馈单薄

答对无奖励，仅“可以继续游戏”，正反馈过于微弱

Buddy 答对释放攻击技能；Studycat 答对推动角色前进找到朋友，每次正确都有明确回报

节奏失衡

Quiz 过于直白，像一个工具界面，缺少沉浸感。
挑战课略显拖沓，加载和切屏导致用户流失

竞品使用IP 角色直接作为出题人出现，且整个UI设计感觉是"在一个场景里做事"，而不是"打开了一个答题弹窗"。
竞品在单次游戏内嵌入 3–4 个知识点，全程零切屏，保持心流不断
 Quiz 重构（先暂停，优先级低）
核心定位与心智
将“我在考试”的心智转化为“我帮 Max 收集今天学到的卡片”。
UI 与换肤机制
弃用纯白底色，采用“沉浸式 2D 背景底图 + 焦点居中”的结构（参考星空/森林等轻度场景，预设4-8套皮肤）。
配置支持：
image.png

Admin -> Lesson Series -> Curriculum Paths -> [具体等级]  -> Unit Edit中添加AI Quiz时新增一个下拉弹窗，支持切换当前预设皮肤
背景图、选项气泡样式、顶部收集板的素材支持读取admin路径配置中的设置，通过标准 JSON 文件进行动态替换，方便后续产品按主题换肤。
核心交互流程
开场： 屏幕展示主题背景，Max 出现在画面中，播放本地化语音“帮我收集知识卡片吧！”。顶部常驻展示含有 N（题数）个空槽位的收集板。（或者直接使用统一后的进度条，卡片直接收起）
题目呈现 (强化“音-形-意”)：
第一题从画面上方滑入。
将关键词的音频播放喇叭控件升级显示目标单词文本（当前只是一个声波图，可以直接放单词加可发音按钮）。
画面中部出现 3 个对应的图片选项。
反馈分支逻辑：
答对 (<1.5秒演出)： Max 播放一段简短的庆祝动画+ 欢呼音效+庆祝特效，对应的单词文本从屏幕上方飞至正确选项处，同时选项高亮发光系统再次播放该单词标准发音，单词图片化作卡片飞入顶部收集板对应的槽位。随后自动进入下一题。
答错第一次： 错误选项闪红并带有轻微的左右抖动物理反馈。Max 出现挠头动画，语音提示“再想想”。
答错第二次 (防卡死)： 触发纠错机制。正确选项高亮发光，对应的单词文本从屏幕上方飞至正确选项处，系统再次播放该单词标准发音，随后自动进入下一题。此题在结算时记为错误。
结算与外化：
展示最终收集卡片状态。
星级评定：全对 = 3星 + 满屏彩蛋特效；错 1-2 题 = 2星；错 3 题及以上 = 1星。
单元挑战课重构
核心定位与心智
剥离弹窗 UI，让题目成为跨越跑酷障碍的核心交互动作。长度约 2-3 分钟，包含 4-12 个障碍。
核心交互流程
子弹时间出题： Max 在跑酷赛道上奔跑，遇到前方障碍物（如陷阱、挡路的怪物）时，不切场景。游戏整体时间流速变缓（画面定格/慢动作）。
天空主题较为特殊，就不卡障碍物了，均匀分散地选择部分进度点位触发题目（无实体外露在地图），触发时出现题目与答题卡，以云团状做答题卡
地图中还可放置部分答题奖励物件（通常放在一连串giggles前面，答对后将正好加速吃完这些Giggles），接触后也会触发子弹时间出题
沉浸式选项：屏幕上方直接出现关键词与选项。孩子选择正确答案则 Max 跨越障碍，选错则撞上陷阱/怪物。全程不切场景，保持沉浸感。
题目与选项样式跟随Quiz设计且需符合挑战课主题样式（丛林、海洋、天空、沙漠）
反馈分支逻辑：
正确： Max 选对答案，卡片化为特效击中Max，并免疫2s伤害，自动做出华丽的跨越动作（空翻）跨越障碍。
天空主题较为特殊，答题成功则答题卡化为特效击中Max，并免疫2s伤害，失败则化为乌云发出雷电将max劈落并重生在3-5s前，然后重新触发答题
Combo 机制： 连续答对 2 题及以上，触发 Combo 状态。Max 获得加速冲刺的视觉效果，同时速度*1.15倍，直到遇见下一个障碍物，增强游戏爽快感。
加速最多叠加三次即1.15*1.15*1.15约1.52倍，加速特效也需要做三个版本
答错将减去一层加速buff
错误第一次： Max 接触陷阱/怪物掉落出屏幕，播放受挫音效，角色重生至该障碍物前 3-5 秒的距离，重新进行该题的子弹时间挑战。
答错将减去一层加速buff
错误第二次 (保底跳过)： 为避免反复挫败，若在同一障碍连续错误两次，触发保底机制。Max重生至障碍物后方1秒位置，并在障碍物后方恢复正常跑酷。
答错将减去一层加速buff
体验优化
沙漠挑战课移除原来的沙丘加速逻辑 @jack
所有地图长度适度拉长（1.25倍左右）@jack

挑战课选择载具后需要出现一个动画，载具变为一道特效光、弹窗消失，特效光击中Max，使得Max从常态变为载具态（或者Max载具态从特效中出现）
