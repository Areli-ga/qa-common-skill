知识库支持数学学科
需求背景
在英语的知识库之外支持数学学科。新增「学科」，学科之间知识点完全隔离。
支持学科切换、数学知识点新建 / 编辑、数学列表与详情、数学体系树、选择知识点弹窗按学科锁定。

需求详情
新增学科
知识库新增「学科」：英语 / 数学。同一张表、同一套 15 位 ID，学科之间知识点完全隔离，不可跨学科引用。
现有学习资产全部刷为英语。

顶部切到「数学」，列表、分组、筛选、计数只算数学知识点
支持按知识点和级别展示
知识点：
交互说明
列表页顶部展示学科切换：英语 / 数学，各带知识点数。默认选中英语。
按账号记住上次停留的学科，下次进入直接停在该学科。
切换学科：清空搜索、筛选、分组选中、勾选，回到第 1 页。
点击知识点名称或「详情」，进入数学知识点详情页。
点击「编辑」，进入编辑页。
点击「+ 新建知识点」，进入新建页，学科继承当前 tab。
左侧分组方式下拉可选：知识点类型 / 级别，默认知识点类型。
点击分组值筛出该组，再次点击取消；点击「全部知识点」取消分组。
分组与上方筛选可叠加；叠加的条件以标签形式展示在列表上方，点 × 单独移除。

数据说明
学科切换，切换后，展示全部数据。
列表：
（1）列：知识点 / 类型 / 数值 / 级别 / 状态 / 操作。
（2）知识点：名称，下方小字为 15 位 ID。
（3）类型：数字 / 图形 / 方位 / 比较 / 属性 / 运算 / 句子。
（4）数值：类型 = 数字时展示整数，其余类型展示「—」。
（5）级别：Foundations / Level 1 / Level 2…
（6）状态：待上架 / 已上架 / 已下架。
（7）排序：按 ID 正序。
（8）标题旁：共 {n} 项，n 为当前分组 + 筛选后的条数。
筛选：
搜索：按知识点名称或 ID 模糊匹配。
类型：全部类型 + 7 个类型值。
状态：全部状态 / 已上架 / 待上架 / 已下架。
分组：
（1）全部知识点：{n}，n = 数学知识点总数。
（2）按知识点类型：每组展示类型名 + 条数，按条数倒序。原型：方位 12 / 数字 11 / 属性 9 / 比较 5 / 图形 4。
（3）按级别：每组展示级别名 + 条数。原型：Foundations 24 / Level 1 12 / Level 2 5。
（4）条数为 0 的类型不出现在分组里；运算、句子本批次为 0。
缺省状态
数学学科下没有任何知识点：列表展示「暂无匹配的知识点」，分组只剩「全部知识点 0」。
筛选或分组后无结果：列表展示「暂无匹配的知识点」。
