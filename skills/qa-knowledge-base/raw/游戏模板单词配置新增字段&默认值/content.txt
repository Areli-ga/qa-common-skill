需求背景

课程运营在课程模板配置（参数配置步骤）中选取Target Words/Starting Word/Distractor Words后：
原画：已自动从词库带出默认插画，可手动替换；
单词读音：系统会自动关联默认读音，但在配置界面不可见、不可调整——运营无法确认/替换本课实际使用的读音；
动画：词库无默认动画概念，每个单词都需要运营逐个手动选择 Spine，配置效率低；
音效：无法在单词维度配置





产品目标

分两侧改造：
词库侧（Libin Learning Asset List 增加默认动画和音效关联）：词库单词新增「默认动画」「默认音效」配置（默认插画、默认读音已有），使每个单词在词库内即拥有插画 / 动画 / 读音 / 音效四类默认资源；
课程配置侧：
游戏模板-Target Words/Starting Word/Distractor Words卡片在现有「美术资源、Spine 资源」基础上，新增三个音频字段——【单词默认读音】【单词特殊读音】【单词音效】，均使用新版资源库的音频选择器
通过「选择单词卡」选中词库单词时，自动带出其默认动画 → Spine 资源、默认读音 → 单词默认读音、默认音效 → 单词音效（插画已支持自动带出，保持不变）





主要特性

选词后四类资源（插画/动画/读音/音效）一次自动带齐，常规课程实现「选词即完成单词资源配置」，仅特殊需求才手动调整；
单个单词的配置操作次数从「选词 + 手选 Spine + 额外配音效」降为「仅选词」；
读音在配置界面显性可见、可试听、可替换，减少上线后才发现读音错配的返工。

字段归属：三个新字段是目标单词项的子结构（与美术资源、Spine 同级），随主题字段结构在每个配置组内复用
选词自动关联逻辑
触发时机：通过「选择单词」选中/更换目标单词时触发一次自动带出；
带出内容：默认插画 → 美术资源、默认动画 → Spine 资源、默认读音 → 单词默认读音、默认音效 → 单词音效；
缺省处理：词库该单词某项默认资源未配置 → 对应字段保持空，由运营手动选择
快照：带出即落库为本课程配置的资源引用快照；之后词库修改该单词默认资源，不回溯影响已带出的课程配置；
不回写：课程配置内的任何替换仅作用于本课程本配置组，不回写词库默认资源；
更换单词：同一卡片更换为另一单词时，五个资源位全部按新单词默认资源重新带出并覆盖（含已手动替换项），特殊读音清空——避免旧词资源残留错配（口径见待确认 4）；
特殊读音不自动带出：始终默认为空，仅手动配置。
单词默认读音 / 单词特殊读音 / 单词音效三个字段统一使用新版资源库音频选择器

边界与异常


场景

期望表现

（选择单词到游戏模板打包期间内）已选音频/Spine 在资源库被删除或下架

字段展示失效态；保存时必填字段失效则拦截并提示

存量课程（改版前已配置）打开配置页

正常展示：新字段为空；不影响已发布课程线上表现

同一配置组/多配置组选择同一单词

各自独立带出、独立编辑，互不影响

自动带出后手动替换，再次打开配置页

展示手动替换后的值，不重新带出

必填字段为空（如默认读音）点击保存/下一步

校验拦截，提示定位到「配置组 X-单词 Y-字段 Z」

词库接口异常导致带出失败

选词成功但带出失败的字段保持空 + toast 提示「默认资源带出失败，可手动配置或重选单词」
