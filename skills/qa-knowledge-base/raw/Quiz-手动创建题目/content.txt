需求背景

随着单词库（Word Bank）已搭建完成，每一个单词都已配套对应的图片与标准发音，出题所需的核心素材已可由词库直接复用，无需通过 AI 推理从教学文档中再生成。教研老师只需根据自己的教学文档，手动挑选单词、组合题型即可快速产出高质量题目。





产品目标

提供独立、可控的手动出题流程，让教研可基于教学文档直接出题
通过词库（单词 + 图片 + 标准发音）填充题目素材，提升手动出题效率





主要特性

手动创建表单：题型 + 知识点 + Skills（多选）+ Difficulty（L1-L10）
题目配置：题干模板（22 个英文模板，下拉单选）+ 线索提示格式（6 种）+ 3 个图片选项
知识点：支持手动输入单词/词组，或点击「Word Bank」按钮从单词库选取
线索：选择非「无」格式时必须从 Word Bank 选 1 个单词作为素材来源（音频/图片/文本均取自该单词）
选项：固定 3 个图片；若 KP 来自词库则按类别自动填充（1 正解 + 2 干扰项），KP 手动输入则人工从词库挑选
本期题型范围：仅支持单选题（choice）

手动创建流程


序号

流程

说明

1

进入手动创建

在题库管理页面点击「Manual Create Question」
打开手动创建表单

2

填写表单

选择测验题目类型（本期仅可选 choice / 单选题）
选择测验的知识点（直接从单词库里选择单词）
添加 Skills（多选）
选择 Difficulty（难度）

3

题目配置（本期仅单选题）

(1) 选择要使用的题干：从题干模板列表中选择（如「Tap the picture.」）
(2) 配置线索提示格式：从「语音 / 语音+文本 / 文本 / 图片 / 图片+语音 / 无」中选择 1 种；从单词库中选择提示（无须线索配置的话，可以不选）
(3) 配置选项：3 个图片选项；从单词库中获取（1 个正解 + 2 个干扰项），并标记正确答案
线索与选项的素材均从单词库配置

4

预览与提交

提供预览：与 Quiz 学生侧一致的题目卡片（含题干、线索、3 图片选项）
确认无误后点击 Submit 落库

是

线索提示格式（6 选 1）
线索（Clue / Hint）用于在题目中给予学生提示。本期支持 6 种格式，对应素材默认取自单词库。


线索格式

呈现内容

默认素材来源（单词库）

语音

播放单词标准发音

单词库中该单词的标准发音音频

语音 + 文本

同时呈现标准发音与文本

音频 + 文本均来自单词库

文本

仅呈现单词文本

单词文本来自单词库

图片

仅呈现单词对应图片

单词图片来自单词库

图片 + 语音

同时呈现图片与标准发音

图片 + 音频均来自单词库

无

不提供线索

—
选项配置
本期固定为 3 个选项，且选项格式为图片
人工选择：从单词库中选择单词添加到选项未知
必须标记 1 个正解
交互细节
校验：所有必填字段未填或未标记正确答案时，Submit 按钮置灰；点击时提示具体缺失项
验收标准
题库管理页可见「Manual Create Question」与「AI Generate Questions」两个入口，互不影响
Manual 表单支持选择题型（本期仅 choice）、知识点、Skills（多选）、Difficulty
可从题干模板中选择题干
线索提示格式可在「语音 / 语音+文本 / 文本 / 图片 / 图片+语音 / 无」6 种中切换；对应素材按所选格式自动呈现
线索素材默认从单词库拉取
选项固定为 3 个，且为图片格式；人工从单词库中选择选项
正确答案标记为必填；提交前未标记时给出明确报错
预览态与学生侧渲染一致（题干、线索、3 图片选项）
提交后题目入库，所有必填字段（题型、知识点、skills、difficulty、stem、clue、options、correct_answer）非空
AI 流程的功能与现有体验保持完全一致，不被本次改造影响
