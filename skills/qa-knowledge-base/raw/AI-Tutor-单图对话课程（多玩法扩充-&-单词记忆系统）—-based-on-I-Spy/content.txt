三、需求背景
原产品只有一个 I Spy 游戏，玩法单一（仅 something begins with letter *），无法兼容所有用户——能力强的觉得太简单，低龄/基础弱的觉得太难。
记忆系统颗粒度太粗：只能笼统记录"玩过/没玩过"，无法体现孩子对每个单词在不同认知维度上的掌握程度，难以做个性化推进与对家长的学习汇报。
因此本次迭代主要做两件事：
把玩法做成多维度、可配置、可切换，有动画有音效
把单词记忆系统细化到"单词 × 认知维度"的粒度

四、产品目标
玩法覆盖度：完整模型含 5 类玩法（👂👀👄👆🫣），覆盖从"磨耳朵"到"独立掌握"的认知链路；本期 MVP v0 先上 👂👀👄🫣 四类（详见 §8.3.3），让不同水平的孩子都能找到合适难度。
记忆系统粒度：单词本展示所有涉及到的单词，记录学习进度（但不对外展示）。
可运营：scenes 支持分组配置、玩法支持按 scene 维度配置；动画/音频资源支持工具化制作 + admin 一键上传，降低内容生产成本。
体验连续性：系统记住用户上次所在的 scene 与玩法，离开后可无缝续玩。

八、功能描述
8.1 核心元件说明


元件


规则 / 逻辑说明


第 2 岛屿 🏝️ 与游戏入口


本期解锁 1 个新岛屿；岛屿内提供 3 个素材，每个素材 = 1 个独立游戏（即一个 scene）；用户点素材缩略图进入游戏详情；AI 知道入口位置，可引导用户点击岛屿进入。


scenes list（场景列表）


APP 展示可玩 scene 列表，支持 group 分组配置；AI 可按学习进度引导用户选择某个 scene；进入后加载该 scene 的单词与素材。


玩法选择器（难度切换器）


展示当前 scene 支持的玩法（v0：👂👀👄🫣）；默认由系统按学习进度（§8.3.3）自动推进，孩子无需操心；切换器作为「手动越权」通道（家长 / 能力强的孩子可直接跳玩法）；系统记住并恢复上次进度（批 / 层 / 轮）。


bbox（对象热区）


画面中每个目标对象的可点击 / 可定位区域；承载点击命中判定、动画与音效触发、目标高亮。玩法 1/2 的孩子点击、玩法 3 的「AI 点 bbox 播放声音」均基于它。


动画 / 音频资源


动画：2 帧实现 word 动画；音频：word 跟读音 + 对象音效（如动物叫声）。均由制作侧工具完成对象识别 / 制作 / 查找编辑并导出资源包（✅ 已实现），admin 一键上传（文件包）；与 bbox 绑定供各玩法调用。


动画 / 音频触发机制


定义标准触发方式；不同玩法按各自约定触发——玩法 1/2 点击 bbox 触发动画+音效，玩法 3 由 AI 主动点 bbox 播放动物声音；具体触发时机写进各玩法步骤（§8.4）。


录音打分组件


在需要孩子开口的环节唤起（玩法 1 跟读、玩法 3 朗读句子、玩法 4 边写边读）；采集孩子语音并对发音 / 跟读打分，产出「好 / 不理想」结果回传给 AI，决定评价语与转场分支；该结果作为掌握信号写入学习日志（见 §8.3.3 执行）。


单词本（含复习入口）


展示当前 scene 用到的全部单词，记录每个单词在各维度的学习状态，状态与符号绑定（👂👀👄🫣/🧠；👆 后续版本），是孩子 / 家长可见的成长地图。玩法 2/3 结果不理想时，AI 在「分支提示」引导孩子进入单词本、点击单词卡片重新进入该词相应玩法复习，复习结果回写掌握状态（与 §8.3.3 联动）。

8.3.2 学习进度控制：广度 × 深度的阶梯式推进
问题
一个 scene 内的单词可能很多（多达 20 个）。如果让孩子在一种玩法里把 20 个单词全部学完才能进入下一种玩法，体验会很糟：同一种玩法重复 20 次过于单调，孩子容易弃玩；而且等学到第二种玩法时，最早的单词早已遗忘。我们需要让学习广度（认识多少词）与学习深度（每个词掌握到什么程度）像爬楼梯一样交替上升，而不是一条道走到黑。
设计：分批 + 阶梯
我们把一个 scene 的单词拆成若干小批次（每批约 3 个词，如 dog / cat / fish），并把 5 种玩法视为由浅到深的学习层（👂 听 → 👀 认 → 👄 说 → 👆 写 → 🫣 综合）。学习按“一小批、一小批，逐层加深”的方式推进：
同一批内，深度优先：先用玩法1（👂）把这 3 个词都过一遍，紧接着用玩法2（👀）把同样这 3 个词再过一遍（此时玩法2 对这批词既是新挑战又是复习），视情况再到玩法3（👄）。
一批爬够深度后，换下一批，从最浅层重新开始：换 3 个新词（如 bird / duck / pig），同样从玩法1 起步。
分轮螺旋回访（深度加码）：当所有批次都完成了第一轮（如 👂👀👄）之后，再开启第二轮，回过头让各批次爬更高的层（👆 书写、🫣 I Spy）。第二轮天然就是隔了一段时间的复习，记得更牢。
这样的好处是：孩子很快就能广泛“见过”很多词（广度），同一个词又会在不同玩法里短间隔地反复出现（深度 + 复习），既不单调，也不会学了后面忘了前面。
直观理解：把“单词 × 玩法”想成一张表（行是单词、列是玩法），我们不是先填满一整列、也不是先填满一整行，而是一小块一小块地、阶梯式地推进。
体验要点
批次 = 一次完整的“玩耍单元”：一批 3 个词 × 几个层，正好是一次低龄孩子合适的游玩时长，也是天然的存档点。孩子中途离开，下次从所在批次 / 层继续。
单词本 = 进度地图：记录每一个单词的学习深度，全部点亮到 🧠 即视为彻底掌握。未来考虑呈现给孩子和家长的成长可视化。
玩法切换器以“系统自动推进”为主：推进由系统按上述阶梯自动安排，孩子无需操心“该玩哪个”
深度单调解锁：更高阶的玩法应在低阶玩法之上解锁，避免让孩子在“还没听过 / 认过”一个词时就直接去书写或猜词。
