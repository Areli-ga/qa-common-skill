需求背景
当前用户反馈主要依赖线下电话访谈，存在效率低、样本量小、覆盖面窄、周期长等问题；且历史样本地区分布失衡（大量为非目标市场用户），难以规模化、及时地获取目标市场（如印尼）用户的真实有效反馈。
为提升用户研究的效率与覆盖面，计划在 App 内新增「调研问卷」功能：由运营侧每隔一段时间（如两周）发布一套调研问卷，面向符合条件的用户群体定向展示；用户在 App 内即可作答并获得 Giggles 奖励，从而更大范围、低成本地收集真实反馈，支撑产品与增长决策。

产品目标
定量：单期问卷面向命中定向条件的用户，「入口曝光 → 完成」转化率 ≥ 10%
定量：预计单期有效问卷回收量为 11 份（把游客看板改造成广告位，预计回收 100 份）；回收量预测算法： 曝光人数 * 10%（广告点击） * 10%（问卷填写）（定向投放印尼用户，每天进入用户数约为280人，预计回收问卷11份）
定量：单次调研从发起到回收的周期，由线下电话访谈的数周缩短至 ≤ 3 天
定性：沉淀可按 国家 / 语言 / 年龄 / 学习级别 拆分的结构化反馈，替代并补充线下电话访谈，直接支撑产品迭代与增长决策
主要特性
App 内【家长中心】看板广告位每月新增「问卷调查」广告
管理系统 - 广告配置新增广告位：家长中心 - 游客模式
问卷内容多语言：随用户界面语言自动展示对应语言
多题型：单选、多选、录音题、问答（开放题）、评分 / 量表题
完成问卷发放 Giggles 奖励（每期奖励数可配置，防重复领取 每个问卷只允许答一次，后端返回问卷答题状态）
运营后台：问卷配置、发布 / 下线、数据回收与导出

问卷调查-交互原型.zip
功能描述（对应交互原型）

整页布局固定,仅题型区随题目类型变化;文案随界面语言切换。「是否展示广告」属广告位管理、「是否已完成」属问卷功能,两者解耦。
一、入口 · 家长中心看板轮播广告位
位置:【家长中心】看板是一个轮播广告位(非多个并列广告位)。轮播内容按位序排列:1 号位 = 「问卷调查」广告、2 号位 = 免费学习资源、后续位按运营配置顺延。
轮播交互:自动轮播(每帧停留约 3–4s、循环)+ 底部圆点指示当前帧、可点圆点手动切;prefers-reduced-motion 时不自动轮播,仅手动。
「问卷调查」卡元素:图标、标题(=问卷标题)、奖励文案「答题得 N Giggles」、红点(表示有新问卷)、右箭头。点击 → 进入说明页。
登录态 / 游客均展示该轮播:登录态上方展示当前孩子档案(如"朵朵");游客上方为 登录/注册 + 第三方登录入口,轮播照常展示,游客也可直接点击参与。
二、说明页
元素:返回(‹)、Giggles 余额、问卷标题、副信息「预计时长(分钟) · 完成得 N Giggles」、「开始作答」按钮。
标题 / 时长 / 奖励数均取自后台"问卷基本信息"。
交互:点「开始作答」→ 第 1 题;返回 → 回家长中心。
三、答题页（逐题）
顶部:返回(‹)、进度条(随题序推进)、Giggles 余额。
题目区:题型标签 + 题序(如「单选题 · 1/5」)、题干。
底部:「上一题」(第 1 题隐藏)、「下一题」;最后一题为「提交问卷」。
必答校验:必答题未作答时,「下一题/提交」置灰不可点;选填题可直接进入下一步。可「上一题」返回修改,答案会话内保留。
本期 5 种题型:

四、完成页
元素:庆祝图标、标题「提交成功」、奖励条「您已获得 N Giggles」、致谢文案、单个「完成」按钮。
奖励:完成并提交成功即发放 N Giggles(N 后台配置,原型示例 30);同一用户/设备同一期仅发放一次(防重复)。
交互:点「完成」→ 返回首页(家长中心),结束本次会话。
登录态与游客完成页一致(均"您已获得 N Giggles")。

功能描述（对应交互原型）
运营后台 · 问卷管理
入口与列表页
位置:左侧菜单 运营 → 问卷管理。
列表列:问卷名称(含内部 ID)、状态、题目数、H5 地址、创建时间、操作。顶部含状态筛选 + 创建问卷 按钮。
问卷状态机(三态):

操作语义:发布(未发布 / 停止发布 → 已发布)、停止发布(已发布 → 停止发布)、重新发布(停止发布 → 已发布)、编辑(打开向导载入该问卷)、删除、数据导出(下载 CSV)。
创建 / 编辑向导（3 步）
Step 1 · 基本信息


校验:名称 + 标题非空,方可下一步。
Step 2 · 题目设置(三栏:题目列表 / 编辑器 / 实时预览)
题目列表:添加 / 选中 / 上移 / 下移 / 删除;显示题型 + 必答标记。
题型(5 种)及配置:

「其他(填空)」选项:每题最多一个,标签可改(默认 Other);App 端用户选中它需输入文本,存为该题的开放文本答案。
通用:每题必答 / 选填开关。
多语言:只录英文源;编辑器顶部有 Tolgee 说明与入口(「在 Tolgee 查看」);发布后英文源同步 Tolgee 翻译。
实时预览:按 App 样式渲染当前题(英文源)。

校验:每题英文题干非空;单选 / 多选有效选项(含「其他」)≥ 2。
Step 3 · 完成
生成问卷 H5 地址(可复制),形如 https://h5.giggleacademy.com/s/{id}?lang={ui_language}。
摘要:名称、标题、题目数、当前状态=未发布、多语言(Tolgee)、时长、奖励。
「完成,返回列表」→ 该问卷以未发布入列表。
下一步提示:① 列表点「发布」上线 → ② Tolgee 完成翻译 → ③ Banner 管理用 H5 + 图片 + 发布周期配置投放。
数据导出
列表「数据导出」→ 直接下载 CSV(UTF-8 BOM,Excel 中文不乱码),文件名 问卷名_responses.csv。
字段:提交时间、用户ID / 游客、国家、语言、状态 + 每题一列(Q1…Qn);问答存文本、录音存音频文件、「其他」存用户填写文本。
数据埋点需求
数据观测方式
统计问卷的曝光、点击、开始、完成、放弃、发奖等，并可按 国家 / 界面语言 / 年龄段 / 学习级别 拆分，评估触达与回收效果。
