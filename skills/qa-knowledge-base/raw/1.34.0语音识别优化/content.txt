需求背景

跟读等待时长不足 + 超时直接丢弃识别结果（已被线上 A/B 实证）：
采集截断：孩子还没说完就停止收音（反应慢的低龄孩子、多音节长词 strawberry/watermelon）。
评分结果截断（主因）：孩子已经说完，但 GiggleSpeech 本地评分没在等待窗内返回；对照组使用cancel 把结果直接丢弃、记成 0 星 / unknown。
影响：
大量满分跟读被错记为 0 星/unknown，语音识别成功率被压低
多次重试逐条上报，无法统计「单个单词在一次会话内最终有没有读对」
开口检测is_speech_detected 被噪音误触，开口率统计失真





产品目标

自适应跟读计时：把倒计时升级为「开口宽限 + 动态录音 + 自适应尾静音」，短词快、长词稳、不截断
单词单次会话识别成功率统计：给 lesson_speech_recognition_end事件加单次会话唯一识别 word_session_id ，以及本次会话最终结果参数speech_word_result
开口检测：端上优化 VAD or 后端音频回流分析，剔除噪音误触，统计"真实开口"

需求详情

需求一：跟读计时调整
把语音识别采集拆成二段：
开始语音识别采集
开口宽限窗：等首次有效发声
若超时，则按原来的未发声重试(回到领读)
若检测到有效发声，则结束此阶段，进入3
录音窗：持续收音，只要还在发声就继续
若触达【录音安全上限】则强制结束，获取结果
结果返回


参数

值

说明

onset_grace（开口宽限窗）

6s

进入聆听起计；检测到有效发声则结束此阶段。沿用 1.33 抢答。

max_record（采集安全上限）

6s + 0.5s ×(音节数−1)，封顶 10s

仅兜底，非正常关闭手段。
闪卡注意同样处理对接

需求二：单词单次会话识别成功率统计
 lesson_speech_recognition_end参数新增


字段

类型

说明

speech_session_id


string

用户进入某节课程的同一单词/句子本次会话的所有重试共享同一值；换词或重进课节生成新值。

speech_session_result

enum

本次会话最终结果，值：success / fail / skip（点了跳过）
移除speech_skip 参数，已被speech_word_result包含
speech_session_id 生成规则：
客户端在某单词本次进入课程后首次领读开始时生成）；该词所有重试复用；
进入下一词 / 退出后重进课节 → 生成新值；
切后台再回前台续读→ 续用同一 speech_session_id，不新开
