# taxonomy · 功能模块清单

> 边 ingest 边长,从空开始。每 ingest 一篇:新功能 → 新建一级模块;已有模块的子功能 → 归二级;新模块追加到这里。**定模块只能从本表挑**,保证模块名统一。
> 关联(related)只靠「**同一级模块** 或 **共享功能标识符**」(标识符 = snake_case/驼峰,如 `app_unit_reward`;已排除通用词、神策公参 `page_name` 等、通用内容事件 `InteractiveLessonStart` 等);**不设通用类型标签**(库内全是产品需求,"新功能/数据埋点"这类词无区分度)。
